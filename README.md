# 水务环保工程技能库

面向水务与环保工程领域的 AI Agent 技能集合，覆盖**投标编制、环境验收、合规整改、工艺优化、工程结算、诉讼应诉、政策查询**等实务场景。每个技能均为独立可用的工作流包，含方法论、检查清单、模板与配套脚本。

> 所有技能源自工程实践沉淀，已做脱敏处理（企业名称、项目地名、内部标识均替换为通用代称），详见 [DESENSITIZATION.md](DESENSITIZATION.md)。

每个技能目录遵循统一结构：

| 文件/目录 | 作用 |
|:---|:---|
| `SKILL.md` | 技能定义：`name` / `description` / 触发场景 / 执行步骤 / 输出格式 / 边界限制 |
| `references/` | 知识与模板：法规标准、报告结构、检查清单、写作模板、案例库 |
| `scripts/` | 可执行脚本：报告生成、表格构建、计算工具、质量检查 |

## 安装方式

将所需技能目录复制到你的 Agent 技能的目录下即可：

```bash
# 安装单个技能
cp -r skills/qf-bid-expert ~/.codebuddy/skills/

# 安装全部技能
cp -r skills/* ~/.codebuddy/skills/
```

## 设计原则

1. **结论先行，步骤可执行**：每个技能给出明确的执行步骤，而非泛泛建议。
2. **模板化输出**：报告结构、检查清单、写作话术均提供可直接套用的模板。
3. **法规依据可核验**：引用法规标准时标注名称与文号，提示以现行有效版本为准。
4. **边界清晰**：明确说明技能不做的事项，避免越界使用。
5. **脚本辅助**：重复性构建工作（报告生成、表格构建、计算）由脚本承担。
