# 票种识别要点与法规依据（invoice-types-and-basis）

> 用途：**识别前先判票种，票种判错会连带要素口径错**。本文件给出票种特征、易误判点与依据来源。

## 一、票种特征速查

| 票种 | 关键识别特征 | 要素差异 |
|---|---|---|
| 增值税**专用**发票 | 票头含"专用发票"；有税率/征收率 | 必含购方税号、地址、开户行（可抵扣） |
| 增值税**普通**发票 | 票头含"普通发票" | 购方可无税号（个人抬头） |
| **数电票**（全电发票） | **20 位发票号码、无发票代码** | 无纸质介质，版式统一 |
| 增值税电子专票 | 电子介质 + 专票特征 | 可抵扣 |
| 通用机打 / 定额发票 | 无税号勾稽 | 仅金额，税额可缺 |

## 二、易误判点（实战）

1. **数电票无"发票代码"**，只有 20 位号码 → 不能按"缺代码 = 废票"判；
2. 全电票版式高度同质 → 需 **号码位数 + 票头字样** 双证据；
3. 卷式/定额票无购方税号 → 汇总时税号列**留空**，而非报错；
4. 跨年票据税率差异（13%/9%/6%/1%/3%）→ 税额按**票面**，不按现行税率反算。

## 三、校验规则（出件前必跑）

- **金额勾稽**：价税合计 = 金额 + 税额，误差 > 0.01 → 标【待核】；
- **号码位数**：与票种登记的位数不符 → 进人工复核清单；
- **开票日期**：超出合理区间（未来日期、早于票种启用）→ 标【待核】。

## 四、来源与依据

- 《中华人民共和国发票管理办法》（国务院令，现行有效）；
- 《中华人民共和国发票管理办法实施细则》（国家税务总局令，现行有效）；
- 国家税务总局关于增值税发票综合服务平台、数电票推广的相关公告；
- **口径**：票面要素以**票面原文**为准；本文件仅作**识别辅助**，**不作真伪鉴定结论**。
