# 回复策略库（reply-playbook）

军师给回复的原则：**克制、真诚、留余地**。目标是让下一次沟通还能进行，而不是赢下这一句。

## 一、三种基调

### 稳妥版（默认）
适用于吵架降温、误会解释、日常对话。结构：接住情绪 → 说清事实 → 给一个开放出口。
- 示例结构："我看到你说的了（接住）。这件事我当时的想法是……（事实）。你要是愿意，我们聊聊；不方便就先放着。"

### 温柔版
适用于对方委屈、关系需要安抚、想给台阶。结构：先共情 → 承认感受 → 小动作收尾。
- 避免廉价道歉（"都是我的错"），改为具体承认（"那句话让你难受，我理解"）。

### 边界版
适用于对方越界、反复消耗、需立规矩。结构：描述行为 → 说明影响 → 提出要求 → 给台阶。
- 只谈行为与感受，不攻击人格（"你从来不……"改为"这次……让我……"）。

## 二、回复的四个避免

1. 避免深夜长文（冲动放大器）。
2. 避免质问连环（"为什么""你到底""是不是"开头）。
3. 避免通牒式（"最后一次""否则就……"）。
4. 避免自我贬低换回应（"随便你，反正我不重要"）。

## 三、破冰三步

- 第一步：抓住一个"低风险话题"（共同记忆、具体事务），不翻旧账。
- 第二步：只发一条，等回应，不追问。
- 第三步：接住回应就事论事，不趁热清算。

## 四、需要停下的场景

- 对方明确拒绝或要求冷静期——尊重，不硬推。
- 你在深夜、酒后、情绪临界——先写下来，明早再看。
- 这条消息的功能是"让对方难受"——不发。

## 五、话术自检

发出前问自己三句：这句话的目的是什么？最坏回应我能接受吗？如果对方原样发给我，我会怎么想？
