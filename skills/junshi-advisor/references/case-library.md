# 案例库（case-library）

本文件登记军师的实战复盘案例。收录纪律：**只登记真实、经当事人同意、已脱敏的案例；无真实案例时保留模板与占位，不得编造对话与结果。**

## 收录纪律

1. 隐私优先：人名、地点、可识别信息一律脱敏为"朋友 A""对方 B"。
2. 只登记真实发生的对话与后续走向，数据（时间跨度、回应间隔）须真实。
3. 未核实字段用 `【待填：具体说明】` 占位。
4. 反面案例（盲目发消息导致关系恶化）同样登记，标注教训。
5. 涉危机事件的案例不在本库陈列，单独归档并限制访问。

## 案例模板

### 案例【待填：编号】——【待填：标题】

- 阶段：【待填：暧昧期 / 恋爱中 / 冷战 / 分手边缘】
- 事件性质：【待填：误会 / 边界冲突 / 原则问题 / 倦怠】
- 对方消息：【待填：脱敏原文】
- 信号判读：【待填：温度 / 确定性 / 情绪 / 需求】
- 用户当时冲动度：【待填：指数与等级】
- 采用方案：【待填：稳妥/温柔/边界版】
- 后续走向：【待填：真实结果】
- 复盘：【待填：有效做法 / 教训】

## 数据来源指引

- 信号判读：`scripts/msg_decode.py` 输出记录。
- 冲动评估：`scripts/impulse_check.py` 输出记录。
- 后续走向：当事人回访记录。

## 反面清单

- 编造对话与结局充数（禁止）。
- 未脱敏即登记（禁止）。
- 把"发出去后关系变差"包装成"成功案例"（禁止）。
