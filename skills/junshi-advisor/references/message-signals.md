# 消息信号判读库（message-signals）

本文件供 `scripts/msg_decode.py` 与人工判读共用。核心提醒：**信号是概率，不是判决**。同一句话在不同关系阶段含义不同，解读必须结合上下文。

## 一、四个判读维度

1. **温度**：主动联系 / 秒回 / 正常节奏 / 隔很久回 / 只回表情 / 已读不回。
2. **确定性**：明确表态 / 温和回应 / 含糊回避 / 转移话题 / 画饼。
3. **情绪**：正向 / 中性 / 试探 / 委屈 / 抵触 / 临界。
4. **需求**：求安慰 / 求确认 / 求空间 / 划边界 / 客套 / 邀约 / 求和。

## 二、常见句式 → 可能含义（均须标注"待确认"）

| 对方的话 | 可能的含义（不止一种） |
|---|---|
| 嗯 / 哦 / 好的 | 中性收束；也可能不想继续 |
| 随便你 | 交付决定权，或已疲惫 |
| 我累了，改天吧 | 真累；或回避当下话题 |
| 你想多了 | 否认过度解读；也可能回避 |
| 你最近很忙吧 | 试探距离，也可能是委婉表达疏远 |
| 我们做朋友吧 | 明确降级关系 |
| 最近有点忙 | 短期客观；也可能渐进冷处理 |
| 你别对我这么好 | 划界，或不配得感 |
| ……（长时间不回） | 犹豫、回避、或生活客观原因 |

判读纪律：给出 2–3 种可能并排序，附一个"如何低风险验证"的动作（如一次简短、无压力的日常问候），避免直接下结论。

## 三、节奏信号

- **主动发起比例**：长期单方发起，是关系失衡的早期信号。
- **回复间隔趋势**：逐渐拉长且内容变短，警惕热度下滑。
- **话题深度**：只聊事务不聊感受，亲密感停滞。
- **见面意愿**：从"随时"到"再看看"，是回避的渐进信号。

## 四、别把这两件事搞混

- 分不清"忙/累"与"冷淡"：先给一次容错，看后续节奏再判断。
- 分不清"性格内向"与"不在乎"：看对方是否在能力范围内回应你，而非以你的节奏为准。

## 五、输出口径

每条解读按四块输出：字面意思 / 潜台词可能（带概率与待确认）/ 信号温度 / 军师点评。禁止把"可能"写成"一定"。
