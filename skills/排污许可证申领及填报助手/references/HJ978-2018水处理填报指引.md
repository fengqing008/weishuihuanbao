## 二、适用范围与排除衔接

**适用对象**：城镇污水处理厂、其他生活污水处理厂、工业废水集中处理厂，覆盖水污染物、大气污染物与固体废物的排污许可管理。

**排除与衔接**：

| 情形 | 处理方式 |
|---|---|
| 执行 GB 13223 的生产设施与排放口 | 按火电行业技术规范执行 |
| 执行 GB 13271 的生产设施与排放口 | 按锅炉行业技术规范执行 |
| 各行业排污单位内部的污水处理设施和排放口 | 按相应行业技术规范执行，不适用本标准 |
| 专门处理单一行业废水的工业废水集中处理厂，且相应行业规范有明确规定 | 从其规定 |
| 本标准未作规定但排放工业废水废气或国家规定有毒有害污染物的其他生产设施和排放口 | 参照 HJ 942 总则执行 |

## 三、排放口分类与编号

- 排放口类型包括废水排放口与雨水排放口；废水排放口全部为主要排放口。有合规的其他排放口时同时填报。
- 废水排放口编号填报地方生态环境主管部门现有编号；无编号时按 HJ 608 编号。雨水排放口编号可填报内部编号，或采用「YS＋三位流水号数字」（如 YS001）。
- 出水直接排入环境水体的，填报排放口地理坐标、排放去向、排放规律、入河排污口名称及编号、受纳环境水体名称、水体功能目标、汇入受纳环境水体的经纬度坐标；间断排放的填报排放污染物时段。
- 出水间接排入环境水体的，填报排放口地理坐标、排放去向、排放规律、受纳单位名称及执行的污染物排放标准。
- 出水再生利用的，填报受纳单位名称。
- 对应许可量的污染物种类：城镇污水处理厂与其他生活污水处理厂为化学需氧量、氨氮、总磷、总氮；工业废水集中处理厂按所执行标准确定，同样明确上述四项。

## 四、许可排放限值的确定

### 1. 一般原则

- 许可排放限值等于许可排放浓度加许可排放量；许可排放量包括年许可排放量与特殊时段许可排放量。
- 城镇与其他生活污水处理厂出水为再生利用时，仅许可排放浓度，不许可排放量；工业废水集中处理厂出水为再生利用时，浓度与排放量均不许可。
- 废气：主要排放口许可浓度与排放量；一般排放口与厂界无组织不许可排放量，仅许可浓度。
- 污泥：许可排放量，城镇污水处理厂污泥还应明确控制标准。
- 许可浓度按国家或地方标准从严确定；许可排放量按本标准计算方法与总量控制指标从严确定；2015年1月1日（含）以后取得环评审批意见的，还须同时满足环评审批意见要求。

### 2. 出水许可排放浓度确定路径

| 情形 | 依据 |
|---|---|
| 城镇污水处理厂出水（含再生利用） | GB 18918 及其修改单 |
| 其他生活污水处理厂出水 | 参照 GB 18918 及其修改单 |
| 处理单一行业废水的工业废水集中处理厂 | 相应行业水污染物排放标准；无行业标准时依据 GB 8978 |
| 处理混合行业废水、出水直接排入环境水体 | 按加权公式计算；结果低于检出限时按「不得检出」处理 |
| 处理混合行业废水、出水间接排放 | 按间接排放公式计算 |
| 排入城镇污水收集系统的工业废水集中处理厂 | 同时满足 GB/T 31962 |
| 无法用公式确定 | 依据 GB 18918 一级标准：重点流域、封闭半封闭水域或景观用水等执行一级A，其他执行一级B |
| 地方标准更严，或国家与地方管理文件、环评批复有明确要求 | 从严确定 |

### 3. 许可排放量计算公式

```
E(j,许可) = Q × C(j,许可) × 10⁻⁶
```

| 符号 | 含义 | 取值规则 |
|---|---|---|
| E(j,许可) | 第 j 种水污染物年许可排放量，t/a | — |
| Q | 年排水量，m³/a | 近三年实际排水量平均值；运行不满三年自投产之日起算；未投运取设计水量；预期水量变化经说明后按预期排水量申报，不得超过设计水量 |
| C(j,许可) | 许可排放浓度限值，mg/L | 按所执行标准取值 |
| 10⁻⁶ | 换算系数 | m³ × mg/L → t |

废气主要排放口年许可排放量：

```
E(i) = h × Q × C × 10⁻⁹
```

特殊时段日许可排放量：

```
E(日许可) = E(前一年环境统计日均排放量) × (1 − α)
```

污泥年许可排放量：

```
E(许可) = 产生量 − 自行综合利用量 − 自行处置量 − 委托处置利用贮存量 = 0
```

### 4. 废气许可浓度

- 有组织：危险废物焚烧设施依据 GB 18484；一般固体废物焚烧设施参照 GB 18485；除臭装置依据 GB 14554；混合排放且只能监测混合废气时执行最严限值。
- 无组织：城镇与其他生活污水处理厂厂界依据 GB 18918；工业废水集中处理厂厂界依据 GB 16297 与 GB 14554。
- 地方标准更严的从其规定。

### 5. 污泥控制标准

城镇与其他生活污水处理厂污泥稳定化处理后应满足 GB 18918 表5；农用的污染物含量应满足 GB 18918 表6。

## 六、环境管理台账

### 1. 一般原则

- 行业规范要求为基本要求，排污单位可自行增加和加严，生态环境主管部门可依法增加和加严。
- 建立台账记录制度，落实责任部门与责任人，真实记录污染治理设施运行、自行监测和其他环境管理信息，对真实性、完整性和规范性负责。
- 实施简化管理的排污单位，台账内容可适当缩减，至少记录污染防治设施运行管理信息与监测记录信息，频次可适当降低。
- 电子化储存与纸质储存同步管理。

## 七、执行报告（行业口径）

- 报告周期分年度、季度、月度执行报告；重点管理单位提交年度与季度执行报告，简化管理单位提交年度执行报告，地方可要求季度或月度。
- 年度执行报告：持证时间超过三个月的年度，报告周期为当年全年；不足三个月的当年可不提交，纳入下一年度。
- 季度执行报告：持证时间超过一个月的季度，报告周期为当季全季；不足一个月纳入下一季度。
- 编制流程按 HJ 944 执行，分资料收集与分析、编制、质量控制、提交四个阶段。
