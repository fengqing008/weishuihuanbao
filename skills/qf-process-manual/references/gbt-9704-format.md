# GB/T 9704-2012 党政机关公文格式 排版规范

> 制度文件/SOP/规程类文件的Word排版标准。本技能默认采用此规范。

## 一、页面设置

| 项 | 参数 |
|:---|:---|
| 纸张 | A4（210mm × 297mm） |
| 上边距 | 37mm |
| 下边距 | 35mm |
| 左边距 | 28mm |
| 右边距 | 26mm |
| 页码位置 | 居中（页脚） |
| 页码格式 | "— 1 —"（破折号+数字+破折号） |

## 二、字体字号

| 元素 | 中文字体 | 英文字体 | 字号 | 加粗 |
|:---|:---|:---|:---:|:---:|
| 大标题 | 方正小标宋_GB2312 | Times New Roman | 二号（22pt） | ✓ |
| 一级标题 | 黑体 | Times New Roman | 三号（16pt） | ✓ |
| 二级标题 | 楷体_GB2312 | Times New Roman | 三号（16pt） | ✓ |
| 三级标题 | 仿宋_GB2312 | Times New Roman | 小三（15pt） | ✓ |
| 正文 | 仿宋_GB2312 | Times New Roman | 三号（16pt） | ✗ |
| 表格内容 | 仿宋_GB2312 | Times New Roman | 五号（10.5pt） | ✗ |
| 页码 | 仿宋_GB2312 | Times New Roman | 小五（9pt） | ✗ |

## 三、段落格式

| 元素 | 对齐 | 缩进 | 行距 | 段前/段后 |
|:---|:---|:---|:---|:---|
| 大标题 | 居中 | 无 | 固定36pt | 段后12pt |
| 一级标题 | 左对齐 | 无 | 固定32pt | 段前12pt/段后6pt |
| 二级标题 | 左对齐 | 无 | 固定30pt | 段前9pt/段后3pt |
| 正文 | 两端对齐 | 首行缩进2字符 | 固定28pt | 0 |
| 表格内 | 左对齐 | 无 | 固定20pt | 0 |

## 四、表格规范

| 项 | 参数 |
|:---|:---|
| 边框 | 0.5磅黑色实线全边框 |
| 表头 | 浅灰底纹 #D9D9D9 或 #CCCCCC |
| 表头字体 | 黑体 三号 加粗 |
| 表格内容 | 仿宋_GB2312 五号 |
| 单元格对齐 | 数字居中，文字左对齐 |
| 列宽 | 根据内容调整，最小列宽15mm |

## 五、章节编号

### 5.1 12章结构（"一、二、三、..."）

```
第一章  →  一、编制目的与依据
第二章  →  二、适用范围与术语
...
```

### 5.2 节（"（一）（二）..."）

```
（1）一级节  →  （一）
（2）二级节  →  1.
（3）三级节  →  （1）
```

### 5.3 条款编号

```
**第一条** ...（用于制度文件）
或
第X条 ...（用于法律规范）
```

## 六、必备元素

### 6.1 标题区

```
[大标题]
文件编号：XX〔年份〕号
版本：V1.0
编制单位：XXX
落款单位：XXX
成文日期：YYYY年M月D日
施行日期：自发布之日起施行

—————（分隔线）
```

### 6.2 落款区

```
（页尾右下）
落款：发文单位全称
成文日期：YYYY年M月D日
```

### 6.3 不需要包含（按通用偏好）

- ❌ 红头（发文机关文件头+红色横线）
- ❌ "印发"（综合部+印发日期+抄送说明）
- ❌ 发文字号横版

## 七、Word内置样式绑定

**关键**：必须使用Word内置标题样式（Heading 1/2/3），不要用粗体+字号模拟标题。这样：
- 导航窗格自动显示12个一级标题
- 可一键插入自动目录
- 后续可批量修改样式

```python
# python-docx 配置示例
h1 = doc.styles['Heading 1']
h1.font.name = 'Times New Roman'
h1.font.size = Pt(16)  # 三号
h1.font.bold = True
# 设置中文字体
rPr = h1.element.get_or_add_rPr()
rFonts = OxmlElement('w:rFonts')
rFonts.set(qn('w:eastAsia'), '黑体')
rPr.insert(0, rFonts)
```

## 八、特殊格式场景

### 8.1 公式

```
居中显示，使用宋体或Times New Roman
ΔM = Σ[(P当期 - P基准) × Q]
段后6pt，段前6pt
```

### 8.2 表格内嵌套

- 表格内不再嵌入表格
- 单元格内多段用空行分隔
- 复杂数据用Excel单独管理

### 8.3 引用块

```
（无标准"引用块"格式，但可用以下方式模拟）
[内容前用"—— 引自《XXX》"标识]
```
