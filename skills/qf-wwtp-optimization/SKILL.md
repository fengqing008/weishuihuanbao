# Wastewater Optimization — 污水处理工艺优化

> v2.0.0 专家级（2026-09-07）：九要素结构化升级，补触发条件/分步工作流检查点/输出规范/边界反模式/曝气节能实战范例；动力学参数默认值与模块清单保持已验证版本不变。

面向市政与工业污水处理厂的全流程工艺优化技能，基于已验证的活性污泥模型与物理化学模型，提供端到端工艺设计、参数标定、动态模拟与敏感性分析能力。与 activated-sludge-ops 分工——本技能管**模型计算优化**（ASM1/ASM2d/ASM3、SRT/F/M、曝气/二沉池通量），activated-sludge-ops 管**调试运行实操知识**（培菌驯化/SVI/生物相镜检/硝化反硝化运行/AB法/SBR/氧化沟）；数据纪律参考 wastewater-ops-analysis 的 GB 18918-2002 标准。

## 定位声明

服务对象：工艺工程师、节能降耗项目负责人、提标改造方案编制人员。解决：SRT/DO/F/M 怎么调更省、曝气还剩多少节能空间、加药量能不能降、提标改造怎么比选方案。方法为模型驱动：默认参数起步 → 厂区数据标定 → 情景模拟 → 敏感性排序 → 给出控制参数取值。数值计算可联动 activated-sludge-calculator 脚本。

## 分步工作流

**输入 → 处理 → 输出 → 检查点**，五步：

1. **数据收集**（输入）：进水水质（BOD/TN/TP/SS）、处理规模、出水标准（GB 18918-2002 等级）、现有工艺参数（MLSS/SRT/DO/鼓风机电耗）。
   - 检查点：缺出水标准等级或水温时停下确认；明确出水标准对应 SRT 要求。
2. **参数标定**（处理）：用厂区实测数据校准动力学参数（Y/kd/mu_max/Ks），至少复核 Y 与 kd。
   - 检查点：无实测数据时用默认值并声明"方案级估算，需标定后复算"。
3. **工艺计算**（处理）：按需求调用模块（SRT/曝气/营养物/加药）；数值计算可跑 activated-sludge-calculator 脚本。
   - 检查点：设计 SRT ≥ 硝化临界 SRT×1.2；曝气量按温度校正后复核。
4. **方案优化**（处理）：稳态与动态模拟，做敏感性分析（DO 设定值/SRT/加药量三轴）。
   - 检查点：各方案能耗/药耗/达标风险三指标同表对比，不留单方案结论。
5. **输出落点**（输出）：工艺控制参数取值、能耗与药耗优化方案、资本规划方向。
   - 检查点：给出现场可执行的参数（DO 设定值、排泥量、加药泵频率）而非笼统方向。

## 输出规范

## 边界与反模式

**不适用场景**：调试培菌、生物相镜检等实操 → activated-sludge-ops；运营数据统计分析与达标率 → wastewater-ops-analysis；膜系统设计 → membrane-system-design。

**禁止行为**：不用未标定模型直接出正式设计参数；不在低温工况照搬 20℃ 参数；不给"提高效率"类空泛表述（必须落到可调参数值）；不承诺具体节能百分比作为合同指标。

**常见错误**：SOTE 直接当 AOTE 用（漏 alpha/beta 与水深修正）；DO 设定值一刀切（应分季节/分负荷）；加药优化只看药费不看出水 TP 达标风险；二沉池通量分析忽略回流比变化。

## 实战范例

**场景（市政污水厂曝气节能审计）**：用户："2 万吨/天氧化沟厂，吨水电耗 0.38 kWh，曝气占大头，怎么降？"

处理：能耗审计定位鼓风机占比 → AerationAnalysis 复核 SOTE（细泡曝气 ≈6%/m，实际水深 4.5m）→ 对比 DO 设定值 2.5→1.8 mg/L 与分季控制两个情景 → 敏感性排序。

输出示意：

1. 结论：DO 精调+分季设定预计吨水电耗降 8%~12%【待核：需以 3 个月实测数据验证】。
2. 推荐参数：好氧末端 DO 1.8 mg/L（冬季 2.0）、MLSS 3800 mg/L、SRT 维持 18d（保冬季硝化，联动 activated-sludge-calculator 校核临界 SRT）。
3. 比选表：DO 精调（投资≈0、周期 1 个月）vs 更换微孔曝气器（投资中、周期 6 个月）。
4. 验证计划：逐周记录吨水电耗与出水 NH3-N，连续 4 周达标且电耗下降方可固化参数。

## 常用诊断计算命令（2026-09-18 增补）

下列计算用于现场快速诊断，可在沙箱内以 Python 一行命令执行，参数按实际取值替换。

```bash
# 污泥龄 SRT（d）= 曝气池有效容积 V(m³) × MLSS(kg/m³) ÷ 剩余污泥排放量(kg/d)
python3 -c "V=5000; MLSS=3.5; WAS=1200; print('SRT=%.1f d'%(V*MLSS/WAS))"

# 污泥负荷 F/M（kgBOD/kgMLSS·d）= 进水量 × 进水BOD ÷（V × MLSS）
python3 -c "Q=10000; Si=180; Se=10; V=5000; MLSS=3.5; print('F/M=%.3f'%(Q*(Si-Se)/1000/(V*MLSS)))"

# 容积负荷 Nv（kgBOD/(m³·d)）
python3 -c "Q=10000; Si=180; V=5000; print('Nv=%.2f'%(Q*Si/1000/V))"

# 需氧量粗估 AOR（kgO2/d）≈ 1.47×去除BOD + 4.57×硝化氨氮 - 2.86×反硝化硝态氮
python3 -c "dBOD=1700; NOx=250; NO3=150; print('AOR=%.0f kgO2/d'%(1.47*dBOD+4.57*NOx-2.86*NO3))"
```

公式与参数速查见 `references/diagnostic-formulas.md`。

## 诊断失败模式（2026-09-18 增补）

一是把设计参数当运行参数。模型默认动力学参数（产率系数、衰减系数）取自典型值，直接用于核算实际厂会产生偏差，须以现场实测 MLSS 与出水水质反算校核。

二是SRT与排泥量脱节。计算SRT未计入污泥浓度波动与排泥含水率，导致泥龄核算偏大，须以干污泥量而非湿泥量计算。

三是硝化与反硝化碳源混算。反硝化碳源不足时单纯加大曝气无效，须先核算碳氮比。

四是曝气量按经验值放大。未做氧转移效率修正，造成能耗虚高。

## 失败模式

1. **关键输入缺失** → 缺出水标准等级或水温，SRT 与需氧量算不出 → 回退到 Phase 0，集中列出缺项索要，未补齐不出数据。
2. **无实测数据标定** → 厂区无 MLSS／DO／电耗记录，动力学参数无依据 → 降级用默认参数（Y=0.6、kd=0.06）出方案级估算，正文声明须标定后复算。
3. **SOTE 当 AOTE 直接用** → 曝气量偏低、鼓风机选型不足 → 按 alpha／beta 与水深修正重算，修正系数缺失时标【待核：alpha／beta 实测值】。
4. **低温工况照搬 20℃ 参数** → 硝化临界 SRT 低估，冬季氨氮超标 → 按温度修正系数（硝化 1.07）重算，设计 SRT ≥ 临界 SRT×1.2 复核后方可交付。
5. **参数越出合理区间** → MLSS 超 8000 mg/L、SRT 超 30 d 等异常组合 → 跑 `python3 scripts/aeration_energy_check.py --self-test` 或带入实测值做区间校验，异常项回退核对输入后重算。
6. **二沉池通量分析忽略回流比** → 固体负荷低估，出水 SS 风险 → 补入回流比变量重算固体通量；边界条件变化时重跑。
7. **加药优化只看药费** → 出水 TP 达标风险被忽略 → 补出 TP 达标校核与药剂单耗对照，风险写入比选表「达标风险」列。
8. **情景模拟不收敛** → 动态模拟迭代发散、无稳态解 → 兜底输出稳态手算结果与参数区间，注明动态解未收敛。
9. **脚本依赖缺失** → numpy／scipy 不可用或 activated-sludge-calculator 调用失败 → 重试一次；仍失败则降级按默认参数与标准公式手算，附计算过程。
10. **未标定模型出正式设计参数** → 模型值被当作施工图设计值 → 拦截并改标为方案级估算，注明须经设计责任主体复核。
11. **BioWin／GPS-X 配置与软件版本不符** → 导入报错或结果不可复现 → 回退输出参数清单与场景说明，由用户在软件内建场景。
12. **异常数值进表** → 进水 BOD 或 TN 填成文字、单位缺位 → 脚本输入校验拦下异常行，错误处理动作＝回补后重算。

## 使用示例

**示例1：曝气节能空间测算**
> 输入：某市政污水厂 5 万吨／日，进水 BOD 180 mg/L，出水要求一级A，鼓风机实测电耗 0.32 kWh/m³，MLSS 4000 mg/L，DO 2.0 mg/L。
> 处理：数据收集（补水温与曝气器型式：细泡）→ 默认参数起步（Y=0.6、kd=0.06）→ 需氧量与 SOTE 换算 → DO 设定值 2.0→1.5 情景对比。
> 输出：五段方案书＋比选表（方案名／改造内容／节能节药量／投资估算／达标风险／实施周期）；无实测 alpha／beta 时标【待核】。

**示例2：提标改造方案比选**
> 输入：某工业污水厂一级B→一级A，现工艺 AO，进水 TN 45 mg/L，水温 12℃。
> 处理：硝化临界 SRT 计算（按 12℃ 修正）→ 反硝化碳源需求测算 → 三方案（延长 SRT／投加碳源／增设后置缺氧）对比。
> 输出：比选表＋推荐参数（DO 设定值、排泥量、碳源投加泵频率）＋实施与验证计划。

## 🔴 关键检查点

1. 🔴 数据标定确认：模型标定所用厂区实测数据须经使用方确认，确认后方可进入情景模拟。
2. 🔴 参数边界：SRT/DO/F/M 调整幅度超出安全区间时停止计算，与使用方确认现场条件后再试。
3. 🔴 工况条件：低温或冲击负荷工况下参数须重新标定，人工确认后方可外推结论。
4. 🔴 结论定稿：设计参数输出前暂停，交工艺负责人确认后再作为方案依据。
5. 🔴 节能承诺：节能比例未经使用方确认，不得写入合同或对外承诺指标。
