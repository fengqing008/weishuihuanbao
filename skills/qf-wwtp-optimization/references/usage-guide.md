# 使用指南（wastewater-optimization v2.1.0）

本文件是污水工艺优化技能的作业手册，配合 SKILL.md 的五步工作流使用。

## 1 响应级别

| 级别 | 触发情形 | 交付深度 |
|---|---|---|
| L1 | 问参数默认值、SOTE 换算口径、温度修正系数 | 直答并注明口径 |
| L2 | 单一模块测算（只算曝气量或只算 SRT） | 测算表＋计算依据 |
| L3 | DO / SRT / 加药三轴敏感性 | 分步工作流＋质量门＋三情景对比表 |
| L4 | 完整优化方案书 | 数据收集→标定→计算→比选→落地全流程 |

## 2 输入要件

1. 进水水质与水量：BOD、COD、TN、TP、SS、日均流量。
2. 出水标准：GB 18918-2002 等级（一级A / 一级B / 二级）。
3. 工艺类型：AO / AAO / 氧化沟 / MBR / 其他。
4. 现有运行参数：MLSS、SRT、DO、回流比、鼓风机电耗、加药量。
5. 场地条件：水温（分季节）、海拔、曝气器型式与水深、电价。

缺出水标准等级或水温时停下确认；其余缺项集中列出并标【待核：参数名】。

## 3 五步作业序列

1. **数据收集**：按上表逐项归集，形成输入清单。
2. **参数标定**：用厂区实测数据校准产率系数 Y、衰减系数 kd、最大比增长速率 mu_max、半饱和常数 Ks；至少复核 Y 与 kd 两项。
3. **工艺计算**：按需调用 SRT、曝气、营养物去除、加药四类模块。
4. **方案优化**：稳态与动态模拟，做 DO 设定值 / SRT / 加药量三轴敏感性。
5. **输出落点**：给出可执行参数（DO 设定值、排泥量、加药泵频率）与实施验证计划。

## 4 参数默认值与合理区间

| 参数 | 默认值 | 合理区间 | 越界处置 |
|---|---|---|---|
| Y | 0.6 g VSS/g BOD | 0.4~0.8 | 回退核对进水水质后重标定 |
| kd | 0.06 1/d | 0.03~0.10 | 同上 |
| MLSS | 4000 mg/L | 2000~6000 | 核对回流比与二沉池负荷 |
| SRT | 15 d | 4~30（需 ≥ 临界 SRT×1.2） | 重算硝化临界值后调整 |
| DO | 2.0 mg/L | 0.3~4.0 | 分季节分负荷重设 |
| alpha | 0.6 | 0.3~0.95 | 无实测值时标【待核：alpha 实测值】 |
| beta | 0.95 | 0.7~1.0 | 同上 |
| 细泡 SOTE | 6 %/m 水深 | 4~8 | 核对曝气器型式与厂家数据 |

## 5 校验脚本用法

```bash
# 带入实测值：需氧量、SOTE 换算、空气量、鼓风功率、区间校验
python3 scripts/aeration_energy_check.py --flow 50000 --bod 180 --tn 45 --t 12 \
    --aote 6 --depth 5 --alpha 0.6 --beta 0.95 --do 2.0 --mlss 4000 --srt 15

# 内置样本自检
python3 scripts/aeration_energy_check.py --self-test
```

脚本输出的关键量：临界 SRT、碳氧化需氧、内源呼吸需氧、硝化需氧、反硝化回收、AOR、AOTE、所需空气量、鼓风功率估算、设计 SRT 与临界 SRT 之比。退出码 0 表示区间校验通过，1 表示存在越界项。

## 6 输出规范

优化方案书固定五段：现状与数据 → 标定结果 → 方案比选表 → 推荐参数与预期收益 → 实施与验证计划。

比选表固定六列：

```
| 方案名 | 改造内容 | 节能／节药量 | 投资估算 | 达标风险 | 实施周期 |
```

关键假设标【待核】；用电价与 SOTE 换算口径写明；节能比例不得写为合同承诺指标。

## 7 交付自检（五项）

1. 数据溯源：进出水数据、能耗数据、加药数据均挂来源。
2. 结果可复算：需氧量、空气量、功率可由参数复算。
3. 参数区间：MLSS、SRT、DO、F/M、alpha、beta 均在合理区间。
4. 标定声明：无实测数据时明确标注方案级估算。
5. 参数可执行：给出 DO 设定值、排泥量、加药泵频率等现场可调值。

## 8 与相邻技能的数据交接

移交 `activated-sludge-calculator` 时给出：进水水质、工艺类型、目标出水、拟用动力学参数。

移交 `wastewater-ops-analysis` 时给出：优化前后的能耗与药耗口径，便于达标率与单耗统计。

移交 `membrane-system-design` 时给出：MBR 工况下的 MLSS 与膜通量边界值。
