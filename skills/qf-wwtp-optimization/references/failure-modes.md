# 失败模式与降级路径

| 场景 | 判据 | 处置 |
|---|---|---|
| 缺运行数据 | 无电耗、药耗台账 | 标【待核：缺 XX】，给出需补台账清单与采集周期建议 |
| 出水指标不明 | 未说明执行标准 | 先确认执行标准等级，再给优化方向 |
| 多目标冲突 | 同时要求降电耗与提脱氮 | 列出取舍关系，按出水达标优先排序 |
| 建议超出工艺能力 | 现有池容无法满足 | 明确说明需改造，不给出仅靠运行调整即可达标的结论 |
| 要求保证达标 | 索要达标承诺 | 说明受进水与设备条件约束，须以实际运行验证 |
| 数据自相矛盾 | 电耗与水量明显不匹配 | 先核对计量口径，暂停优化建议 |

> 原则：优化建议必须可执行、可验证，附验证指标与观察周期。
