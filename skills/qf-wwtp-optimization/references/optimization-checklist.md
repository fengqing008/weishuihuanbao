# 工艺优化检查清单

## 一、能耗侧

1. 鼓风机是否按溶解氧实时调节风量，是否存在恒定风量运行
2. 曝气器是否堵塞或破损，曝气是否均匀
3. 提升泵与回流泵是否在高效区运行，有无频繁启停
4. 污泥脱水机是否在最佳絮凝剂投加量下运行

## 二、药耗侧

1. 除磷药剂投加点是否合理，投加量是否随出水总磷动态调整
2. 絮凝剂配制浓度与投加比例是否经过小试优化
3. 消毒剂投加是否按出水余量控制，有无过量投加

## 三、工艺侧

1. 泥龄是否满足硝化要求，低温季节是否留有余量
2. 好氧区溶解氧分布是否合理，有无前段缺氧后段过曝
3. 内回流比与外回流比是否匹配缺氧区反硝化能力
4. 碳源投加是否必要，进水碳氮比是否已被充分利用

## 四、数据侧

1. 在线仪表是否校准，数据与化验值是否一致
2. 是否有连续的水电药耗台账，能否支撑单耗对比
3. 是否存在长期未处理的设备缺陷

> 使用方式：逐项核查并标记符合、不符合、不适用，不符合项进入整改清单。
