# 备案流程与应急演练要点

## 一、备案流程

按《企业事业单位突发环境事件应急预案备案管理办法（试行）》办理：

1. 预案编制完成后组织评审，形成评审意见。
2. 由单位主要负责人签署发布。
3. 向所在地生态环境主管部门备案，提交预案及备案材料。
4. 备案材料一般含：备案申报表、预案文本、环境风险评估报告、应急资源调查报告、评审意见。
5. 取得备案编号，妥善保存备案材料。

## 二、备案材料清单

| 材料 | 说明 |
|---|---|
| 突发环境事件应急预案 | 正式文本 |
| 环境风险评估报告 | 风险源与分级 |
| 应急资源调查报告 | 现有应急资源 |
| 预案评审意见 | 专家评审结论 |
| 备案申报表 | 按主管部门格式 |

## 三、备案后管理

一是预案修订后重新备案。二是重大变动（工艺、药剂、组织）时及时修订。三是备案信息变更时更新。四是接受主管部门检查时提供备案材料。

## 四、应急演练要点

演练类型：桌面推演与实战演练。频次：每年至少一次，重点风险源可增加。内容：药剂泄漏、污水超标、有限空间事故等场景。

演练流程：

1. 编制演练方案，明确场景、参演人员、目标。
2. 组织演练，记录处置过程与时间节点。
3. 评估演练，找出预案与执行差距。
4. 修订预案，落实改进措施。

## 五、演练记录要素

演练时间、地点、场景、参演单位与人员、处置过程、发现问题、改进措施、评估结论。

## 六、常见问题

预案照抄他厂导致与实际不符；备案材料不全被退回；演练走过场无评估；修订不及时导致预案失效。

## 七、检查应对

接到主管部门检查通知，准备预案文本、备案材料、演练记录、风险源清单与分布图、外部救援联系方式，核对信息与现状一致。
