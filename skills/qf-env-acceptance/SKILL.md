# 污水厂竣工环保验收编制

污水处理厂建设项目竣工环境保护验收的编制与全流程管理专家件。服务对象为建设单位（项目公司/运营公司）及其委托的环保技术服务机构，产出物是可直接报送、可公示、可归档的验收工作清单、验收监测方案、验收监测报告、验收意见与信息公开材料。

## 一、专家定位

污水处理厂竣工环保验收，本质是把"环评批复承诺"与"现场实际建成与运行"做逐条对账，并用有资质机构的监测数据证明生态影响可控。编制定稿的判断标准只有一条——报告拿出去能公示、能归档、能经得起生态环境部门抽查复核。

三条底层判断：

1. 验收依据是环评报告书（表）及审批决定当时的标准与要求，不是最新标准。环评批复之后发布的新标准，只在批复或新规明确要求执行时适用。
2. 建设单位是验收第一责任主体，对结论与公开信息的真实性负责。委托第三方编制不转移责任，报告结论仍由建设单位承担。
3. 是否合格的判定不看感觉，看《建设项目竣工环境保护验收暂行办法》第八条的九条不合格情形，逐条对照，命中一条即不得出具合格意见。

## 三、五维阶段评估

接触项目先做五项判定，缺项直接列为待办而不是跳过：

1. **手续维度**：环评报告书（表）与批复是否齐备、排污许可证是否取得、是否有重大变动未重新报批。
2. **建成维度**：环保设施是否与主体工程同步建成、是否具备调试条件（无证、未同步建成的不得调试）。
3. **数据维度**：监测数据是否有CMA资质、工况是否稳定、监测因子与频次是否覆盖批复要求。
4. **风险维度**：卫生防护距离内敏感点是否解决、地下水与土壤防渗是否落实、应急预案是否备案并演练。
5. **时限维度**：环保设施竣工之日起算，一般不超过 3 个月；需调试或整改的最长不超过 12 个月，截止日为向社会公开验收报告之日。

## 四、四级响应

- **L1 单点速答**：问标准编号、问某类监测因子频次。直接给结论加来源，不展开流程。
- **L2 单件编制**：编制工作清单、方案或报告某一章。按模板产出，附对应 references。
- **L3 全流程编制**：从自查到报告定稿。按 §六 八步推进，每步设确认点。
- **L4 风险处置**：已存在不合格情形或验收受阻。先定位命中的不合格条款，再给整改路径与补救材料。

## 六、验收全流程八步

1. **项目竣工与前期准备**。主体与环保设施全部竣工后，公开环保设施竣工日期并告知属地生态环境部门；对照 §十一 开展内部自查，梳理基础资料。
2. **环保设施调试与动态监测**。调试前公开调试起止日期；调试期污染物须达标排放，留存调试台账与监测数据；工况稳定、设施正常运行方可进入验收监测。
3. **委托与实施验收监测**。委托具备CMA资质的检测机构，按 §八 确定因子、点位、频次，如实记录生产负荷。
4. **逐项排查不合格情形**。对照九条不合格情形全面复核，命中条款先整改再进入下一环节。
5. **编制验收监测报告**。按 §九 十一章结构编制，结论明确、数据可溯源、附件齐备。
6. **组建验收工作组并召开验收会议**。成员含设计、施工、环评、监测及行业专家；现场核查、听取汇报、质询讨论，形成验收意见并由验收组成员签字确认。
7. **验收报告公示**。编制完成后 5 个工作日内公开验收监测报告、验收意见、其他需要说明的事项三项文件，公示期不少于 20 个工作日。
8. **平台填报与资料归档**。公示期满后 5 个工作日内登录全国建设项目竣工环境保护验收信息平台填报；全套资料按"一项目一档"长期存档。

🔴 检查点1：设施未与主体工程同步建成、或应取得排污许可证而未取得，不得开展调试，此处是最高频的一票否决点。
🔴 检查点2：验收期限起算日是环保设施竣工之日，超期即构成未验先投风险，编制启动时先算清剩余天数。
🔴 检查点3：验收监测必须在工况稳定、设施正常运行下进行，报告中必须如实记录实际负荷，负荷不合规数据整份失效。
🔴 检查点4：公示渠道不得使用需注册或付费才能获取信息的网站，否则公示程序无效。

## 七、验收资料四类清单

按"一项目一档"分类归档，四类材料缺一即归档不完整：

- **基础资料**：立项、用地、规划、施工文件；环评报告书（表）及批复；排污许可证；环保设施设计文件、施工记录、设备采购合同与运维台账。
- **验收报告**：验收监测报告；验收意见；其他需要说明的事项。
- **过程资料**：验收工作组组建文件与签到表；现场核查记录与影像；验收会议纪要、专家意见与答复；整改方案与整改前后对比；监测原始数据与工况记录。
- **公示与报备资料**：竣工日期公示、调试起止日期公示截图；验收报告公示页面与公众意见处置记录；全国信息平台填报截图与凭证。

逐项核对表与核查要点见 `references/acceptance-checklist.md`，可用 `scripts/acceptance_checklist.py` 一键生成工作清单。

## 八、验收监测方案与实施

监测方案推荐包含：项目概况、验收依据、建设情况、环保设施、验收执行标准、验收监测内容、现场注意事项、其他环保设施核查内容、质控方案。

污水厂典型监测配置（以批复要求为准）：

| 类别 | 点位 | 因子 | 频次 |
|---|---|---|---|
| 废水 | 进口、总排口 | pH、COD、BOD₅、SS、氨氮、总氮、总磷、动植物油、石油类、粪大肠菌群及批复特征因子 | ≥2天，每天4次 |
| 有组织废气 | 除臭设施排放口 | 氨、硫化氢、臭气浓度 | ≥2天，每天3次 |
| 无组织废气 | 厂界上下风向、厂区浓度最高点 | 氨、硫化氢、臭气浓度、甲烷 | ≥2天，每天3次 |
| 厂界噪声 | 厂界四周1m | 等效连续A声级 | ≥2天，昼夜各1次 |
| 地下水 | 上游、厂区内、下游监测井 | GB/T 14848-2017 常规指标 | ≥2天，每天2次 |
| 环境空气/敏感点 | 最近居民点 | 氨、硫化氢 | ≥2天 |
| 地表水 | 排口上下游 | GB 3838-2002 指标 | ≥2天 |
| 土壤 | 厂区及周边农用地 | GB 36600-2018 或 GB 15618-2018 指标 | 取样1次 |

负荷与工况、监测方法、质控要求详见 `references/monitoring-spec.md`。

## 九、验收监测报告编制

报告十一章骨架：①建设项目概况 ②验收依据 ③项目建设情况 ④环境保护设施 ⑤环评报告书（表）主要结论与审批决定 ⑥验收执行标准 ⑦验收监测内容 ⑧质量保证和质量控制 ⑨验收监测结果 ⑩验收监测结论 ⑪建设项目环境保护"三同时"竣工验收登记表。

第③章必须包含环评阶段与实际建设的对比表与变动情况判定；第④章必须写明环保设施投资金额与占总投资比例；第⑩章结论按"设施调试运行效果"与"工程建设对环境的影响"两分块，采用"检测结果 → 执行标准 → 达标表述"固定句式。

每章要点、结论范式、附件与附图清单见 `references/report-structure.md`；生成空白框架用 `scripts/report_builder.py`。

## 十、验收意见与其他需要说明的事项

验收意见六要素：工程建设基本情况、工程变动情况、环境保护设施落实情况、环境保护设施调试效果、工程建设对环境的影响、验收结论和后续管理要求。结论须明确"是否验收合格"，验收组成员逐人签字。

"其他需要说明的事项"用于承载不属于报告与意见主体、但影响责任判定的内容：分期验收安排、依托其他治理设施的权责划分、敏感点搬迁承诺与时限、遗留问题的整改承诺。

文书模板（验收意见、公示稿、报送函、承诺函）见 `references/writing-templates.md`。

## 十一、验收不合格九条与重大变动六条

九条不合格情形：未按批复建成或不能同时投产使用；排放不符合标准、批复或总量指标；性质规模地点工艺或防治措施重大变动未重新报批；造成重大污染未治理或生态破坏未恢复；纳入许可管理却无证或不按证排污；分期验收环保设施能力不匹配；因本项目违法被责令改正尚未完成；报告数据明显不实、重大缺项或结论不明确；其他规定不得通过的情形。

水处理项目重大变动六条（适用于工业废水集中处理厂及日处理规模≥500吨的城乡污水厂）：处理能力增加30%及以上；重新选址或调整导致防护距离内新增敏感点；处理工艺变化或进水水质水量变化导致污染物项目或排放量增加；新增废水排放口、间接改直排或直排口位置变化加重影响；废气设施变化导致排放量增加或排气筒高度降低10%及以上；污泥产生量增加且处置能力不足、处置方式变化加重影响。

逐条比对可用 `scripts/compliance_checker.py`，输出命中项与整改方向。判定明细见 `references/regulations-and-standards.md`。

判定输入文件的格式（`answers.json`，键 f1~f9 对应九条不合格情形，c1~c6 对应重大变动六条，true 表示存在该情形）：

```json
{"f1": false, "f2": false, "f3": true, "c1": false, "c4": false, "c6": false}
```

九条中任一条为 true 即不得出具合格意见；重大变动条为 true 的，须核对是否已重新报批环评文件。

## 十二、信息公开与平台填报

- 竣工后公开**竣工日期**，调试前公开**调试起止日期**，同时报送县级以上生态环境部门。
- 报告编制完成后 **5 个工作日**内公示三项文件，公示期**不少于20个工作日**。
- 公示期满后 **5 个工作日**内登录**全国建设项目竣工环境保护验收信息平台**（https://cepc.lem.org.cn）填报，对信息真实性负责。
- 附录部分：环境风险应急预案须在生态环境部门备案并留存演练记录，此项常被漏检。

步骤与平台填报字段清单见 `references/procedure-and-filing.md`。

## 十四、失败模式

1. **验收依据错用新标准**。以现行最新标准评价历史批复项目，导致标准限值对不上、结论被推翻。正确做法是以环评批复当时的标准为基准，新规有明确时限要求时才适用。
2. **重大变动定性靠感觉**。仅凭主观判断"不算重大变动"就出报告，未逐条比对水处理六条清单。导致报告结论不成立、验收被否。
3. **监测工况失真**。为凑数据在低负荷或不稳定工况下采样，报告中未如实记录负荷。此类报告抽查时整份失效。
4. **卫生防护距离内敏感点未解决却不披露**。防护距离内居民未搬迁，报告回避该问题。命中"重大变动未重新报批"或"重大缺项"条款。
5. **附件缺项**。缺排污许可证、危废处置协议与转移联单、应急预案备案证明、在线监测验收报告等关键附件。归档不完整即视为验收程序未走完。
6. **公示渠道不合规**。使用需注册或付费的网站公示，或公示期不足20个工作日。程序性瑕疵同样导致验收不被认可。
7. **污泥危废属性未定**。污泥未开展危废鉴定即按一般固废处置，处置去向与资质链断裂。
8. **期限管理失控**。环保设施竣工后超期未公开验收报告，构成未验先投，须承担条例规定的行政处罚风险。
9. **时限临界点的降级处置缺失**。剩余期限不足以完成公示与填报时，未及时启动延期申请或补救路径，直接造成超期与程序瑕疵。
10. **边界条件未留痕**。分期验收、依托其他治理设施、防护距离内敏感点等边界条件未在报告中明示，导致责任边界与整改承诺不清，后续纠纷时缺少处置依据。

## 十五、反例清单

严禁输出以下内容：

- 不写"一般情况下""视项目具体情况而定"这类无操作性的表述替代具体判定。
- 不引用未核实的标准限值与条款，标准编号、限值必须逐一核对来源。
- 不把验收结论写成"基本符合""原则上合格"，结论必须二选一明确。
- 不省略附件清单，不能用"详见附件"替代对附件齐备性的实质核查。
- 不将建设单位责任表述为第三方检测机构责任，编制委托不转移主体责任。
- 不生成红头与印发页，对外公文仅保留正文与落款。

## 十六、质量门禁

交付前逐项核对，任一不达标即返工：

🔴 门禁1：九条不合格情形逐条判定完成，无遗漏项，命中项已给出整改方向。
🔴 门禁2：监测因子与频次覆盖环评批复全部要求，含特征污染物。
🔴 门禁3：报告十一章齐备，第③章含建设内容对比与变动判定，第④章含环保投资与占比。
🔴 门禁4：四类归档资料清单完整，失项已标注【待核】并给出补齐路径。
🔴 门禁5：时效节点明确到日——竣工日、调试起止日、公示起止日、平台填报截止日。
🔴 门禁6：标准编号与法规名称经独立核验，机构名称与文号无漏字错字。

## 十七、工作流示例

**示例一：新建污水厂（5000m³/d）首次验收，从零到报告定稿**

输入：环评报告书及批复、设计文件、运行台账、排污许可证。
执行：①五维评估定位进度与时限；②生成六阶段工作清单，识别未完成项（如污泥危废鉴定、地下水检测、应急预案备案）；③编制验收监测方案，明确因子点位频次；④委托CMA机构监测，核对工况记录；⑤用 report_builder.py 出报告框架，逐章填充；⑥compliance_checker.py 判定九条情形；⑦组建验收组、召开会议、出具意见；⑧公示20个工作日后平台填报、归档。
产出：验收工作清单、验收监测方案、验收监测报告、验收意见、其他需要说明的事项、公示材料。

**示例二：验收推进受阻，定位堵点并给出补救路径**

输入："报告快做完了，但防护距离内有居民没搬，能不能先报？"
执行：①判定该情形是否构成重大变动（调整导致防护距离内新增敏感点属重大变动）；②若属重大变动未报批，则构成第九条不合格情形第(三)项，不得出具合格意见；③给出两条路径——完成搬迁并提供搬迁证明，或按重大变动重新报批环评；④在"其他需要说明的事项"中如实披露并附承诺函与时限。
产出：合规判定结论、整改路径、需补充的证明材料清单。

## 降级路径速查

| 情形 | 识别信号 | 降级路径 |
|---|---|---|
| 验收条件不符 | 9条不合格情形命中 | 中止并列出整改清单 |
| 重大变动误判 | 工艺/规模变动未识别 | 回退重大变动清单核对 |
| 监测频次不足 | 点位/频次不达标 | 补足并重排监测方案 |
| 信息公开缺项 | 未按要求公开 | 提示补公开并留痕 |
| 报告中断 | 验收报告截断 | 断点续跑 |
| 数据未溯源 | 监测数据无来源 | 标注【待核】 |

遇未覆盖情形按失败分支回退，必要时重试；异常与错误处理以兜底方案优先，涉边界条件给出容错处理，长任务支持断点续跑与补救，无法自动处置时降级为人工复核。
