# 法规标准矩阵

## 一、技术标准体系（四层结构）

生态环境损害鉴定评估技术标准体系按"总纲—环境要素—基础方法—生态系统"四层组织，选择方法时按"国家标准→行业标准与技术规范→专业领域多数专家认可的方法"三级递进采用。

| 层级 | 标准编号 | 名称 | 作用 |
|---|---|---|---|
| 总纲 | GB/T 39791.1—2020 | 生态环境损害鉴定评估技术指南 总纲和关键环节 第1部分：总纲 | 程序、基线、损害确认、报告书编制要求（附录A） |
| 总纲 | GB/T 39791.2—2020 | 第2部分：损害调查 | 初步调查与系统调查、调查方案六要素、三级质控 |
| 环境要素 | GB/T 39792.1—2020 | 环境要素 第1部分：土壤和地下水 | 土壤与地下水损害鉴定评估 |
| 环境要素 | GB/T 39792.2—2020 | 环境要素 第2部分：地表水和沉积物 | 地表水与沉积物损害鉴定评估 |
| 基础方法 | GB/T 39793.1—2020 | 基础方法 第1部分：大气污染虚拟治理成本法 | 大气损害数额计算 |
| 基础方法 | GB/T 39793.2—2020 | 基础方法 第2部分：水污染虚拟治理成本法 | 地表水损害数额计算（本技能核心量化依据） |
| 生态系统 | GB/T 43871.1 | 生态系统 第1部分：农田生态系统 | 农田生态系统损害鉴定评估 |

## 五、地方依据（按案件所在地叠加）

按案件所在省级行政区叠加实施方案与调查管理办法。湖北省示例：《湖北省生态环境损害赔偿制度改革实施方案》（鄂办发〔2018〕40号）、《湖北省生态环境损害赔偿调查管理办法（试行）》（鄂生改组办〔2022〕5号）。地方标准示例：《湖北省生态环境损害鉴定通用规范》DB42/T 1905—2022。引用前须核对现行有效性，名称与文号以原文为准。

## 六、引用纪律

1. 法规、规章、机构名称独立核验，不得照抄二手转写；引用规范写"部门规范全称+《规章全称》"。
2. 标准引用标注完整编号与年份（GB/T 39791.1—2020），不写简称替代。
3. 地方标准不得冒充国家标准；已废止标准不得引用。
4. 文号不确定的，写法规全称加印发年份，文号处标【待核】，核验后回填。
