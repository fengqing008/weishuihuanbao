## 二、登记案例（某市某水务集团水污染案）

| 字段 | 内容 |
|---|---|
| 案件名称 | 某水务集团涉嫌超标排放水污染物案生态环境损害鉴定评估 |
| 鉴定评估机构 | 湖北天欧检测有限公司生态环境损害司法鉴定所 |
| 委托方 | 某州生态环境局某市分局、某水务集团（联合委托） |
| 报告编号 | 天欧环损鉴〔2023〕委字第10号 |
| 损害类型 | 地表水（超标排放废水） |
| 量化方法 | 水污染虚拟治理成本法 |
| 关键取值 | E=142,420 t；C=0.634 元/t；α=1；κ=3.27→τ=1.25；ω=1.5；γ=1.875 |
| 损害数额 | ≈169,302 元（16.93 万元） |
| 结论要点 | ①超标排放 14.242 万吨，环境污染事实明确；②未发现明显损害或已自然恢复；③损害量化 16.93 万元；④承担侵权赔偿义务，建议增殖放流、河道清理等替代性修复 |
| 数据来源 | 案件卷宗、某州地表水环境质量报告、三家污水厂治理成本调查表、现场踏勘表、人员访谈记录 |

**要点复盘**：本案是"排放行为事实明确、损害事实不明确"适用虚拟治理成本法的典型。基线采用标准基准法（历史数据缺失）；受纳水体为山间池塘无特定功能，危害系数取 1；氨氮最大超标倍数 3.27 落在 0<κ≤10 档，超标系数取 1.25；功能区以外环境功能系数取 1.5。每项取值均有处可查。

## 三、教材式方法示例（例示逻辑，不指向真实案件）

> 以下两例用于说明量化方法与判定路径，**不指向任何真实企业、自然人或裁判文书**；凡出现数字均为便于说明计算过程的假设值，交付时须以真实卷宗数据替换。

### 案例三 地表水超标排放·虚拟治理成本法（典型适用）

| 字段 | 内容 |
|---|---|
| 场景 | 某污水处理设施排放口废水氨氮长期超标排入无特定功能地表水体 |
| 损害类型 | 地表水（排放行为事实明确、损害事实不明确） |
| 量化方法 | 水污染虚拟治理成本法 D = E × C × γ |
| 假设取值 | E=100,000 t；C=0.80 元/t（3 家同类企业调查均值）；α=1；κ=(Z−B)/B=25→τ=1.5；ω=1.75 |
| 算式 | γ=1×1.5×1.75=2.625；D=100,000×0.80×2.625=210,000 元 |
| 结论要点 | ①排放事实明确；②基线缺乏历史数据，采用标准基准法；③损害数额 21.0 万元；④建议替代性修复 |
| 数据来源 | 排放口在线/手工监测报告、成本调查表、现场踏勘记录（假示例） |

**要点复盘**：κ 落在 10<κ≤100 档取 1.5；一般工业/景观用水功能取 ω=1.75。取值须逐项回溯到附件单据，不得凭经验拍数。

### 案例四 治理费用已明确·不用虚拟治理成本法（方法误用纠正）

| 字段 | 内容 |
|---|---|
| 场景 | 突发环境事件后，应急处置与治理费用已由单据确定 |
| 损害类型 | 地表水（治理费用可确定） |
| 处理方法 | **不适用**虚拟治理成本法，改用恢复费用法/实际费用核算法 |
| 关键取值 | 恢复方案工程量、实施成本、持续时间（据实核算） |
| 结论要点 | ①据实归集 R1 污染清除费用；②按恢复方案核算 R2 恢复费用；③明确不叠加虚拟治理成本 |
| 数据来源 | 应急与治理费用单据、招投标与结算资料、验收记录（假示例） |

**要点复盘**：虚拟治理成本法的适用前提是"排放事实明确、损害事实不明确且无法以合理成本确定"；费用已明确时误用该法，属 §十 明令纠正的方法误用。
