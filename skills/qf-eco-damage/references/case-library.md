## 二、登记案例（某水务集团水污染案）

| 字段 | 内容 |
|---|---|
| 案件名称 | 某水务项目公司涉嫌超标排放水污染物案生态环境损害鉴定评估 |
| 鉴定评估机构 | 湖北天欧检测有限公司生态环境损害司法鉴定所 |
| 委托方 | 属地生态环境分局、某水务项目公司（联合委托） |
| 报告编号 | 天欧环损鉴〔2023〕委字第10号 |
| 损害类型 | 地表水（超标排放废水） |
| 量化方法 | 水污染虚拟治理成本法 |
| 关键取值 | E=142,420 t；C=0.634 元/t；α=1；κ=3.27→τ=1.25；ω=1.5；γ=1.875 |
| 损害数额 | ≈169,302 元（16.93 万元） |
| 结论要点 | ①超标排放 14.242 万吨，环境污染事实明确；②未发现明显损害或已自然恢复；③损害量化 16.93 万元；④承担侵权赔偿义务，建议增殖放流、河道清理等替代性修复 |
| 数据来源 | 案件卷宗、属地地表水环境质量报告、三家污水厂治理成本调查表、现场踏勘表、人员访谈记录 |

**要点复盘**：本案是"排放行为事实明确、损害事实不明确"适用虚拟治理成本法的典型。基线采用标准基准法（历史数据缺失）；受纳水体为山间池塘无特定功能，危害系数取 1；氨氮最大超标倍数 3.27 落在 0<κ≤10 档，超标系数取 1.25；功能区以外环境功能系数取 1.5。每项取值均有处可查。
