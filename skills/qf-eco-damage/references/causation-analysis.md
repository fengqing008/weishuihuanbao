# 因果关系判定

## 一、污染环境行为——六个判定方向

| 方向 | 判定内容 | 证据形式 |
|---|---|---|
| 时间顺序分析 | 排放行为发生在损害之前，时序上可衔接 | 生产记录、排污记录、监测时点、踏勘时间 |
| 污染同源性分析 | 受损介质中特征污染物与排放源污染物种类、浓度特征一致 | 特征污染物指纹、检测报告比对 |
| 迁移路径合理性分析 | 从排放点到受体的迁移通道可通（水、气、土、生物） | 水文水系、地形高差、流向流速、扩散条件 |
| 受体暴露可能性分析 | 受体存在暴露途径与暴露时间 | 取水口、灌溉、养殖、居民区位置关系 |
| 受体损害可能性分析 | 暴露剂量足以引起观察到的损害 | 毒性数据、剂量−反应、损害表现 |
| 排除其他因素分析 | 排除其他污染源或自然因素 | 周边污染源排查、背景值、气象水文异常 |

## 二、破坏生态行为——四个判定方向

时间顺序分析、损害可能性分析、因果关系链建立、排除其他可能因素。

## 三、判定结论

结论写明因果关系存在与否，以及存在的不确定性。六（四）方向证据链完整、无断点方可认定成立；某方向证据缺失时，写明该处不确定性与对结论的影响，不得跳过或臆断。因果关系不成立或无法认定时，不得进入损害量化环节。

## 四、证据种类（司法鉴定视角）

书证、物证、视听资料、证人证言、当事人陈述、鉴定意见、勘验笔录。依法依规收集制作的视听资料、电子数据、监测报告、检验报告在诉讼中可作为证据使用。机构有权了解案件材料、查阅复制资料，必要时可询问赔偿义务人与权利人代表。

## 五、质证应对要点

被质疑因果关系时，逐方向提交对应证据：时间线、同源性检测数据、迁移路径图件、暴露关系说明、毒性依据、其他因素排除说明。任一方向缺证据的，如实说明并提请补充调查，不用推测填补。
