# 报告书写作模板与结论范式

## 一、声明范式（四条）

1. 本机构及鉴定人依法独立进行鉴定评估，与本案当事人无利害关系，并对所出具的鉴定评估意见负责。
2. 本报告仅供委托方用于××用途，采信权归委托方。
3. 本报告完整有效，复制件无效；如需摘录引用，不得断章取义。
4. 对鉴定评估意见有异议的，可依法向委托方或有关部门提出。

## 二、结论文书范式（分条列项）

鉴定评估结论一般分四条，与委托事项对应：

1. 事实认定：写明排放行为的时间、地点、方式、污染物、数量、浓度、超标情况，确认环境污染事实。
2. 损害认定：写明对比基线与现状的结果，是否存在生态环境损害、损害类型、时空范围与程度；六项确认条件均不成立时写明"未发现明显损害或已自然恢复"。
3. 价值量化：写明量化方法、关键取值与损害数额。
4. 责任承担与修复建议：写明责任方应承担的赔偿义务，提出修复或替代性修复建议。

## 三、恢复建议范式

- 基本恢复：明确恢复目标、措施、工程量、期限、验收标准。
- 补偿性恢复：针对期间损害，提出补偿措施。
- 补充性恢复：基本恢复未达标或补偿性恢复不足时，提出额外措施。
- 替代性修复：无法原地恢复时提出（如增殖放流、河道清理、生态廊道建设）。

## 四、特别事项说明范式

1. 报告资料来源于委托方提供及本机构调查获取，本机构仅对本案结论负责。
2. 报告所有数据可溯源至附件，未标注来源的数据不作结论依据。
3. 报告编制过程与结果存在的不确定性（数据局限、取样代表性、方法假定）已在本报告相应章节说明。
4. 报告使用范围限于本次委托用途，超出范围使用本机构不承担责任。

## 五、常见段落句式

- 委托段："××（委托方）于××年××月××日委托本机构对××（事项）造成的生态环境损害进行鉴定评估，本机构于××年××月××日受理。"
- 方法段："鉴于××（排放行为事实明确、损害事实不明确），本报告采用 GB/T 39793.2—2020《生态环境损害鉴定评估技术指南 基础方法 第2部分：水污染虚拟治理成本法》量化损害数额。"
- 取值段："单位治理成本 C 经实际调查法确定，调查××、××、××三家同类污水处理厂，平均单位治理成本为××元/吨。"
- 结论段："（1）××（事实认定）；……（4）××（责任与修复建议）。"

## 六、占位与标注规范

未核实数据用【待核：具体说明】标注；关键数据缺失且影响结论的，在特别事项说明中披露，不作强行结论。金额用千分位格式（如 169,321 元）。日期标全年月日。
