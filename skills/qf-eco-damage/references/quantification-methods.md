# 损害量化方法

## 一、方法选择

| 情形 | 选用方法 |
|---|---|
| 损害事实明确、时空范围与恢复方案可确定 | 恢复费用法（优先）、环境价值评估方法 |
| 排放行为事实明确、损害事实不明确或无法以合理成本确定 | 水/大气污染虚拟治理成本法 |
| 生态环境无法完全恢复 | 环境价值评估方法量化损失 |
| 实际已发生污染清除费用 | 实际费用核算法（审核单据完整性、规范性、逻辑合理性） |

## 二、价值量化五项内容

R1 污染清除费用；R2 生态环境恢复费用；R3 期间服务功能丧失损失；R4 永久性损害损失；R5 防止损害发生和扩大的合理费用。逐项分别核算，不重不漏。

## 三、水污染虚拟治理成本法（GB/T 39793.2—2020）

### 3.1 公式

D = E × C × γ，γ = α × τ × ω

- D：地表水生态环境损害数额（元）
- E：排放数量（超标排放时为超标排放的废水或特征污染物总量，单位 t 或 m³）
- C：单位治理成本（元/t 或元/m³）
- γ：调整系数；α 危害系数；τ 超标系数；ω 环境功能系数

### 3.2 排放数量 E

- 超标排放废水进入地表水体的，取超标排放的废水或特征污染物总量。
- 偷排、倾倒废水的，取排放的废水或特征污染物总量。
- 排放倾倒固体废物的，取固体废物总量。
- 计算方法：实测法、物料衡算法、排污系数计算法。倾倒类一般通过现场核定、人员访谈、生产或运输记录获取。

### 3.3 单位治理成本 C

**实际调查法（优先）**：调查相同或临近地区、相同或相近生产工艺与产品类型、相近规模、能稳定达标排放的企业，取平均单位治理成本。C = ΣCj / n，n 原则上不少于 3 家。

Cj = (λ×Fj×μj + cj(tj)) / Tj

- λ 价格指数（可取工业生产者购进价格指数）；Fj 治理设施固定资产投入（元）；μj 折旧系数；cj 运行成本（元）；tj 运行时间；Tj 处理量（t）。

来源单位自有处理设施且满足"近三年正常运行达标记"或"未运行但资料证明工艺有效达标记"之一时，可采用来源单位自行核算的治理成本，但须作合理性评估。

**成本函数法**：调查样本量足够大时建立典型行业治理成本函数，C = λ × f(l, d, k, s)，l、d、k、s 分别为地区、行业、治理工艺、企业规模。

### 3.5 超标系数 τ（表3 废水）

超标倍数 κ = (Z − B) / B，Z 为污染物实测浓度，B 为排放标准限值；多污染物超标时取所有检测样品中各项污染物的最大超标倍数。

| 最大超标倍数 | τ |
|---|---|
| κ > 1000 | 2 |
| 100 < κ ≤ 1000 | 1.75 |
| 10 < κ ≤ 100 | 1.5 |
| 0 < κ ≤ 10 | 1.25 |
| 未超标 | 1 |

固体废物超标系数见 GB/T 39793.2—2020 表4（危险废物 2；一般工业固废 II 类 1.75、I 类 1.5；化学品 1.5；生活垃圾 1.25）。

### 3.6 环境功能系数 ω（表5）

| 排放行为发生地点 | ω |
|---|---|
| 集中式生活饮用水地表水源地、水生动植物自然保护区、水产种质资源保护区及其他国家自然保护区；或保护区外但污染物进入且监测表明引起水质异常 | 2.5 |
| 渔业用水功能区；或区外但监测表明引起渔业用水水质异常 | 2.25 |
| 农业用水功能区；或区外但监测表明引起农业用水水质异常 | 2 |
| 非直接接触娱乐用水、一般工业用水、一般景观用水功能区；或区外但监测表明引起上述水质异常 | 1.75 |
| 上述功能区以外 | 1.5 |

同时影响多种功能取最大值。

### 3.7 工作程序

1. 方法适用性分析：核实排放或倾倒事实，掌握来源、特征污染物、排放规律与去向、数量、浓度、受纳水体功能，分析适用性。
2. 确定排放数量 E。
3. 确定单位治理成本 C（实际调查法或成本函数法）。
4. 确定调整系数 γ（危害系数、超标系数、环境功能系数）。
5. 计算损害数额 D。

### 3.8 适用范围与不适用

适用于非法排放或倾倒废水或固体废物（含危险废物）等排放行为事实明确、但损害事实不明确或无法以合理成本确定损害范围程度与数额的情形。不适用于突发环境事件中应急处置费用或治理费用明确、通过调查可确定的损害。

## 四、算例（某水务集团水污染案）

E = 142,420 t（14.242 万吨超标排放废水）；C = 0.634 元/t（三家同类污水厂实际调查平均）；α = 1（受纳水体为山间池塘，无特定用水功能）；κ = 3.27（氨氮最大超标倍数），0<κ≤10 故 τ = 1.25；ω = 1.5（功能区以外）。γ = 1×1.25×1.5 = 1.875。D = 142,420 × 0.634 × 1.875 = 169,301.78 元 ≈ 16.93 万元。
