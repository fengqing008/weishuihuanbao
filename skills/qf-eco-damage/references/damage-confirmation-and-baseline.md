# 损害确认与基线确定

## 一、损害确认（GB/T 39791.1—2020 第5.3条）

对比评估区生态环境及其服务功能现状与基线，必要时开展专项研究，满足下列任一条件即确认存在生态环境损害：

| 序 | 确认条件 | 判定要点 |
|---|---|---|
| a | 特征污染物浓度或相关理化指标超过基线 | 空气、地表水、沉积物、土壤、地下水、海水中特征污染物或理化指标与基线对比 |
| b | 物质浓度足以导致生物毒性反应 | 以毒性数据支撑，未必已有实际死亡 |
| c | 生物个体发生死亡、病变、行为异常、肿瘤、遗传突变、生理功能失常、畸形 | 个体水平证据 |
| d | 种群、群落或生态系统特征较基线不利改变 | 种群密度、性别比例、多度、生物多样性等 |
| e | 生态服务功能降低或丧失 | 供给、调节、文化、支持服务 |
| f | 造成生态环境损害的其他情形 | 兜底条款，需专业论证 |

**关键纪律**：六项均不成立时，结论写"未发现明显生态环境损害，或受损生态环境已自然恢复"，不得为凑数额硬认损害。事实明确的排放行为仍可量化其虚拟治理成本（如本案），但结论须分开表述——行为造成环境污染的事实明确、损害本身未确认。

## 二、基线确定（GB/T 39791.1—2020 第5.2条）

### 2.1 四种方法及优先顺序

1. **历史数据法**：优先利用行为发生前的历史数据。样本数不少于 5 个；注明资料来源与时间；对变异性作统计描述，识别并处理极值或异常值。
   - 服从正态分布：指标升高取 90% 参考值上限（算术平均数 + 1.65×标准差）；指标降低取 90% 参考值下限（算术平均数 − 1.65×标准差）。
   - 不服从正态分布：升高取第 90 百分位数；降低取第 10 百分位数。
2. **对照数据法**：缺乏历史数据或不满足要求时，选取一个或多个可比且未受影响的对照区域。样本数不少于 5 个，确定原则同历史数据法。
3. **标准基准法**：前两法不可行时，参照适用的国家或地方环境质量标准或环境基准。标准与基准并存时优先适用环境质量标准；缺乏适用标准或基准时参照国外政府部门或国际组织发布的适用文件。
4. **专项研究法**：必要时按环境基准制定技术指南推导环境基准，或构建生态环境质量与生物效应之间的剂量−反应关系。

### 2.2 常见错误

- 有历史数据却改用标准基准法，导致基线偏松或偏严。
- 样本数不足 5 个即作统计。
- 未区分正态与非正态分布，误用 1.65 倍标准差公式。
- 用评估区受污染后的数据充当基线。

## 三、期间损害与永久损害

- 期间损害：损害发生至恢复至基线期间，生态系统服务功能的丧失或减少，须单独计算。
- 永久损害：受损生态服务功能难以恢复、提供服务能力完全丧失的部分。

## 四、确认与基线关系示意

基线（历史/对照/标准基准/专项研究）→ 评估区现状调查 → 逐项对比 → 命中六项条件之一 → 确认损害类型、时空范围与程度 → 进入因果关系判定与量化。基线未确定前，损害确认与量化均不成立。
