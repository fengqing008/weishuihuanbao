# 质量检查清单（theme-factory）

交付前逐条勾选，15 项。任一项为否，即暂停交付并回到对应步骤整改。

## 一、主题与资产

- [ ] 1. 主题名取自 themes/ 下 10 套内置主题，或为用户确认过的自定义主题，无臆造名称。
- [ ] 2. 四色 hex 值逐字符取自主题文件或用户明确给定值，无凭印象填写，格式统一为小写 `#rrggbb`。
- [ ] 3. themes/*.md、theme-showcase.pdf、LICENSE.txt 三个只读资产未被改动、未被删除（交付前核对文件状态）。
- [ ] 4. 主题适配场合与本次材料场合匹配，规格表已写明匹配理由。

## 二、槽位与落地

- [ ] 5. bg / primary / accent / text 四槽位与主题四色一一对应，无空槽、无重复占位。
- [ ] 6. heading / body 两个字体槽位已填，拉丁字体与中文字体分别落在正确位置。
- [ ] 7. 同类元素全篇同色同字体：标题、正文、注释、表格、图表系列无残留旧主题样式。
- [ ] 8. 强调色使用比例控制在约 10%，未大面积铺底，未充当正文色。
- [ ] 9. PPT/Word 类材料已改样式集或母版主题色，未仅逐页手改。

## 三、校验与记录

- [ ] 10. 正文文字与背景对比度 ≥4.5:1，复算数值已记入规格表。
- [ ] 11. 大字与图形元素对比度 ≥3:1；低于 3:1 的浅色已标注"仅装饰，不作文字色"。
- [ ] 12. 中文字体回退链闭合（主题拉丁字体 → Noto Sans CJK SC / Source Han Sans SC / 微软雅黑 → 通用族）。
- [ ] 13. 抽页复核完成：封面、正文页、图表页各一页，三页与规格表一致。
- [ ] 14. 规格表按 references/output-template.md 骨架填写完整，降级项与【待核】项逐条标注。
- [ ] 15. 自定义主题已经用户确认命名与四色，并按 references/case-library.md 模板登记案卷。

## 四、常见不通过原因（对应整改）

| 不通过项 | 典型表现 | 整改动作 |
|---|---|---|
| 第 2 项 | 手抄色值时少一位或大小写混写 | 重读 themes/*.md 逐位核对 |
| 第 10 项 | 浅底配浅字，复算值低于 4.5 | 换主题内更深一档色作文字色，重算 |
| 第 12 项 | 中文材料只挂 DejaVu Sans，汉字回退到系统默认字体 | 补中文字体至回退链首位之后 |
| 第 7 项 | 内页表格仍为旧主题蓝、封面已换新色 | 全篇检索旧色值与旧字体名，逐个替换 |
| 第 9 项 | 只改幻灯片上的形状填充，母版未动 | 改母版主题色与样式集后重新套用 |
