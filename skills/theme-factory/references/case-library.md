# 案例库（theme-factory）

本文件用于登记主题应用与自定义主题的真实案例，作为后续选型的对照依据。

**登记纪律**：严禁编造具体项目名、客户名、金额、日期。凡证物不齐的条目一律留【待填】，不得以推测内容补齐。每条案例须能回溯到可核验的证物（文件路径、截图留档位置、用户原始要求记录）。

## 二、数据来源指引

1. **主题规格来源**：themes/ 目录下 10 个主题文件（arctic-frost.md、botanical-garden.md、desert-rose.md、forest-canopy.md、golden-hour.md、midnight-galaxy.md、modern-minimalist.md、ocean-depths.md、sunset-boulevard.md、tech-innovation.md），色值与字体一律以此为准。
2. **总览来源**：theme-showcase.pdf，仅作可视比较，读取不修改。
3. **条款来源**：LICENSE.txt，资产使用范围的唯一依据。
4. **交付件来源**：每次交付的主题应用规格表与校验记录，按 references/output-template.md 与 references/quality-checklist.md 生成。
5. **入库条件**：证物位置可查、对比度数值可复算、降级项已注明，三者齐备方可登记；缺一项即记为【待填】并暂缓入库。

## 三、案例条目

### 案例一：单页 HTML 汇报套用 Ocean Depths（L1 轻量场景）

- **背景**：一份汇报 HTML 需要"专业、沉稳"的观感，用户未指定主题名，只给出场合描述。
- **做法**：呈现 theme-showcase.pdf 总览 → 读 `themes/ocean-depths.md` 取回四色与字体 → 四色入
  bg/primary/accent/text 四槽位、字体入 heading/body 两槽位 → 写入 CSS 变量 → 复算对比度。
- **结果**：正文/背景 14.32（≥4.5 通过）、强调/背景 3.56（≥3.0 通过）、次级/背景 1.42（未达 3.0）。
  据此判定海沫色 `#a8dadc` 不可承担文字或小图标，规格表在 accent 槽位注明"仅装饰，不作文字色"。
- **要点**：对比度复算须逐对做，不能只算正文一对；未达标的色只能降级为装饰用途并写明。

### 案例二：产品发布 PPT 换肤为 Tech Innovation（L2/L3 标准场景）

- **背景**：24 页产品发布 PPT 需统一换肤，强调科技感与高对比。
- **做法**：读 `themes/tech-innovation.md` → 电光蓝 `#0066ff` 作 primary、深灰 `#1e1e1e` 作 background、
  白 `#ffffff` 作 text，霓虹青 `#00ffff` 仅作 10% 强调 → 同步改母版主题色与图表色序 →
  抽页复核封面、第 8 页数据页、第 18 页图表页。
- **结果**：PPT 与规格表交付；规格表标注"霓虹青仅用于强调，不得用于正文或大面积色块"；三页色值
  与字体与规格表逐项一致。
- **要点**：换肤须改母版与样式集而非单页；霓虹类高饱和色严禁大面积铺底，这是本技能的反模式红线。

### 案例三：自定义主题生成并入库（L4 专家场景）

- **背景**：环保宣讲场合，用户要求"接近自然、但不能与既有 10 套主题雷同"。
- **做法**：起草四色（深底 + 主色 + 辅助 + 浅底）→ 按"形容词 + 名词"命名 → 复算对比度 →
  经用户确认命名与四色后写入规格表 → 按本文件登记模板登记案卷。
- **结果**：主题名 Moss Stream 苔溪；槽位 bg `#22302c` / primary `#3f7d6a` / accent `#cbb98a` /
  text `#f4f1e9`；字体 FreeSerif Bold / FreeSans；正文/背景对比度 11.8（通过）。
- **要点**：自定义主题须经用户确认命名与四色后方可入库；与既有主题高度重合时应复用既有主题，
  不重复建档（降级处理）。

## 四、选型对照用法

1. 新任务到手，按场景类型检索本库同类型条目，优先复用已验证通过的槽位映射与字体链。
2. 同类型条目存在多套主题时，比对对比度记录与失败模式列，取降级项最少者。
3. 本库无同类型条目时，按 SKILL.md 第二节触发场景选主题，落地后回填新条目。
4. 自定义主题登记后，与既有 10 套比对色系重合度；重合度高的记为复用既有主题，不重复建档。

## 五、维护规则

1. 每季度核对一次证物位置的有效性，失效条目改标【待核：证物失效】。
2. 同一主题在同一场景类型下累计三次以上出现同一失败模式，须同步更新 SKILL.md 第八节。
3. 对比度数值一律以本库记录为准口径，重算结果与旧记录不一致时，新值覆盖旧值并注明重算日期。
