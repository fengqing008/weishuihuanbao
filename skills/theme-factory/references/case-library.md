# 案例库（theme-factory）

本文件用于登记主题应用与自定义主题的真实案例，作为后续选型的对照依据。

**登记纪律**：严禁编造具体项目名、客户名、金额、日期。凡证物不齐的条目一律留【待填】，不得以推测内容补齐。每条案例须能回溯到可核验的证物（文件路径、截图留档位置、用户原始要求记录）。

## 一、案例登记模板

新案例按此表登记，一条一表：

| 字段 | 内容 |
|---|---|
| 案例编号 | 【待填：TF-YYYY-NN】 |
| 场景类型 | PPT 汇报 / Word 报告 / HTML 页面 / 信息图 / 多材料统一 |
| 主题名 | 【待填：如 Ocean Depths / 或自定义主题名】 |
| 主题来源 | themes/*.md 内置 / 自定义生成（附四色 hex） |
| 场合描述 | 【待填：场合与受众，不写客户名】 |
| 槽位映射 | bg / primary / accent / text 四个 hex |
| 字体映射 | heading / body 与中文字体回退链 |
| 对比度记录 | 正文/背景、强调/背景两组数值 |
| 遭遇的失败模式 | 参照 SKILL.md 第八节条目勾选 |
| 降级项 | 【待填：无 或 具体降级动作】 |
| 待核项 | 【待填：字段名 + 待补证物】 |
| 证物位置 | 【待填：成品路径 / 规格表路径 / 留档位置】 |
| 登记人 | 【待填】 |
| 登记日期 | 【待填：YYYY-MM-DD】 |

## 二、数据来源指引

1. **主题规格来源**：themes/ 目录下 10 个主题文件（arctic-frost.md、botanical-garden.md、desert-rose.md、forest-canopy.md、golden-hour.md、midnight-galaxy.md、modern-minimalist.md、ocean-depths.md、sunset-boulevard.md、tech-innovation.md），色值与字体一律以此为准。
2. **总览来源**：theme-showcase.pdf，仅作可视比较，读取不修改。
3. **条款来源**：LICENSE.txt，资产使用范围的唯一依据。
4. **交付件来源**：每次交付的主题应用规格表与校验记录，按 references/output-template.md 与 references/quality-checklist.md 生成。
5. **入库条件**：证物位置可查、对比度数值可复算、降级项已注明，三者齐备方可登记；缺一项即记为【待填】并暂缓入库。

## 四、选型对照用法

1. 新任务到手，按场景类型检索本库同类型条目，优先复用已验证通过的槽位映射与字体链。
2. 同类型条目存在多套主题时，比对对比度记录与失败模式列，取降级项最少者。
3. 本库无同类型条目时，按 SKILL.md 第二节触发场景选主题，落地后回填新条目。
4. 自定义主题登记后，与既有 10 套比对色系重合度；重合度高的记为复用既有主题，不重复建档。

## 五、维护规则

1. 每季度核对一次证物位置的有效性，失效条目改标【待核：证物失效】。
2. 同一主题在同一场景类型下累计三次以上出现同一失败模式，须同步更新 SKILL.md 第八节。
3. 对比度数值一律以本库记录为准口径，重算结果与旧记录不一致时，新值覆盖旧值并注明重算日期。
