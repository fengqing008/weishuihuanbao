# 合同起草审查 · 实战案例库（case-library）

> 本案例集为参照范式，来源为知识库「合同范本库」（壹典法阅）与公开实务整理；个案结论不构成法律意见，具体以现行法律与用户核实为准。每条注明出处与依据，未核实项以【待核】标注。

## 案例一：设备采购合同付款条款审查（买方立场）

- **来源**：用户上传《设备采购合同》，知识库采购合同范本比对。
- **事实**：合同约定"签约后 3 日内付全款"，交货期为签约后 60 日，无验收与质保安排。
- **问题**：付款与交付对价严重失衡，买方承担全部资金与履约风险（🔴 高风险）。
- **处置**：按范本给出修改文本——"30% 预付 + 60% 验收合格后付 + 10% 质保金（质保期满付）"，并补充逾期交货违约金与质量异议期。
- **交付物**：风险摘要表（1🔴1🟡）+ `设备采购合同-审查版.docx`（真实修订标记，买方逐条接受/拒绝）。

## 案例二：房屋租赁合同起草（承租方立场）

- **来源**：知识库租赁合同范本为蓝本，结合用户提供的租期、租金、押金信息。
- **事实**：用户需一份住宅租赁合同，关注押金退还与维修责任。
- **处置**：以范本为骨架，重点补强"押金退还时限与条件""房屋维修责任划分""提前解约的违约金上限"三个条款，措辞具体可粘贴。
- **输出**：`房屋租赁合同.docx`（完整合同文本，双方信息 + 第X条结构），确认门后生成。
- **检查点**：核心模块齐备、无遗漏违约与争议解决、押金条款可执行。

## 案例三：技术开发合同范本缺失下的降级起草

- **来源**：广场检索「合同范本库」未命中技术开发类范本，触发降级路径。
- **事实**：用户要求起草一份细分领域技术开发合同，知识库无直接匹配范本。
- **处置**：回退 `search(source="kb")` 查本地库 → 未果 → 联网检索示范文本补充 → 按合同通用框架（主体/标的/价款/交付/知识产权/违约/争议解决/生效）起草，并在确认门明确声明"无范本直接参照，按通用框架起草"。
- **检查点**：降级口径已如实告知用户，关键条款未臆造，知识产权归属条款经用户确认。

## 案例四：文件损坏的失败分支处理

- **来源**：用户上传的 docx 损坏无法解析。
- **事实**：脚本读取报错，无法获取合同正文。
- **处置**：按失败分支处理——不做推测性补全，回报错误并请用户重传或粘贴正文文本；重试一次仍失败则转人工提供文本。
- **检查点**：静默跳过 = 违规；已如实回报并给出补救路径。
