# 合规使用场景与参数配置

## 一、场景清单

| 场景 | 关注点 | 参数建议 | 交付级别 |
| --- | --- | --- | --- |
| 年会抽奖 | 现场可感知、结果不可预判、气氛 | `--count N` 单轮，`--prove` 留痕 | L3 |
| 客户答谢抽奖 | 参与名单来自报名表、需公示 | csv 名单 + `--prove` + 校验报告 | L3 |
| 优秀员工评选抽签 | 名额有限、需向员工说明规则 | csv + `--weight-col`（司龄/绩效权重）+ `--prove` | L3 |
| 专家评审抽取 | 需回避关联、需可追溯 | `--exclude` 回避名单 + `--unique` + `--prove` | L4 |
| 面试顺序抽签 | 每人只出现一次 | `--unique` + `--count` 等于人数 | L2 |
| 保障房摇号 | 对象众多、社会关注、须公示 | `--seed` 固定种子 + `--prove` + 第三方复核 | L4 |
| 公租房选房顺序 | 顺序即权益，须可复现 | `--seed` + `--unique` + `--out` 顺序表 | L4 |
| 配额与名额分配 | 需按权重倾斜 | `--weight-col` + `--prove` | L3 |
| 课堂随机点名 | 频次高、轻量 | txt + `--count 1` | L1 |
| 值班随机排班 | 需多轮、不重复 | `--rounds` + `--unique` | L2 |
| 礼品/物资分发对象 | 名单来自登记表 | `--exclude` 已领取 + `--prove` | L2 |

## 二、参数速查

```
# 单轮等权抽 3 人
python3 scripts/lucky_draw.py --input names.txt --count 3 --out winners.txt

# csv 指定列 + 权重 + 排除名单
python3 scripts/lucky_draw.py --input staff.csv --name-col 姓名 --weight-col 权重 \
    --count 5 --exclude excluded.txt --out winners.txt --prove proof.json

# 固定种子复现审计 + 证明
python3 scripts/lucky_draw.py --input names.txt --count 3 --seed 42 --replay \
    --prove draw_proof.json

# 多轮抽奖且跨轮去重
python3 scripts/lucky_draw.py --input names.txt --count 2 --rounds 3 --unique \
    --out winners.txt --prove proof.json

# 第三方复核
python3 scripts/verify_proof.py --proof proof.json    # exit 0 表示一致
```

参数含义：`--count` 每轮人数；`--rounds` 轮数；`--unique` 跨轮去重；`--exclude` 排除文件；`--seed` 复现种子；`--replay` 显式声明复现审计（须与 `--seed` 同用）；`--prove` 证明文件路径；`--out` 名单路径。

## 三、加权抽取的使用规则

- 权重列只接受正数，支持小数；内部按 `10^6` 放大取整，保持相对比例。
- 权重代表「相对被抽中的倾向」，不构成「必定抽中」的允诺。公示时须向参与方说明这一点，避免误解。
- 等权抽取不必传 `--weight-col`，全部按 1 处理。
- 权重来源须有可核验依据（司龄、绩效、积分表），不得由抽签执行人临时口述。

## 四、留痕与公示流程（审计级）

1. 抽取前，对候选池文件计算并公示 `candidates_sha256` 与时间戳。
2. 执行抽取，产出名单与证明文件。
3. 立即运行校验脚本，公示校验结论与退出码。
4. 按公示要求决定是否公开 `seed`；公开后任何人均可完整重放。
5. 把名单、证明、校验报告、公示截图一并归档，保存期限按组织内控要求执行。

## 五、博彩与赌博场景的处理

以下请求一律拒绝，不做变通、不做「技术演示」：

- 彩票号码预测、选号推荐、开奖结果推算、走势图分析。
- 网络博彩、赌球、赌马、线上赌场的中奖用户抽取或派彩对象确定。
- 具有博彩性质的盲盒玩法、抽奖返现、以小博大的概率游戏设计。
- 为境外赌博平台、私彩、六合彩等提供随机数、名单抽样或结果生成。

拒绝时的标准口径：本技能只用于组织内部资源分配的公平抽签，不参与任何形式的博彩活动；涉及赌博的请求违反法律与平台规则，无法提供协助。若用户的真实需求是「活动抽奖」「员工福利发放」等合规场景，请把场景与名单重新描述清楚，再进入办理流程。

## 六、个人信息处理提示

名单常含真实姓名与身份信息。抽签环节只取姓名与权重，不读取身份证号、手机号；原始表格若含敏感字段，先做脱敏再交付抽签文件，抽签输出的名单按组织内控范围控制流转。
