# 发布资料 · 摇号抽签（lucky-draw）

## 一、技能简介

**摇号抽签**——由 Python 标准库 secrets 密码学安全随机数驱动的公平抽取工具。从 txt / csv / json 名单中按指定人数摇出中奖者，支持多轮抽签、跨轮去重、权重分配、排除名单与 `--seed` 复现审计，并输出含输入名单 SHA256、随机熵摘要、抽取索引与时间戳的可验证证明文件，供年会抽奖、优秀员工评选、专家评审抽取、保障房摇号、配额分配等场景留痕核对。

## 二、使用说明（6 条）

1. **单轮抽取**：说「从这份名单里摇出 10 名中奖者」，我按名单一次性抽取并列出结果。
2. **多轮去重**：说「年会抽奖要三轮、每轮不重复」，我按轮次抽取并跨轮去重。
3. **权重分配**：说「专家评审抽取，需按权重分配」，我按权重抽样，权重高的被抽概率更高。
4. **排除名单**：说「排除已中奖名单后再抽」，我先剔除指定人员再抽取。
5. **固定种子复现**：说「用固定种子复现这次结果」，我用 `--seed` 复现同一批次，供第三方核对。
6. **出具证明**：说「出一份可验证证明文件」，我输出含名单 SHA256、随机熵摘要、抽取索引与时间戳的证明，随证明附校验脚本。

## 三、使用示例

```bash
python3 scripts/lucky_draw.py --input 名单.csv --count 10 --rounds 3 \
    --no-repeat --seed 20260923 --proof proof.json
```

退出码：0 = 正常；非 0 = 输入异常（详见提示）。

## 四、适用场景

- 年会抽奖、优秀员工评选；
- 专家评审抽取、评标专家随机抽取；
- 保障房摇号、配额分配等需留痕核对的合规抽取。

## 五、不适用边界

| 场景 | 处理方式 |
|------|----------|
| 赌博、博彩、彩票预测 | 不提供 |
| 需要公证效力的抽取 | 由公证机构按法定程序办理 |
| 商业赛事结果操控 | 不提供 |
