# 二十四山与八卦方位说明

## 一、二十四山

二十四山是传统罗盘的基本刻度，由三类组成：

- **八天干**：甲、乙、丙、丁、庚、辛、壬、癸（戊己属中宫，不入方位）
- **十二地支**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥
- **四维**：乾、坤、艮、巽

共 24 山，每山占 **15°**。

## 二、四正位

| 山 | 度数（中心） | 方位 |
|---|---|---|
| 子 | 0° | 正北 |
| 卯 | 90° | 正东 |
| 午 | 180° | 正南 |
| 酉 | 270° | 正西 |

## 四、定山规则

给定度数 D（正北为 0°，顺时针），按每山 15° 计算：山中心度 ±7.5° 即该山范围。

```bash
python3 scripts/luopan.py --deg 120      # → 辰山（巽宫）
python3 scripts/luopan.py --name 巽       # 单山查询
python3 scripts/luopan.py --bagua 坎      # 查一宫三山
```

## 五、用途说明

二十四山在传统上用于确定坐向（宅门或主窗朝向即「向」，其反向为「坐」）。本技能仅把它作为方位定位与文化说明之用，不涉吉凶推算。测量坐向可用手机罗盘 App，取正北为 0°、顺时针读数。
