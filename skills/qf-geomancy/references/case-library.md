# 案例登记模板与来源指引

本文件为案例登记模板。案例库遵循**不编造**原则：仅登记有公开来源、可查证的真实材料；无可靠来源时保留占位并标注来源指引，不以虚构案例充数。

## 一、案例登记模板

```
### 案例编号：GS-YYYY-NNN
- 来源类型：典籍原文 / 公开民俗资料 / 用户授权记录（脱敏）
- 出处：
- 点位性质：城区 / 乡村 / 山地 / 滨水（不记精确地址）
- 环境要素：水体、道路、建筑等客观观察
- 传统格局对照：四神砂方位情况
- 涉及形煞：
- 文化解读：
- 备注：
```

## 二、可登记案例的类型

1. **典籍中的形局描述**：《葬书》《雪心赋》等对理想格局的论述，属公有领域，可逐字登记并注明篇目。
2. **传统聚落选址**：经整理刊布的古镇、村落选址研究资料（如依山傍水、背风向阳的布局）。
3. **公开的城市环境观察**：基于公开地图信息对某类环境（如滨水、临路）的客观描述与文化对照。
4. **方法示范案例**：为演示技能能力构造的**示范案例**，须在备注中明确标注「示范案例，非真实个案」。

## 三、来源指引

- 典籍原文：中国哲学书电子化计划、国学网等公有领域古籍库。
- 地方志与聚落研究：各级地方志、已刊行的建筑与民俗研究著述。
- 环境观察：公开地图服务（要素方位与距离为客观测量，仅作对照）。

## 四、免责条款

案例部分同样适用统一免责声明：所录内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。用户提供的点位信息在登记前须脱敏，并取得授权。
