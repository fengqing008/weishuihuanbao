# 案例库（case-library）：登记模板、真实案例与来源指引

> 本库遵循**不编造**原则：只登记有公开来源、可查证的真实材料；无可靠来源时保留占位并标注来源指引，不以虚构案例充数。
> 所有具体数字与地名一律来自公开典籍或已刊布研究资料，未核实项标【待核】。

## 二、真实案例（含背景 / 做法 / 结果）

### 案例 GS-001 ——《葬书》四神砂原始表述的文化解读
- **背景**：四神砂是形法派描述理想局部的核心措辞，散见后世堪舆书，源头在旧题晋·郭璞《葬书》。用户问「四神砂到底讲什么」。
- **做法**：不转述、不概括，直接引《葬书》逐字原文——「玄武垂头，朱雀翔舞，青龙蜿蜒，白虎驯俯」；对应 `assets/sixiang.json` 四条，逐一说明玄武（后）主靠山宜高、朱雀（前）主明堂宜开阔、青龙（左）主文宜蜿蜒、白虎（右）主武宜低伏；再落到今义——其精神是对空间层次与围合感的要求（背有依托、前有缓冲、左右围合而不逼压）。
- **结果**：输出为文化解读，末尾附统一免责声明；**未**作任何吉凶判断。经 `scripts/qf_geomancy_check.py` 复核，免责声明与章节齐备，退出码 0。
- **出处**：旧题晋·郭璞《葬书》（公有领域古籍）；中国哲学书电子化计划等公版古籍库。

### 案例 GS-002 ——《地理五诀》「龙穴砂水向」五要的结构化呈现
- **背景**：用户希望了解古人择地到底看哪几件事，是否只有「看方位」。
- **做法**：以清·赵九峰《地理五诀》的「龙、穴、砂、水、向」五要为骨架，逐项给出古义与今义对应——龙＝山脉走势（今对应地形大势）、穴＝选定的位置、砂＝左右的护卫（今对应周边建筑与绿化）、水＝河流湖泊（古代道路亦作水看）、向＝朝向；并明确本技能以**形势派为主线**，理气派仅取二十四山与八卦方位作定位刻度，全篇口径一致，不混说。
- **结果**：形成七章报告中的「典籍背景」与「四神砂参照」两章，具备可核验的典籍条目（对应 `assets/classics.json`）。方位部分经 `scripts/luopan.py` 核对，每山 15°、中心度 ±7.5° 无误。
- **出处**：清·赵九峰《地理五诀》（公有领域古籍）。

### 案例 GS-003 —— 公开地图环境观察的四神砂对照（滨水临路点位）
- **背景**：用户给出某滨水城区的坐标，问「这里的形势，按传统怎么看」。
- **做法**：走 `scripts/geo_analyze.py --lat ... --lng ...` 检索周边水体、道路、建筑等**客观要素**（方位与距离为公开地图测量值）；按四神砂作方位对照，对「路冲」「反弓」等**形煞**同时给出「传统认知」与「文化解读」（含今日可理解的合理内核，如车流噪声与安全视线），不作吉凶恐吓；报告中只保留必要的地理范围描述，**不记精确门牌**。
- **结果**：产出七章 HTML 报告并附免责声明；联网受限时按失败模式表 D1 **回退**为离线框架模式，报告仍可交付。html_check 复核 FAIL=0。
- **出处**：公开地图服务（要素方位为客观测量，仅作对照）；形煞名目以 `assets/shas.json` 为准，库外名目标「未收录」。
- **备注**：点位信息属**边界条件**，登记前须脱敏；坐标仅作方位比对，不外传第三方。

### 案例 GS-004 —— 方法示范案例（非真实个案，仅演示调用链）
- **背景**：为演示技能能力，构造一个**示范案例**（**明确标注「示范案例，非真实个案」**），用于说明从点位到报告的完整链路。
- **做法**：`luopan.py --deg 120` → 判为【辰】山（巽宫，五行土）；`report_render.py --address "..." --deg 120` → 装配七章并渲染 HTML；`htmlbase/html_check.py` 复核密度与围栏。
- **结果**：交付物为单文件自包含 HTML 与 Markdown 底稿，两图（四神砂方位示意、二十四山罗盘示意）base64 内嵌，零外链。
- **备注**：**示范案例，非真实个案**，不得作为真实点位记录引用。

## 三、可登记案例的类型

1. **典籍中的形局描述**：《葬书》《雪心赋》《撼龙经》《地理五诀》等对理想格局的论述，属公有领域，可逐字登记并注明篇目。
2. **传统聚落选址**：经整理刊布的古镇、村落选址研究资料（如依山傍水、背风向阳的布局）。
3. **公开的城市环境观察**：基于公开地图信息对某类环境（如滨水、临路）的客观描述与文化对照。
4. **方法示范案例**：为演示技能能力构造的**示范案例**，须在备注中明确标注「示范案例，非真实个案」。

## 四、来源指引（去哪里找可靠案例）

| 来源类型 | 获取位置 | 可用字段 | 备注 |
|---|---|---|---|
| 典籍原文 | 中国哲学书电子化计划、国学网等公版古籍库 | 引文原文、篇目、书名 | 逐字引用，严禁改写 |
| 地方志与聚落研究 | 各级地方志、已刊行的建筑与民俗研究著述 | 选址格局、地形描述 | 注明版本与页码 |
| 公开环境观察 | 公开地图服务 | 要素方位与距离 | 仅为客观测量，仅作对照 |
| 技能运行回显 | 脚本命令输出与渲染日志 | 山卦、密度、FAIL 计数 | 数字直接引用，不得改写 |

**引用与溯源纪律**：本库所有案例的出处以典籍版本或公开资料为准；涉及坐标与地图的判定依据见 SKILL.md「引用依据与溯源」一节；未核实项一律标注【待核】，不得用行业惯例替代实测数据。
