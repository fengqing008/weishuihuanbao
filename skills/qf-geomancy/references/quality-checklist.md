# 交付质检清单

## 一、内容层

- [ ] 输出末尾附统一免责声明：「本内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。」
- [ ] 输出结构完整：要素观察 → 四神砂对照 → 形煞文化解读 → 典籍背景。
- [ ] 形煞条目同时给出「传统认知」与「文化解读」（含今日合理内核），未只作吉凶恐吓。
- [ ] 典籍引文逐字保留、注明书名，未改写未杜撰。
- [ ] 形煞/方位库无对应条目时如实说明「未收录」，未临时编造。

## 二、边界层

- [ ] 未给出确定性吉凶断言（「大凶」「不宜居住」等）。
- [ ] 未参与购房、选址、投资、医疗、法律决策。
- [ ] 涉及购房或墓址选择时，已提示咨询专业人士。
- [ ] 坐标与位置信息仅用于方位比对，未暴露精确住址细节。

## 三、技术层

- [ ] 方位判断以度数/罗盘刻度为依据（每山 15°、中心度 ±7.5°）。
- [ ] 报告正文每章不少于 300 中文字，无空架子章节。
- [ ] 文风无套话与序列化行文路标。
- [ ] HTML 报告经 `scripts/htmlbase/html_check.py` 自检，FAIL=0。
- [ ] 联网失败时已回退（改用坐标、读图或离线模式）并说明。

## 四、交付层

- [ ] Markdown 底稿与 HTML 成品同时产出并留存。
- [ ] 报告七章结构完整。
- [ ] 交付物按四件齐备归档（内容／数据溯源／入库／下载链接）。
