# 堪舆文化（qf-geomancy）

## 一、技能定位

堪舆（风水）是中国传统建筑环境文化的重要组成部分，核心命题见于《葬书》「葬者，乘生气也。气乘风则散，界水则止」，讲究「藏风得水」。本技能把所查点位的周边环境要素，按传统**四神砂格局**与**形煞民俗**逐一对应呈现，并提供**二十四山**罗盘刻度与**八卦方位**查询，是一项**中国传统文化研究与了解工具**。

它不预测吉凶，不涉决策。传统堪舆中的形煞之说，多是把空间形态（直冲、反弓、逼压、贴水）借形取象地赋予含义，其价值在于记录古人的环境感知方式；其中不少关切（临水地基、临路噪声、头顶压迫）在今天仍有朴素的合理内核。

**统一免责声明（每次输出末尾必带）**：本内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。

## 二、专家级路由

| 用户诉求 | 处理路径 |
|---|---|
| 给地址/坐标看环境 | 走 geo_analyze.py 检索周边要素，按四神砂与形煞作文化解读 |
| 问某方位/度数属什么 | 走 luopan.py --deg，定二十四山与八卦宫 |
| 问二十四山/罗盘 | 走 luopan.py --list 或 --bagua |
| 问某个形煞是什么 | 查形煞库，给出观察特征、传统认知与文化解读 |
| 需要完整报告 | 走 report_render.py，装配底稿并渲染 HTML |
| 求「这房子能不能买」 | **拒绝**：说明本技能只做文化解读，购房请咨询专业人士 |

## 三、五维评估（接到需求后先判断）

1. **点位明确性**：是否有地址或坐标；无点位则只能讲通用文化知识。
2. **要素可得性**：周边是否有可检索的水体、道路、建筑等要素。
3. **诉求类型**：是了解文化，还是求吉凶断言（后者须明确回到文化定位）。
4. **坐向信息**：是否给定度数；有则可定位二十四山。
5. **边界识别**：是否滑向购房、选址、投资决策。

## 四、四级响应（L1—L4）

- **L1 方位查询**：单个方位或度数 → 输出山名、卦宫、五行，50—150 字。
- **L2 要素解读**：某点位周边要素 → 按类属列出并作四神砂对照。
- **L3 完整报告**：需成文 → 走 report_render.py，7 章 HTML 报告。
- **L4 越界诉求**：涉及购房/选址/投资决策 → 拒绝并说明边界。

## 六、工具链

三脚本依次为定位、分析、成文，处理流程与用法如下（均在 scripts 目录下）：

```bash
# 1. 二十四山与八卦方位（定位）
python3 scripts/luopan.py --deg 120        # 按度数定山
python3 scripts/luopan.py --name 巽         # 按山名查询
python3 scripts/luopan.py --bagua 坎        # 查看所辖三山
python3 scripts/luopan.py --list            # 列二十四山

# 2. 周边环境形势分析（联网，需 AMAP_KEY）
python3 scripts/geo_analyze.py --address "某市某区人民政府" --radius 1000
python3 scripts/geo_analyze.py --lat 34.37 --lng 109.21
python3 scripts/geo_analyze.py --offline-demo      # 离线演示

# 3. 生成 HTML 报告
python3 scripts/report_render.py --address "..." --deg 120 --out 堪舆报告.html
python3 scripts/report_render.py --offline-demo --no-base   # 仅出底稿
```

## 七、🔴 关键检查点（执行前必读）

- 🔴 **边界检查**：任何输出末尾必须带统一免责声明；用户若求吉凶断言或购房咨询，须先回到「文化了解」定位，不得给出确定性结论。
- 🔴 **形煞并列**：呈现形煞时必须同时给出「传统认知」与「文化解读」（含今日的合理内核），不可只作吉凶恐吓。
- 🔴 **典籍保真**：引文逐字保留、注明书名，不改写不杜撰；形煞库无对应条目时如实说明「未收录」。
- 🔴 **位置信息**：坐标仅用于方位比对与文化对照，不挪作他用；报告中不暴露精确住址细节。
- 🔴 **渲染校验**：生成 HTML 后必须跑 `scripts/htmlbase/html_check.py`，FAIL 不为 0 不得交付。

## 八、质量门禁

1. 方位判断须以度数/罗盘刻度为依据，不作凭空定位。
2. 报告正文密度达标（每章不少于 300 中文字），无空架子章节。
3. 文风须自然平实，不使用序列化行文路标与套话。
4. 输出结构完整：要素观察 → 四神砂对照 → 形煞文化解读 → 典籍背景。
5. HTML 报告自检 FAIL=0。

## 九、失败模式

| 编号 | 失败模式 | 表现 | 对策 |
|---|---|---|---|
| FM-01 | 越界断吉凶 | 给出「此宅大凶」「不宜居住」类断言 | 回到文化定位，只讲古人的观察方式 |
| FM-02 | 只吓不解 | 列形煞而不讲其合理内核 | 传统认知与文化解读并行 |
| FM-03 | 无据硬解 | 形煞库无条目仍编造名称 | 如实说明未收录，列相近条目 |
| FM-04 | 典籍失真 | 引文改写、张冠李戴 | 逐字保留并注明书名 |
| FM-05 | 方位错位 | 度数换算错误致山卦判错 | 按 15° 分度、中心度 ±7.5 校验 |
| FM-06 | 联网失败无回退 | 地理编码失败即中断 | 降级提示改用坐标或读图，必要时回退离线模式 |
| FM-07 | 数据读取异常 | 方位库 JSON 缺失致脚本报错 | 读取前校验文件，异常时提示并重试 |
| FM-08 | 位置滥用 | 报告暴露精确住址或挪作他用 | 仅作方位比对，输出做必要模糊 |
| FM-09 | 密度不足 | 报告章节只有标题无内容 | 每章 300 字下限，交付前核算 |
| FM-10 | 流派混说 | 形势派与理气派说法混杂 | 以形势派为主线，明确所取口径 |

## 十、输出规范

- **方位查询（L1）**：格式为「方位 X° → 【山名】山（某宫，五行 X）→ 说明 → 免责」。
- **报告（L3）**：七章结构——点位概览／周边要素／四神砂参照／形煞文化解读／二十四山与坐向／典籍背景／说明与免责。
- 引用典籍一律保留书名号与原文，不转述替代原文。
- 位置信息只作方位比对，不作其他展示。

**默认配图**：报告默认内嵌两张示意图——图 1「四神砂方位示意」（对应三章）、图 2「二十四山罗盘示意」（对应五章）。两图由 `scripts/diagram.py` 程序化绘制为 SVG，随报告生成并 base64 内嵌，零外部依赖、零版权风险；输出目录下会同步留存 `images/` 原图。图注已声明为文化知识图解，不含吉凶判断。加 `--no-images` 可关闭配图。
