## 二、简介（发布用）

堪舆文化——中国传统建筑环境文化（堪舆/风水）的研究与了解工具。按地址或坐标检索周边环境要素（水体、道路、建筑、文教、医疗、宗教），对照传统四神砂格局与形煞民俗逐一作文化解读；内置二十四山罗盘刻度与后天八卦方位，可查询坐向、方位、五行与卦宫，并输出结构清晰的可视化 HTML 报告。收录 24 山、8 宫、4 神砂、12 条形煞与 12 部堪舆典籍条目，整理自公有领域资料。定位为传统文化研究工具，不作吉凶预测。

## 三、使用说明（6 条）

1. 给出地址或坐标，会检索周边环境要素并按传统格局作文化解读。
2. 想查方位，给出度数，会得到所属山名、卦宫与五行。
3. 想问某个形煞，直接说名称（如「路冲煞」「反弓煞」）。
4. 想查二十四山或某卦所辖，说「二十四山」或卦名即可。
5. 需要成文，可要求生成完整 HTML 报告。
6. 报告末尾附免责声明，内容属传统文化研究范畴。

## 四、使用示例

```
用户：某市某区人民政府周边的环境，按传统风水怎么看？
产出：检索周边水体/道路/建筑等要素，按四神砂方位对照，并列出传统形煞提示与文化解读，
     末尾附免责声明，不作吉凶判断。

用户：坐向 120° 是什么山？
产出：【辰】山（巽宫，五行土），辖 112.5°—127.5°。
```

## 五、适用场景

- 了解堪舆（风水）这一传统建筑环境文化
- 阅读《葬书》《雪心赋》等典籍时查证概念
- 查询二十四山、八卦方位的对应关系
- 以某一地点为例，对照传统环境观
- 创作与传统文化、建筑人文相关的文稿时取用素材

## 六、边界声明

**不适用于**：购房选址决策、墓址选择决策、投资判断、医疗与法律事项，以及任何形式的吉凶预测。

本技能内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。
