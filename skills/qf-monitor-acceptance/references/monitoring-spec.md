# 调试检测、安装与联网验收要求及脚本参数

## 一、调试检测五项性能指标

| 指标 | 含义 | 操作要点 |
|---|---|---|
| 零点漂移 | 仪器在零点附近读数的漂移 | 用零点校准液连续测定，记录 24h 漂移量 |
| 量程漂移 | 仪器在量程浓度点读数的漂移 | 用量程校准液连续测定，记录 24h 漂移量 |
| 重复性 | 同一样品多次测定的离散程度 | 同一标准液连续测定 6 次，计算相对标准偏差 |
| 示值误差 | 测定值与标准值的偏差 | 用标准溶液比对，计算相对误差 |
| 实际水样比对 | 现场水样在线值与实验室值偏差 | 按下文比对限值判定 |

上述检测须在稳定工况下实施，量程、校准曲线、报警限值一并记录。

## 二、安装验收要点
- 排放口位置具备代表性，测流段满足堰槽安装的直线段要求。
- 监测站房面积、通风、温湿度满足仪器要求；供电配稳压电源，配备 UPS；给排水满足试剂配制与废液收集。
- 采样管路材质耐腐蚀、易清洗、防堵，采样泵扬程与流量匹配。
- 数据控制单元具备断电保护、来电自恢复、数据本地存储与远程传输功能。
- 防雷接地、消防器材、防盗设施齐备。

## 三、联网验收要点
- 传输方式：有线或无线，通信协议符合平台要求。
- 上传平台：属地生态环境部门污染源监控平台。
- 传输率、运转率、时段数据完整性核验。
- 时间戳与数据同步一致，异常数据有标记。

## 四、比对限值与判定
依据 HJ 355-2019：

| 参数 | 判定指标 | 限值 |
|---|---|---|
| pH | 绝对误差 | ≤±0.5 |
| 流量 | 相对误差 | ≤±10% |
| CODcr/氨氮/总磷/总氮 | 相对误差或绝对误差（按量程段） | 以标准原文与许可量程为准 |

## 五、脚本参数

### compare_checker.py
```
python3 scripts/compare_checker.py -i 比对数据.csv -o 判定结果.csv
```
输入 CSV 列：参数, 在线值, 实验室值, 限值类型(rel/abs), 限值。
输出：各参数误差值、是否合格、超限幅度、总体结论。退出码 0（全部合格）/ 1（存在超限）。

### acceptance_report_builder.py
```
python3 scripts/acceptance_report_builder.py --type acceptance -o 验收报告框架.md
python3 scripts/acceptance_report_builder.py --type comparison -o 比对检测报告框架.md
```
生成章节齐全、字段以【待填：xx】占位的 Markdown 框架。

### report_docx_builder.py
```
python3 scripts/report_docx_builder.py -i 报告.md -o 报告.docx
```
Markdown 标题挂接 Heading 1/2/3，插入可一键更新目录域与页码。
