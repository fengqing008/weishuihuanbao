# 两类报告章节骨架与逐章要点

## 一、在线监测系统验收报告（八章）

### 1. 封面与基本信息
报告编号、企业名称、组织代码、排放口编号与名称、点位名称、运行单位、委托验收单位、验收日期。表格化填写，编号规则与备案系统一致。

### 2. 系统构成与设备配置
逐台列示：流量计、水质自动采样器、CODcr/氨氮/总磷/总氮/pH 分析仪的型号、出厂编号、测量原理、量程、安装位置、生产厂家。型号与编号须与备案清单逐字一致。

### 3. 安装验收
按 HJ 353-2019 分五单元核查：

| 验收单元 | 核查要点 |
|---|---|
| 排放口 | 位置代表性、测流段顺直、安全防护 |
| 流量监测单元 | 堰槽规格、液位零点、安装水平度 |
| 监测站房 | 面积、供电、给排水、温湿度、防雷接地、消防 |
| 采样单元 | 采样泵、管路材质、防堵、反冲洗 |
| 数据控制单元 | 数采仪、通信模块、UPS、接地、网络安全 |

每单元给出"符合/不符合"与结论。

### 4. 调试检测报告
列五项性能指标实测数据：零点漂移、量程漂移、重复性、示值误差、实际水样比对。附量程设置、校准曲线、报警限值。

### 5. 基本功能与应用要求
自动采样、数据采集与传输、异常报警、断电保护与来电自恢复、数据存储（不少于规定时长）、网络安全核查。

### 6. 比对监测验收
比对项目、点位、方法、限值、在线值与实验室值、误差值、判定结论。对应"表5 比对监测验收"。

### 7. 联网验收
传输方式、上传平台名称、传输率、数据完整性、时间戳一致性。对应"表6 联网验收"。

### 8. 结论与附件
安装调试报告主要结论、安装验收结论、设备资质认证证书与检测报告清单（含环保产品认证证书、环境监测仪器质检中心检测报告）。

## 二、比对检测报告（七章）

### 1. 声明
报告有效性、复制要求、异议期限、结果适用范围等条款。

### 2. 检测内容
检测点位、检测项目、监测频率一览表；样品基本情况表；污水处理设施基本情况表（设计处理能力、实际处理能力、工况）。

### 3. 检测仪器及分析方法
各参数所用实验室方法、检出限、在线仪器型号与编号。

### 4. 质量控制
空白样、平行样、加标回收、质控样措施说明。

### 5. 质量控制结果
全程序空白检测结果、实验室质控样检测结果、质量控制检测结果。

### 6. 检测结果
各参数在线值与实验室值对照表，计算相对误差或绝对误差。

### 7. 结果评价与附图
按 HJ 355-2019 限值判定合格与否；附设备现场打印图、数据日志、点位图。

## 三、通用要求
- 时间基准一致：验收日期、调试起止日期、比对日期、联网日期须能相互衔接。
- 数据可溯源：每个检测值可回溯到原始记录或检测报告页码。
- 附件齐全：设备资质认证证书、检测报告、比对检测报告、联网截图。
