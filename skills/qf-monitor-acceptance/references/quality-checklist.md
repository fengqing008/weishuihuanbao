# 交付质检清单

交付前逐项核查，全部通过方可交付。

## 一、资料完整性
- [ ] 设备清单、安装记录、调试检测记录、比对检测报告、联网记录齐全
- [ ] 排污许可证复印件或编号已附
- [ ] 设备资质认证证书、检测报告作为附件完整附后
- [ ] 验收工作组或责任签署记录齐备

## 二、数据准确性
- [ ] 各参数比对误差按判定指标计算正确（pH 用绝对误差、流量用相对误差）
- [ ] 低浓度段按绝对误差、高浓度段按相对误差，判别正确
- [ ] 设备运转率、数据传输率按公式实测
- [ ] 每个检测值可回溯到原始记录或检测报告页码
- [ ] 时间基准一致（调试、比对、联网、验收日期相互衔接）

## 三、一致性
- [ ] 设备型号、出厂编号与备案清单逐字一致
- [ ] 点位名称与许可载明一致
- [ ] 报告编号规则与备案系统一致
- [ ] 附件清单与正文引用一一对应

## 四、格式规范
- [ ] Word 标题挂接 Heading 1/2/3 大纲级别
- [ ] 目录域可一键更新生成目录
- [ ] 表格有表头、有编号、有单位
- [ ] 页码连续、附件有页码
- [ ] 无【待填】占位残留（交付稿须全部落实）

## 五、判定口径
- [ ] 标准引用为 HJ 353/354/355/356-2019 现行版本
- [ ] 判定结论明确"合格/不合格"，不含模糊表述
- [ ] 超限项已整改复测，附整改与复测记录
