# 失败模式手册

| 编号 | 失败模式 | 根因 | 处置与防复发 |
|---|---|---|---|
| FM-01 | 依据错版本 | 沿用 HJ/T 354-2007，未更新为 HJ 354-2019 | 核对标准年代号，全部改为 2019 版；建立标准现行版本清单 |
| FM-02 | 型号编号不一致 | 报告与备案清单存在字符差异 | 逐字核对型号与出厂编号；建立型号编号对照表 |
| FM-03 | 两率估计填报 | 未按公式实测运转率与传输率 | 按实际运行小时数与应运行小时数计算，留存计数记录 |
| FM-04 | 比对超限未整改 | 直接把超限值写为合格 | 查明原因、整改后复测；附整改与复测记录 |
| FM-05 | 点位与许可不符 | 现场新增点位未在许可载明 | 先办理许可变更，再纳入验收 |
| FM-06 | 原始记录涂改 | 为凑合格数字涂改打印记录 | 保留原始记录并另附说明；此为红线 |
| FM-07 | 判定指标误用 | 低浓度段误用相对误差判定 | 按量程段选择判定指标，核对标准附表 |
| FM-08 | 附件缺失 | 设备资质证书、检测报告未附 | 逐份补齐并编页码，附清单 |
| FM-09 | 时间基准错乱 | 调试、比对、联网日期矛盾 | 建立时间轴，核对各节点先后关系 |
| FM-10 | 他人报告套用 | 直接套用其他项目报告未核对点位参数 | 以本项目许可与设备清单为准，逐项替换 |
| FM-11 | 断电保护漏验 | 未核查来电自恢复与数据存储时长 | 按 HJ 353-2019 基本功能逐项核查 |
| FM-12 | 数据无源 | 检测值无法回溯原始记录 | 每个检测值标注来源页码，建立溯源索引 |

## 反例（禁止做法）
- 以出厂合格证替代现场安装验收；
- 排污单位自行比对充当验收依据；
- 运转率或传输率不达标仍判合格；
- 报告设备编号与备案不一致即归档。
