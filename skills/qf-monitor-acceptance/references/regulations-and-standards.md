# 法规标准矩阵与限值明细

## 一、核心规范

| 编号 | 名称 | 关键内容 |
|---|---|---|
| HJ 353-2019 | 水污染源在线监测系统（CODCr、NH₃-N 等）安装技术规范 | 排放口、流量监测单元、监测站房、采样单元、数据控制单元的安装要求 |
| HJ 354-2019 | 水污染源在线监测系统（CODCr、NH₃-N 等）验收技术规范 | 验收条件、验收程序、验收内容、验收判定 |
| HJ 355-2019 | 水污染源在线监测系统（CODCr、NH₃-N 等）运行技术规范 | 运行维护、比对限值、质量控制、数据审核 |
| HJ 356-2019 | 水污染源在线监测系统（CODCr、NH₃-N 等）数据有效性判别技术规范 | 数据有效性判别、异常数据处置 |

上述四项代替 HJ/T 353-2007、HJ/T 354-2007、HJ/T 355-2007、HJ/T 356-2007。编制时一律引用 2019 版。

## 二、参数与技术要求

| 参数 | 安装要求要点 | 主要性能指标 |
|---|---|---|
| pH | 电极安装于代表性位置，具备自动清洗 | 零点漂移、量程漂移、重复性、示值误差 |
| 化学需氧量 | 采样管路易清洗、防堵 | 零点漂移、量程漂移、重复性、示值误差、实际水样比对 |
| 氨氮 | 试剂补给与废液收集规范 | 同上 |
| 总磷 | 消解单元温度可控 | 同上 |
| 总氮 | 消解与比色单元稳定 | 同上 |
| 流量 | 明渠流量计安装符合堰槽规范 | 液位与流量比对 |

## 三、比对限值口径（HJ 355-2019）

| 参数 | 判定指标 | 限值口径 |
|---|---|---|
| pH | 绝对误差 | ≤±0.5（无量纲） |
| 流量 | 相对误差 | ≤±10% |
| 化学需氧量 | 相对误差 | 按量程段取值，常见 ≤±15%，低浓度段按绝对误差 |
| 氨氮 | 相对误差 | 按量程段取值，低浓度段按绝对误差 |
| 总磷 | 相对误差 | 按量程段取值，低浓度段按绝对误差 |
| 总氮 | 相对误差 | 按量程段取值，常见 ≤±15%，低浓度段按绝对误差 |

具体限值以 HJ 355-2019 原文及排污许可证载明的量程为准。低浓度段判定指标的选择，须核对标准附表，不得统一按相对误差判定。

## 四、设备运转率与数据传输率

- 设备运转率 = 实际运行小时数 ÷ 企业排放小时数 × 100%
- 数据传输率 = 实际传输数据量 ÷ 应传输数据量 × 100%

两率按规定值考核，未达标不得判定联网验收合格。

## 五、实验室分析方法

| 参数 | 方法标准 |
|---|---|
| pH | 《水质 pH 值的测定 电极法》HJ 1147-2020 |
| 化学需氧量 | 《水质 化学需氧量的测定 重铬酸盐法》HJ 828-2017（检出限 4 mg/L） |
| 氨氮 | 《水质 氨氮的测定 纳氏试剂分光光度法》HJ 535-2009（检出限 0.025 mg/L） |
| 总磷 | 《水质 总磷的测定 钼酸铵分光光度法》GB 11893-1989（检出限 0.01 mg/L） |
| 总氮 | 《水质 总氮的测定 碱性过硫酸钾消解紫外分光光度法》HJ 636-2012（检出限 0.05 mg/L） |
