# 某水务集团实测案例库

本案例库提炼自某水务集团项目实际验收与比对文件，作为编制参照。

## 案例一 某城区污水处理厂在线监测系统验收

- 排污单位：某运营单位（运营）；运行单位：某第三方运维单位。
- 监测参数：pH、CODcr、NH₃-N、TP、TN 及明渠流量。
- 关键数据：设备安装符合 HJ 353-2019；调试及试运行指标满足 HJ 354-2019；设备运转率与数据传输率均为 100%；比对监测与联网验收合格。
- 材料结构：封面及基本信息 → 单元验收 → 表5 比对监测验收 → 表6 联网验收 → 附件一（设备资质认证证书与检测报告，含 CODmax II 型 COD 分析仪、CA80AM 型氨氮分析仪的中国环境保护产品认证证书与质检中心检测报告）。
- 可借鉴点：设备资质证书与检测报告作为独立附件整体附后，编号连续；验收单元按"排放口—流量—站房—采样—数据控制"五段组织。

## 案例二 某市生物医药产业园污水处理厂在线监测设备验收

- 结构特点：排污单位情况、设备安装与功能验收、监测参数配置、比对监测、调试检测、168 小时连续试运行数据。
- 关键结论：COD、氨氮、总磷、总氮及流量计在稳定性、准确性、合规性方面满足 HJ 354-2019；运转率与数据传输率 100%。
- 可借鉴点：以"168 小时连续试运行"作为稳定性证据单列一节；资质与试运行数据分列附件。

## 案例三 某城区污水处理厂一季度在线监测设备比对检测

- 出具机构：湖北华正环境检测技术有限公司；检测项目：pH、化学需氧量、氨氮、总磷、总氮、流量。
- 报告结构：声明 → 一、检测内容 → 二、检测仪器及分析方法 → 三、质量控制 → 四、质量控制结果 → 五、检测结果 → 六、结果评价 → 七、附图。
- 评价依据：HJ 355-2019 运行技术规范限值（pH 绝对误差 ≤±0.5，流量相对误差 ≤±10%，总氮相对误差 ≤±15% 等）。
- 可借鉴点：质量控制结果以"表5 全程序空白、表6 实验室质控样品、表7 实验室质量控制"三表呈现；检测结果按参数分表并给出误差列。

## 使用提示
- 案例中的单位名称、报告编号为真实项目信息，套用时不得直接复制到其他项目，须替换为本项目信息。
- 168 小时试运行、运转率与传输率 100% 属项目实测结果，不得作为通用结论套写。
