## 三、选用规则

| 场景 | 首选 | 备选 | 判断依据 |
|---|---|---|---|
| 领导汇报、数据仪表盘 | 深海蓝调 | 现代极简 | 深底衬数据，观感专业 |
| 投资与财务分析 | 午夜星河 | 极地霜白 | 深底适合大表格，浅底适合打印 |
| 行业研究与长文 | 森林冠层 | 植物园 | 低饱和，长时间阅读不疲劳 |
| 学术与政策解读 | 极地霜白 | 现代极简 | 中性色压住主观色彩 |
| 技术前沿与产品发布 | 科技创新 | 深海蓝调 | 高对比蓝黑契合技术叙事 |
| 市场与品牌传播 | 日落大道 | 沙漠玫瑰 | 暖色有传播亲和力 |
| 环保与 ESG | 植物园 | 森林冠层 | 绿色系与环境议题语义一致 |
| 纸质打印分发 | 极地霜白 | 现代极简、森林冠层 | 浅底深字墨耗低、灰度还原好 |

一页只用一套配色。需要多套时用于多份交付物之间区分，不在同一页内混用。

## 四、CSS 变量约定

| 变量 | 含义 | 使用位置 |
|---|---|---|
| `--bg` | 页面底色 | body |
| `--surface` | 卡片与页头背景 | .card / .topbar |
| `--surface-2` | 次层背景 | 表头、条纹行 |
| `--text` | 正文色 | 正文、标题 |
| `--muted` | 弱化文字 | 副标题、注释、页脚 |
| `--accent` | 强调色 | 链接、小标题、角标 |
| `--accent-2` | 辅色 | 渐变、装饰 |
| `--accent-soft` | 强调色浅底 | 标签底、选中态 |
| `--on-accent` | 强调块上的文字 | 编号徽标、实心按钮 |
| `--border` | 边框与分隔线 | 表格、卡片 |
| `--hero-1` / `--hero-2` | 页头渐变两端 | .hero |
| `--hero-text` | 页头文字 | .hero 标题与说明 |
| `--ok` / `--danger` | 语义色 | 达标/风险标记 |

生成与取用：

```bash
python3 "$S/scripts/palettes.py" css --theme ocean          # 单套变量块
python3 "$S/scripts/palettes.py" css > themes.css           # 十套全量
python3 "$S/scripts/palettes.py" json > themes.json         # 机器可读
```

## 五、自定义主题流程

一、定三色：主强调、页面底、正文色，从场景语义出发取色。
二、派生容器色：卡片底取底色向白或向黑偏移 6%—10%，`palettes.py` 的 `mix()` 可直接调用。
三、派生弱化色：正文向底色混 45%—55%，保证弱化文字对卡片底 ≥4.5。
四、派生边框色：底色向强调色或中性灰偏移 15%。
五、跑门禁：把变量写入页面的 `[data-theme]` 块后执行 `html_check.py`，CONTRAST 项须为 OK。
六、登记：把新主题补进 `palettes.py` 的 `RAW` 列表，复跑 `palettes.py check` 保证十套以上全部达标。

## 六、常见错误

- 深底主题配浅色卡片：正文与卡片底对比骤降，改用同族深色卡片。
- 把装饰性辅色当强调色用于小字链接：辅色门禁为 3.0，不足以承载正文级信息。
- 用透明度（`opacity`）制造弱化文字：打印时叠加失效，改用 `--muted` 实色。
- 强调色直接铺在大块背景上承载长文本：大面积高饱和底导致阅读疲劳，仅用于徽标、按钮与角标。
- 深底配色用于纸质分发：灰度后层次糊在一起，换亮底主题。
