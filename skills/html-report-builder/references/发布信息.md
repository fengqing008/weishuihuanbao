## 简介（中文）

把报告、说明书、方案、汇报、试题输出为单文件自包含 HTML——离线可开、可直接打印。内置 10 套经 WCAG 对比度校验的配色、来源分级与可追溯标注、信息缺口徽标、自动目录与返回顶部；支持 KaTeX 数学公式、八大画板、图表（bar/donut/line/area）、图片内嵌与内容动效。v6.0 补齐无障碍（焦点可见、跳至正文、表头 scope、aria-current）、分享卡片（Open Graph）、打印版心与局部避断、图片放大、目录搜索、长表排序、跟随系统深色，并增强动画层。适用于成果页、可视化报告与网页版汇报。

## 简介（English）

Turn reports, decks and exam papers into one self-contained HTML file — offline-ready and print-friendly, with 10 WCAG-checked palettes, auto TOC, 17 structural checks, KaTeX math and 8 board components.

## 使用示例（7 条）

1. **把可研报告转成果页**：「把这份可研报告做成 HTML 成果页，用深海蓝配色」——输出单文件 HTML，含目录、来源分级、缺口区块。
2. **数据报告加图表**：「这份水质分析要 KPI 卡和折线图」——`:::kpi` 与 `:::chart line` 围栏自动渲染。
3. **深色 + 侧栏目录**：「给这篇访谈做成深色配色、侧栏目录的 HTML」——`--style dark --layout sidebar`。
4. **交付前自检**：「检查这个成果页的对比度、结构与无障碍」——`html_check.py` 全量校验（对比度、锚点、围栏、体积、焦点、跳转、分享元信息、打印规则等）。
5. **带公式的试题**：「把这份带公式的试题排成 HTML 试卷」——KaTeX 数式 + `:::q-card` 三段式。
6. **打印分发**：「这份要打印发给对方」——@page 版心 + 跨页重复表头，长章节不再断出大片空白。
7. **看细节**：「这张图看不清」——图片可点击放大（lightbox），移动端目录支持搜索。

## 常用命令

```bash
# Markdown → 单文件 HTML（主入口）
python3 scripts/md2report.py 成稿.md -o 成果页.html --theme forest --check

# 深色配色 + 侧栏目录 + 数学公式
python3 scripts/md2report.py 成稿.md -o 成果页.html --style dark --layout sidebar --math

# 查看十套配色
python3 scripts/palettes.py --list
```
