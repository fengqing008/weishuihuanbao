# 配图路由规范（illustration-routing.md）

> 适用技能：html-report-builder **v5.3.0** 起。规定「不同成果文件用哪种配图、用哪种 ima 生图类型、色调如何与文档主题一致」，以及画质与体积的取舍。
> 图形类可视化（流程图/时序图/架构图）见 `diagrams-guide.md`；本文只管「插图」。

## 一、触发规则：按需配图

**默认不配图。** 仅当用户明确要求（「配图 / 加图 / 插图 / 来几张图 / 给某章配图」）时才执行配图链。
未明确要求时，正文可视化由**图形围栏**（```` ```mermaid ````）与**文字化图表**（`:::chart` / `:::timeline` / `:::matrix` / `:::phase`）承担，不调用任何出图。

## 二、ima 生图类型库（11 种）

`illustrate.py styles` 可速查。`tone=True` 的类型会注入文档主题色卡（见第四节）。

| 类型 id | 名称 | 适用成果 | 注入色卡 |

| flat-vector | 扁平矢量插画 | 政务公文、政策解读、流程说明、科普 | 是 |
| editorial | 杂志编辑插画 | 文章、散文、评论、杂谈 | 是 |
| handdrawn-warm | 暖调手绘水彩 | 生活、文化、游记、亲子、情感 | 是 |
| tech-abstract | 科技抽象 | 技术前沿、AI、数字化、产品发布 | 是 |

判定方式：对全文（frontmatter + 全部标题 + 正文）做关键词投票，得分最高者为路由结果；全为 0 时默认**实景图**（报告类最常见）。
`--source` 覆盖配图源，`--style` 覆盖 ai 通道的生图类型。

```bash
python3 illustrate.py styles                              # 列出 11 类生图类型 + 17 类成果路由
python3 illustrate.py route 成稿.md --theme sunset        # 查看成果类型/配图源/生图类型/色卡
python3 illustrate.py route 成稿.md --source photo        # 人工覆盖配图源
python3 illustrate.py route 成稿.md --style editorial     # 人工覆盖 ai 生图类型
```

散文/文章类（ai 通道）自动切换为 **article 模式**：配图点识别不再要求标题含视觉关键词，篇幅 ≥60 字的章节即可入选，使散文、随笔也能配图。

## 四、配图色调与主题色一致

配图须与全文主题色协调，避免「一张冷色调配图插进暖色报告」的突兀感。

1. **ai 通道**：`build_prompts` 把主题色卡注入中英提示词——主色 `accent`、辅色 `accent2`、底色 `bg`，并要求「低饱和、与文档主题色统一协调、避免冲突的高饱和杂色」。
2. **线稿通道**：`--palette auto` 按主题色温就近映射（下表），也可 `--palette` 直接指定。
3. **实景图通道**：以内容真实性为先，不强制改色；由版面（主题色标题、图注样式）统一观感。
4. `--theme` 传配色 id（如 `sunset`），未指定时从成稿 frontmatter 的 `theme:` 读取，再退回默认。

**线稿主题映射表**（`--theme` → `--palette`）：

| 主题 | 线稿配色 | 主题 | 线稿配色 |
|---|---|---|---|
| ocean / minimal / arctic / tech / galaxy | ink（墨黑，冷色/深色主题） | sunset | terracotta（陶土） |
| forest / botanical | olive（暖橄榄） | golden | amber（暖金） |
| desert | rosewood（玫瑰木） | （未识别主题） | sepia（暖褐，默认） |

## 五、三条通道的操作

### A. 实景图通道（调研/规划类，优先）

```bash
python3 illustrate.py plan 成稿.md --source photo --theme forest --max 4
# → 生成 illustration/plan.md：每张给出 search_query 与检索要求
# 联网检索真实照片（政府/官方媒体/景区官网/权威图库优先），下载原图到 images/，命名 photo_01.jpg…
python3 illustrate.py apply 成稿.md --plan illustration/plan.json
```

- 实景图**不加**「AI 配图」角标（是真实照片，非生成图）；
- 图注须标注来源（形如「图 1 …（图源：XX）」）；
- 优先真实实景照片：自然光、真实质感、无 CGI/插画/渲染感；避免摆拍模特图与人像特写。

### B. ima 商业插画通道（文章/散文/文化类）

```bash
python3 illustrate.py plan 成稿.md --source ai --style editorial --theme sunset
# → 生成中英提示词（含主题色卡）；逐张调用 image_gen 出图到 images/，命名 ai_01.jpg…
python3 illustrate.py apply 成稿.md --plan illustration/plan.json
```

- 插画**加**「AI 配图」角标；
- 出图后必经像素校验（边缘均值 ≥5，拦纯色/大片渐变）。

### C. 线稿通道（技术/工程/内部材料）

```bash
python3 illustrate.py lineart 成稿.md --max 3 --palette auto --theme sunset --stroke pencil
# --palette auto 按 --theme 映射；也可显式 sepia/ochre/amber/terracotta/rosewood/olive/ink
```

## 六、画质与体积（画质优先）

**不追求最小体积，避免过度压缩损伤画质。**

| 项 | 触发值 / 默认值 |
|---|---|
| 触发压缩的阈值 | **900KB**（低于阈值不压缩） |
| 瘦身长边上限 | **1920** |
| JPEG 质量 | **q92** |
| 含图页体积上限 | `--max-kb 2000`（3—4 张高清图可用 2400） |

- 确需瘦身时可调 `--max-side` / `--quality` / `--threshold-kb`；
- 需要完全保留原图：`apply --no-compress`；
- 单文件自包含仍要求：图片 base64 内嵌。

## 七、综合美观约定

- 统一横图比例 16:9（1536×864），封面 1536×640；
- 提示词固定含「主体突出、留白充足、层次清晰、光线柔和统一」；
- 同一文档所有配图使用**同一生图类型**，整册风格统一，不混搭；
- 图注自动编号（图 1、图 2…）全篇连续，与 mermaid 图形共用计数器。

## 八、边界

- 数据类一律用 `:::chart` 或表格，不用配图承载数值；
- 实景图须**来源可追溯**，禁止用 AI 图冒充实景图；
- AI 生成图必须带「AI 配图」角标，与实拍图、线稿图在视觉上区分；
- 版权与合规：实景图仅用于内部或已授权范围的说明用途，对外发布须标注来源。
