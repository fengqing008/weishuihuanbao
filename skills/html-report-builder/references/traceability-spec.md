# 可追溯与来源标注规范（traceability-spec）

本规范把「信息收集与整理 v3.0」的来源分级、缺口标注、事实与观点分离三项机制落到 HTML 页面结构上。

## 一、来源分级

| 级别 | 来源类型 | 进页规则 |
|---|---|---|
| P0 | 政府官方文件、上市公司财报、国际组织报告 | 可作基准数据，进正文与结论 |
| P1 | 权威咨询机构（Gartner / IDC / 麦肯锡等） | 标注发布日期，超两年标时效风险 |
| P2 | 主流财经媒体（Reuters / Bloomberg / 36氪等） | 可作佐证，单一来源不支撑关键结论 |
| P3 | 行业垂直媒体、分析师 | 需交叉验证，页内注明"据 XX" |
| P4 | 社交媒体、论坛 | 只作市场情绪参考，不进数据区 |

## 二、三类标注的写法

来源角标（跟在数据后，标注级别）：

```html
污水处理服务费单价 <b>2.68 元/吨</b><span class="src">P0</span>
```

缺口徽标（黄底高亮，写明待核事项）：

```html
<span class="gap">【待核：2026 年一季度回款数据来源】</span>
```

观点块（与事实叙述分离，左侧色条并自动加"观点"标签）：

```html
<div class="quote">行业普遍判断补贴退坡将在两年内落地，该判断来自券商研报，尚无政策文件支撑。</div>
```

三条附加规则：

- 单一来源的关键数据，在角标后追加 `[单一来源，待交叉验证]`。
- 两个来源数据矛盾时并列两组数值与各自角标，页内不替读者裁决。
- 数据年份距交付日超过两年，角标处追加 `[数据截至 YYYY，时效性待确认]`。

## 三、来源区块

页面末尾固定挂"参考来源"区块，逐条列出出处与级别：

```html
<section id="sources">
  <h2>参考来源</h2>
  <table>
    <thead><tr><th style="width:52%">来源</th><th style="width:12%">级别</th><th>备注</th></tr></thead>
    <tbody>
      <tr><td>《关于规范政府和社会资本合作存量项目建设和运营的通知》（国办函〔2023〕115 号）</td><td>P0</td><td>2023 年发布</td></tr>
    </tbody>
  </table>
</section>
```

页脚固定挂数据来源行与成文日期，便于单页转发后仍能追溯：

```
数据来源：XXX（P0）　·　落款单位：XXX　·　成文日期：2026年9月21日
```

## 四、缺口区块

页面出现任何缺口徽标时，必须配套"信息缺口与风险"区块，三列结构：

| 缺口 | 不填补的影响 | 建议补充渠道 |
|---|---|---|
| 缺 2026 年一季度回款台账 | 回款率测算按上年均值估算，误差可能超过 5 个百分点 | 财务部季度报表、银行流水 |

## 五、六项自检

| 检查项 | 判定标准 | 不通过的修复动作 |
|---|---|---|
| 目的一致性 | 每节都能回答"这如何服务于读者要做的动作" | 删除无关章节 |
| 来源完整性 | 关键数据均有角标，末尾有来源区块 | 补角标与来源条目 |
| 缺口诚实度 | 缺口有徽标且进入缺口区块 | 补徽标与区块行 |
| 事实与观点分离 | 观点性内容进观点块 | 移入观点块 |
| 时效性 | 超两年数据有标注 | 补时效标注 |
| 矛盾暴露 | 来源矛盾并列呈现 | 补双版本数值 |

## 六、漏标高发场景

- 表格内的数字：表格易被当作"自带来源"，每一列的关键数值仍需角标。
- 图注与图表：图表下方写数据来源与统计口径。
- 转述他人结论：注明原始出处，不注明中转媒体。
- 预计值与测算值：标明"测算"字样与测算依据，不用确定性表述。
- 引用政策原文：引全称与发文字号，缩略语首次出现时定义。
