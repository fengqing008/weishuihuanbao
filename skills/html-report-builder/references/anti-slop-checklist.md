# 反 AI 模板化 · 视觉产出检查清单 v1.0

> **定位**：所有视觉类产出——单文件 HTML 报告、公众号推文、卡片、汇报页、界面/落地页——交付前的审美质检件。
> **来源**：Taste Skill（github.com/Leonxlnx/taste-skill，MIT）+ Impeccable（github.com/pbakaus/impeccable，Apache-2.0）+ WCAG 2.2 + 中文字体栈实践。
> **收编日期**：2026-10-01。**权威版**：本文件；各技能 references/ 下同名文件为副本，以本版为准。
> **用法**：生成前先答"四问"（页面类型 / 品牌气质 / 信息密度 / 动效强度）；生成后逐条核对；命中**硬红线任意一条即回退**。

---

## 一、硬红线（AI 套路黑名单，命中即改）

### 1. 字体（中英混排必须显式字体栈）
- 禁止用 Inter / Roboto / Arial / 系统默认裸字体承担正文与标题。
- 中文字体栈示例：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Source Han Sans SC", sans-serif`；正文与标题可用同一族不同字重制造层级。
- 衬线体（宋/楷/思源宋）仅在**有明确品牌或文体理由**时使用，不作默认。
- 中文行高 ≥ 1.6（正文 1.7 更佳）；不用等宽英文字体排版中文。

### 2. 配色（避开收敛套路）
- 禁止"紫→蓝渐变"（如 `#8b5cf6 → #6366f1`、`#a855f7 → #3b82f6`）作默认 hero / accent。
- 禁止直接使用纯黑 `#000` / 纯白 `#fff`；改用近邻（`#0f172a` / `#111827`、`#fff` 配 `#f8fafc`）。
- 禁止在彩色背景上放低对比灰字。
- 全篇只用一套主题色系；强调色与辅色有明确分工，不混色。

### 3. 对比度（WCAG 2.2）
- 正文 / 背景（含卡片）≥ **4.5:1**；大字号（≥24px 或 ≥18.66px 且粗体）≥ **3:1**。
- 图标、边框、图表线 ≥ **3:1**；不以低对比装饰性文字承载关键信息。

### 4. 布局
- 禁止"居中 hero + 三等分特性卡片 + 大圆角"万能模板照搬。
- 禁止卡片套卡片（card in card）；禁止对全部元素套同一个大圆角。
- 网格/Bento 中留出**视觉多样性**：至少 2–3 个单元用真实图片、品牌渐变或差异化卡片，避免清一色色块。
- 标题与正文有明显字号/字重落差（建议 ≥1.5×），信息层级一眼可辨。
- 留白有**疏密节奏**，不是均匀松垮；密集页（表格/看板）不得用低密度大间距交付。

### 5. 动效
- 禁止 bounce / 弹性缓动（`cubic-bezier` 回弹）作默认。
- 各过渡时长不一味统一；动效须承载语义（引导、反馈、层级）。
- 必须支持 `prefers-reduced-motion`。

### 6. 交互与无障碍
- 禁止移除 focus ring、或用 `outline: none` 静默键盘可见性。
- 禁止仅靠 hover 可达的交互（触屏不可达）。
- 触控目标 ≥ **44×44 px**，相邻目标间距 ≥ **8 px**。
- 禁止只有图标的按钮而无可访问名称（`aria-label` / 可见文本至少一项）。
- 禁止用 Emoji 充当功能图标。
- 禁止把 Placeholder 当唯一字段标签。
- 禁止仅用颜色传达信息（图表/状态须另有图例、形状或文字）。

### 7. 中文本地化
- 中英文标点不混排错误（中文正文用全角标点，代码/英文词内用半角）。
- 金额千分位、日期标全（与既有写作规范一致）。
- 段首缩进/对齐方式统一，标题层级连续不跳级。

## 二、需复核项（按场景判断，非一律回退）

| 项 | 复核要点 |
|---|---|
| 品牌 vs 产品双模式 | 落地页（品牌/营销）与应用后台（产品/工具）用不同的默认密度与动效 |
| 视觉多样性 | 是否有"统计上最安全"的均齐感；有无刻意的不对称、错落、重点放大 |
| 图片 | 优先真实图片（平台 `search format=image`，禁用 AI 生成真实照片）；AI 生成图须加「AI 配图」角标 |
| 图标体系 | 同一页面图标风格统一（线性/填充不混用） |
| 深色模式 | 不照搬亮色对比度；重新校验 |
| 响应式 | 小屏（375px）无横向滚动；移动端底部主导航 ≤ 5 项 |

## 三、执行方式（三件套）

1. **生成前**：答四问——①页面类型（品牌落地 / 产品后台 / 报告 / 推文卡）②品牌气质（克制高级 / 鲜明活力 / 编辑杂志 / 工业直白）③信息密度（低 / 中 / 高）④动效强度（静 / 轻 / 显）。
   - 对应 Taste Skill 三旋钮：设计要求方差 `DESIGN_VARIANCE`、动效强度 `MOTION_INTENSITY`、视觉密度 `VISUAL_DENSITY`（各 1–10）。
   - 对应 Impeccable 双模式：`brand`（营销/落地/作品集）与 `product`（应用/后台）。
2. **生成后**：跑本清单 + 对应技能自带质检（html-report-builder 用 `html_check.py`；推文用 `quality-checklist.md`；文本用 `report_checker_pro.py`）。
3. **交付前**：逐条核对；任一硬红线命中即回退，不宣告完成。
