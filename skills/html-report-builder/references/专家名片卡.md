# 专家名片 · HTML 成果输出引擎（html-report-builder）

> 技能：html-report-builder　｜　快捷示例卡（照《ima 技能名片规范 v1.0》）

**一句话定位**：把成稿变成离线可用、可直接打印的单文件自包含 HTML 成果页。

**擅长（做什么）**：
- 把 Markdown/Word 成稿、结构化数据装配为单文件自包含 HTML 成果页
- 按受众与场景选配色（10 套已过 WCAG 对比度校验）并生成可切换主题
- 来源分级标注（P0–P4）、信息缺口徽标、观点块，事实/观点/未证实信息视觉分离
- 目录与返回顶部、KaTeX 数学、内联 SVG 图表、mermaid 图形围栏、打印与移动端适配
- 对已有 HTML 交付物做结构级自检并给修复清单；指标 JSON → 数据看板（KPI 卡+条形对比+阈值预警）；按需配图任务单与回填

**不做（边界）**：
- 不做 Word/PDF 正式公文排版 → 移交 docx-gw-format / contract-format
- 不做 PPT 演示文稿 → 移交 ima-ppt；不做纯视觉海报设计 → 走社交卡片类技能
- 不做站点与后台开发、需接口取数的动态页面；页面必须自包含，不得依赖外部链接存活

**快捷召唤示例**：
- 把这份 Markdown 成稿转成单文件 HTML 成果页，用海洋蓝配色，带目录、来源区块和缺口标注
- 做一份内部汇报用的 HTML 页面：结论置顶、左目录右单栏、可直接打印
- 自检这份 HTML：跑 scripts/html_check.py，把 FAIL 清零并给我逐条修复清单
- 把这些运营指标做成数据看板（KPI 卡 + 条形对比 + 阈值预警）
- 为这份研究报告配图：识别配图点 → 出配图任务单 → 出图后瘦身回填

**关键脚本/成员**：`scripts/html_check.py`（结构自检与正文抽取）、`scripts/build_report.py`、`scripts/palettes.py`、`scripts/md2report.py`、`scripts/board.py`、配图任务单脚本；`references/structure-templates.md`、`references/traceability-spec.md`、`templates/`（81 套模板库）。
