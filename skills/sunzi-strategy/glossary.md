# 术语表 Glossary

| 术语 | 英文 | 释义 |
|:--|:--|:--|
| 道 | Moral Law | 上下同心、正当性基础 |
| 天 | Heaven | 时机与趋势 |
| 地 | Earth | 环境、场域与条件 |
| 将 | Commander | 主事者素质（智信仁勇严） |
| 法 | Method & Discipline | 组织编制、权责与制度 |
| 庙算 | Calculations in the Temple | 行动前的全面推演 |
| 诡道 | Deception | 兵者诡道——隐真示假 |
| 全胜 | Complete Victory | 以最小代价保全而胜 |
| 奇正 | Qi & Zheng | 正面稳阵（正）与出奇制胜（奇） |
| 虚实 | Weak & Strong | 避实击虚、以实击虚 |
| 势 | Momentum | 蓄积的势能与释放之势 |
| 节 | Timing/Fulcrum | 势的释放时机与支点 |
| 形 | Form | 己方可被观察的表象（无形=不可测） |
| 致人 | Controlling the Enemy | 掌握主动，令对方被动 |
| 九地 | Nine Grounds | 散/轻/争/交/衢/重/圮/围/死 |
| 五间 | Five Kinds of Spies | 因/内/反/死/生间 |
| 五危 | Five Perils | 必死/必生/忿速/廉洁/爱民 |
| 以迂为直 | Circuitous & Direct | 以迂回路径达成直接目标 |
