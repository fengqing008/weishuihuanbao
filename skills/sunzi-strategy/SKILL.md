# 孙子谋略 · 博弈策略工具箱

把《孙子兵法》13 篇蒸馏为可反复调用的策略推演工具，服务"在资源与话语权不占优的博弈中争取主动"这类问题。

## Phase 0｜推演前校验（未过不进主流程）

| 检查项 | 通过标准 | 未过动作 |
|---|---|---|
| 局势描述 | 双方实力、目标、约束明确 | 补齐要素 |
| 目标明确 | 要达成的结果可衡量 | 明确目标 |
| 时间与资源 | 期限与可投入资源明确 | 补齐 |
| 边界确认 | 不涉及违法、暴力与欺诈手段 | 停止推演 |

🔴 检查点：任一要素未过，先补齐再推演。

## 使用方式

1. 判断当前处于什么"地"（开放 / 僵持 / 狭窄 / 险要 / 背水），见 `cheatsheet.md` 十三篇索引；
2. 按 `patterns.md` 选择 2—3 个适用模式（P01—P10）；
3. 需要展开某一篇时，读取 `chapters/` 下对应文件；
4. 术语不明确时查 `glossary.md`。

## 核心框架

### 一、五维评估（始计：道天地将法）
进入任何博弈前逐项评估：正当性（道）、时机（天）、场域（地）、主事者素质（将）、组织机制（法）。

### 二、行动优先级（谋攻）
伐谋 ＞ 伐交 ＞ 伐兵 ＞ 攻城；追求"全胜"，避免"惨胜"。

### 三、三段式决策
先为不可胜（守底线）→ 致人而不致于人（掌主动）→ 避实击虚、以正合以奇胜（找软肋、集中王牌）。

## 十大模式
P01 庙算先行 · P02 不战而屈 · P03 先为不可胜 · P04 致人而不致于人 · P05 避实击虚 · P06 以正合以奇胜 · P07 以迂为直 · P08 知彼知己 · P09 因地为兵 · P10 非利不动（详见 `patterns.md`）

## 十三篇索引
始计 / 作战 / 谋攻 / 军形 / 兵势 / 虚实 / 军争 / 九变 / 行军 / 地形 / 九地 / 火攻 / 用间（详见 `cheatsheet.md` 与 `chapters/`）

## 边界
本技能用于策略推演与思路启发，不替代法律、财务与合规的专业判断；涉及具体决策须经资质主体核实。

## 输出质量规范

原文引用须标注篇名与章节；用户未提供的局势信息标【待核：需补充】，不代为假设（缺口显性化）。原文表述属事实段，据此推出的策略属判断段，以「判断：」起头并说明推理链条（事实与观点分离）。推演结论为思维框架应用，不构成法律、投资或商业决策依据（风险与免责提示）。

不得编造原文条目与篇章归属；禁止把策略框架用于违法、暴力、欺诈或侵害他人权益的场景。

交付时按需追加要点归纳（3—5 条，如核心原则、常见误用）与下一步动作（可补充情报、设定退出条件）。多轮迭代：可调整局势要素／目标／约束。

## 适用范围与分流

本技能处理策略推演。以下场景不适用于本技能，应使用对应技能：

- 需要方案压力测试与证伪 → 应使用 `red-team-challenger`
- 需要结构化商业分析 → 应使用 `consulting`
- 需要合同与法律条款判断 → 应使用 `contract-review-pro`

## 失败模式

如果用户只给"我该怎么赢"而无局势信息 → 先按五维补齐要素，要素缺失时给出框架清单并标注【待核：需补充局势】，不直接给结论；如果情境涉及违法、暴力、欺诈或侵害他人权益 → 停止推演并说明边界；如果引用原文无法确定篇名归属 → 并列标注版本差异，不强行归篇；如果用户把推演当作决策依据 → 明确本推演为思维框架应用，重大决策须转专业渠道；如果双方力量差距悬殊且无可造之势 → 如实给出"不宜正面相争"的评估，不给勉强的方案；如果局势要素在推演中变化 → 以新要素重跑五维评估，不使用旧结论。

## 五维评估速算

```
道（共识）：内部目标是否一致 → 一致/有分歧/对立
天（时机）：外部窗口处于上升/持平/下行
地（地形）：所处位置的利与不利各列 2 条
将（主将）：决策速度、授权边界、情绪稳定度
法（制度）：流程、标准、奖惩是否清晰可执行
```

## 标准推演流程（8 步）

1. **过校正门**：核对「局势描述 / 目标明确 / 时间与资源 / 边界确认」四要素，任一未过先补齐。
2. **落五维**：按道、天、地、将、法逐维给我方与对方取值，不留空。
3. **算差值**：逐维比对强弱结构，判明「宜避 / 待势 / 可争」。
4. **选模式**：从 P01—P10 中挑 2—3 个适用模式，须说明选择理由。
5. **定优先级**：按 伐谋 ＞ 伐交 ＞ 伐兵 ＞ 攻城 排序动作。
6. **设退出条件**：预先写下止损线与收兵线（不可省略）。
7. **出交付物**：按「可交付物与输出规范」出推演稿（含推理链条与适用条件）。
8. **自检与迭代**：跑 `scripts/sz_check.py` 做红线与齐备性自检；局势变化则以新要素重跑。

## 红线声明（固定拒绝口径）

1. **不得**将本推演用于违法、暴力、欺诈或侵害他人权益的场景，触发即停止并说明边界。
2. **严禁**把推演结论当作法律、投资、财务或商业决策依据；重大决策须转有资质主体核实。
3. **不得**编造原文条目、篇章归属与作者言论；引用存疑时并列标注版本差异。
4. **不在范围**内的需求（合同与法律条款判断、结构化商业分析、方案压力测试）须分流至对应技能，不得勉力代答。
5. **严禁**以「古代兵法」名义给出确定性成败断言或承诺，凡涉吉凶与输赢必附不确定性说明。
6. **不得**省略退出条件与适用边界；无止损线的推演稿不予交付。

## 能力边界与不适用范围

本技能处理**策略推演与思路启发**，输出为思维框架应用，不构成任何专业结论。以下**不适用**本技能，应按场景路由：

| 用户诉求 | 处理路径 |
|---|---|
| 需要方案压力测试与证伪 | 应使用 `red-team-challenger` |
| 需要结构化商业分析 / 战略咨询 | 应使用 `consulting` |
| 需要合同与法律条款判断 | 应使用 `contract-review-pro` |
| 需要财务测算与估值 | 应使用投融资 / 造价类技能 |
| 需要人生重大抉择谋断 | 应使用 `史鉴谋断` |
| 需要纯粹的历史知识问答 | 直接检索史料，不必加载本技能 |

## 失败模式与降级路径

推演中的**失败模式**，多数不是「想不出策略」，而是「局势不清、要素打架、越界越轨」。以下失败分支触发即按表处置。

| 序号 | 场景 | 触发条件 | 降级处置（含兜底方案与回退策略） |
|---|---|---|---|
| F1 | 局势要素缺失 | 只给「我该怎么赢」，无双方实力 / 目标 / 约束 / 期限 | 不直接给结论；降级输出五维要素清单 + 【待核：需补充局势】，补齐后重跑 |
| F2 | 目标不可衡量 | 目标为「赢」「压住对方」等模糊表述 | 降级为可衡量口径（量化到数字 / 比例 / 期限），回退到确认门 |
| F3 | 越界红线 | 情境涉及违法、暴力、欺诈或侵害他人权益 | 立即停止推演，说明边界并引导合法渠道 |
| F4 | 篇章归属不可考 | 原文无法确定篇名或版本有异文 | 并列标注版本差异，不强行归篇 |
| F5 | 误作决策依据 | 用户将推演当作法律 / 投资 / 商业决策依据 | 明确为思维框架应用，重大决策须转专业渠道 |
| F6 | 力量悬殊无可造之势 | 差距极大且无可用窗口与地形 | 如实给出「不宜正面相争」的评估，不给勉强方案 |
| F7 | 局势中途变化 | 推演中目标 / 约束 / 对手动作改变 | 以新要素重跑五维评估，不复用旧结论 |
| F8 | 脚本不可用 | `sz_check.py` 无法运行（无 Python 环境） | **回退到人工核对**：按「五事齐备 / 目标可衡量 / 退出条件 / 红线未触」四项勾选兜底 |

**容错与补救原则**：①任一要素缺依据即标【待核】并列取数路径，禁止用行业惯例替代实际局势（**边界条件**）；②推演结论须可复算（列五维取值与差值），便于第三方复核；③脚本先看退出码（0 通过 / 1 校验**异常** / 2 输入不足），按码**错误处理**与**补救**，**不重试**同一错误输入；④多轮推演可把局势卡存为 JSON **断点续跑**；⑤交付前做一次**防御**性红线自检，命中即**回退**到边界声明；⑥已发出口径有误的出具更正说明并留痕。

**FALLBACK / 降级与兜底口径**：主通道为 `sz_check.py` 程序化校验；不可用时**降级处理**为人工勾选清单；局势卡 JSON 不可解析时返回退出码 2，**降级为**框架清单交付（直接给五维表供用户填写），不硬出结论。完整失败模式表见 `references/02-降级与失败模式.md`。
