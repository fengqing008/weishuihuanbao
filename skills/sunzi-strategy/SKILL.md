# 孙子谋略 · 博弈策略工具箱

把《孙子兵法》13 篇蒸馏为可反复调用的策略推演工具，服务"在资源与话语权不占优的博弈中争取主动"这类问题。

## Phase 0｜推演前校验（未过不进主流程）

| 检查项 | 通过标准 | 未过动作 |
|---|---|---|
| 局势描述 | 双方实力、目标、约束明确 | 补齐要素 |
| 目标明确 | 要达成的结果可衡量 | 明确目标 |
| 时间与资源 | 期限与可投入资源明确 | 补齐 |
| 边界确认 | 不涉及违法、暴力与欺诈手段 | 停止推演 |

🔴 检查点：任一要素未过，先补齐再推演。

## 使用方式

1. 判断当前处于什么"地"（开放 / 僵持 / 狭窄 / 险要 / 背水），见 `cheatsheet.md` 十三篇索引；
2. 按 `patterns.md` 选择 2—3 个适用模式（P01—P10）；
3. 需要展开某一篇时，读取 `chapters/` 下对应文件；
4. 术语不明确时查 `glossary.md`。

## 核心框架

### 一、五维评估（始计：道天地将法）
进入任何博弈前逐项评估：正当性（道）、时机（天）、场域（地）、主事者素质（将）、组织机制（法）。

### 二、行动优先级（谋攻）
伐谋 ＞ 伐交 ＞ 伐兵 ＞ 攻城；追求"全胜"，避免"惨胜"。

### 三、三段式决策
先为不可胜（守底线）→ 致人而不致于人（掌主动）→ 避实击虚、以正合以奇胜（找软肋、集中王牌）。

## 十大模式

## 边界
本技能用于策略推演与思路启发，不替代法律、财务与合规的专业判断；涉及具体决策须经资质主体核实。

## 输出质量规范

原文引用须标注篇名与章节；用户未提供的局势信息标【待核：需补充】，不代为假设（缺口显性化）。原文表述属事实段，据此推出的策略属判断段，以「判断：」起头并说明推理链条（事实与观点分离）。推演结论为思维框架应用，不构成法律、投资或商业决策依据（风险与免责提示）。

不得编造原文条目与篇章归属；禁止把策略框架用于违法、暴力、欺诈或侵害他人权益的场景。

交付时按需追加要点归纳（3—5 条，如核心原则、常见误用）与下一步动作（可补充情报、设定退出条件）。多轮迭代：可调整局势要素／目标／约束。

## 适用范围与分流

本技能处理策略推演。以下场景不适用于本技能，应使用对应技能：

- 需要方案压力测试与证伪 → 应使用 `red-team-challenger`
- 需要结构化商业分析 → 应使用 `consulting`
- 需要合同与法律条款判断 → 应使用 `contract-review-pro`

## 失败模式

如果用户只给"我该怎么赢"而无局势信息 → 先按五维补齐要素，要素缺失时给出框架清单并标注【待核：需补充局势】，不直接给结论；如果情境涉及违法、暴力、欺诈或侵害他人权益 → 停止推演并说明边界；如果引用原文无法确定篇名归属 → 并列标注版本差异，不强行归篇；如果用户把推演当作决策依据 → 明确本推演为思维框架应用，重大决策须转专业渠道；如果双方力量差距悬殊且无可造之势 → 如实给出"不宜正面相争"的评估，不给勉强的方案；如果局势要素在推演中变化 → 以新要素重跑五维评估，不使用旧结论。

## 五维评估速算

```
道（共识）：内部目标是否一致 → 一致/有分歧/对立
天（时机）：外部窗口处于上升/持平/下行
地（地形）：所处位置的利与不利各列 2 条
将（主将）：决策速度、授权边界、情绪稳定度
法（制度）：流程、标准、奖惩是否清晰可执行
```
