# 孙子谋略案例库（case-library / 案例集）

本案例库为博弈推演的标准化参照（案例集），每则按「处境 / 推演 / 结论 / 要点」四段呈现。
套用时须按己方实际局势复核，不得直接复制结论；局势要素缺失的，一律标注【待核：需补充】。

---

## 案例一　以弱胜强：资源劣势方的迂直之计

- **处境**：我方为后进入者，品牌与渠道均不占优，正面价格战必亏；对方占据主流货架，但决策链长、响应慢。
- **推演**：五维评估——道（我方内部共识强，对方空）、天（对方年度考核窗口临近，急于结案）、地（我方主攻对方覆盖薄弱的细分场景）、将（我方授权快）、法（我方小步快跑）。判定「不宜正面相争」，改用「以迂为直」：先攻对方未覆盖的场景建立根据地，再以标杆案例撬动主渠道。
- **结论**：避实击虚，先为不可胜；不追求一次全胜，先求不可败之立足点。
- **要点**：①「全胜」非「速胜」，弱势方先求不败；②迂直之计的核心是选对方覆盖不到的地；③窗口期（天）是弱势方唯一可造之势。

## 案例二　谈判博弈：五维差值决定议价姿态

- **处境**：与单一供应商谈判，我方为长期大额买家但当期只有一个备选；对方为老牌厂商，报价坚挺。
- **推演**：五维对照——道（双方都想长期合作，共识高）、天（我方采购计划刚性、时间紧，天不在我）、地（主场谈判）、将（对方决策链长）、法（对方审批标准不透明）。差值判读：我方在「道、地」占优，在「天」处于劣势，故**不压价到底**，改以「长期量换阶价」换取让步，同时预备第二供应商以补「天」之短。
- **结论**：知彼知己，非一味强攻；以我方强项（长期量、主场）交换对方可让之处。
- **要点**：①差值不在总量而在结构，逐维比对；②「天」劣势时须造势（引入备选）；③谈判目标须可衡量（量化到单价与期限）。

## 案例三　多方博弈：致人而不致于人

- **处境**：三方竞争同一项目（我方、强敌、地方伙伴），我方实力居中；地方伙伴掌握关键资源亦为我方短板。
- **推演**：评估断「不宜两线争锋」。先「伐交」——与地方伙伴结盟补短板，把强敌拉入我方设定的比较维度（服务响应而非纯价格）；再「以正合以奇胜」，在标的技术条款上布下我方强项作为「奇兵」。
- **结论**：先伐谋伐交再伐兵；使对手在我方设定的战场上比拼，掌握主动。
- **要点**：①行动优先级 伐谋＞伐交＞伐兵＞攻城；②「致人」＝把战场拉到自己设定的比较维度；③同盟须先明确退出条件，避免被拖入。

## 案例四　情报不足时的降级处置（失败模式示例）

- **处境**：用户只问「我该怎么赢」，未提供双方实力、约束与期限，无法进入主推演流程。
- **推演**：触发失败模式——不直接给结论；先按五维补齐要素，输出「道天地将法」要素清单与【待核：需补充局势】标注，并要求补①双方目标 ②期限与可投入资源 ③退出条件。
- **结论**：以框架清单替代结论交付；要素补齐后重跑五维评估，不使用旧判断。
- **要点**：①缺口显性化，不代为假设；②局势变化即以新要素重跑，不复用旧结论；③越界（违法 / 暴力 / 欺诈）立即停止并说明边界。

## 案例五　优势方的收敛：非利不动，得算多也

- **处境**：我方在五维全面占优，对方几无还手之力，团队倾向「一口吃掉」。
- **推演**：军形篇「先为不可胜」，虚实篇「非利不动」——全面碾压的收益边际递减，且过度施压会催生对手联合与舆论反噬。改为设定明确「收兵线」：达成核心诉求即停手，保留对方基本体面以维持战后关系。
- **结论**：可战而不必尽战；明确止损与收兵条件，避免惨胜。
- **要点**：①优势方最大风险是判断被自身气势扭曲；②预设收兵线即「退出条件」；③留有余地以保后续长期博弈。
