# 图像增强质量检查清单（quality-checklist）

> 用法：每张增强图处理完成后逐项核对，勾选 `[x]`；任一项未过即 STOP，不得进入交付，未过项写入 failed.log 并注明原因与处置。
> 核对时机：单图任务在第六节质检核验步；批量任务在批量执行完成后整体抽检 + 逐图自动核。

## 一、文件与命名

- [ ] 1. 输出文件存在且可打开，命名符合 `<原名>_enhanced.<ext>` 规则
- [ ] 2. 源图未被覆盖、移动或删除，原图路径仍可访问
- [ ] 3. 输出扩展名与编码格式一致（PNG 不以 .jpg 命名，反之亦然）
- [ ] 4. 批量输出保留原相对目录结构，无文件名冲突与互相覆盖

## 二、尺寸与规格

- [ ] 5. 输出尺寸等于输入尺寸乘放大倍数（误差 ≤1px，取整方式已记录）
- [ ] 6. 单边尺寸未超过 4096px，超限项已在报告中注明"先缩后放"处理
- [ ] 7. 输出体积在合理区间，PNG 类截图未出现体积异常膨胀（较原图 > 8 倍需复核）
- [ ] 8. 含文字图的分辨率满足用途要求（PPT 投影类建议输出长边 ≥ 1920px）

## 三、画质与通道

- [ ] 9. 文字边缘清晰，无笔画粘连、无断笔，放大 200% 目视可读
- [ ] 10. 无锐化过度痕迹：无色边白边、无边缘振铃、无噪点被放大
- [ ] 11. 透明通道完整保留（源图含 alpha 时输出仍含 alpha，未被填白底）
- [ ] 12. 色彩模式正确（RGB / RGBA / L 未被误转，偏色与色阶断层已排除）

## 四、内容与场景

- [ ] 13. 图像内容完整：无裁切缺失、无边界裁边、无印章与骑缝线破坏
- [ ] 14. 对比度与亮度正常，未出现整体发灰、过曝或暗部细节丢失
- [ ] 15. 文字类截图的 OCR 抽检前 5 行可读（无 OCR 环境时改为人工目视核对并注明方式）
- [ ] 16. 交付用途匹配：预设选择与最终用途一致（PPT / 文档 / 网页 / 印刷 / 归档）

## 五、台账与交付

- [ ] 17. manifest.json 已生成，逐图记录预设、参数、输入输出尺寸与体积、status
- [ ] 18. failed.log 已生成或为空；每条失败项含 `file | reason | action` 三字段，原因可归入失败模式表
- [ ] 19. 增强前后对比报告已按 references/output-template.md 成文，含逐图明细与质检结论
- [ ] 20. 断点续跑可验证：重跑同一条批量命令时，已完成项被正确跳过
