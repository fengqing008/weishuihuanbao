# 设计哲学生成法（design-philosophy）

本文件是"设计哲学"这一前置产物的执行依据。任何画布作品在动笔之前，先有一份可被引用的宣言。宣言是作品的裁判文书，不是作品的说明书。

---

## 一、宣言的地位与作用

一份合格的宣言要回答一个问题：**为什么这张画只能长成这样**。

判断标准：把宣言交给另一位设计师，对方据此独立完成的作品，与你的作品在气质上属于同一族。若两人成品相差甚远，说明宣言写得过虚，须回到本文件重写。

宣言的四个用途：

1. 约束自己：画面中每一个元素都能在宣言里找到出处。
2. 约束系列：同族的第二张、第三张作品按同一份宣言派生。
3. 对齐他人：向甲方或团队交代视觉决策的依据。
4. 可比对：作品与宣言放在一起，能看出偏差在哪。

---

## 二、段落结构（4—6 段）

| 段序 | 段名 | 必答问题 | 篇幅 |
|---|---|---|---|
| 一 | 主张 | 这个运动把什么压到最低，把力气集中在哪一处 | 3—5 句 |
| 二 | 色彩立场 | 色板几席、各占多少面积、强调色出现在哪里 | 4—6 句 |
| 三 | 形态语言 | 用哪几类母题、尺度与笔画的比例关系 | 4—6 句 |
| 四 | 材质与工艺 | 纸面质感、对齐方式、导出配比 | 4—5 句 |
| 五 | 与主题的关联 | 主题如何被换算为结构关系而非插图对象 | 3—5 句 |
| 六 | 检验与复现 | 按哪些检查点核验、如何复现 | 3—5 句 |

段落数取 4 时删去第四、第六段；取 5 时删去第六段；取 6 时全用。四段以下的宣言不承载足够的决策密度。

---

## 三、艺术运动命名法

命名是一个 1—2 词的短语，承担画面眉标的排版任务。

**构词公式**

```
候选 A：形容词 + 名词     例式：Chromatic Silence／色度静默
候选 B：单个名词          例式：Interval／间隙
```

**英文词库**（可扩充，同词根不得在同一系列内重复使用）

- 形容词位：Chromatic / Brutalist / Silent / Luminous / Tidal / Mineral / Organic / Gridded / Ashen / Verdant / Kinetic / Static / Basalt / Hollow / Radiant / Latent
- 名词位：Silence / Tide / Reverie / Monolith / Field / Interval / Verdict / Chorus / Margin / Signal / Basin / Vertex / Threshold / Residue / Column / Passage

**中文词库**

- 形容词位：色度 / 粗野 / 静默 / 流明 / 潮汐 / 矿质 / 有机 / 网格 / 灰烬 / 苍绿
- 名词位：静默 / 潮汐 / 冥想 / 碑体 / 原野 / 间隙 / 裁决 / 复调 / 余像 / 微光

**命名校验三条**

1. 长度：拉丁字符不超过 18 个，汉字不超过 6 个。
2. 可读性：眉标以全大写渲染时，字母宽度不超过画布安全宽度的 45%。
3. 唯一性：同一系列内不得出现两个含义重叠的运动名。

---

## 四、段落写作口径

**句式要求**

- 用陈述句下判断，不用疑问句和感叹句。
- 每段至少出现一个可量化的数值（比例、倍数、像素、阈值）。
- 每段只讲一件事，段内不出现两个并列的论点。

**词汇纪律**

- 禁用模糊副词：比较、相对、大概、差不多。
- 禁用推诿式表达：按照需求、结合实际情况。
- 禁用陈词式赞美：震撼、极致、匠心独运。
- 数量、比例、阈值一律写出具体数字。

**段落长度上限**：单段不超过 220 字。超出即拆段。

---

## 五、宣言质检清单

定稿前逐条核验：

- [ ] 段落数落在 4—6 之间。
- [ ] 已命名一个 1—2 词的艺术运动，且通过命名校验三条。
- [ ] 每段含至少一个可量化数值。
- [ ] 色彩段落写明四席色板的各自职责与面积占比。
- [ ] 形态段落写明母题种类与尺度相对短边的倍数。
- [ ] 检验段落列出的检查点与作品导出前的核验项一一对应。
- [ ] 全文无禁用词汇，且无未处理的【待填】以外的空白。
- [ ] 把宣言交给第二位设计者，两人独立产出的作品气质同族。

---

## 六、示例（自造范例，用于说明格式）

以下为格式示范，不指向任何真实作品或真实作者。

```
# 设计哲学 · 潮汐的余量

## 一 · 主张
「潮汐的余量」把画面的解释功能清零，只保留举证功能……

## 二 · 色彩立场
四席色板中底色占 78% 面积，图案色以 12% 不透明度铺陈……
```

生成底稿的命令：

```bash
python3 scripts/philosophy.py --theme "<主题>" --mood "<情绪>" --segments 5 -o philosophy.md
```

底稿生成后须由设计者补写主题相关段落，并把【待填】占位替换为实际内容。
