# 案例库（case-library）

> **本文件不含任何具体作品、作者、年份、拍卖数据或获奖记录。**
> 未取得可核验来源之前，任何具名案例都不得写入本文件。需要引用时按下表的登记模板填入，并把来源链接与核验日期一并落档。

---

## 一、收录纪律

1. 只收录来源可溯、可复核的案例；来源不明的一律不收。
2. 案例的每一条事实字段都须附来源，来源与字段逐条对应。
3. 无法核实的字段写【待填：字段名】，不得以近似值或印象值代替。
4. 不得把个人推测、二手转述、模型生成内容登记为案例事实。
5. 不得为说明观点而虚构作品名、作者名、年份、尺寸、收藏机构。

违反以上任一条的条目须整条撤下，不做局部修改。

## 三、反面清单（不得登记的内容）

- 凭印象写出的作品名与作者名。
- 由模型生成的"参考案例"，即使读起来像真的。
- 拍卖成交价、展览参观人次、设计奖项等级等无法当场复核的数字。
- 从社交平台截取的无出处转述。
- 与本技能无构图关联的名作堆砌。

以上内容一旦出现在登记表中，按第一节收录纪律第 5 条处理。

## 四、数据来源指引

来源按可信度分四级。登记案例时在"来源层级"列填写级别。

| 层级 | 来源类型 | 特征 | 使用方式 |
|---|---|---|---|
| P0 | 机构一手档案 | 博物馆、美术馆、档案馆、设计机构官网的藏品页与图录页 | 可直接作为事实依据 |
| P1 | 权威出版物 | 正式出版的作品集、展览图录、学术期刊论文、机构年报 | 可直接作为事实依据，须记文献号 |
| P2 | 专业媒体报道 | 有署名的行业媒体、设计媒体深度报道 | 须两条独立来源互证后才可登记 |
| P3 | 用户生成内容 | 社交平台帖子、博客、论坛、短视频 | 不作为事实依据，只用于发现线索 |

### 检索路径

1. **机构官网藏品检索**：在目标博物馆、美术馆、设计机构的藏品库按媒材、年代、流派筛选，取藏品页的标准著录信息（题名、作者、年代、尺寸、编号）。藏品页页面本身即是 P0 来源，登记时记录完整 URL 与访问日期。
2. **权威图录与作品集**：在图书馆或出版社电子平台按 ISBN 检索正式图录，摘录图版说明页的信息与页码，登记为 P1。
3. **学术检索**：在学术数据库中按流派名与设计史关键词检索，取摘要与图版说明，登记为 P1，附 DOI 或文献号。
4. **版权核查**：登记完成的作品若要用于对外材料，须另行确认版权与授权状态，未获授权时不得复制图版。

### 采集口径

- 采集页面的题名、作者、年代、尺寸四项，逐项与来源页面文字一致，不做同义改写。
- 来源页面缺少某项时，该项写【待填】而非按常识补齐。
- 页面出现多个年代版本时，登记来源明确标注的那一个，并注明该来源的判断依据。

## 六、登记流程

```
1. 按第四节检索路径取得来源页面
2. 抄录题名、作者、年代、媒材尺寸四项
3. 判定来源层级，P2 须再取一条独立来源互证

6. 逐条核对第一节收录纪律五条
7. 更新第五节清单条目数
```
