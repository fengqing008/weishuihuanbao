# 画布设计（canvas-design）

一个从"设计哲学"到"单页视觉成品"的完整链路技能。核心主张：先写下可被命名的美学立场，再让画布成为该立场的证据。视觉承担 90% 的信息量，文字承担 10%。

---

## 一、专家定位与适用边界

**定位**：视觉概念设计师 + 静态图形工艺师。产出物是**单页、可打印、可发布**的视觉作品文件，而非图片素材的编辑切片。

**适用**：
- 设计哲学撰写（4—6 段美学宣言 + 1—2 词艺术运动命名）
- 单页视觉作品生成（海报、封面、社交媒体配图、品牌概念页、系列作品）
- 构图、配色、重复图案、几何构成、字体层级的设计决策
- 批量风格一致化产出（同一哲学下的系列变体）

**边界**：
- 画布设计只管**从零构造**视觉，不承担**修改既有照片**的任务
- 输出为栅格图（PNG）与页面文件（PDF），不做三维渲染、视频、交互动效
- 画面不引用未获授权的真实摄影素材、商标、人物肖像

---

## 二、触发条件与不适用场景

**触发条件**（出现任一条即进入本技能）：
- 用户提出"画一张海报／设计一张封面／做一个视觉概念页／生成艺术图"
- 用户给出主题词、情绪词或一句口号，要求转为视觉作品
- 用户要求先写"设计哲学／设计宣言／艺术运动命名"
- 用户要求同一套视觉在多种尺寸（竖版帖子、方图、A4）下成套产出

**不适用场景**（应改派其他技能）：
- 照片修图、抠图、去水印、老照片修复 → 图像增强／抠图类技能
- 视频剪辑、动图、GIF 合成 → 视频处理类技能
- 三维建模与渲染 → 三维类技能
- CAD 工程图纸、工程制图 → 制图类技能
- 需要真实实拍照片的成品（产品图、人像照） → 拍摄或图生图类能力

---

## 三、五维评估

接到需求后按五维打分（每维 0—5 分，总分 25），任一维低于 2 分时须先补齐信息或降级交付范围。

| 维度 | 评估问题 | 判定依据 |
|---|---|---|
| 输入完整性 | 主题、用途、尺寸、调性四要素是否齐全 | 缺项按 L1—L2 响应，并向用户补齐 |
| 美学质量 | 是否已形成可命名的美学立场 | 无立场则先走"设计哲学创作"步骤 |
| 工艺完成度 | 边距、对齐、笔画粗细、留白是否到位 | 按第七章 🔒 检查点逐项核验 |
| 合规原创 | 是否引用未授权素材、真实商标、他人肖像 | 命中即阻断，改用纯几何／纯文字构造 |
| 交付效率 | 尺寸、格式、交付件数是否一次说清 | 一次导出全部规格，不反复返工 |

## 四、四级响应 L1—L4

| 级别 | 触发情形 | 响应动作 | 交付深度 |
|---|---|---|---|
| **L1 速答** | 用户只问设计概念、配色思路、排版原则 | 输出设计要点文字说明，不生成文件 | 说明 ≤ 400 字 |
| **L2 单件** | 给定主题与尺寸，要求一张成品 | 运行 `scripts/canvas.py` 出图一次 | 1 个 PNG |
| **L3 完整链路** | 要求含设计哲学 + 成品 + 系列变体 | 跑 `scripts/philosophy.py` 再跑 `scripts/canvas.py` 出 2—4 张变体 | philosophy.md + 系列 PNG |
| **L4 成套** | 多尺寸、多格式、含评审说明的正式提案 | L3 全流程 + 全尺寸导出（PNG/PDF）+ 检查点核验报告 | 全套文件 + 核验清单 |

## 五、核心工作流

按以下编号步骤顺序执行，前一步未完成不得进入后一步。

**步骤 1 · 设计哲学创作**
产出一份 4—6 段的 markdown 美学宣言，命名一个 1—2 词的艺术运动（示例命名结构：形容词 + 名词，如"色度静默""粗野潮汐"）。宣言须写清：核心主张、色彩立场、形态语言、材质与工艺态度、与该主题的关联。执行 `python3 scripts/philosophy.py --theme "<主题>" -o philosophy.md` 生成底稿，再按主题补写两到三段。

**步骤 2 · 概念线索推断**
从宣言中抽取三条可执行的视觉线索：① 主导图案族（网格／条纹／同心弧／点阵／三角平铺）② 主色与辅助色的数量与配比 ③ 一个大尺度几何主体。把三条线索写成一行参数，供步骤 3 使用。

**步骤 3 · 画布构造**
运行 `python3 scripts/canvas.py --philosophy-phrase "<运动名>" --palette "#0f172a,#e2b34a" --title "<主题>" --pattern grid --size post -o out.png`。画面按"背景 → 图案层 → 几何主体 → 文字层"四层叠放，各层独立可调。

**步骤 4 · 去冗余精修**
删掉画面中不承担信息或节奏作用的元素：多余装饰线、超过三种的强调色、无意义的渐变、与主张无关的小图标。保留下来的每个元素都须能用一句话说明其作用。

**步骤 5 · 导出**
按目标平台导出：竖版帖子 1080×1350、方图 1080×1080、故事 1080×1920、A4 打印 2480×3508（300dpi）。需要印刷件时加 `--pdf` 直接输出 PDF。文件命名采用"运动名_尺寸_序号"格式。

## 六、交付物与输出规范

| 交付物 | 路径 | 规范 |
|---|---|---|
| 设计哲学 | `philosophy.md` | 4—6 段，含艺术运动命名，UTF-8 |
| 单页视觉 | `out.png` | 1080×1350 起，PNG，无透明底 |
| 打印件 | `out.pdf` | A4 300dpi，页边距不低于 18mm |
| 系列变体 | `out_01.png`…`out_04.png` | 同一色板与图案族，仅几何主体变化 |
| 规格记录 | `spec.json` | 尺寸、色板、字体、seed，供复现 |

视觉配比执行 90/10 原则：画面面积 90% 由图形承担，文字总量不超过 25 个汉字或 40 个拉丁字符（标题 + 一行副题 + 一处角落标记）。

---

## 七、关键检查点

导出前逐项核验，任一项不通过即回到步骤 4 精修。

- 🔒 **边界无溢出**：所有元素落在安全边距（画面短边的 6%）以内，任何笔画不得贴边或被裁切。
- 🔒 **无元素重叠**：文字区块与几何主体保持明确间距，重叠面积占比为 0；确需叠压时，对比度检查升级为准入条件。
- 🔒 **配色对比度**：正文文字与背景的相对对比度不低于 4.5∶1，大标题不低于 3∶1，按 WCAG 相对亮度公式计算。
- 🔒 **字体回退可用**：字体按 Noto Sans SC → Noto Sans CJK → DejaVu Sans 顺序回退，缺失时不得出现方框乱码。
- 🔒 **图案节奏一致**：重复图案的间距在整张画面内保持一致，误差不超过 1 像素。
- 🔒 **文字量上限**：汉字总数不超过 25，拉丁字符不超过 40。
- 🔒 **可复现**：记录 seed 与参数，同一参数组重复运行输出字节级近似一致的画面。

## 八、失败模式

| 现象 | 原因 | 对策 |
|---|---|---|
| 画面元素贴边或被裁切 | 边距按固定像素硬编码，未随画布尺寸缩放 | 边距按短边的 6% 计算，所有坐标先减边距再布局 |
| 中文显示为方框 | 字体链中只有拉丁字体，未含 CJK 字形 | 字体链首位放 Noto Sans SC，依次回退到 Noto Sans CJK、DejaVu Sans |
| 文字与背景糊在一起 | 文字色直接沿用调色板首色，未做对比度校验 | 按相对亮度公式挑选 ink 色，对比度不足 4.5∶1 时切白或黑 |
| 画面杂乱无重心 | 图案层与几何主体使用了同等视觉权重 | 图案层压到 8%—15% 不透明度，主体保持 100% 不透明度 |
| 重复图案出现接缝 | 平铺步长与画布宽高不整除，末行残缺 | 步长取画布可整除值，溢出部分在画布外裁掉 |
| 输出文件巨大 | PNG 以 RGBA 未压缩保存，且含无意义噪点层 | 导出时转 RGB，启用 `optimize=True`，噪点层不透明度压到 3% 以下 |
| 同一参数两次出图不一致 | 随机源未固定，seed 由系统时间派生 | seed 由运动名哈希派生，并允许 `--seed` 显式覆盖 |
| 系列变体风格漂移 | 每次运行重新抽色板与图案族 | 变体固定同一色板与图案族，仅改动几何主体的数量与位置 |

## 九、反例黑名单

以下做法一律不得出现在交付物中：

1. 用彩虹渐变填充整块背景，把视觉重心交给渐变本身。
2. 画面塞入超过 5 种颜色，且各色面积占比接近。
3. 使用被划掉的三类陈词：居中大标题配上下双三角、无意义的圆形徽章、装饰性艺术字签名。
4. 添加与主张无关的图标（齿轮、灯泡、握手）充当"设计感"。
5. 从网络抓取真实商标、人物照片、未授权插画贴入画面。
6. 编造具体作品的作者、年份、拍卖数字、获奖记录来抬高说明文案。
7. 用四层以上嵌套阴影制造"立体感"，导致边缘出现灰边。
8. 把段落级长文排进视觉作品，破坏 90/10 配比。
