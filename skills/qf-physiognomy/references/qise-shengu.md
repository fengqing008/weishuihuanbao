# 气色论与神骨论

## 一、气色论

### 1.1 五色配五行

相书立五色配五行之说，与中医望色语汇同源：

| 色 | 五行 | 望诊多应 |
|---|---|---|
| 青 | 木 | 肝、寒、痛 |
| 赤 | 火 | 心、热 |
| 黄 | 土 | 脾、湿 |
| 白 | 金 | 肺、虚、寒 |
| 黑 | 水 | 肾、寒、瘀 |

### 1.2 四时与分部

- 四时：春气宜青、夏气宜赤、秋气宜白、冬气宜黑（相书四时配色之说）；
- 分部：印堂、准头、地阁、年寿各有气色之名目，属相书流年口诀。

### 1.3 审视

气色由睡眠、饮食、疾患、情绪、光线、妆造、影像条件共同决定，**随境而变**，不能稳定对应人事际遇。以气色断顺逆，是把一时的生理状态与影像条件附会为遭遇之兆。故本技能：**只述其说，不据气色论人**。

## 二、神骨论（《冰鉴》一派）

旧题清·曾国藩《冰鉴》以「神、骨、气、态」为纲：

| 目 | 主张 | 出处 |
|---|---|---|
| 神 | 神藏于目，有清浊邪正之分，论人先观其神 | 《冰鉴·神骨》 |
| 骨 | 骨有贵贱之别，以头面骨之隆薄分论 | 《冰鉴·神骨》 |
| 气 | 气有收敛发扬之别，关乎器局，与神相须 | 《冰鉴·气色》 |
| 态 | 观人动静之间，见其举止之态 | 《冰鉴·情态》 |

## 三、审视

「神」「骨」「气」抽象而难定义，缺乏可操作标准与可证伪性，易滑向玄谈与主观印象。其价值在文献与文辞，不在判断效力；一旦用于论人，便难脱以貌取人的窠臼。

## 四、写作规范

- 引「神骨」「气色」时，主语为「相书」「《冰鉴》」，属知识史陈述；
- 审视段须落到可证伪性与现实风险，不作「其实也很准」式反向立论；
- 不据气色、神骨对具体个人作任何判断。
