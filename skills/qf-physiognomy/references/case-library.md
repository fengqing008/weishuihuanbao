## 四、来源指引

### 4.1 原典来源

本技能规则库的纲要求自下列公有领域文献，可在中国哲学书电子化计划、中华典藏、国学大师等古籍平台查对原文：

| 文献 | 通行托名 | 检索提示 |

| 冰鉴 | 清·曾国藩（托名） | 检索「冰鉴 神骨」 |
| 柳庄相法 | 明·袁珙 | 检索「柳庄相法」 |
| 相理衡真 | 清·陈钊 | 检索「相理衡真」 |
| 月波洞中记 | 唐·任逍遥（旧题） | 收于《四库全书》子部术数类 |

### 4.2 引用核对要点

1. 同一名目在《麻衣神相》与《神相全编》中表述可能不同，注明所引书目即可，不必求同；
2. 古籍版本差异大，标注以通行本为准；
3. 托名现象普遍，标注「旧题」「托名」而不作定论；
4. 引文若为节引，加「节引」二字。

### 4.3 补充条目的流程

需要扩展规则库时，按下列次序：

1. 查得原文，抄录段落，记下书名与篇章；
2. 提炼为一句纲要式论述（不超过 50 字）；
3. 写入 `assets/rules.json` 对应部位，字段：desc／palace／reading／source；
4. 若引入新描述词，同步写入 `assets/vocab.json`；
5. 跑 `rule_engine.py --list-rules` 复核条目总数。

## 五、工作流实测案例（3 例）

> 说明：下列案例为本技能三段式闭环（读图 → 匹配 → 渲染）的实测记录，用于校准流程与门禁；
> 案例只描述流程与门禁表现，不对任何个人作判断；不得编造案例。

### 案例 W-01：模板驱动的完整链路跑通（不看照片）

- **背景**：用户仅需了解报告结构与十二宫体系，未提供照片。
- **做法**：以 `face_analyze.py --template` 生成带词库提示的空白 features.json →
  `rule_engine.py --features features.json --out result.json` 匹配 →
  `report_render.py --input result.json --out 解读.html` 装配七节底稿并渲染 HTML。
- **结果**：约 10 秒出报告骨架；`html_check.py` 自检 FAIL=0；无有效特征时按 FM-08 输出明确提示，不出空报告。
- **门禁表现**：门 3（词库一致性）对空模板不误报，门 5（HTML 自检）通过。

### 案例 W-02：内置样例复现（demo 数据）

- **背景**：验证报告渲染与两张程序化 SVG 示意图的内嵌效果。
- **做法**：`report_render.py --demo --out 示例.html` 使用内置样例数据渲染；
  检查 `images/` 与 base64 内嵌图是否随报告生成。
- **结果**：报告含「五行形相示意」与「面部十二宫分布示意」两图，零外部依赖、零版权风险；
  页脚固定免责声明在位。
- **门禁表现**：门 4（误差声明 + 免责声明）通过，门 5（正文密度 ≥225 字/章）通过。

### 案例 W-03：仅查询模式（不读照片，只查规则与宫位）

- **背景**：用户问「十二宫各在哪里」「六十条形态与论述有哪些」。
- **做法**：`rule_engine.py --list-palaces` 列十二宫；`rule_engine.py --list-rules` 列全部规则；
  结果以表格呈现，逐条带 source 出处。
- **结果**：输出为文化知识对照，全程不涉及任何个人面容判断。
- **门禁表现**：门 2（引文出处齐备）通过；无禁止词命中。
