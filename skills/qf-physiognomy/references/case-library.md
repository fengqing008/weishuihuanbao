# 案例登记模板与来源指引

## 一、说明

本节用于登记本技能的实际使用案例，供后续校准读图准确度与表述规范。**不得编造案例。** 无真实案例时保留模板与指引，逐条留空。

## 二、案例登记模板

复制下表填写，每案例一行：

| 编号 | 日期 | 输入类型 | 特征项数 | 命中条文 | 质检结果 | 备注 |
|---|---|---|---|---|---|---|
| C-001 | | 照片／仅查询 | | /8 | 门 1—5 | |

字段口径：

- **输入类型**：照片（实际出报告）／仅查询（只跑 `--list-rules` 之类）；
- **特征项数**：实际录入并通过校验的描述词个数；
- **命中条文**：规则库匹配成功数；
- **质检结果**：五道门禁的通过情况，写「门 1—5 全过」或具体失败项；
- **备注**：出现的失败模式编号（如 FM-06）。

### 4.2 引用核对要点

1. 同一名目在《麻衣神相》与《神相全编》中表述可能不同，注明所引书目即可，不必求同；
2. 古籍版本差异大，标注以通行本为准；
3. 托名现象普遍，标注「旧题」「托名」而不作定论；
4. 引文若为节引，加「节引」二字。

### 4.3 补充条目的流程

需要扩展规则库时，按下列次序：

1. 查得原文，抄录段落，记下书名与篇章；
2. 提炼为一句纲要式论述（不超过 50 字）；
3. 写入 `assets/rules.json` 对应部位，字段：desc／palace／reading／source；
4. 若引入新描述词，同步写入 `assets/vocab.json`；
5. 跑 `rule_engine.py --list-rules` 复核条目总数。
