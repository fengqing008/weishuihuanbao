# 交付质检清单

交付前逐项核对，任一项不通过即返工。

## 一、合规词扫描

全文（含报告正文、图注、页脚、文件名）不得出现下列词：

| 类别 | 禁用词 |
|---|---|
| 判断类 | 运势、命运、吉凶、富贵、贫贱、克夫、克妻、旺夫、旺妻、注定、必定、必然 |
| 交易类 | 请符、开光、化解、改运、转运、大师、付费 |
| 评价类 | 有福、命好、命薄、贵相（作结论时）、贱相 |

说明：引用古籍原文时若原句含上述词，须在句末加括注「此系古籍原文之文化表述，非本报告之判断」，并在报告开头声明。除此之外不得出现。

## 二、引文出处

- [ ] 每条论述均有 source 字段（书名 + 篇章）
- [ ] 手工补充的条文能指明出处
- [ ] 无「古籍云」「古人说」这类无出处的引述
- [ ] 未逐字杜撰原文

## 三、词库一致性

- [ ] `face_analyze.py --validate <特征文件>` 返回 0
- [ ] 所有特征词在 vocab.json 内
- [ ] 无匹配条文的特征已在报告中如实列出

## 四、表述规范

- [ ] 主语是「古籍」「传统相学」，不是「你」
- [ ] 无评价人、推断未来、指导决策的表述
- [ ] 无主观色彩词（用「眼形细长」不用「眼小」）
- [ ] 识别误差声明在位
- [ ] 免责声明在位

## 五、报告结构

- [ ] 七节齐备（概览／三停／五官分论／十二宫／典籍／小结／免责）
- [ ] 页脚含固定免责声明
- [ ] 十二宫位置取自 palace12.json，未手写

## 六、技术自检

- [ ] html_check.py 返回 FAIL=0
- [ ] 正文密度 ≥225 字/章
- [ ] 报告在移动端可正常阅读，目录可跳转
- [ ] 无 `:::gap` 空壳（特征缺失时已给出提示）

## 七、交付四件

- [ ] 内容完整，无未替换占位
- [ ] 数据有溯源（规则库 source 字段 + 典籍索引）
- [ ] 已上传成果库，media_id 已记录
- [ ] 已提供下载链接
