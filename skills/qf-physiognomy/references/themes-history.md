# 传统相学议题史（方法纲要）

> 本件是「议题史」章节的写作与审查规范。核心口径一句话：**讲古人如何立说，不讲此人如何**。

## 一、为什么要立「议题史」

相学文献里，寿夭、禄命、性情、才具、气色、形神、婚姻子嗣、行藏出处是反复出现的命题。这些命题是相学最受市井关注的部分，也最容易滑向「对个人下断言」。

本技能的处理办法是：**把命题本身作为对象**——陈述古人如何立说、各书有何出入、其说不合于何种检验——而不把命题落到读者或照片中的人身上。

## 二、结构规范（每议题五段）

| 段 | 内容 | 起句范式 |
|---|---|---|
| 命题概要 | 一句话说明该命题是什么 | 「相书中有……之说」 |
| 古人论说 | 逐条列典籍义项 + 出处 | 「《×××》载……」 |
| 流变 | 该命题在相书中的沿革与出入 | 「××之论在相书中……」 |
| 现代审视 | 从可证伪性、心理机制、历史语境的审视 | 「以……定……缺乏可证伪的检验」 |
| 结语 | 固定声明 | 「命题史陈述；古人持此说，今人不必信从」 |

## 三、八个议题（本技能收录）

1. **寿夭**——古人如何论寿数短长（人中、保寿官眉、法令、地阁、寿上）
2. **禄命**——古人如何论贵贱贫富（官禄宫额、财帛宫鼻）
3. **性情**——古人如何论气质心性（五行形相、神骨）
4. **才具**——古人如何论贤愚才学（额、目、神气）
5. **气色**——古人如何论气色与际遇（明润枯暗、五色配五行）
6. **形神**——古人如何论「形」与「神」（神藏于眼、神骨）
7. **婚姻子嗣**——古人如何论婚育（妻妾宫眼尾、男女宫泪堂）
8. **行藏出处**——古人如何论士农工商（五行形相配身份）

## 四、现代审视的四个抓手

写「现代审视」段时，从以下角度立论，避免空泛的道德评判：

- **可证伪性**：该说能否被检验、有无统一判据（各书条目常自相抵牾即为证）；
- **认知偏差**：事后归因、幸存者偏差、巴纳姆效应（说辞宽泛而众皆觉准）；
- **历史语境**：命题多植根于科举、宗族、等级、性别等旧制度，是时代的投射；
- **现实风险**：历史上每被用于检生议死、以貌取人、敛财话术，须点明。

## 五、写作红线（违者返工）

- 🔴 主体是「传统/古籍」，禁用「你/您/此人/这个人」等指向具体人的表述；
- 🔴 不让古代命题「应验」到现实：不写「凡……者多……」，只写「古以……为说」；
- 🔴 现代审视段不得反向立论（如「其实相术也有道理」）——审视即审视；
- 🔴 结语统一用固定句，不逐议题改写。
