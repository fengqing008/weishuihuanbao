# 发布资料 · 极简压缩官（caveman-distillate）

## 一、技能简介

**极简压缩官**是一种输出侧的模式开关：开启后，AI 回复走「极简压缩」通道，把长句蒸馏为骨架，用最少 token 保留完整技术准确度，字符量通常降到正常模式的 60% 以内。

三条底线：技术准确度不降、语义不反转、安全不打折。压缩对象是措辞，不是内容。

### 使用说明（6 条）

1. **极简输出**：说「少啰嗦，只要结论，输出压到最短」，我切换极简压缩通道。
2. **省 token**：说「这条回答用极简模式，省 token」，我压缩措辞保留信息。
3. **蒸馏回复**：说「帮我把 AI 回复蒸馏到核心信息」，我提炼骨架要点。
4. **短屏场景**：说「终端 / 移动端阅读，回复要短」，我按窄屏习惯给短回复。
5. **压缩率校验**：说「压缩率校验一下，是否降到 60% 以内」，我跑量化校验脚本给出比例。
6. **判断能否压缩**：说「哪些场景不能压缩（代码 / 法律 / 安全）」，我按红线表逐项判断。

## 二、使用示例

### 示例 1：技术问答压缩

- 正常版（约 120 字）：内存泄漏排查需依次确认分配跟踪、对象引用链、循环引用三项，并在关键位置做快照比对。
- 压缩版（约 35 字）：内存排查：tracemalloc 跟踪分配，objgraph 查引用环，gc.collect() 手动回收。三处打快照对比。

### 示例 2：调试场景（代码块保持原样）

```python
data = json.load(open("file.json"))
```

压缩版：白屏无报错 → 组件 render 抛异常被吞，加 ErrorBoundary 抓。

### 示例 3：概念解释

问：什么是 WebSocket？
答：TCP 长连接协议。HTTP 一问一答，WS 持久双向。实时推送用（聊天/行情）。

### 示例 4：压缩率校验命令

```bash
python3 scripts/compress_check.py --normal normal.txt --compressed distilled.txt --threshold 60
```

退出码：0 = 达标；1 = 未达标；2 = 输入异常。

## 三、适用场景

- 长链路、按 token 计费的批量模型调用，需要压成本。
- 终端、窄屏、移动端阅读，需要短回复。
- 需要「结论先行、下一步明确」的执行型问答。
- 反复出现同一问题、需要极短复述的批量作业。
- 与 `references/compression-guide.md` 配合做分层压缩教学与演示。

## 四、不适用边界

| 场景 | 处理方式 |
|------|----------|
| 代写代码、commit message、PR 描述、SQL | 正常模式，字段与语法不可压 |
| 安全警告、不可逆操作、生产环境操作 | 正常模式，完整输出 |
| 法律、合规、合同、监管文本 | 正常模式，条款不可压 |
| 医疗、财务建议类内容 | 正常模式，保留完整前提与免责说明 |
| 情绪安抚、危机沟通、对外正式函件 | 正常模式 |
| 需要完整论证、教学讲解 | 正常模式 |

红线：命中上述任一条即切回正常模式；压缩让位于安全与准确度。
