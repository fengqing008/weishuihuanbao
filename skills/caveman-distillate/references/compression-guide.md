# 压缩指南

## 压缩原则

1. **删冗余不删语义**：修饰词、客套、重复信息可删；否定词、条件句、技术术语不可删。
2. **短词替代长词**：use → 用；implement → 做；approximately → ~；because → 因。
3. **片段句 OK**：不需要完整语法结构，主谓宾齐即可。
4. **技术术语精确**：Kubernetes 不缩写为 K8s（除非用户自己用了 K8s）。

## 压缩层级

| 层级 | 方法 | 示例 |
|------|------|------|
| L1 删废话 | 删除客套、填充词 | "好的，我来帮你看看" → 直接回答 |
| L2 缩句子 | 片段化，去连接词 | "because of the fact that" → "因" |
| L3 换短词 | 同义短词替换 | "utilize" → "用"；"demonstrate" → "显示" |
| L4 结构压缩 | 合并同类信息 | 多句描述 → 一行 `[X] [Y] [Z].` |

## 何时停止压缩

- 技术术语出现时停止，保留原文。
- 否定/条件句出现时停止，保留完整。
- 安全相关描述出现时停止，完整保留。
