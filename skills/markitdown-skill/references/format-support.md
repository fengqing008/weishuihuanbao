# MarkItDown 支持的格式与限制

## 支持的格式（15+ 种）

| 类别 | 格式 | 转换质量 | 备注 |
|------|------|----------|------|
| 文档 | PDF（文字层） | ★★★★★ | 直接提取文本，保留结构 |
| 文档 | PDF（扫描件） | ★★☆☆☆ | 需要 Azure OCR，无API时降级 |
| 文档 | Word (DOCX) | ★★★★★ | 完整保留标题、表格、列表 |
| 演示 | PowerPoint (PPTX) | ★★★★☆ | 提取幻灯片文本和备注 |
| 表格 | Excel (XLSX/XLS) | ★★★★☆ | 保留表头和数据，复杂公式丢弃 |
| 图片 | PNG/JPG/GIF/BMP/TIFF | ★★★☆☆ | 仅EXIF元数据+OCR文字提取 |
| 音频 | MP3/WAV/M4A/OGG | ★★★☆☆ | EXIF+语音转文字（需API） |
| 网页 | HTML | ★★★★★ | 提取正文，剔除导航/广告/页脚 |
| 数据 | CSV | ★★★★★ | 原样转Markdown表格 |
| 数据 | JSON | ★★★★☆ | 格式化输出 |
| 数据 | XML | ★★★★☆ | 提取文本节点 |
| 压缩 | ZIP | ★★★☆☆ | 解压后逐文件转换，不递归子ZIP |
| 电子书 | EPUB | ★★★★☆ | 提取章节文本 |
| 视频 | YouTube URL | ★★★☆☆ | 提取字幕/描述（需网络） |

## 转换限制

1. **PDF扫描件**：纯图片PDF无文字层时，OCR功能依赖Azure Document Intelligence，无API密钥则返回空内容或仅提取元数据
2. **Excel复杂公式**：公式计算结果丢失，仅保留显示值；图表、图片、SmartArt等嵌入对象不转换
3. **Word复杂排版**：多栏排版、文本框、艺术字可能丢失格式；VBA宏代码不转换
4. **PowerPoint**：SmartArt图形、动画效果、嵌入视频不转换；备注区内容提取
5. **音频/图片OCR**：需要Azure Document Intelligence API密钥，未配置时功能不可用
6. **ZIP递归**：ZIP中的ZIP子文件不递归解压转换
7. **编码问题**：GBK/GB2312编码文件可能出现乱码，优先使用UTF-8编码
8. **大文件**：单文件超过100MB时可能出现内存不足，需分段处理
