# 案例库

## 一、记录原则

只登记已实际完成且有留存的配图任务；未经核实的内容不写入，一律留占位符待补。

## 二、案例登记模板

```markdown
### 案例编号：QL-YYYY-NN
- 场景：（书刊成套配图 / 推文头图 / 汇报插图 / ……）
- 主题词与命中母题：（如「长夜里的灯与远方」→ lamp / mountain / cloud）
- 风格参数：--palette ？ --style ？ --roughness ？ --seed ？
- 交付形态：张数、尺寸（wide / inline）、透明底或纸底
- 质检结果：G1–G6 逐项结论
- 复盘要点：哪里一次过、哪里回修、回修原因
- 来源与留存：（清单文件路径、总览图路径）
```
