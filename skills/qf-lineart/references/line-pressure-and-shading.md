# 压感走笔与体量排线（v2.4.0）

把线稿从「均匀细线」推向「有提按、有体量」的两处机制。二者都挂在同一支手绘笔（`Pen`）上，改参数即改全局。

## 一、压感走笔（Pen._taper）

线宽沿路径呼吸，由两层叠加：

| 层 | 公式 | 作用 |
|---|---|---|
| 包络 | `env = 0.20 + 0.80·sin(πt)^0.72` | 起笔收笔收窄、行笔最宽，出手写提按 |
| 起伏 | `1 + ripple·0.26·sin(2πt·1.35 + φ)` | 行笔速度变化带来的微颤，ripple 取 0.30–0.80 |

最终线宽系数 `k = (1 - press) + press·env·wave`：`press=0` 时退化为等宽直线，`press=1` 时提按最明显。墨色同步：收笔处 alpha 乘 `0.74 + 0.26·env`，形成浓淡。

各笔触的 press：毛笔 1.00 / 炭笔 0.85 / 铅笔 0.74 / 钢笔 0.58 / 马克笔 0.00。马克笔保持等宽是刻意的——马克笔本就扁平。

## 二、出锋（Pen._overshoot）

开放路径两端沿切线各延长 `over × scale` 像素，模拟手绘果断过笔。over：毛笔 1.45 / 钢笔 1.10 / 炭笔 1.00 / 铅笔 0.75 / 马克笔 0.00。

两条护栏：

1. 首尾点距离小于 `4×amount` 视为闭合，不出锋——圆、闭合框、椭圆不会长出尾巴；
2. 点数小于 3 的路径直接返回。

## 三、体量排线（Pen.shade / fill_hachure）

`Pen.shade(shape_pts, angle, gap, alpha, cross)` 给一个面铺浅斜排线，入参是一圈多边形顶点。它转调 `fill_hachure(use_pen=True)`——每条排线由 `Pen.line()` 绘制，因此自带抖动、压感、收锋，并逐条随机浓淡（alpha×0.70–1.12）；形状遮罩保证排线止于面内。

参数取值基线：

| 参数 | 取值 | 说明 |
|---|---|---|
| angle | 38–58° | 斜向排线；水体用 38°、柜体用 58°，避免相邻母题撞角度 |
| gap | 15–18px | 间距越小越密；过密即发糊 |
| alpha | 40–52 | 越浅越干净；压过主轮廓即打回 |
| 形状内缩 | 4–5px | 顶点相对轮廓内缩，防越界 |

已接入的母题：处理池（水体）、档案柜（柜体）。新增母题接入的写法：

```python
pen.shade([(x0 + 4, y0 + 4), (x1 - 4, y0 + 4), (x1 - 4, y1 - 4), (x0 + 4, y1 - 4)],
          angle=38, gap=15, alpha=46)
```

## 四、开关与复现

- `--no-shade` 关闭体量排线，只留纯轮廓线；
- `--transparent` 输出透明底；
- 三处开关都与 `--seed` 兼容，同种子逐像素复现。

## 五、调校与失败模式

| 现象 | 处置 | 对应台账 |
|---|---|---|
| 排线越出形状、压住主轮廓 | 形状内缩 4–5px；gap≥15、alpha≤50 | FM-13 |
| 短线被压感压断 | 跨度＜44px 自动收敛；仍弱则降 `--roughness` | FM-14 |
| 排线显机械 | 确认 `use_pen=True`；每条排线的抖动与浓淡由 `self.rng` 驱动 | — |

排线开／关的同种子对照是验收手段：像素差异应集中在排线面内，不波及轮廓外。
