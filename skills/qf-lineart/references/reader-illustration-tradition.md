# 《读者》插图传统与对标要求

本文件是 qf-lineart「文意提取」通道的立论依据。为文章配图时，先读本文件，再动手。

| 事实 | 内容 | 来源 |
|---|---|---|

## 二、三条创作铁律

### 1. 插图是文章思想内涵的投影，不是文字图解
画家杜凤宝（为《读者》画 35 年）：「插图能使文章形象，文章能使插图深刻，它们之间应该互为补充」；「插图的灵魂是构思，构思一定要巧妙、要深刻……那不是看图识字，读者可没有那么幼稚」。

落到本引擎：**画面必须从这一篇文章里长出来**。母题库选题只作兜底。

### 2. 先读文稿，再选中心点
画家张弘（为《读者》创作 16 年）自述流程：「仔细阅读文稿，从文章中选择适合插画表现的中心点，充分发挥自身艺术表现特色，将文稿中的故事、人物以及体现出的思想情感表现出来」。

《读者》对插画作者的三项要求：①强劲的绘画造型能力；②丰富的知识储备与多元文艺修养；③表现手法与技法多样化。
《读者》同时又极宽松：「充分尊重作者的艺术思维和创作构想，最大程度释放画家的艺术想象空间」。

落到本引擎：**六步流程的第一步是通读全文，第二步是锁定中心点**，不得跳过直取关键词。

### 3. 一图与一文相生
读者评价（新浪网 2023-10-29 转载）：「《读者》的美编太牛了，文章配图极精准，好像这幅图是专门为这篇文章创作的」。

典型案例：陈忠实《毛乌素沙漠的月亮》→ 李晨作素描插图，画面为「沙漠的夜色之中，一轮又大又圆的满月高悬在天上，干枯的胡杨顶天立地，远处有两人相伴而行」。画面直接取自文中场景，非"月亮=象征"式图解。

## 三、版面规矩（图书与期刊通行惯例）

| 规矩 | 内容 |
|---|---|
| 图跟文走 | 「先文后图，图跟文走，图文紧靠」，插图尽量安排在相关正文附近 |
| 通长图居中 | 图版宽度超过版心三分之二时居中排，两侧不排文字 |
| 一页两图 | 交叉排——上图靠切口一边，下图靠订口一边 |
| 一页三图 | 三角交叉排——第一、三图靠切口，第二图靠订口 |
| 图题 | 文艺类书刊多数插图只有图片、不设图题图注；确需说明时图注排在图片下方 |
| 内容不重复 | 插图内容不应与正文或表格重复 |

来源：《图书约定俗成的版式规矩》（编辑校对）、《插图与表格的排版规则》。

## 四、对本引擎的落地要求

1. **通道**：AI 生图为默认通道（画面表现力）；程序化线稿引擎为兜底（风格绝对统一、离线可复现）。
2. **封面/篇首大图**：承担"文章思想投影"，允许有情节、有主体动作。
3. **栏内小图**：承担"文中一件具体物象"，静物式特写，与篇首大图不重复。
4. **色调**：整册统一。以「素」为基准——墨黑/暖褐线条为主，浅色点缀，米白纸底，大量留白。
5. **负向约束**：不出现文字、字母、数字、logo、水印、企业名、真实人名。
6. **禁项**：不得用"箭头+上台阶=晋升""天平=公平"一类看图识字式图解，除非文章本身在讨论该物件。
