# 引擎规格与算法原理

## 一、三段式渲染管线

```
几何建模 → 手绘化 → 质感合成
（贝塞尔/椭圆采样）  （复笔+两层抖动+bowing）  （纸纹颗粒+晕染+排线填充）
```

### 1. 几何建模
曲线走三次贝塞尔采样（`bez(p0,p1,p2,p3,n)`，默认 40 段）；圆与椭圆按角度均匀采样（`ellipse_pts`，支持指定起止角，用于画弧而不画整圆）。所有几何最终都收敛为**点序列**，交给同一套手绘化处理——这是「改一处即改全局笔感」的关键。

### 2. 手绘化（Rough.js 参数化）
与 Rough.js 的对应关系：

| Rough.js | 本引擎 | 说明 |
|---|---|---|
| `roughness` | `--roughness` | 抖动基准 = 1.7 × roughness × jitter_k |
| `bowing` | `--bowing` | 两点直线在中点加垂向偏移，弯曲量随机取正负 |
| 双描线 | `passes` | 2–3 遍复线，第 p 遍抖动 ×(1+0.35p)、透明度递减 |
| `maxRandomnessOffset` | 两层抖动 | 见下 |
| `seed` | `--seed` | 同种子逐像素复现 |
| `strokeWidth` | 线宽 × width_k | 毛笔走变宽笔触（两端 0.35 倍、中段 1.0 倍） |

**两层抖动（关键设计）**：
1. **整体偏移**：整条线一次性位移 ±0.7j，保证形状不被抖散；
2. **逐点微扰**：每个点再叠加 ±0.45j，出手绘毛边。

早期版本只用逐点独立随机，导致圆偏心、轮廓散架（见失败模式 FM-01）。另设**短元素收敛**：路径跨度小于 40px 时抖动整体 ×0.45，避免星点、书页线糊成一团。

**圆的低频柔波**：圆不用逐点随机半径，改为半径乘 `1 + 0.014·sin(3a+φ) + 0.007·sin(7a+1.7φ)`——保留手绘呼吸感，同时圆仍是圆。

### 3. 质感合成
对应 SVG 手绘滤镜链：

| SVG | 本引擎 | 实现 |
|---|---|---|
| `feTurbulence` | `_value_noise` | 低分辨率随机点阵 + 双线性放大（Perlin 噪声的轻量等价物） |
| `feDisplacementMap` | 两层抖动 | 噪声场位移源的解析等价 |
| `feBlend` 多副本 | 复笔叠线 | 2–3 遍不同 alpha 的线叠加 |
| `feGaussianBlur` | `blur` | 收笔后整体高斯晕染（墨水洇纸 / 铅笔柔边） |
| `feColorMatrix` 锐化 alpha | 颗粒反转 | 纸纹颗粒局部削弱 alpha，形成浓淡 |

**纸纹颗粒**（`apply_grain`）：生成值噪声图 → 反向映射为 alpha 乘子 `255-(255-v)·strength` → 与原图 alpha 相乘。铅笔 0.22、炭笔 0.35、钢笔 0.06。

**暖纸底**（`apply_paper`）：铺 `palette.paper` 暖色 + 极轻纸纹，用于网页与幻灯片等需要不透明底的场景；出版内页保持透明底。

## 二、排线填充（hachure）

`hachure_mask()` 等价于 Rough.js 的 `fillStyle`：在形状包围盒内沿指定角度铺等距平行线（间距 `gap`、抖动 `jitter`），再用形状轮廓做 alpha 遮罩裁剪。支持三种填充：

- `hachure`：单斜排线（默认 45°）；
- `cross-hatch`：正反两向叠加，第二层透明度 ×0.75；
- `dots`：点阵，按 `gap×1.7` 步长铺点；
- `use_pen`：排线走手绘笔（默认开）——每条排线由 `Pen.line()` 绘制，带抖动、压感、收锋与逐条浓淡；关闭后退回等宽机械排线。母题内部的 `Pen.shade()` 走此路径。

## 三、参数总表

| 参数 | CLI | 取值 | 默认 |
|---|---|---|---|
| 笔触 | `--style` | fountain / pencil / brush / marker / charcoal | fountain |
| 配色 | `--palette` | sepia / ochre / amber / terracotta / rosewood / olive / ink | sepia |
| 尺寸 | `--size` | WxH | 1500x820 |
| 粗糙度 | `--roughness` | 0–3 | 1.0 |
| 弯曲度 | `--bowing` | 0–3 | 1.0 |
| 颗粒 | `--grain` | 0–0.5 | 按笔触档案 |
| 种子 | `--seed` | 整数 | 2026 |
| 纸底 | `--paper` | 开关 | 关 |

## 四、复现性

同 `--motif --style --palette --seed --size` 组合出图逐像素一致。交付成套图时把 seed 写入配图清单，便于返修时只改单张而不牵动全局。

## 五、压感与出锋（v2.4.0）

`Pen._taper()` 让线宽沿路径呼吸：包络 `env = 0.20 + 0.80·sin(πt)^0.72`（起笔收笔收窄、行笔最宽），再乘低频起伏 `1 + ripple·0.26·sin(2πt·1.35 + φ)`；`press` 决定两者对线宽的影响权重（press=0 退化为等宽）。收笔处 alpha 乘 `0.74 + 0.26·env`，墨色随之变淡。

`Pen._overshoot()` 在开放路径两端沿切线各延长 `over × scale` 像素，模拟手绘过笔；首尾点距离小于 `4×amount` 视为闭合，不出锋，避免圆与闭合框留尾巴。

短路径收敛：`_taper` 对跨度小于 44px 的路径把 press 乘 0.35，`_overshoot` 对点数小于 3 的路径直接返回，保证星点、书页短线不被压断或拖尾。
