# 插画任务单（art brief）规范

任务单是「读文→构思→出图」之间的交接件。它把一篇文章变成一到两条可执行的画面指令。

## 一、任务单字段

```json
{
  "order": 28,
  "title": "竣工验收这半年",
  "column": "人生",
  "wide": {
    "subject": "深夜的办公桌，摊开的验收问题台账",
    "scene": "一只手正捏笔往台账某一行打勾，纸角压着一枚印章，杯里茶已凉，画面上方露出窗外厂区轮廓与一线夜色",
    "composition": "横版 16:9，主体偏左，右上留白",
    "mood": "沉静、笃定"
  },
  "inline": {
    "subject": "一枚印章压在纸面横线上（特写）",
    "scene": "印面只露一半，旁边一道未打完的勾，纸纹清晰",
    "composition": "竖版 3:4，主体偏下，上方留白",
    "mood": "郑重"
  },
  "palette": "sepia",
  "style": "pencil",
  "anchor": "kn:销号"
}
```

| 字段 | 说明 |
|---|---|
| `subject` | 画面主体。一件人/物/场景，必须能在本文找到出处 |
| `scene` | 展开描述：主体在做什么、周围有什么、光线氛围。60–120 字 |
| `composition` | 版式与构图：比例、主体位置、留白方向 |
| `mood` | 情绪基调，一到两个词 |
| `anchor` | 落位锚点：`kn:关键词` 或 `p:段落序号`，供排版时"图跟文走" |

## 二、两条任务的取法

### wide（篇首/跨栏大图）——取"文章的核心场景"
在文中找**一处有场景、可入画**的段落：一个动作瞬间、一处场所、一场对话的现场。
- 卷首语类：取"心境落点"的画面，如清晨书桌、归途路灯
- 人物类：取"身份与处境"的画面，如安全帽挂在椅背、会议室角落的一只保温杯
- 方法/经验类：取"工作现场"的画面，如台账打勾、图纸摊开、阀门扳手搁在池沿

### inline（栏内小图）——取"文中一件具体物象"
在与 wide 不同的段落里找**一件可特写的静物**，它应在文中出现、且承载情绪或转折。
- 例：一份签完字的验收单角落、一只磨旧的卷尺、半杯凉茶、安全帽上的划痕

## 三、质量标准（六条红线）

1. **有出处**：`subject` 必须能在本文找到对应语句或物件，不得凭空造设。
2. **非图解**：不得把文章主题直接翻成符号（"晋升=上台阶""公平=天平"）。
3. **两图不重**：wide 与 inline 的主体、场景、视角均不相同。
4. **可入画**：画面能被"看见"——有具体主体与空间关系，避免抽象概念。
5. **无字**：画面中不得出现文字、字母、数字、logo、水印、企业名、真实人名。
6. **克制**：一个画面讲一件事，元素不堆砌，留白不少于三成。

## 四、示范（三篇）

### 示范一 · 卷首语《35岁环保水务人的职业路径》
- **wide**：清晨六点的一处厂区小路上，一个背影正拎着资料袋走向沉淀池，池面浮着一层薄雾，远处塔吊尚未落架；构图横版，主体偏右，左侧大面积晨雾留白。基调：清醒、未定。
- **inline**：安全帽挂在椅背上，帽檐内侧有一圈汗渍印痕（特写）。
- 淘汰写法：三级台阶+向上箭头（看图识字）。

### 示范二 · 《竣工验收这半年》
见上文 JSON 示例。
- 淘汰写法：`checklist` 母题"一块夹板清单，三个方框打勾"——通用且与本文的"台账/签章/最后一公里"无呼应。

### 示范三 · 《一封"异议函"》
- **wide**：一张摊开的信纸压在会议桌上，纸面竖排横线尚未落字，纸旁一叠章程文书与一支搁下的笔，桌角露出一枚印章；横版，主体偏左，右侧桌面留白。基调：克制、郑重。
- **inline**：信纸右下角的一枚签章与一段留白（特写）。
- 淘汰写法：天平母题"一端砝码一端文书"——把"异议"图解为"称重"。

## 五、自检清单

- [ ] 每条 `subject` 都能指出文中出处（段落或原句）
- [ ] wide 与 inline 的主体不同
- [ ] 画面里没有文字类元素
- [ ] 未出现"箭头/台阶/天平/齿轮"这类符号化图解
- [ ] 构图写明比例、主体位置、留白方向
- [ ] `anchor` 指向与画面最相关的那一段
- [ ] 全书 palette / style 保持统一
