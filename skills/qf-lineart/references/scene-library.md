# 场景母题库（v2.0，16 个）

场景母题与象征母题的分工：**象征母题**（叶、云、月）给氛围，**场景母题**给内容。图与文对得上，靠的是场景。

## 二、人物基元

`person(d, pen, x, y, h, ink, pose)`：`y` 为脚底，`h` 为身高比例，`pose` 取四种。

| pose | 姿势 | 用在 |
|---|---|---|
| `stand` | 站立（双臂自然下垂） | 台阶、队列、路上 |
| `sit` | 坐姿（大腿水平、小腿向下） | 会议、对坐、办公 |
| `point` | 抬臂指向 | 讲解、交接、递交 |
| `raise` | 双臂上举 | 表态、达成、庆祝 |

人物只画头 + 躯干 + 四肢，不画五官——保持线稿的克制，也避免"画不像脸"。

## 三、选题与权重

- 场景母题在选题打分中权重 **×1.5**，与象征母题同池竞争，能命中就优先。
- 命中不足时，补位顺序为：`steps3 → desk → plant → checklist → leaf → book`。
- 一篇文章配 2 张时，优先让跨栏大图用场景、栏内浮图用象征，形成"内容 + 氛围"的搭配。

## 四、扩展方式

```python
def s_wrench(d, W, H, pen, ink):
    """扳手：喻动手与维修"""
    pen.line(d, [(W*0.3, H*0.7), (W*0.68, H*0.32)], ink, 4)
    ...

DRAW["wrench"] = s_wrench
MOTIF_META["wrench"] = {"cn": "扳手", "kw": ["维修", "动手", "抢修"], "desc": "扳手，喻动手与维修"}
SCENES.append("wrench")
```

新增场景只需三行注册，即自动继承全部笔触、配色、颗粒与落位能力。

## 五、验收

场景出图后必须拼总览图逐格目视，判定"不看标签能否认出"。判据与失败模式 FM-10 一致：**认不出就改画法，不靠标签解释**。
