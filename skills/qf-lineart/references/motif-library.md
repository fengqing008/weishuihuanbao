# 母题库（16 个）

每个母题的构图要素、意象与选用指引如下。母题是**意象**，不是写实插画——画的是「灯」的意味，不是灯具说明书。

## 一、基础母题（12）

| 母题 | 构图要素 | 意象 | 关键词 |
|---|---|---|---|
| `leaf` 一叶 | 主叶脉曲线 + 四组对生小脉 | 成长与自然 | 叶 树 枝 花 草 生长 林 森 春 绿 |
| `sprout` 新芽 | 地平线 + 主茎 + 双叶 + 顶端圆点 | 起点与希望 | 种 芽 新生 希望 开始 幼 萌 育 |
| `mountain` 远山 | 两峰折线 + 山脊短线 + 日轮与地平线 | 志向与远征 | 山 峰 远方 路 跋涉 岭 高 登 |
| `window` 窗 | 田字窗棂 + 窗台线 | 日常与家园 | 窗 家 屋 巷 门 邻 房 院 |
| `lamp` 灯 | 吊线 + 梯形灯罩 + 灯碗 + 柔光晕圆 + 桌沿线 | 温暖与守候 | 灯 光 夜 照 明 亮 火 暖 |
| `book` 书 | 双侧书脊 + 双弧书页 + 中缝 + 页纹短线 | 阅读与文思 | 书 读 字 页 翻 写 纸 文 |
| `bird` 飞鸟 | 三组尺度递减的 V 形双翼 | 自由与远方 | 鸟 飞 天空 自由 翅 翔 |
| `cloud` 云 | 三朵圆弧叠云 + 底线 | 闲适与变幻 | 云 天 风 雨 飘 空 |
| `moon` 月 | 外弧（左侧 228°）+ 内凹弧闭合的月牙 + 三点散星 | 静思与梦境 | 月 星 梦 静 夜 黑 |
| `ripple` 水波 | 五层同心椭圆（仅保留下半） | 时间与流动 | 水 河 海 波 流 湖 雨 |
| `boat` 舟 | 船身弧 + 船沿 + 桅杆 + 双帆 + 水面线 | 渡越与前行 | 船 舟 渡 帆 远航 |
| `pattern` 纹样 | 双同心圆 + 八向短辐条 + 圆心点 | 秩序与哲思 | 时间 生命 人生 世界 岁月 |

## 二、扩展母题（4）

| 母题 | 构图要素 | 意象 | 关键词 |
|---|---|---|---|
| `tea` 一盏茶 | 杯身梯形 + 杯沿 + 托碟 + 杯柄弧 + 三缕热气 | 慢与从容 | 茶 咖啡 饮 香 煮 杯 闲 |
| `bridge` 桥 | 拱曲线 + 桥面线 + 双侧桥墩 + 栏柱 + 水线 | 连接与过渡 | 桥 连接 跨越 两岸 通 渡口 |
| `star` 星 | 五角星（外内交替顶点）+ 三颗散点 | 愿望与指引 | 星 愿 梦 闪耀 期 盼 |
| `home` 小屋 | 三角屋顶 + 屋身 + 烟囱 + 门 + 田字窗 | 归处与团圆 | 家 房子 屋 居 团圆 归 |

## 三、选题逻辑

1. 统计标题与正文中各母题关键词的出现次数；
2. 按次数降序取前 n 个（同分时按 seed 随机打散）；
3. 命中不足 n 个时，按 fallback 顺序补位：`leaf → moon → pattern → cloud → ripple → star`；
4. 补充的母题在清单中同样带 `motif` 字段，便于人工复核替换。

## 四、易混母题辨析

- `moon` 与 `star`：月牙主体 + 散星 vs 五角星主体 + 散点，主题为「静」取月、为「愿」取星。
- `lamp` 与 `star`：灯有吊线与灯罩实体，星无支撑结构。
- `ripple` 与 `bridge`：都有水线，水波稿无水岸结构，桥稿有拱与墩。
- `window` 与 `home`：窗只截取窗棂局部，小屋含屋顶与烟囱的整体轮廓。

## 五、扩展方式

新增母题只需两步：

1. 在 `lineart_engine.py` 的 `MOTIF_META` 中加条目（中文名 / 关键词 / 说明）；
2. 写绘制函数 `m_xxx(d, W, H, pen, ink)` 并注册进 `DRAW` 字典。

绘制函数只调 `pen.line / pen.curve / pen.circle / pen.dot`，即可自动继承全部笔触、配色与质感能力。
