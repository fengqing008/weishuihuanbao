# AI 生图通道（引进自公众号排版技能的配图引擎）

## 一、两条通道的分工

| 通道 | 工具 | 特征 | 什么时候用 |
|---|---|---|---|
| **AI 生图通道**（主） | `scripts/prompt_builder.py` + 外部/平台绘图后端 | 场景更丰富、更贴合文章内容；靠统一提示词模板抑制风格漂移 | **成书与成套交付的主通道** |
| **程序化引擎**（兜底） | `scripts/lineart_cli.py` | 离线、逐像素可复现、风格绝对统一、体量小（一张图 0.5–2 秒） | AI 出图缺位或失败时补位，保证图文齐备 |

主通道出图须用**同一套提示词模板**（米白纸底 + 暖褐线条 + 具体场景 + 负面约束）压住风格漂移；兜底通道补齐主通道未覆盖的图位。

底色一律**米白纸实底**：透明底在深色界面或深色底纹上会呈黑底观感，故默认 `paper=True`；确需透明底才显式 `--transparent`。

## 二、提示词范式（引进要点）

公众号配图的经验里有三条关键：

1. **落到具体物件**——"台阶、扳手、图纸、池体、管线"比"渐变、发光、抽象几何"更耐看、更有信息量；
2. **结尾必附负面约束**——否则会生成文字、字母、数字与 logo；
3. **留白要留够**——头图右侧留白供叠标题，方图主体不压底部标题区。

提示词结构：

```
简约手绘线条插画，米白色纸张质感背景，<比例与构图>。<具体场景>。
以<主色>线条为主，<点缀色>点缀，线条干净疏朗，大量留白。不得出现任何文字、字母、数字、logo、水印。
```

## 三、用法

```bash
# 从稿件清单批量生成提示词
python3 scripts/prompt_builder.py --manifest book.json --per-article 2 -o prompts.json

# 单条（给一句话，直接得到提示词）
python3 scripts/prompt_builder.py --text "竣工验收这半年" -o one.json

# 查看 32 个母题的画面描述
python3 scripts/prompt_builder.py --list-prompts
```

输出结构：


## 四、后端选择

| 后端 | 端点 | 说明 |
|---|---|---|
| 阿里百炼 Qwen-Image | DashScope `text2image/image-synthesis` | 中文提示词友好，需 Key 与额度；沙箱账号当前欠费（2026-09-20 实测 `Arrearage`） |
| Pollinations | `image.pollinations.ai/prompt/<提示词>` | 免费无 Key；**中文易跑题，建议英文提示词**；有速率限制 |
| 本地 SD / ComfyUI | 自建 | 可控性最高，需算力 |

出图后按 `references/quality-checklist.md` 的 G1–G6 逐项复核；AI 图额外加一条：**同批图的风格必须一致**，发现漂移就重出该张。

## 五、叠字（可选）

若图要用于封面或头图，可借鉴公众号管线的做法：生成图**不带字**，标题在本地叠加，文字位置取留白区（横图从宽度 55% 起排），字体用 Noto Serif CJK（标题）与 Noto Sans CJK（副题），浅底配深字、深底配浅字。

## 六、失败模式

| 现象 | 根因 | 处置 |
|---|---|---|
| 图里出现文字或字母 | 提示词未附负面约束 | 每条提示词末尾必附 `不得出现任何文字、字母、数字、logo、水印。` |
| 中文提示词跑题 | 部分后端对中文语义理解弱 | 改用英文提示词，或换中文友好的后端 |
| 同批图风格不统一 | 逐张调参、未锁定风格词 | 提示词固定风格词与色名；漂移的图重出 |
| 请求被限流 | 免费后端速率限制 | 降并发、加退避重试；仍不通就回到程序化引擎 |
| 生成图带水印 | 后端默认加水印 | 关闭水印参数（如 `nologo=true`）或换后端 |

## 七、沙箱现状（2026-09 更新）

- 程序化引擎：可用，已用于《江江手记》成书与成套配图。
- **AI 通道：可用**。平台绘图后端（image_gen）可正常出图，实测一批 35 张场景图一次成批产出、无文字事故；单图 864×1152 约 1.8MB，缩为 720 宽 JPEG 约 150KB。
- 工作分工：AI 通道负责成批场景插画，程序化引擎负责缺位补图与需固定复现的场合；两通道不得在同批混用同一图位。
- 调用方式：按本文第二节范式逐条撰写提示词（含负面约束），交绘图后端出图，落盘后按 `references/quality-checklist.md` 的 G1–G7 复核。

## 八、Qwen-Image-2.1 接入路径与约束（2026-09-20）

Qwen-Image-2.1 于 2026-09-19 开源（7B 视觉组件、文生图与编辑合一、原生透明图像），官网 `qwen.ai/blog?id=qwen-image-2.1`。它对线稿与手绘风格的还原在社区实测中表现稳定，原生透明底便于叠到手绘稿上。

三条接入路径与各自约束：

| 路径 | 做法 | 约束 |
|---|---|---|
| 本机 / 云 GPU 部署 | 取 HuggingFace / ModelScope 权重自行部署 | 7B 视觉组件需约 16GB 显存；沙箱为 CPU、无 GPU，跑不动 |
| 百炼云 API | DashScope 图像接口 | 沙箱账号欠费（`Arrearage`）；2.1 未上架百炼，云上当前为 `qwen-image-3.0` |
| 第三方站点 | `qwenimg2.com` 一类提示词站 | 涉密内容不外传；出图品质不可控 |

沙箱内的可用替代：平台绘图后端（image_gen）与程序化引擎（`lineart_cli.py`）。提示词范式沿用第二节，风格词固定为 `hand-drawn line art`，叠图场景再补 `transparent background optional`。
