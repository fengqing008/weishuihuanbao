# 质检判据 G1–G7

出图后逐项过门，任一项不过即回修，不带病交付。

## G1 可辨

**判据**：输出图与母题语义一致，掩盖文件名后仍能认出主题。

**验收动作**：拼一张总览图（`--sheet`），逐格目视；发现「认不出」或「与语义不符」的格子，回查该母题绘制函数与坐标。

## G2 一致性

**判据**：同批图笔触与配色完全一致，无混搭。

**验收动作**：检查批量清单中所有图项是否共用同一 `--palette` 与 `--style`；抽查 2–3 张图的可见线宽与色调。

## G3 比例

**判据**：跨栏 1500×820、栏内 760×980；不拉伸变形。

**验收动作**：`python3 -c "from PIL import Image;print(Image.open('x.png').size)"` 逐张核对；落位时按 role 取尺寸。

## G4 干净度

**判据**：无孤立杂线、无意外色块、无越界元素。

**验收动作**：把图放到纯白与纯深两色底上各看一遍；深底看白边、白底看残影。关注复线是否散架、是否残留低透明度色块。

## G5 底色

**判据**：出版内页为透明底；网页与幻灯片按承载背景决定是否铺纸底。

**验收动作**：透明底看 alpha 通道是否保留（`Image.open(x).mode == 'RGBA'`）；深底场景确认线条对比度不低于 4.5。

## G6 可复现

**判据**：交付版固定 seed，同参数重跑逐像素一致。

**验收动作**：同命令跑两次，比对文件哈希；把 seed 写入配图清单。

## G7 排线

**判据**：体量排线不出形状边界、不覆盖主轮廓线、不形成污渍块。

**验收动作**：裁剪排线区域放大 3 倍目视；排线止于轮廓内侧、与主轮廓留 4–5px 间隙、密度不过糊。用 `--no-shade` 出同种子对照图，像素差异应集中在排线面内而不波及轮廓外。

## 附：一次性质检命令

```bash
# 总览（查 G1）
python3 scripts/lineart_cli.py --sheet check_sheet.png --palette sepia --style pencil

# 尺寸核查（查 G3）
python3 -c "
from PIL import Image, ImageChops
import glob
for f in sorted(glob.glob('images/auto/*.png')):
    im = Image.open(f)
    print(f, im.size, im.mode)
"
```

## 门禁与响应档位的关系

- L1 直出：至少过 G1、G4、G7；
- L2 选型：过 G1、G4、G6、G7；
- L3 成套：过 G1–G7 全部；
- L4 成建制：过 G1–G7 全部，并留一份总览图与清单备查。
