# 文意构思器（content_composer.py）

把「读文」与「出图」之间那一步自动化：先提文章的核心内容与核心框架，再据此构思画面。

## 一、在链路里的位置

```
正文 ──text_brief.py──▶ 素材底稿（物象／场景段／基调）      只提素材
     ──content_composer.py──▶ 核心框架卡 + 画面任务单        提框架 + 构思画面
     ──prompt_builder.py──▶ 提示词 ──▶ AI 出图 / 程序化兜底
```

旧链路里"读文写任务单"由人（或模型）逐篇手写，无法复用。本脚本承担这一步，并把"提关键词"升级为"提核心框架"。

## 二、核心框架四件

| 件 | 内容 | 取法 |
|---|---|---|
| 一句话主旨 | 文章的论点句 | 短句（≤46 字）且含判断词（不是／才是／要／在于／重在／关键／底线）中权重最高者 |
| 结构骨架 | 各节标题 + 该节核心句 | 按小标题切段（首行无序号的大标题剔除），每段取权重最高的句子作该节核心句 |
| 核心意象 | 去噪后的高频词 | 2–4 字 n-gram，词频 ≥2、虚字占比 <50% 入围，长词优先、互为子串者去重 |
| 画面落点 | wide 与 inline 两条 | 见下节分派规则 |

## 三、画面分派规则

- **论点句 → 主旨**：只作框架卡的首行，不直接入画。
- **叙事句 → wide**：在正文句里按"叙事标记 ×3 ＋ 物件 ×2 ＋ 动作"打分取最高者；`subject` 取句中物件（长词优先），`scene` 由动作转写成画面语言。
- **物象句 → inline**：在与 wide 不同段落的句子里，取一件未用过的**静物**做特写。物象分两类——`ABSTRACT`（事务词：书面意见、关联交易、定价依据）与 `PHYSICAL`（静物：合同、章程、钢笔、台账）；特写只取 `PHYSICAL`，事务词不参与特写。
- **画面语言转写**：动作按 `ACTION_RENDER` 转写（"整理成"→"把散开的纸页理齐、叠成一沓"），氛围按基调补光（`MOOD_LIGHT`），时间词转画面短语（`TIME_PHRASE`："会前"→"这时会议尚未开始"）。场景描述不照抄原文句子，原文原句留在 `evidence` 字段里备核。
- **母题兜底**：`motif_for()` 按 subject 与核心意象命中原生母题，单字关键词权重 ×0.45（避免"书面"把"书"母题抬上来）。此结果只用于程序化兜底出图与落位。

## 四、用法

```bash
# 单篇：任务单 + 核心框架卡
python3 scripts/content_composer.py --file src_52.md -o brief.json --frame-out core_frame.md

# 批量：逐篇出任务单，汇总为 art_brief_auto.json
python3 scripts/content_composer.py --manifest book.json --outdir briefs --palette sepia --style pencil

# 只给标题或短文本，看框架卡
python3 scripts/content_composer.py --text "竣工验收这半年"
```

输出：`<stem>_frame.md`（核心框架卡）、`<stem>_brief.json`（单篇任务单，人读）、`-o` 指定的 `{"briefs":[...]}`（供 `prompt_builder.py --brief` 消费）。

## 五、实测对照（《江江手记》52-一封"异议函"）

| 项 | 旧法（`pick_motifs` 全文关键词） | 新法（核心框架驱动） |
|---|---|---|
| wide | book 书（泛） | 书面意见 → letter 函件 |
| inline | contract 合同 | 合同（特写）→ contract 合同 |
| 第三条 | lab 化验台（"数据"误命中，与文无关） | — |
| 主旨 | 无 | 提反对，不是为了"赢"，是为了"对"。 |
| 结构骨架 | 无 | 六节骨架 + 各节核心句 |

## 六、失败模式

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| FC-01 | 主旨取到长叙事句 | 纯按权重排句，未区分论点句与叙事句 | 主旨限定为"短句 + 判断词"，叙事句改派给 wide |
| FC-02 | 要点混入文档大标题 | 首行大标题与节标题同被记为 heading | 首行无序号者判为文档标题剔除 |
| FC-03 | 关键词出现"是把""封异议函"等噪声 | 虚词组合与跨词 n-gram 未过滤 | 虚字占比 ≥50% 丢弃、词频 ≥2 入围、保留引号与括号作分词边界 |
| FC-04 | 特写选到"关联交易"这类事务词 | 抽象事务词与静物同表 | 物象拆为 ABSTRACT 与 PHYSICAL，特写只取 PHYSICAL |
| FC-05 | 母题兜底给出 book 而非 letter | "书面"含单字"书"，抬高书母题 | 单字关键词权重 ×0.45 |
| FC-06 | `prompt_builder --brief` 报 `'str' object has no attribute 'get'` | 任务单写成裸 dict，消费端期望 `{"briefs":[...]}` | `-o` 统一输出 `{"briefs":[brief]}` |
