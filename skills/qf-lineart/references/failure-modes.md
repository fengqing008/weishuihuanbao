# 失败模式台账（FM-01 至 FM-14）

## FM-01 圆形偏心、轮廓散架

- **现象**：圆看着像两三个错位圆叠在一起；矩形边框错位。
- **根因**：复线按「逐点独立随机」抖动，形状被抖散。
- **处置**：复线改为「整条线整体偏移 ±0.7j + 逐点微扰 ±0.45j」两层；圆改低频柔波（sin 组合）而非逐点随机半径。
- **验证**：渲染后在圆心的水平扫描线上，最右墨点应落在内弧深度处（月牙为 0.62r 量级），而非外圆处。

## FM-02 短元素糊成一团

- **现象**：星点、书页短线、窗棂细节变成墨团。
- **根因**：抖动幅度对小尺寸元素相对过大。
- **处置**：路径跨度小于 40px 时抖动整体 ×0.45。
- **验证**：放大 3 倍看小元素是否仍有清晰结构。

## FM-03 污渍状淡色块

- **现象**：主体旁边出现范围不小的低透明度圆形色块。
- **根因**：早期为「增强画面层次」叠加了低 alpha 大圆。
- **处置**：默认关闭强调层，画面只留墨线；层次靠笔触与颗粒表达。
- **验证**：把图放到纯深底上看有无突兀雾团。

## FM-04 同批图风格不统一

- **现象**：一本册子里有的钢笔有的炭笔，色调不一致。
- **根因**：逐张调参，未锁定风格。
- **处置**：同批强制同一 `--palette` 与 `--style`，参数由主控技能一次传入。

## FM-05 出图不可复现

- **现象**：同参数两次出图不一样，返修牵动全局。
- **根因**：未固定 seed。
- **处置**：交付版固定 seed 并写入清单；返修时只改目标图的 seed。

## FM-06 深色底上线条消失

- **现象**：透明底线稿贴在深色幻灯片上几乎看不见。
- **根因**：透明底未做承载适配。
- **处置**：铺暖纸底，或改浅色墨，或由页面给浅色卡片底。

## FM-07 关键词命中为零

- **现象**：自动选题结果与文本毫不相干。
- **根因**：文本缺少母题关键词。
- **处置**：按 fallback 顺序补位，并把该篇列入人工复核清单。

## FM-08 落位挤压正文

- **现象**：栏内浮图占高过大，正文被挤掉或溢出。
- **根因**：栏内图误用了跨栏比例。
- **处置**：严格按 role 取尺寸（wide 1500×820 / inline 760×980），并复核插入点段落序号。

## FM-09 中文标签渲染成方块

- **现象**：总览图角标的中文显示为方块或报编码错。
- **根因**：角标未加载中文字体，退回 PIL 默认位图字体。
- **处置**：显式加载 CJK 字体（Noto Sans CJK / 文泉驿），加载失败退化为英文标签而不中断出图。

## FM-10 场景画出来认不出

- **现象**：场景母题的关键物件语义不明（跑鞋画成半圆、交接画成悬浮物）。
- **根因**：人物过简、物件只取其形未取特征。
- **处置**：关键物件只画「一眼能认出」的写法；改完拼总览图目视复核，逐个判定可辨性。
- **验证**：掩盖文件名后能认出主题。

## FM-11 抽象符号与内容脱节

- **现象**：只用象征母题（叶／云／月）表达具体主题，图与文对不上。
- **根因**：选题未区分象征与场景母题。
- **处置**：场景母题权重 ×1.5 优先命中；象征母题只作补位。
- **验证**：核对图与正文的物象是否同源。

## FM-12 核心框架提取跑偏

- **现象**：文意构思器给出的论点句与叙事句混位、要点混入文档大标题、跨词 n-gram 入榜。
- **根因**：分派规则未生效或 n-gram 边界过宽。
- **处置**：按 `references/content-composer.md` 第六节的 FC-01 至 FC-06 逐条处置。
- **验证**：核心框架卡四件（主旨／骨架／意象／落点）逐项与原文对应。

## FM-13 排线越出形状或压住主轮廓

- **现象**：体量排线越过形状边界，或压住主轮廓线使画面发脏。
- **根因**：shade 形状点贴轮廓、间距过密、透明度偏高。
- **处置**：形状点相对轮廓内缩 4–5px；间距≥15px、透明度≤50；出图后放大看边界。
- **验证**：`--no-shade` 出同种子对照图，像素差异应集中在排线面内而不波及轮廓外。

## FM-14 压感过强致短线断裂

- **现象**：短元素（星点、书页线）被压感收窄到断裂或断续。
- **根因**：press 施加于超短路径。
- **处置**：跨度＜44px 的路径自动收敛压感（press×0.35）；仍偏弱时降低 `--roughness`。
- **验证**：放大 3 倍看短线是否连续。

## 记录格式

新增失败模式时按「现象 / 根因 / 处置 / 验证」四段记录，并回填 SKILL.md 第十节表格。
