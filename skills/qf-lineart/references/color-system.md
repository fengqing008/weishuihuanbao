## 二、对比度核算

按 WCAG 相对亮度公式核算（`L = 0.2126R + 0.7152G + 0.0722B`，通道先做 sRGB 线性化；`CR = (L_亮+0.05)/(L_暗+0.05)`）：

| 配色 | 主墨对暖纸 | 主墨对纯白 |
|---|---|---|
| sepia 暖褐 | 7.37 | 7.94 |
| ochre 赭石 | 5.50 | 5.87 |
| amber 暖金 | 6.47 | 6.81 |
| terracotta 陶土 | 6.19 | 6.68 |
| rosewood 玫瑰木 | 7.75 | 8.35 |
| olive 暖橄榄 | 6.67 | 7.06 |
| ink 传统墨 | 13.55 | 14.16 |

**门禁**：插图主墨对承载底色的对比度不低于 4.5。上表全部达标，最低为赭石 5.50。

## 三、选色建议（按场景）

| 场景 | 首选取色 | 理由 |
|---|---|---|
| 书刊内页（淡黄纸） | sepia 暖褐 | 与米黄纸色同族，最融 |
| 公众号推文头图 | ochre 赭石 / amber 暖金 | 屏幕显色亮，缩略图辨识度高 |
| 汇报材料与方案 | terracotta 陶土 | 沉稳不抢正文 |
| 节庆与温情主题 | rosewood 玫瑰木 | 偏红暖调，气质温厚 |
| 自然与乡土主题 | olive 暖橄榄 | 低饱和，久看不累 |
| 需极高清晰度的印刷小图 | ink 传统墨 | 对比度最高，缩印不失真 |

## 四、与主题色板的映射

与其他技能联动时，配色口径由主控技能统一传入。若主控技能有自有色板（例如版式主题的纸色与栏题色），映射规则：

1. **纸色对齐**：本引擎 `paper` 取主控技能的页面底色；
2. **主墨取深色槽位**：取主控色板中最深的正文/标题色，或直接用本引擎同类暖色；
3. **强调取亮色槽位**：取主控色板中的点缀色；
4. **对比度复核**：映射后重算主墨对底色的对比度，低于 4.5 时回到本引擎暖色系兜底。

## 五、深色底适配

透明底线稿贴在深色背景上会失去可见度，处理方式三选一：

1. 铺暖纸底（`--paper`）后贴图，最稳；
2. 改用浅色墨（把 `ink` 换为浅色），适用于深底就地绘制；
3. 由承载页面给插图加浅色卡片底（推荐用于深色幻灯片）。
