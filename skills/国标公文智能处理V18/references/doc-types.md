# 各类文书完整写作规范与模板结构

> 依据：《党政机关公文处理工作条例》（中办发〔2012〕14号）、《党政机关公文格式》（GB/T 9704-2012）
> 编写日期：2026年5月27日

---

## 一、法定公文类

### 1. 请示

**法定定义**：适用于向上级机关请求指示、批准。

**核心特征**：
- 行文方向：上行文（下级→上级）
- 核心要求：**一文一事**，不得一文多事
- 行文时机：**事前请示**，不能先斩后奏
- 主送机关：只能一个主管上级机关
- 是否需回复：**是**（上级须用"批复"答复）
- 请示是"办件"——需要上级办理并回复

**与报告的关键区别**：请示需要上级批复，报告不需要。

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的请示

[主送机关]：

　　[请示缘由]：说明请示的背景、原因和必要性（可分段）。
　　[请示事项]：明确请求批准的具体内容（如经费金额、人员名单、方案要点等）。
　　[结语]：妥否，请批示。
            （或：请审批。/ 以上请示如无不妥，请批复。）

                                                [发文机关]
                                                [日期]
（联系人：[姓名]  联系电话：[电话]）
```

**写作要点**：
- 请示缘由要合理充分，有据可依
- 请示事项要具体明确，不可模糊
- 结尾必须有请示结语（"妥否，请批示"等）
- 附件如有则标注（如方案、预算明细等）
- 联系人信息置于落款后（当请示事项需上级进一步沟通时）

---

### 2. 报告

**法定定义**：适用于向上级机关汇报工作、反映情况，回复上级机关的询问。

**核心特征**：
- 行文方向：上行文（下级→上级）
- 行文时机：**事后行文**（"事前请示，事后报告"）
- 语言特点：陈述性为主
- 是否需回复：**否**（报告是"阅件"）
- **禁止夹带请示事项**

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的报告

[主送机关]：

　　[引言/背景]：简述报告缘由或依据。
　　[主体内容]：
　　一、基本情况/主要工作
　　二、主要做法与成效
　　三、存在问题和困难
　　四、下一步工作计划/建议
　　[结语]：特此报告。
            （或：专此报告。）

                                                [发文机关]
                                                [日期]
```

**写作要点**：
- 实事求是，数据准确
- 条理清晰，分层叙述
- 不夹带请示事项
- 结语可用"特此报告""专此报告"

**报告的分类**：
1. **工作报告**：汇报常规工作进展（如年度工作报告）
2. **情况报告**：反映专项情况或突发事件（如事故报告、调查核实报告）
3. **回复报告**：回复上级询问（如"关于××问题的情况报告"）
4. **自查报告**：对标上级要求进行自我检查（如"意识形态责任制落实自查报告"）


---

### 3. 通知

**法定定义**：适用于发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文。

**核心特征**：
- 行文方向：下行文（上级→下级）
- **使用频率最高的文种**
- 一事一通知
- 内容要具体明确，可操作性

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的通知

[主送机关]：

　　[通知缘由]：说明目的、依据。
　　[通知事项]：
　　一、×××
　　二、×××
　　三、×××
　　[执行要求]：时间要求、反馈要求等。
　　[附件说明]：附件：1.××
　　[结语]：特此通知。

                                                [发文机关]
                                                [日期]
```

**通知的分类**：
1. **发布性通知**：印发规章制度——"关于印发《××办法》的通知"
2. **转发性通知**：转发上级/同级公文——"关于转发《××通知》的通知"
3. **指示性通知**：部署工作安排——"关于开展××工作的通知"
4. **任免性通知**：人事任免——"关于××同志任职的通知"
5. **会议通知**：告知会议安排——"关于召开××会议的通知"

**写作要点**：
- 标题不能只写"通知"二字，必须包含"关于×××"
- 主送单位必不可少
- 事项分条列述，清晰可操作
- 印发方案/办法时，正文简述，"××方案"作为附件


---

### 4. 通报

**法定定义**：适用于表彰先进、批评错误、传达重要精神和告知重要情况。

**核心特征**：
- 行文方向：下行文
- 特点：及时性、告知性、教育性
- 与通知的区别：通知侧重"执行"，通报侧重"告知+教育"

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的通报

[主送机关]：

　　[通报事实]：陈述事件经过（时间、地点、人物、行为）。
　　[处理结果/评价]：表彰或批评的具体措施。
　　[警示/号召]：希望引以为戒（批评性）或号召学习（表彰性）。

                                                [发文机关]
                                                [日期]
```

**通报的分类**：
1. **表彰性通报**：表扬先进集体/个人
2. **批评性通报**：批评违规违纪事件（必须含：事件经过→处理决定→警示要求）
3. **情况通报**：传达重要情况、会议精神

**写作要点**：
- 事实要清楚准确，不得主观臆断
- 定性要准确适度，与事实相匹配
- 批评性通报必须包含警示/预防措施
- 表彰性通报要提炼精神价值


---

### 5. 决定

**法定定义**：适用于对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项。

**核心特征**：
- 行文方向：下行文
- 约束性强
- 发文主体：常设的党政机关

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的决定

[主送机关]：

　　[决定依据]：说明作出决定的缘由、政策依据。
　　[决定事项]：明确具体决定内容。
　　[执行要求]：对执行落实提出要求。

                                                [发文机关]
                                                [日期]
```

**与通报的区别**：
- 决定侧重"决断"——具有决策性质，层级更高
- 通报侧重"告知"——具有信息传递和教育性质


---

### 6. 函

**法定定义**：适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

**核心特征**：
- 行文方向：平行文（不相隶属机关之间）
- 核心原则：一事一函，语气谦和
- **易错提醒**：平行机关请求批准必须用"函"，不可用"请示"

**标准结构**：
```
[红头标识]
[标题]：×××关于×××的函

[主送机关]：

　　[致函缘由]：说明发函的背景和目的。
　　[致函事项]：具体商洽/请求/答复的内容。
　　[结语]：请予支持为盼。
            （或：此函。/ 盼复。）

                                                [发文机关]
                                                [日期]
```

**写作要点**：
- 语气平等谦和，不用命令式
- 结语与事由匹配（商洽→"请予支持"，询问→"盼复"，答复→"此函"）
- 函有去函和复函两种，复函需引用对方来函文号


---

### 7. 纪要（会议纪要）

**法定定义**：适用于记载会议主要情况和议定事项。

**核心特征**：
- 性质：内部文种
- 三大特性：纪实性（如实记载）、概括性（提炼要点）、内部性（不可替代正式文件）
- **不可替代决定、批复等正式行政文件**

**标准结构**：
```
[标题]：×××会议纪要

[会议基本信息]：
时　间：20XX年X月X日（星期X）X:XX
地　点：×××
主持人：×××
出席人：×××
列席人：×××
记　录：×××

[会议内容]：
一、关于×××
（汇报内容、讨论要点、形成意见）

二、关于×××
（汇报内容、讨论要点、形成意见）

[议定事项]（或"会议决定"）：
1. ×××
2. ×××
3. ×××

[结尾]：
出席：[签名处]（可选）
请假：×××（可选）

分送：×××
```

**写作要点**：
- 只记"议定事项"，不记所有发言
- 如存在分歧，可如实记载
- 领导姓名排序要准确
- 纪要印发日期与会议日期应接近

**与会议记录的区别**：纪要是提炼后的要点概括，记录是原汁原味的全程文字。

## 二、非法定事务文书（学院常用）

### 8. 申请

**性质**：非法定公文文种，属事务文书。

**与"请示"的区别**：
- 请示：正式上行公文，对上级主管机关，需批复
- 申请：向有关部门请求资源/支持，语气较"请示"稍轻

**适用场景**：
- 向校内职能部门请求支持（如图书馆、财务处、教务处等）
- 面向特定管理单位提出具体请求
- 当行文对象为平级或不相隶属单位时

**标准结构**：
```
[标题]：关于×××的申请

[主送单位]：

　　[申请缘由]：说明申请原因和必要性。
　　[申请事项]：明确申请的具体内容。
　　[结尾]：妥否，请予批准。
            （或：请予审批。/ 望予支持为盼。）

                                                [申请单位]
                                                [日期]
```


---

### 9. 总结

**性质**：非法定公文文种，属事务文书。

**适用场景**：年度/半年/季度/专项工作总结

**标准结构**：
```
[标题]：××年度（阶段）××工作总结

[引言]：概述工作背景和总体情况。

一、基本情况
（概述工作总体情况、主要成绩）

二、主要做法
（一）[做法一]
（二）[做法二]
（三）[做法三]

三、存在的主要问题
（客观描述不足之处）

四、下一步工作打算
（一）[具体措施1]
（二）[具体措施2]
```

**写作要点**：
- "基本情况→做法→问题→打算"四段式
- 问题表述要客观，不夸大不回避
- 下步打算要具体可操作
- 数据支撑、成效突出

**建议字数**：1500-3000字（年度总结）、800-1500字（专项总结）


---

### 10. 新闻稿

**性质**：非法定公文文种，属新闻报道体裁。

**核心特征**：遵循新闻写作"5W1H"原则（Who, What, When, Where, Why, How）

**标准结构**：
```
[标题]：简洁凝练、信息密度高

[导语段]（100字以内，必须包含）：
　　×月×日（时间），×××（人物/单位）在×××（地点）举办了×××活动（事件）。
　　出席的有×××、×××等X余人。

[详情段]（展开活动过程）：
　　"……"（直接引语，领导讲话原文）
　　活动中，×××。

[意义段]（升华总结）：
　　此次活动是×××的重要举措。下一步，学院将×××。
```

**写作要点**：
- 导语不能漏5W要素
- 领导名字和职务准确无误
- 引用直接引语→增强现场感
- 结尾避免空泛套话，用具体意义收尾
- 500-800字为佳

---

### 11. 情况说明

**性质**：非法定公文文种，属事务文书。

**适用场景**：对特定事件、人员情况进行客观说明（不含请求审批性质）

**标准结构**：
```
[标题]：关于×××的情况说明

[主送单位/致：]：

　　[背景简述]：说明起因。
　　[事实经过]：客观陈述事件经过。
　　[处理/说明]：相关处理措施或解释说明。

                                                [说明单位]
                                                [日期]
```

**与报告的区别**：情况说明更侧重"解释性"，不展开分析和建议。


---

### 12. 工作方案/实施方案

**性质**：非法定公文文种，属事务文书；通常以"通知"附件形式下发。

**标准结构**：
```
[标题]：×××实施方案

一、工作背景（必要性分析）
二、总体目标
三、基本原则
四、主要任务
（一）[任务1]
（二）[任务2]
五、保障措施
（一）组织保障
（二）制度保障
（三）经费保障
六、工作要求
```

**建议字数**：1000-2500字

## 三、文体辨识对照表（速查）

| 场景 | → 应使用 | 常见错误 |
|------|---------|----------|
| 向校领导请求批准经费 | → 请示 | ❌ 写成"申请"或"报告" |
| 向图书馆申请资源 | → 申请 | ❌ 写成"请示" |
| 工作完成后的汇报 | → 报告 | ❌ 写成"请示"（报告不需批复） |
| 发布人事任免 | → 通知 | ❌ 写成"通报" |
| 批评违纪行为 | → 通报 | ❌ 写成"通知" |
| 表彰先进个人 | → 决定 或 通报 | - |
| 给平行学院发函 | → 函 | ❌ 写成"请示" |
| 记载会议内容 | → 纪要 | ❌ 用纪要替代正式文件 |
| 对特定事件解释 | → 情况说明 | ❌ 写成"报告" |
| 对外宣传报道 | → 新闻稿 | ❌ 套用公文格式 |
| 部署工作安排 | → 通知 | - |

## 四、学院特色品牌材料

### "讲好中国故事"系列材料

**特殊要求**：
- 紧扣"党建 + 国际传播"主线
- 突出"红色译路"品牌特色
- 体现 MTI 硕士点专业优势
- 示范参考：以《"红色译路"铸魂育人》材料为模板

**参考结构**：
```
一、背景与缘起
二、品牌定位与内涵
三、主要实践路径
（一）课堂教学融合
（二）实践活动创新
（三）成果转化推广
四、典型案例
五、品牌成效
六、推广价值与展望
```

### 品牌推介材料

**建议字数**：800-1500字

**结构**：
```
一、品牌背景与定位
二、主要内容与做法
三、特色亮点
四、工作成效
五、推广价值
```

## 五、讲话稿/发言材料

**建议字数**：1000-2500字（按实际时间控制，约每分钟200字）

**三段式结构**：
1. 肯定成绩 → 2. 部署任务 → 3. 提出要求

**要点**：
- 适当口语化，注意朗读节奏感
- 多用祈使句："要……""必须……""切实……"
- 开场称呼准确（"各位老师，同志们：""各位领导，同事们："）

---

## 六、立项/投标类文书

### 实验室建设经费请示

**特殊要求**：
- 须包含：建设必要性 → 建设内容（含设备清单） → 经费预算（明细表） → 预期效益
- 附件应包括：平面布局图、设备技术参数、三家以上报价单
- 预算表格式：序号/设备名称/规格型号/数量/单价/金额/备注

### 采购请示

**特殊要求**：
- 须说明现有设备状况及不足
- 采购清单须注明品牌/型号/数量/单价
- 大额采购需附询价记录或论证意见
