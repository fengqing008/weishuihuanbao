# 国标公文智能处理V18 · 实战案例库（case-library）

> 本案例集为 GB/T 9704-2012 与《党政机关公文处理工作条例》口径下的实务范式。来源为技能内置文种模板库与公开实务整理；示例中的人名、文号、金额均为占位，以【待核】标注，须用户核实后替换，不编造。

## 案例一：请示（水务场景 · 上行文）

- **输入**："给市住建局打个请示，申请污水处理厂提标改造资金补助。"
- **来源**：references/doc-types.md 请示模板 + 《党政机关公文处理工作条例》中办发〔2012〕14号。
- **处理**：文种速判→请示（请求批准、一文一事、事前行文、需批复）；字数档 300-800；主送"××市住房和城乡建设局："单一主送、顶格；结构=背景→事项（分条）→结语`妥否，请批示。`；落款后加联系人行。
- **输出**：`关于申请污水处理厂提标改造工程资金补助的请示.docx`（导出桌面）。
- **检查点**：有结语；主送顶格不缩进；金额千分位；未核实数据全部标【待核】。

## 案例二：报告（不得夹带请示）

- **输入**："写一份年度工作情况的报告上报。"
- **来源**：references/doc-types.md 报告模板。
- **处理**：文种速判→报告（事后行文、禁夹带请示、不需批复）；字数 1000-2000；结构=背景→做法→成效→问题→打算。
- **输出**：`关于2026年度工作情况的报告.docx`。
- **检查点**：结尾不得写"妥否，请批示"；不得夹带请求事项；事实与判断分离（判断以「判断：」起头）。

## 案例三：纪要（内部文种 · 无红头无落款）

- **输入**："把这次××项目推进会的会议纪要整理出来。"
- **来源**：references/doc-types.md 纪要模板。
- **处理**：文种速判→纪要（内部文种、无红头无落款、文末注参会）；结构=时间地点→主持人→参会→议题→议定事项；人名以 OA 电话本为准。
- **输出**：`××项目推进会会议纪要.docx`。
- **检查点**：不得加红头落款；参会名单完整；议定事项可执行。

## 案例四：修改已有 docx（含降级）

- **输入**：用户上传一份格式错乱的既有公文要求重新排版。
- **事实**：原文件 run 散乱，直接导出会被格式覆盖。
- **处理链**：先 `read_docx.py` 读全文 → 跑 `merge_runs.py` 合并散乱 run → 改写并 `Write` 临时 md → `format_and_export.py` 导出 → `render_check.py` 转图逐页核对。
- **降级**：soffice 缺失时跳过渲染验证，回退为逐条对照自审清单人工核查；桌面不可写时用 `--output` 指定目录，仍失败兜底交付 Markdown 源稿。
- **检查点**：字体/行距/缩进/表格与国标逐项对照；未核实文号、日期以【待核：具体项】占位。
