# 党政公文写作风格规范

> **必读配套文件**：[punctuation-errors.md](punctuation-errors.md)——公文写作中常见标点符号误用例析，全文中文标点符号强制执行。

## 整体风格定位

党政公文风格，专业精炼，四字成语密集，对仗句式频繁，冒号式标题最常用。

## 标志性语言特征

### 1. 四字成语/词组密集使用

典型表达（高频出现）：
- 铸魂育人、守正创新、凝心聚力、砥砺前行
- 提质增效、落地见效、多措并举、久久为功
- 立德树人、培根铸魂、固本强基、强基筑魂
- 聚焦主责主业、紧扣时代脉搏

### 2. 对仗句式

常用结构：
```
以X为Y，以X为Z
抓X促Y，以X带Z
既要X，又要Y
一方面X，另一方面Y
```

示例：
```
以党建为引领，以育人为根本
抓内涵促发展，以改革带创新
```

### 3. 冒号式标题（最常用格式）

```
[主标题]：[副标题/内容概括]

示例：
守正创新：高校党建品牌建设实践与探索
铸魂育人：以"红色译路"打造党建+国际传播特色品牌
```

### 4. 排比结构

三段式排比最常见：
```
一是……；二是……；三是……
首先……，其次……，再次……（注：此结构仅在逻辑并列时使用，非AI套话）
```

### 5. 数字量化强调

在成果描述中大量使用具体数据：
```
举办活动XX场次、覆盖师生XX人次、形成成果XX项
```

## 禁止使用的 AI 套话

以下表达会让文章显得 AI 味过重，**严禁使用**：
- "首先、其次、最后"（作为行文逻辑词时禁用，作为序列标注时可用）
- "综上所述"
- "总的来说"
- "不难发现"
- "值得注意的是"
- "总而言之"
- "需要指出的是"
- "毋庸置疑"

## 段落写作习惯

- 段落不宜过长，一般 3-5 句话
- 论点 + 论据 + 小结的三段式段落结构
- 多用短句，少用复合从句
- 数据、案例具体，不泛泛而谈

> 格式排版标准统一见 [format-standard.md](format-standard.md)，此处仅列写作风格层面的要求。

## 新闻稿特殊要求

- 凝练不冗长，500-800字为佳
- 导语（第一段）须包含：时间、地点、人物、事件核心
- 多引用直接引语（领导讲话原文）
- 结尾升华意义

## 党建类材料特殊要求

- 紧扣上级精神（引用会议、文件精神）
- 成效数据具体化
- "做法 → 成效 → 经验" 三段式结构
- 突出特色创新点

## 工作总结/汇报特殊要求

- "基本情况 → 主要做法 → 存在问题 → 下步打算" 四段式
- 问题表述要客观，不夸大不回避
- 下步打算要具体可操作
