> 依据：《党政机关公文格式》GB/T 9704-2012 + 通用公文版式示例 + 发文注意事项 + 公文写作中常见标点符号误用例析
> 编写日期：2026年5月27日

## 〇、标点符号规范（全文强制）

> 详见 [punctuation-errors.md](punctuation-errors.md)，以下为最核心规则：

| # | 规则 | 错误示例 | 正确示例 |
|---|------|---------|---------|
| 1 | 全文统一使用**中文标点符号** | 学院,党委 | 学院，党委 |
| 2 | 并列书名号/引号间不加顿号 | 《通知》、《报告》 | 《通知》《报告》 |
| 3 | 时间起止用一字线（—） | 2025年5月-6月 | 2025年5月—6月 |
| 4 | 数值范围用浪纹线（～） | 300-500元 | 300～500元 |
| 5 | 发文字号年份用六角括号〔〕 | (2026)5号 | 〔2026〕5号 |
| 6 | 句号用中文全角（。） | ...报告完毕. | ...报告完毕。 |
| 7 | 逗号用中文全角（，） | 但是,必须 | 但是，必须 |
| 8 | 冒号用中文全角（：） | 如下: | 如下： |
| 9 | 分号用中文全角（；） | 其一;其二 | 其一；其二 |
| 10 | 括号统一使用全角（） | 请示(已批复) | 请示（已批复） |
| 11 | 引号统一使用全角"" | "重要指示" | "重要指示" |
| 12 | 连接号区分使用场景 | —（一字线）/ ～（浪纹线）/ －（半字线） | 按场景正确使用 |

## 二、字体字号规范

### 2.1 红头标识（发文机关标志）【已全局禁用】

- 字体：方正小标宋简体
- 字号：小初号（36pt）
- 颜色：红色
- 对齐：居中
- 说明：**当前版本全局禁用红头标识，所有文档均不自动生成红头。** 此节仅供参考。

### 2.2 标题

- 字体：方正小标宋简体（推荐）或黑体
- 字号：二号（22pt）
- 对齐：居中
- **不加粗**
- **上方不空行**（紧接发文字号）
- 标题结构：发文机关名称 + 事由 + 文种
  - 示例：`××大学××学院关于推荐×××任××中心主任的请示`

### 2.3 一级标题

- 格式：`一、` `二、` `三、`
- 字体：黑体
- 字号：三号（16pt）
- 对齐：两端对齐，首行缩进2个字符，回行顶格
- **不加粗**

### 2.4 二级标题

- 格式：`（一）` `（二）` `（三）`
- 字体：楷体_GB2312
- 字号：三号（16pt）
- 对齐：两端对齐，首行缩进2个字符，回行顶格
- **不加粗**
- **注意**：括号为六角括号〔〕还是圆括号（）——二级标题使用圆括号（）

### 2.5 三级标题

- 格式：`1.` `2.` `3.`
- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 对齐：两端对齐，首行缩进2个字符，回行顶格
- **不加粗**

### 2.6 四级标题

- 格式：`（1）` `（2）` `（3）`
- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 对齐：两端对齐，首行缩进2个字符，回行顶格
- **不加粗**

### 2.7 正文

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 对齐：两端对齐
- 首行缩进2个字符，回行顶格
- **不加粗**

### 2.8 主送机关

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 对齐：左对齐
- 与标题之间空一行
- 末尾加冒号

### 2.9 附件说明

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 与正文间空一行
- 首行缩进2个字符
- 格式：`附件：1.×××××`（回行与附件名称对齐）

### 2.10 落款

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 发文机关署名：居中
- 成文日期：两端对齐，右空2个字符
- 日期使用阿拉伯数字：`2026年5月27日`
- 与正文/附件/联系人间空三行
- **不加冒号**

### 2.11 联系人信息

- 字体：仿宋_GB2312
- 字号：三号（16pt）
- 格式：`（联系人：×××  联系电话：×××××××××××）`
- 对齐：居中
- 联系人与联系电话中间空2个字符
- 与正文/附件空一行

### 2.12 页码

- 位置：底端外侧（双面打印）
- 奇数页：右下角（右外侧）
- 偶数页：左下角（左外侧）
- 格式：`-1-`（宋体四号 14pt，通过 Word/WPS 内置 `numberInDash` 页号格式自动生成短横线）
- 实现：VML 浮动文本框 + `mso-position-horizontal:outside` 自动定位（奇数页外侧=右，偶数页外侧=左），单一页脚无需奇偶页分开
- 页脚距底边：992 twips（约 1.75cm）
- 编号：封面/目录/摘要等前置页面不显示页码，正文从第 1 页开始（`pgNumType start="1"`）
- 强制规则：若用户未特别说明，默认覆盖文档中原有错误的页码设置

## 三、段落格式

| 设置项 | 标准值 |
|--------|--------|
| 行间距 | 固定值 28 磅（全文统一） |
| 首行缩进 | 2 个字符（正文段落） |
| 段前间距 | 0 磅 |
| 段后间距 | 0 磅 |
| 段间空行 | **禁止**（正文段落之间不插入空行） |

**关键规则**：
- 主标题与主送机关之间空一行
- 主送机关与正文之间空一行
- 正文各段之间**不空行**
- 附件说明与正文之间空一行
- 联系人信息与落款之间空一行
- 落款与正文之间空三行

---

## 四、发文字号格式

- 格式：`发文机关代字〔年份〕序号`
- 示例：`外院〔2026〕5号`
- 年份使用六角括号〔〕（非圆括号）
- 序号不编虚位（即5不写05）

## 五、公文格式示例（v12：无红头标识）

```
                    ××大学文件

××院〔2026〕5号

                ××大学××学院
              关于推荐×××任××的请示

人事处：

    正文内容……

                                                ××大学××学院
                                                2026年5月27日

（联系人：×××  联系电话：×××××××××××）
```

## 六、会议纪要特殊格式

- **无标题**（仅有"×××会议纪要"字样）
- **无落款**
- 需在文末注明所有参会人员（格式同正文附件）
- 时间段非跨年的，结束时间不用填写年份，月份同理
