# 常用标准限值速查

## 一、排放标准

| 标准 | 名称 | 主要适用 |
|---|---|---|
| GB 18918-2002 | 城镇污水处理厂污染物排放标准 | 城镇污水厂 |
| GB 8978-1996 | 污水综合排放标准 | 工业排水 |
| GB 21900-2008 | 电镀污染物排放标准 | 电镀行业 |
| GB 13458-2013 | 合成氨工业水污染物排放标准 | 合成氨 |
| GB 15580-2011 | 磷肥工业水污染物排放标准 | 磷肥 |
| GB 25467-2010 | 铜镍钴工业污染物排放标准 | 有色金属 |

> 选择原则：有行业标准的优先执行行业标准，无行业标准的执行综合排放标准；地方标准严于国家标准的执行地方标准。

## 四、使用提示

1. 标准与导则存在修订，使用前须核对现行有效版本。
2. 限值判定须注意标准的适用范围、时段与特别排放限值。
3. 涉及地方标准时须同时核对地方生态环境部门的要求。
