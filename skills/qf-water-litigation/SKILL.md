# 水务工程诉讼应诉实务（被告方）

水务工程涉诉的败因，多数不在法理，而在时限与举证：答辩期过了才想起提管辖异议，举证期限满了才想起申请鉴定，结算资料散在项目部与财务两个抽屉里，对不上判决认定的付款节点。本技能把"收到传票"到"结案修复信用"的链条拆成可执行动作，每一步绑定法定期间、举证责任与现行裁判规则。

## 需求澄清（收到任务先评，缺项一次问清，只问一轮）

**不评不开工**：下表五维逐一对照，任何一维不明确，开工前一次性追问，只问一轮；问清即进入工作流。

| 维度 | 判断要点 | 不明确时的动作 |
|---|---|---|
| 诉讼阶段 | 收到起诉状／答辩／举证／开庭／上诉 | 追问 |
| 案由 | 工程款／质量／工期／劳务／确认无效／执行异议 | 追问 |
| 本方角色 | 被告／原告／第三人 | 追问 |
| 案件事实与证据 | 争议焦点、现有证据材料 | 追问 |
| 交付范围 | 答辩状／证据目录／质证意见／应诉策略 | 按交付范围匹配响应级别 |

**响应分级**：L1 程序/期限问答→直接答；L2 单件文书→标准流程；L3 答辩+证据+质证→分步+质检；L4 全套应诉策略→全流程+归档。

## 一、专家级路由

先定层级，层级决定响应深度与产出形态。

| 层级 | 使用者 | 核心诉求 | 主产出 | 首选专家件 |
|---|---|---|---|---|
| A 案件经办人 | 法务专员、合约专员 | 什么时候交材料、交哪些材料 | 应诉台账、时限表、材料清单 | `references/evidence-and-burden.md` |
| B 答辩负责人 | 法务负责人、外聘律师 | 答辩理由怎么立、证据怎么组 | 答辩状、证据目录、质证意见 | `references/answer-templates.md`、`references/judicial-rules.md` |
| C 项目公司负责人 | 总经理、分管副总 | 赔多少、上不上诉、会不会被执行 | 风险评估与处置方案 | `references/case-library.md` |

黄金窗口是送达日到答辩期届满这一段。答辩期一过，管辖权异议权同步丧失（《中华人民共和国民事诉讼法》第一百三十条第一款），民诉法第一百二十八条规定的十五日答辩期为法定期间，不因内部审批未走完而顺延。拿到任何涉诉材料，先答三问：送达单上的日期是哪天、案由与诉讼请求是什么、我方在合同链条上占哪一环。三问答不出，后续所有动作都是空转。

## 二、五维评估（任何应诉任务先跑）

1. **程序位置**：处于收案登记、管辖权异议期、答辩期、举证期、庭前会议、开庭、判决后上诉期、执行哪一段。程序位置决定可用的抗辩手段：管辖异议只能在提交答辩状期间提出，鉴定申请只能在举证期限届满前提出，逾期即消灭。
2. **案由与诉讼请求**：案由是建设工程施工合同纠纷、确认合同无效纠纷、劳务合同纠纷、追索劳动报酬纠纷、买卖合同纠纷还是执行异议。诉讼请求逐项拆解为"请求权基础 + 金额 + 责任主体"三列，含优先受偿权、连带责任、确认无效等复合请求的，逐项单列。
3. **主体与责任边界**：我方是发包人、总承包人、分包人、转包人、实际施工人还是代建方；上游是否欠付、下游是否已付清。边界不清，答辩状会写成认责书。
4. **证据与举证责任**：主张已付款的举证责任在我方，主张工程质量不合格的举证责任在我方，主张对方无实际施工人身份的举证责任在我方。举证责任分配判断错，证据组织方向即错。
5. **风险与信用等级**：标的额、是否已被保全、是否可能被纳入失信被执行人名单、裁判文书是否会被互联网公布。标的额超过公司净资产一定比例或已被保全的，按 L4 处置。

五维结论用一张表落定：维度、结论、依据、缺口、风险等级。任何一维标注【待核：说明】的，在补齐前不得出正式文书。

## 三、四级响应

| 档位 | 触发情形 | 动作 | 产出 |
|---|---|---|---|
| L1 | 问法定期限、问答辩要点、问某个裁判规则 | 直接答复并援引法律全称与条款 | 问答 + 法律依据 |
| L2 | 单份文书处理：写一份答辩状、算一次期限、列一次证据目录 | 走对应模板与脚本 | 答辩状、期限表、证据目录 |
| L3 | 完整案件应诉：从收案到判决后处置 | 八步全流程 | 应诉台账 + 答辩状 + 证据目录 + 质证意见 + 处置方案 |
| L4 | 财产保全、协助执行、农民工工资群体性被诉、执行异议、企业信用修复、标的额重大 | L3 全套 + 程序专项 + 风险与信用专项 | 全套文书 + 程序申请书 + 风险与信用报告 |

L4 触发词：财产保全、冻结、协助执行、执行异议、失信被执行人、农民工工资、群体性起诉、破产重整、优先受偿权、信用修复。

## 四、应诉全流程八步

### Step 1 收案登记与时限锁定

- 登记九项：案号、法院、案由、当事人、诉讼请求、标的额、送达日、开庭时间、承办法院联系方式。
- 送达日以送达回证签收日为准；留置送达、邮寄送达、电子送达的送达日认定见 `references/evidence-and-burden.md`。
- 用 `scripts/deadline_calc.py` 一次算出答辩期、举证期、管辖异议截止日、上诉期，全部写进应诉台账。
- 命令：

```bash
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type first-instance --json
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type appeal-judgment
```

- 🔴 送达日不明时，先向法院调取送达回证，不得按"大概这几天"倒排。

### Step 2 管辖与程序性抗辩审查

- 管辖异议：在提交答辩状期间提出，依据《中华人民共和国民事诉讼法》第一百三十条第一款。合同约定仲裁条款、约定管辖法院的，逐条比对是否排除法院管辖。
- 主体资格：我方是否为适格被告，是否应追加当事人。
- 程序性申请：延期举证、证据保全、鉴定、追加第三人、反诉，全部在举证期限届满前提出。
- 计算与登记命令：

```bash
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type evidence-period --mode ordinary
```

### Step 3 主体资格与责任边界审查

- 画三段链条：发包人 → 总承包人 → 分包/转包人 → 实际施工人/班组。画出我方位置，逐段标注合同号、金额、已付比例。
- 发包人责任的边界：依据《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第四十三条，发包人只在欠付建设工程价款范围内对实际施工人担责；欠付额为 0 则不担责，且该责任不含建设工程价款优先受偿权。
- 转包、违法分包导致合同无效的，依据《中华人民共和国民法典》第七百九十三条，验收合格的参照合同关于工程价款的约定折价补偿承包人，补偿口径以约定为准。
- 表见代理：依据《中华人民共和国民法典》第一百七十二条，无权代理行为有效的要件是相对人"有理由相信"行为人有代理权；项目经理越权签认工程量、签收材料的效力，逐案核对授权范围与相对人善意。

### Step 4 实体答辩与请求权基础拆解

- 把每一诉讼请求拆成"请求权基础 → 构成要件 → 我方抗辩"三列。对抗拒付工程款的请求，可用要件事实逐条否定：合同关系、工程量确认、结算口径、付款条件成就、质量合格。
- 常用抗辩五类：合同效力抗辩、结算依据抗辩（财政评审条款与下浮率约定）、付款条件未成就抗辩、质量与工期抗辩（违约金抵扣）、诉讼时效抗辩（《中华人民共和国民法典》第一百八十八条，三年）。
- 答辩状按 `references/answer-templates.md` 的五段结构成文，程序抗辩在前，主体抗辩居中，实体抗辩在后。
- 裁判规则的逐条引用与适用条件见 `references/judicial-rules.md`。

### Step 5 证据组织与举证

- 证据目录按"证明对象"分组，不按文件类型堆放。每组写清证据名称、来源、页码、证明对象、对应诉讼请求。
- 核心证据五组：合同与招投标文件、结算与送审/评审资料、签证与变更确认、付款凭证与对账、往来沟通记录（含微信记录与电子数据）。
- 举证责任分配、逾期举证的后果、电子数据固定方法见 `references/evidence-and-burden.md`。
- 从判决书或起诉状文本中批量抽取要素，命令：

```bash
python3 scripts/case_extract.py --file ./判决书.txt --json --out ./case.json
python3 scripts/case_extract.py --text "原告某某公司诉被告某某公司建设工程施工合同纠纷一案，诉讼请求如下：……" 
```

### Step 6 庭审准备与出庭

- 准备三张表：事实时间轴、争议焦点与举证对应表、对方证据质证意见表。
- 传票应到时间、应到处所、承办人电话逐字抄录；传票注意事项载明被告迟到十分钟或不到庭将被缺席审理。
- 出庭人员携带：传票、授权委托书（须记明委托事项与权限，承认、放弃、变更诉讼请求与和解、反诉、上诉需特别授权）、营业执照复印件、法定代表人身份证明书、证据原件。

### Step 7 判决后处置

- 收到判决书当日锁定上诉期：判决十五日、裁定十日，起算点为送达日（《中华人民共和国民事诉讼法》第一百七十一条）。
- 决定不上诉的，核算履行期限与利息起算点，安排资金；判决生效后未按期履行将加倍支付迟延履行期间债务利息。
- 提上诉的，上诉状围绕一审认定事实错误与适用法律错误分成两组，各组对应到具体证据与法条。

### Step 8 结案复盘与信用修复

- 复盘四问：时限有没有被自己拖累、证据有没有在链条上断掉、责任边界在合同中能不能前置约定、同类案件在集团内是否重复发生。
- 已进入执行程序的，核对财产报告义务、执行和解条款、失信名单与征信记录；征信不良记录在履行完毕后仍保存五年，履行完毕后主动申请信用修复。
- 结案材料归入案件卷宗与集团法务台账，文书范本沉淀回 `references/answer-templates.md`。

## 五、常见案由与答辩要点速查

| 案由 | 原告典型请求 | 我方核心答辩点 | 关键证据 | 法律依据 |
|---|---|---|---|---|
| 建设工程施工合同纠纷（工程款） | 支付欠付工程款及利息、主张优先受偿权 | 结算依据约定优先；付款节点与比例已履行；付款条件未成就；质量与工期抗辩扣减 | 施工合同、结算书、财政评审意见、付款凭证、对账确认单 | 《中华人民共和国民法典》第八百零七条、第七百九十三条；解释（一）第四十三条 |
| 确认合同无效纠纷（分包/转包） | 确认分包合同无效并判令付款 | 我方主体是否适格；无效后折价补偿口径；下浮率约定的效力与解释 | 分包合同、招投标文件、送审报告、验收记录 | 《中华人民共和国民法典》第七百九十一条、第七百九十三条；《中华人民共和国建筑法》第二十八条 |
| 劳务合同纠纷、追索劳动报酬 | 支付劳务费、要求发包人承担连带责任 | 我方与原告无合同关系；原告既非实际施工人亦非农民工；严格适用合同相对性；已向上游付清 | 施工合同、付款凭证、工资结清承诺书与工资支付清单 | 《中华人民共和国民法典》第四百六十五条、第一百八十八条；《保障农民工工资支付条例》第三十条 |
| 买卖合同纠纷（设备、材料款） | 支付货款及违约金 | 交付与验收未达标；对账差异未确认；质量异议期届满；到期债权抵销 | 采购合同、到货验收单、对账确认单、质量异议函 | 《中华人民共和国民法典》第五百九十五条、第六百二十六条 |
| 执行异议、协助执行 | 追加被执行人、要求协助扣划款项 | 协助范围仅限通知书载明事项；案外人实体权利优先；超标的查封提出异议 | 协助执行通知书、付款台账、合同关系证明 | 《中华人民共和国民事诉讼法》第二百三十六条、第二百三十八条【待核：条号按现行有效文本核对】 |
| 财产保全 | 冻结应得工程款 | 保全必要性；担保是否足额；保全范围与标的额是否超限；申请复议 | 保全裁定书、担保保函、付款节点证明 | 《中华人民共和国民事诉讼法》第一百一十一条 |

## 六、应诉时限速查

| 程序节点 | 法定期限 | 起算点 | 法律依据 |
|---|---|---|---|
| 答辩期 | 15 日 | 收到起诉状副本之日 | 《中华人民共和国民事诉讼法》第一百二十八条 |
| 管辖权异议 | 提交答辩状期间 | 收到起诉状副本之日 | 《中华人民共和国民事诉讼法》第一百三十条第一款 |
| 举证期限（一审普通程序） | 不少于 15 日 | 法院指定或当事人协商经法院认可 | 《最高人民法院关于民事诉讼证据的若干规定》第五十一条 |
| 延期举证申请 | 举证期限届满前 | 举证期限届满日 | 《最高人民法院关于民事诉讼证据的若干规定》第五十四条 |
| 鉴定、增加或变更诉讼请求、反诉 | 举证期限届满前 | 举证期限届满日 | 《最高人民法院关于民事诉讼证据的若干规定》第五十一条、第三十一条 |
| 财产保全复议 | 5 日，一次 | 收到裁定书之日 | 《中华人民共和国民事诉讼法》第一百一十一条 |
| 上诉期（判决） | 15 日 | 判决书送达之日 | 《中华人民共和国民事诉讼法》第一百七十一条 |
| 上诉期（裁定） | 10 日 | 裁定书送达之日 | 《中华人民共和国民事诉讼法》第一百七十一条 |
| 建设工程价款优先受偿权行使 | 最长 18 个月 | 发包人应当给付建设工程价款之日 | 解释（一）第四十一条 |
| 诉讼时效 | 3 年 | 权利人知道或应当知道权利受损及义务人之日 | 《中华人民共和国民法典》第一百八十八条 |

期间计算规则：期间开始的日不计入，自次日起算；期间届满的最后一日是法定休假日的，以法定休假日结束的次日为届满日（《中华人民共和国民事诉讼法》第八十五条）。日期换算用 `scripts/deadline_calc.py` 落地，不得手工推算。

## 七、责任边界与关键裁判规则

1. 建设工程价款优先受偿权的权利主体限于与发包人订立建设工程施工合同的承包人（解释（一）第三十五条），实际施工人不享有优先受偿权；对原告主张优先受偿权的，先攻主体资格。
2. 实际施工人以发包人为被告主张权利的，法院追加转包人或违法分包人为第三人，查明发包人欠付数额后，判决发包人在欠付建设工程价款范围内承担责任（解释（一）第四十三条）；欠付数额为零即不担责，我方须以付款凭证与结算资料证明欠付为零。
3. 合同无效但工程验收合格的，参照合同关于工程价款的约定折价补偿承包人（《中华人民共和国民法典》第七百九十三条）；无效不等于按实际成本据实结算，约定口径仍是基准。
4. 约定以财政评审价下浮一定比例结算的，财政评审意见构成结算依据；主张评审价仅为预算依据的，须举证约定已被变更或被排除适用，并承担不配合报送结算资料的不利后果。
5. 发包人股东的出资义务已履行完毕的，公司独立承担民事责任，股东不因未参与经营而担责（《中华人民共和国公司法》相关规定）。
6. 劳务合同纠纷与建设工程分包合同纠纷属不同法律关系，班组仅持个人欠条起诉的，请求权指向欠条出具人，不适用实际施工人突破合同相对性的规则。
7. 诉讼时效届满的，我方行使时效抗辩权（《中华人民共和国民法典》第一百八十八条）；工程完工退场与对方未主张的时间节点须有退场记录、结算资料、往来函件支撑。
8. 表见代理成立的，被代理方承担责任（《中华人民共和国民法典》第一百七十二条）；反制路径是举证相对人不具善意、授权范围明示排除、印章与签字早有异议记录。

## 八、工具与命令

```bash
# 案件要素批量抽取（判决书、起诉状、答辩状文本 → 案号/当事人/案由/诉请/判项）

python3 scripts/deadline_calc.py --deliver 2026-02-15 --type first-instance --json
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type appeal-judgment --holidays 2026-04-04,2026-04-05,2026-04-06
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type evidence-period --mode simplified
python3 scripts/deadline_calc.py --deliver 2026-02-15 --type preservation-reconsider
```

工作流片段：

```
收案登记 → 时限锁定 → 程序抗辩 → 责任边界 → 实体答辩 → 证据组织 → 庭审 → 判决后处置 → 结案复盘
```

抽取脚本输出字段（`--json`）：`case_no`（案号）、`court`（法院）、`cause`（案由）、`parties`（当事人及诉讼地位）、`claims`（诉讼请求）、`judgment`（判决主文）、`amounts`（金额，千分位规范化）、`missing`（缺失字段，标【待核】）。

## 九、失败模式与降级

| 编号 | 失败模式 | 处置（降级/兜底） |
|---|---|---|
| FM-01 | 答辩期已过才发现，管辖异议权同步丧失 | 立即核对送达回证；确实逾期则以实体答辩与证据抗辩补齐，并记录时限失控原因 |
| FM-02 | 举证期限届满后才申请鉴定或反诉 | 提出延期举证申请并说明客观障碍；被驳回的，转以已有资料作反证 |
| FM-03 | 送达日无法认定，全部期限无法起算 | 向法院调取送达回证或电子送达记录；未取得前全部期限标【待核：送达日】 |
| FM-04 | 付款凭证散落项目部与财务，欠付数额证不出 | 回落银行流水、对账确认单、发票三源交叉，逐笔重算欠付额 |
| FM-05 | 把劳务合同纠纷当建设工程施工合同纠纷答辩 | 回到案由本身，先否主体资格与法律关系，再谈实体 |
| FM-06 | 答辩状直接承认工程款数额，只争付款时间 | 金额争议与时间争议分开处理，未经结算核对的金额一律标【待核】 |
| FM-07 | 认定优先受偿权时漏攻主体资格 | 先适用解释（一）第三十五条否主体资格，再论行使期间与工程范围 |
| FM-08 | 协助执行通知书收到后不予回应 | 在通知书指定期内书面回复，明确可协助范围与超出范围的异议 |
| FM-09 | 微信记录只截图不固定原始载体 | 保留原始载体，做公证或当庭演示，附完整对话上下文 |
| FM-10 | 授权委托书未记明特别授权，庭上无法和解或变更请求 | 开庭前补办特别授权委托书 |
| FM-11 | 判决书关键数据（金额、期限）未核对即执行 | 逐项与卷宗核对，缺项的标【待核：来源】 |
| FM-12 | 案件信息含当事人身份信息被写入对外材料 | 对外材料只留案号与抽象事实，身份信息脱敏后使用 |

异常处理：`scripts/deadline_calc.py` 在送达日格式非法时退出码非零，此时不得以估算日期出表；`scripts/case_extract.py` 抽取字段缺失时，`missing` 列表非空，缺项一律标【待核：说明】，禁止凭上下文推断填充。脚本运行环境缺 Python 3.8 以上版本时，降级为手工台账并保留字段清单。

## 十、🔴 关键检查点

- 🔴 送达日以送达回证为准，未取得回证前全部期限标【待核：送达日】，不得先出文书后补期限。
- 🔴 管辖异议、鉴定申请、延期举证、反诉四项程序性动作，须在各自期限届满前完成，逾期即止，不再补救。
- 🔴 答辩状提交前经法务负责人确认，涉重大标的额的经公司负责人确认，确认后定稿。
- 🔴 证据目录每项须写明证明对象与对应诉讼请求，无对应请求的证据不入目录。
- 🔴 出庭前核对传票应到时间与处所，开庭当日提前到场；被告迟到或不到庭将被缺席审理。
- 🔴 判决书送达当日锁定上诉期并书面记录送达日与截止日，需确认是否上诉的，在截止日前三日提交决策意见。
- 🔴 对外提交的任何文书不得含当事人身份证号、银行账号等身份信息，涉敏信息脱敏后使用。

## 十一、反例与红线

1. 反例：答辩状写"我方资金紧张，请求延期支付"。红线：答辩状不认不存在的责任，资金困难不是抗辩理由，反而构成对债务的默认。
2. 反例：收到协助执行通知书后先划款再研究。红线：协助范围以通知书载明为准，超范围协助与拒不协助同样产生责任。
3. 反例：主张已付清却只提供内部台账。红线：付款须以银行流水与对账确认单为据，内部台账不作对外证据。
4. 反例：把实际施工人的优先受偿权主张当成立即谈判。红线：优先受偿权主体资格有法定限制，未经主体审查不得让步。
5. 反例：庭上承认工程量结算数据以换取"和解空间"。红线：承认即免除对方举证责任，数据未核对前禁止当庭认可。
6. 反例：用微信截图打印件代替原始载体举证。红线：电子数据须保留原始载体，否则真实性不予认可的风险由我方承担。
7. 反例：把集团内另一个项目的付款凭证当作本项目证据提交。红线：项目、合同、主体三者不一的证据不得混用。
8. 反例：在起诉状或判决书文本上直接编辑后对外报送。红线：法院文书原文禁止改动，全部引用以原文为准。

## 降级路径速查

| 情形 | 识别信号 | 降级路径 |
|---|---|---|
| 期限误算 | 答辩/举证期限不清 | 回退按收件日重算并提示 |
| 主体资格抗辩失败 | 被告主体不适格判断存疑 | 标注【待核】并保留抗辩 |
| 证据链断裂 | 关键证据缺失 | 列证据清单并提示补强 |
| 裁判规则误用 | 援引规则不适用 | 回退核对最新口径 |
| 文书生成中断 | 答辩状截断 | 断点续跑 |
| 越权代理 | 出现代理出庭表述 | 删除并声明边界 |

遇未覆盖情形按失败分支回退，必要时重试；异常与错误处理以兜底方案优先，涉边界条件给出容错处理，长任务支持断点续跑与补救，无法自动处置时降级为人工复核。
