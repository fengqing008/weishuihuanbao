# 翻译技能使用指南（baoyu-translate / references）

本文件是 SKILL.md 的配套速查件，覆盖模式选择、参数确认、分块口径与术语表用法。

## 一、模式选择

| 模式 | 参数 | 步骤 | 适用内容 |
|---|---|---|---|
| quick | `--mode quick` | 翻译 | 短文本、口语化内容、临时任务 |
| normal | `--mode normal`（默认） | 分析 → 翻译 | 文章、博客、通用内容 |
| refined | `--mode refined` | 分析 → 翻译 → 审查 → 打磨 | 出版级交付、重要文档 |

## 二、参数优先级

参数取值按下列顺序覆盖，越靠前优先级越高：

1. CLI 标志（`--to` / `--mode` / `--audience` / `--style`）。
2. EXTEND.md 中的对应键（`target_language` / `default_mode` / `audience` / `style`）。
3. 技能内置默认值：`target_language=zh-CN`、`mode=normal`、`audience=general`、`style=storytelling`。

## 三、首次配置

1. 按 EXTEND.md 的三级路径查找：项目级、XDG 级、用户主目录级，命中第一个即生效。
2. 三级都未命中时，先跑首次配置再翻译，不可静默使用默认值。
3. 首次配置一次性问齐目标语言、模式、受众、风格与保存位置，用户答完后写入所选路径并回报路径。
4. 用户拒答或要求直接开工时，回退为默认配置并在交付说明中标注。

## 四、分块口径

| 参数 | 默认 | 说明 |
|---|---|---|
| chunk_threshold | 4000 | 超过该词数触发分块 |
| chunk_max_words | 5000 | 单块最大词数 |

1. 分块后逐块翻译再回拼，回拼顺序与源文顺序一致。
2. 指代跨块错位时，把上一块末段作为衔接上下文随块传入后重跑。
3. 分块脚本异常时按标题手动切分，并记录切分位置便于回拼核对。

## 五、术语表用法

1. 术语表支持三种写法：`源词 = 译词`、`源词: 译词`、`源词<Tab>译词`；`#` 开头为注释行。
2. 术语表加载前用 `scripts/glossary_check.py` 预校验，格式错误按报错行修正后重试。
3. 同一源词出现两个译法时，以表内优先级高的条目为准，并把冲突项单列通告用户。
4. 交付时报告术语命中数，便于用户判断术语表覆盖度。

## 六、交付物清单

- 译文终稿 `translation.md`，位于输出目录。
- 译文过程文件与分块记录（分块任务）。
- 术语命中数与非一致项清单。
- 图片待本地化候选清单（源文含图片时）。

## 七、边界

- 不适用于：图片内文字翻译与本地化、整篇文档格式转换、把文章要点提炼成报告。
- 不在范围：字幕制式转换、配音、术语表以外的译法自造。
- 禁止把机翻原样交付冒充精翻终稿；不要改动原文的专有名词、数字与引用编号。
