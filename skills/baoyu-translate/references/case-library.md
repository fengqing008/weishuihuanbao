# 翻译案例库与登记模板（baoyu-translate / references/case-library.md）

本文件为 baoyu-translate 的**案例库**：上半部分为按模板登记的真实案例（每例含背景／做法／结果），下半部分为空白登记模板与数据来源指引。登记值以实际执行回执为准，未核实项保留【待填】/【待核】占位与来源指引。

---

## 一、真实案例（3 例）

### 案例 1：英文技术长文精翻（refined 模式 + 术语表）

- **背景**：用户提供一篇约 6,200 词的英文技术博客（含代码块与图片），要求翻成中文并统一术语，用于团队内部分享。未预先配置 EXTEND.md。
- **做法**：
  1. 命中 BLOCKING 首次配置，一次性询问目标语言/模式/受众/风格/保存位置，写入 `$HOME/.baoyu-skills/baoyu-translate/EXTEND.md`；
  2. 词数 6,200 > chunk_threshold 4000，`main.ts` 自动分块（每块 ≤5000 词），逐块翻译后回拼；
  3. 术语表经 `python3 scripts/glossary_check.py --file glossary.md --json` 预校验（条目数 42，冲突 0）；
  4. 走 refined 四步：Analyze → Translate → Review → Polish，输出终稿。
- **结果**：输出 `translation.md`（约 1.1 万字）+ 分块过程文件；术语命中 42/42，全文术语一致；回执附「图片待本地化候选清单」2 张（框架图标签仍为英文），转 image-text-edit 处理。

### 案例 2：网页文章 quick 翻译（抓取失败重试）

- **背景**：用户给出一个英文网页链接，要求「快速翻一下」。
- **做法**：
  1. 判定为 quick 模式，先抓取正文；
  2. 首次抓取失败（页面为 JS 动态渲染）→ 命中失败模式 F3，转 web-scraper 重试；
  3. 重试成功拿到正文后直接翻译，不跑分析与审查；
  4. `translate_check.py` 校验配置与输出路径。
- **结果**：约 900 词当场交付译文正文与终稿；回执注明「经抓取重试后取得正文」，未凭标题臆造内容。

### 案例 3：合同条款 normal 翻译（术语冲突处置）

- **背景**：一份英文服务合同需翻成中文供内部审阅，用户提供自定义术语表（含「Service Provider → 服务提供方」等 18 条）。
- **做法**：
  1. normal 模式：Analyze → Translate；
  2. 术语表检查发现同一源词「Party」有两个译法「当事方/一方」→ 命中失败模式 F6，按优先级高的条目为准，冲突单列；
  3. 全文替换重跑，交付说明标注冲突处置；
  4. 交付时提示：正式对外译文须由具资质机构复核（红线第 6 条）。
- **结果**：输出终稿并附术语冲突清单；用户据清单修订术语表后，第二轮一次通过；未改动原文数字、条款编号与署名。

## 二、案例登记模板

| 字段 | 填写要求 |

| 触发问法 | 抄录用户原始表达【待填：用户原话】 |
| 输入形态 | URL / 本地文件 / 图片 / 粘贴文本【待填：输入形态】 |

| 失败与补救 | 命中的失败模式（F1–F7）与处置动作【待填：处置记录】 |

## 三、数据来源指引

1. 分块记录：`scripts/main.ts` 运行输出与分块文件清单。
2. 术语统计：`python3 scripts/glossary_check.py --file 术语表.md --json` 输出的条目数、冲突数与命中数。
3. 配置回执：EXTEND.md 的路径与首次配置时用户的回答。
4. 交付回执：输出目录清单、终稿字数与术语命中数汇总行。
5. 用户评价：用户对文风、术语与排版的具体反馈原文。

## 四、质量抽查项

1. 术语一致性：同一源词在全文中是否只用一种译法。
2. 指代一致性：代词与指代对象在分块回拼后是否保持正确指向。
3. 数字与专名：数字、单位、专有名词与引用编号是否与原文一致。
4. 结构保真：标题层级、列表、代码块与链接是否保持不变。
5. 语域匹配：受众与风格设置是否与目标读者一致。

## 五、登记纪律

1. 只登记可回溯的字段，回执里没有的一律写【待填：字段名】；无法核实项标【待核】。
2. **不编造**原文出处、机构名与数据；案例正文里的示例值一律用占位符表达。
3. 涉及未公开材料的案例先脱敏，人名与机构名用代号替换。
4. 失败案例与成功案例同等登记，失败案例须写明失败分支与补救动作。

> 依据溯源：译文质量与标点数字规范参见 SKILL.md「引用依据与溯源」小节（GB/T 19363.1—2003、GB/T 19682—2005、GB/T 15834—2011 等）。
