# 风格与图型适配矩阵（完整版）

本文件为 fireworks-tech-graph 技能原正文《Styles》表与《Style-to-Diagram-Type Adaptation Guide》
的完整归档。选风格时加载本文件，7 套风格的精确颜色令牌见 `references/style-1-flat-icon.md`
至 `references/style-7-openai.md`。

## 一、七套风格总览

| # | Name | Background | Best For |
|---|------|-----------|----------|
| 1 | **Flat Icon** (default) | White | Blogs, docs, presentations |
| 2 | **Dark Terminal** | `#0f0f1a` | GitHub, dev articles |
| 3 | **Blueprint** | `#0a1628` | Architecture docs |
| 4 | **Notion Clean** | White, minimal | Notion, Confluence, Wiki |
| 5 | **Glassmorphism** | Dark gradient | Product sites, keynotes |
| 6 | **Claude Official** | Warm cream `#f8f6f3` | Anthropic-style diagrams |
| 7 | **OpenAI Official** | Pure white `#ffffff` | OpenAI-style diagrams |

## 三、选风格速判

- 技术文档 / 架构说明书 / 内网 Wiki → 3 Blueprint 或 4 Notion Clean
- 开发者博客 / GitHub README / 终端风格演示 → 2 Dark Terminal
- 汇报演示 / 路演 / 产品页 → 5 Glassmorphism 或 1 Flat Icon
- 通用交付且要求最大兼容性 → 1 Flat Icon（默认）
- 对标 Anthropic 或 OpenAI 视觉体系 → 6 Claude Official 或 7 OpenAI Official
