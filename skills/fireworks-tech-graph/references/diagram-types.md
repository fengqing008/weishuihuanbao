# 图表类型与布局规则

本文档为 fireworks-tech-graph 技能的图表类型参考手册，供 SKILL.md 在生成各类图表时加载。

## 支持的图表类型清单

| 类型 | 英文名 | 典型用途 | 关键布局规则 |
|------|--------|---------|-------------|
| 架构图 | Architecture | 服务/组件分层 | 水平分层，层间距120px |
| 数据流图 | Data Flow | 数据传递路径 | 每条箭头标注数据类型 |
| 流程图 | Flowchart | 决策/流程步骤 | 顶底优先，菱形=决策 |
| Agent架构图 | Agent Architecture | AI推理/工具/记忆 | 含循环箭头，记忆分层 |
| 记忆架构图 | Memory Architecture | Mem0/MemGPT式记忆 | 读写路径分色 |
| 序列图 | Sequence | 时序消息交互 | 垂直生命线，顶底时序 |
| 对比矩阵 | Comparison | 方案/系统对比 | 列=系统，行=属性 |
| 时间线/Gantt | Timeline | 阶段/里程碑 | X轴=时间，Y轴=任务 |
| 思维导图 | Mind Map | 概念发散 | 中心辐射，贝塞尔曲线 |
| 类图 | Class Diagram (UML) | 类/属性/关系 | 3格矩形，继承/组合箭头 |
| 用例图 | Use Case (UML) | 用户功能视角 | 角色+椭圆+系统边界 |
| 状态机图 | State Machine (UML) | 实体生命周期 | 圆角矩形=状态，箭头=转换 |
| ER图 | ER Diagram | 数据库模式 | 矩形=实体，菱形=关系 |
| 网络拓扑图 | Network Topology | 网络基础设施 | 分层（Internet→Edge→Core→Access） |

## ViewBox 尺寸速查

| 场景 | ViewBox | 备注 |
|------|---------|------|
| 标准（≤12节点） | `0 0 960 600` | 默认推荐 |
| 高堆栈 | `0 0 960 800` | 节点层数多时 |
| 宽布局 | `0 0 1200 600` | 横向展开 |
| 时间线 | `0 0 960 400` | 时间轴类 |

## 节点尺寸规范

- 标准节点：180×90px
- 核心节点：1.25倍标准（225×112px），3-4px描边
- 次要节点：标准尺寸，2-2.5px描边
- 文本标注：≥12px，推荐13-14px，标题16-18px

## 网格对齐

- 基础网格：8px
- 水平间距：120px间隔
- 垂直间距：120px间隔
- 画布边距：≥40px
- 节点最小间距：≥60px
