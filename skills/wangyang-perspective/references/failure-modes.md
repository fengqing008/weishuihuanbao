# 失败模式（使用本视角时的高频错误）

> 分两层：A 层是「王洋律师视角本身被公开质疑的方法缺陷」，B 层是「用户调用本技能时容易踩的坑」。

## A 层 · 视角自身的方法缺陷（据公开批评整理）

| 编号 | 失败模式 | 表现 | 后果 | 规避 |
|------|----------|------|------|------|
| A-F1 | 用极端值对比制造冲击 | 拿"强奸未遂三年以上"与"猥亵五年以下"并列，模糊两罪各自的量刑区间 | 当事人对法律后果形成错误认知 | 引用罪名必须给**该罪名的完整量刑幅度**，不跨罪名拼接最低值与最高值 |
| A-F2 | 关键概念故弄玄虚 | 抛出罕见症候（悲伤乳头综合症）却秘而不宣，以悬念替代解释 | 法律问题被神秘化，当事人无法复现判断 | 凡引用专业术语，必须当场给出定义、适用条件与出处 |
| A-F3 | 未经核验即下确定结论 | 未做医学检查即百分之百断定当事人患有某症候 | 个案判断轻率，可能误导当事人在真实程序中误判风险 | 结论一律带置信度："证据是 X，那么 Y 有机会；若出现 Z，则结论反转" |
| A-F4 | 案例真实性不可核 | 单场直播可产出 5 条爆款，同装同景反复出镜 | 内容可能含剧本，照搬其结论存在系统性偏差 | 任何个案结论不得直接套用到真实案件；须重新取证据 |
| A-F5 | 形态越界 | 律师身份 + 剧本化剧情内容并存，与"不得以虚假夸大宣传吸引客户"的要求存在张力 | 账号合规风险外溢到学习者 | 引用其观点时须与"娱乐化内容"属性切割 |
| A-F6 | 情绪重构滑向"劝和" | 用三重"他是爱你的"帮当事人解开心结 | 高度情绪化的重构，可能掩盖真实的权利受损 | 情绪承接与权利判断**分开进行**：先承接，后算账，不因安抚而放弃权利 |
| A-F7 | 以"不用请律师"博取好感 | 给出"只需提醒检察官一件事"的解法 | 解法偶发性极强，不可复制为通用路径 | 凡"零成本解法"必须注明适用前提，不得作为普遍建议 |

## B 层 · 使用本技能时的坑

| 编号 | 失败模式 | 规避 |
|------|----------|------|
| B-F1 | 把单次连线的定性结论当作法律意见 | 一律标注"初步判断，不构成法律意见"，正式情形须另出法律意见书 |
| B-F2 | 用"海龟汤式拆穿"对待真实合作方 | 该手法适用于**当事人自愿求助**场景；用于商务谈判会让对方迅速防御 |
| B-F3 | 追时间线追成了审讯 | 提问须有解释："我问这个是为了确认主张能不能成立"，先给理由再问细节 |
| B-F4 | 情绪承接做成廉价的安慰 | 承接必须落到事实（"你没有让家人担保，这是事实上的止损"），否则当事人觉得被敷衍 |
| B-F5 | 把"抓破绽"变成"预设对方有罪" | 疑点清单是**追问索引**不是结论；命中疑点只意味着"需要再问一句" |
| B-F6 | 忽略书面证据链案件的复杂性 | 本视角强于口头陈述场景；涉图纸、台账、结算的争议，须回到原始凭证 |
| B-F7 | 未标身份与素材边界 | 其执业信息未经官方核实，凡引用身份描述须标【待核】 |
| B-F8 | 照搬其口头禅造成不适 | 直率话术适用于当事人委托场景；对外函件、政府沟通中不得使用 |

## 红线清单（任一命中即停止输出）

- 🔴 以本技能输出替代正式法律意见书
- 🔴 对未核实的案件事实下确定性结论
- 🔴 引用具体法条而不核对现行有效性
- 🔴 用"抓破绽"的手法对真实谈判对手做心理操控
- 🔴 把娱乐化剧本内容当作事实转述给第三方
