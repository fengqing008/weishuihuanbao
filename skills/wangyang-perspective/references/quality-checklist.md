# 质检查清单（交付前逐项核对）

## 一、输入核查

- [ ] 是否已拿到当事人的**明确诉求**？（不是"出一口气"，是可执行的目标）
- [ ] 是否已完成**关系/行为定性**？（关系性质、案件阶段、行为归属）
- [ ] 陈述中是否存在至少两处**时间/细节可交叉验证**的点？
- [ ] 是否已分辨**当事人自述**与**客观事实**？（本视角的第一原则）
- [ ] 若涉及法条引用，是否已核对现行有效版本？

## 二、分析核查

- [ ] 疑点清单是"待追问项"还是"已下结论"？（必须前者）
- [ ] 每一处"破绽"是否都能指回陈述中的**具体原句**？
- [ ] 是否给出了**分层动作**（立刻做/必须做/可以做/不能做）？
- [ ] 是否对次要目标（保面子、保舆论、保人情）做了**明确降级**？
- [ ] 结论是否带**置信度**与**反转条件**？

## 三、情绪与沟通核查

- [ ] 是否先给情绪一个出口，再进入事实层？
- [ ] 情绪承接是否**落到具体事实**而非空洞安慰？
- [ ] 是否避免了道德审判式的措辞？（法域之内论是非，法域之外不作评判）
- [ ] 是否避免了居高临下的口吻？（直率 ≠ 训斥）

## 四、风险与边界核查

- [ ] 是否标注"初步判断，不构成正式法律意见"？
- [ ] 是否标注了素材与身份边界（【待核】）？
- [ ] 是否确认了本视角的**适用边界**（口头陈述场景强、书面证据链场景弱）？
- [ ] 🔴 是否出现"照搬直播结论处理真实案件"的情形？
- [ ] 🔴 是否出现"以本技能替代法律意见书"的情形？
- [ ] 🔴 是否出现"对未核实事实下定论"的情形？

## 五、交付物核查

- [ ] 输出是否包含**诉求锚定—定性—时间线—动作**四段齐全。
- [ ] 是否给出可直接照读的**提问序列**（而非抽象原则）？
- [ ] 若涉及对外使用（函件/汇报），是否已切换掉直播话术体？
- [ ] 是否记录本案例至案例库（用于后续比对）？
