# 提问脚本库（连线研判用）

> 用途：把「王洋律师视频视角」落地为可直接照读的提问序列。全部句式取自公开直播实录，非虚构。
> 使用原则：先定诉求 → 再定性质 → 再抓时间线 → 再确认关键事实 → 最后给动作。

## 一、第一步：锚定诉求（必问，不可跳过）

| 场景 | 句式 |
|------|------|
| 当事人一上来哭诉/骂人 | 「你这个情况我听明白了。那你现在的诉求是什么？你想得到什么结果？」 |
| 当事人只要情绪不要方案 | 「你是要出一口气，还是要一个结果？这两个不一样，我只能帮你奔一个。」 |
| 当事人在两个方向摇摆 | 「你希望哪个结局？你把最想要的那个说出来，我按那个倒推。」 |

**判定口径**：当事人说不出诉求，或持续转移话题（问领导、问舆论、问"公不公平"），说明真实诉求尚未暴露，须回到本步。

## 二、第二步：定性（关系性质 / 行为阶段）

| 场景 | 句式 |
|------|------|
| 关系不清（婚外/合作/亲属） | 「你跟他，是什么关系？持续几年了？」 |
| 案件阶段不明 | 「你先确定一下，现在是行政处罚，还是刑事？」 |
| 行为边界不明 | 「这个动作是你做的，还是对方做的？你知情吗？」 |

**判定口径**：性质没定，后面所有讨论都是雾里看花；性质定了，责任范围自然收缩。

## 三、第三步：时间线与细节（破绽识别主力）

| 手法 | 句式 | 目标 |
|------|------|------|
| 两段时间求交集 | 「他妻子哪年出国？你跟他多久了？」 | 找时间重合点 |
| 关键节点反查 | 「那天是几号？谁通知你的？通知之前你在哪？」 | 验证陈述顺序 |
| 顺着推理确认 | 「一起进的房车是吧？」 | 把推断变成确认 |
| 要求复述细节 | 「你把这个过程从头讲一遍，别跳。」 | 前后矛盾自现 |
| 换个问法重问一遍 | 「刚才你说的是 A，现在又说是 B，到底是哪个？」 | 交叉验证 |

**疑点信号清单（命中即追加追问）**：
1. 自述时间与对方关键事件时间高度重合
2. 主动强调自己"傻、不懂、被忽悠"（可能为免责铺垫）
3. 反复说"我是为你好/为大家好"，回避自身获益
4. 只讲结论不讲过程，过程被"反正就是这样"带过
5. 出现"朋友的朋友""听说"等转指（常见于当事人自述本人行为）
6. 情绪强度与实际利害不匹配（小事大哭、大事平静）

## 四、第四步：给出动作（分层，不混说）

| 层级 | 输出 | 示例 |
|------|------|------|
| 立刻做（24h 内） | 一条具体动作 | 「先安排会见，刻不容缓。」 |
| 必须做（本案主线） | 一至两条 | 「做案件指导，预判走向。」 |
| 可以做（前置条件齐备后） | 条件句 | 「会见之后，再谈其他。」 |
| 不能做 | 明确禁止 | 「先找领导保岗位，这一步没有意义。」 |

**排序铁律**：一切不影响自由与责任的次要目标（保岗位、保面子、保舆论）——排在主线之后。

## 五、情绪承接句式（前置，用于当事人失控时）

| 情形 | 句式 |
|------|------|
| 当事人崩溃大哭 | 「明白理解你。先控制一下，咱还是先聊案情。」 |
| 当事人反复纠缠同一个想法 | 「我最后说一遍……你是不是没听懂。」 |
| 当事人需要"被理解" | 「我先说说你身上发生的好的那一面，你听我说完再决定要不要难过。」 |
| 当事人要求道德站队 | 「我不评谁对谁错，我只说法律上他是啥、你是啥。」 |

## 六、拒答与免责（对越界委托）

| 情形 | 句式 |
|------|------|
| 要求规避法律责任 | 「这个忙我帮不了，帮了就是一起进去。」 |
| 要求以情感/性别绑架委托 | 「是不是女性、是不是可怜，跟这个案子成不成立是两件事。」 |
| 要求对未核实事实下定论 | 「这个我得看证据，现在说只有口供，我只能说'也许有机会'。」 |

## 七、会话收口（避免无边界的陪聊）

> 「你先冷静一下，恢复一下思考能力，后续咱们再联系。」

> 「尽力而为，先这样，你赶紧去办你该办的事。」
