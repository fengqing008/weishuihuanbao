# 地区参数表与精度分层

## 一、覆盖范围（3,421 个地区）

| 层级 | 数量 | 数据来源 | 精度 |
|---|---:|---|---|
| 全国 | 1 | 胡润锚点 + 央行中位数 | 较可靠 |
| 省级 | 31 | 国家统计局 2025 年各省居民人均可支配收入（真实） | 中等（密度为代理） |
| 地级市 | 334 | 省级收入 × 城市等级系数【估】 | 粗估 |
| 县区 | 3,056 | 所属市收入 × 0.92【估】 | 粗估 |

> 陕西省 25 条（陕西省、10 地市、杨凌示范区、西安 13 区县）含胡润实测富裕家庭密度，**精度高于全国其他地区**。

## 二、计算规则

```
收入比 income_ratio = 地区居民人均可支配收入 ÷ 43,377
   省级：真实值
   地级市：省级收入 ×（省会/计划单列市 1.15，普通地级市 1.00）
   县区：所属市收入 × 0.92
   直辖市下辖区：省级收入 × 0.95

密度比 density_ratio = 地区 600 万资产家庭密度 ÷ 全国密度 1.024%
   省级：0.640 × income_ratio^3.096   （用陕西、上海两点标定）【估】
   陕西省 / 西安 / 某市：胡润实测
   地级市 / 县区：上级密度比 ×（本级收入 ÷ 上级收入）

系数 coef = √(income_ratio × density_ratio)
家庭户数 households = 常住人口 ÷ 2.62
   省级：2025 年真实常住人口
   地级市 / 县区：按上级人口平均分摊【估】
```

## 四、行政区划代码规则

| 位数 | 含义 | 示例 |
|---|---|---|
| 前 2 位 + 0000 | 省级 | 610000 = 陕西省 |
| 前 4 位 + 00 | 地级市 | 610100 = 西安市 |
| 全部 6 位 | 区/县 | 610115 = 某市区 |

脚本按 `region_code` 自动向上衍生。**直辖市**（北京 11、天津 12、上海 31、重庆 50）无地级市节点，其区县直接挂省级（前端已做兜底：选省后直接列出该省全部县区）。

## 五、提升精度

1. **单点批量导入**（推荐）：准备 CSV（code, name, population_wan, urban_income[, household_600w]），执行
   ```bash
   python3 scripts/build_regions.py --csv regions.csv --merge
   ```
   提供 `household_600w`（该地 600 万资产家庭户数）时，密度比将用真实值而非代理。
2. **全国重构**：更新 `scripts/gen_national.py` 内的 `PROV_INCOME` / `PROV_POP` / `CAPITALS` 后重跑。
3. **优先补齐方向**：用户常驻与项目地（陕西、湖北某县、福建某区）、以及榆林神木府谷等能源富县。
