# 分位定位方法论

## 一、要解决什么问题

个人财富排名在任何司法辖区都属于隐私，没有任何机构会公布"某自然人排第几"。所以本技能不做"排名查询"，只做**统计分位近似定位**：给定一个净资产数值，估算"在某个统计总体里，有多少比例的家庭净资产不低于这个数"，即"排在前百分之几"。

## 二、模型

### 2.1 全国分布：对数正态 + 高端锚点

家庭净资产呈右偏、厚尾分布。用两层拼接：

**中低段（< 600 万元）——对数正态**

设 X 为家庭净资产，lnX ~ N(μ, σ²)。

- μ 由中位数标定：μ = ln(全国净资产中位数)
- σ 由中位数与任一高端锚点联立：

```
σ = [ ln(锚点门槛) − ln(中位数) ] / Φ⁻¹(1 − 锚点占比)
```

取锚点 = 600 万元、占比 = 1.024%：

```
σ = (ln 6,000,000 − ln 836,000) / 2.318 ≈ 0.8505
```

则任意值 x 的分位：

```
前 p% = 100 × [ 1 − Φ( (ln x − μ) / σ ) ]
```

**高段（≥ 600 万元）——胡润锚点对数插值**

600 万以上用真实门槛插值，避免对数正态尾部过薄导致低估：

| 门槛 | 前占比 | 来源 |
|---|---|---|
| 6,000,000 | 1.024% | 胡润 2025：600 万家庭 506 万户 |
| 10,000,000 | 0.41% | 胡润 2025：千万家庭 200.5 万户 |
| 100,000,000 | 0.0255% | 胡润 2025：亿元家庭 12.6 万户 |

在 ln(门槛) − ln(占比) 坐标下线性插值；超过 1 亿元按末段斜率幂律外推（此时结果仅作量级参考）。

### 2.2 地区校准

同一数值在不同地区对应的分位不同。地区门槛 = 全国门槛 × 地区系数 k。

k 取**几何平均**：

```
k = √( 收入比 × 富裕家庭密度比 )
```

- 收入比 = 该地区居民人均可支配收入 ÷ 全国（43,377 元）
- 富裕家庭密度比 = 该地区 600 万资产家庭密度 ÷ 全国密度（1.024%）

**为什么要几何平均**：单用收入比会低估地区财富差距（存量差距 > 流量差距）；单用富裕密度比会把尾部差异外推到全分布，高估中段分位（因为全国分布是多峰的，被京沪深等超级城市拉高尾部）。几何平均是两端折中，且与两端的实际数据都能对上。

### 2.3 排名户数

```
约前 N 户 = 分位比例 × 该地区家庭户数
```

家庭户数 = 常住人口 ÷ 户均 2.62 人（第七次人口普查）。这是一个推算值，报告须注明。

## 三、精度与局限

| 区间 | 可信度 | 说明 |
|---|---|---|
| 前 10% 以外 | 较高 | 主要受中位数与收入比影响，稳健 |
| 前 1%–10% | 中等 | 受 σ 标定与地区系数影响 |
| 前 1% 以内 | 偏低 | 厚尾外推，误差放大，仅作量级参考 |

必须在报告中保留免责声明，不得宣称"某人排第 X 名"。

## 四、模型更新

每年 Q1（胡润报告与统计公报发布后）更新 `assets/baseline.json`：

1. 替换全国 anchors（胡润三门檻与家庭数）
2. 替换全国中位数、户均净资产
3. 替换各地区收入与 600 万家庭数 → 重算 income_ratio / density_ratio / coef
4. 同步更新 `references/data-sources.md` 的来源与年份
