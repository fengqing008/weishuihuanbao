# 活性污泥工艺计算器

## 使用说明

1. **用途**：活性污泥工艺动力学计算器（ASM2d 简化模型）。
2. **典型问法**：“污泥产量”、“SRT污泥龄”、“硝化菌临界SRT”、“反硝化SDNR”。
3. **调用方式**：在 ima 对话中直接描述需求或上传相关文件，本技能按触发词自动匹配调用。
4. **注意事项**：非活性污泥类的水处理工艺（如纯物化/膜过滤选型用membrane-system-design）、水质达标率分析（用wastewater-ops-analysis）、运行实操知识（用activated-sludge-ops。

> v2.0.0 专家级（2026-09-07）：九要素结构化升级，补触发条件/分步工作流/输出规范/边界反模式/依赖降级与市政污水厂 AO+MBR 实战范例；ASM2d 公式与参数保持已验证版本不变。

## 定位声明

把活性污泥工艺设计/校核中"能算数"的环节（污泥产量、SRT、硝化临界、反硝化速率、膜面积、需氧量）用 ASM2d 简化动力学固化为可复算的计算器。服务对象：工艺设计工程师、污水厂运行技术人员、投标与方案编制人员。与知识型技能分工：本技能负责**出数字**，activated-sludge-ops 负责**讲原理与判断**，membrane-system-design 负责**膜系统选型细节**。依赖本地脚本 `scripts/activated_sludge_calculator.py`。

## 触发条件

满足任一即触发：

- 算污泥产量、排泥量、脱水干泥量
- 校核设计 SRT 是否足够（尤其低温硝化工况）
- 算硝化菌临界 SRT、反硝化 SDNR、反硝化所需碳源
- 算需氧量 AOR、折算鼓风曝气量
- MBR 膜面积与膜组件数量估算
- 按出水 TP/TN 目标选 MLE/A2O/后置缺氧工艺
- 关键词：污泥产量、泥龄、SRT、SDNR、AOR、膜面积、物料平衡、sludge production、SRT、nitrification、denitrification rate、membrane area、ASM

## 核心能力

| 计算模块 | 输出 | 关键参数 |
|---|---|---|
| 物料平衡 | 去除 COD、污泥产量(异养+自养+惰性)、氮同化、硝化量 | Y_H=0.625, Y_A=0.24, VSS/TSS=0.85 |
| 硝化菌临界 SRT | SRT_crit（washout 判定） | μ_A,20=0.90, θμ=1.09, b_A,20=0.17 |
| 反硝化 SDNR | 反硝化速率 | (b0+b1·ln(F/M))×1.09^(T−20) |
| 需氧量 AOR | O2_COD + O2_nit − O2_credit | 4.57 gO2/gN, 2.86 gCOD/gN |
| MBR 膜面积 | 膜面积 m² | 通量 18 LMH / 污染系数 1.8 |
| 工艺选型 | MLE / A2O / MLE_POST 建议 | 按 TP/TN 目标严格度 |

## 分步工作流

**输入 → 处理 → 输出 → 检查点**，按序执行：

1. **收集输入**
   - 必需：Q 流量 m³/d、进水 COD/TKN/TP、水温℃。
   - 按需：出水 COD/NH4/TP、进水 TSS、MLSS、设计 SRT、DO、出水 TN/TP 目标（如 GB 18918-2002 一级 A）。
   - 检查点：缺水温或缺任一进水指标，停下询问，不臆测默认水质。
2. **选择计算方式**：优先跑脚本；环境不可用时按"关键公式速查"手算，口径一致。
3. **跑数与校验**
   - 核对：设计 SRT ≥ SRT_crit × 1.2；不满足必须明确提示并给调整建议。
   - 核对：出水目标严格（TP<1 或 TN<10）时选型偏保守，提示 EBPR/后置缺氧/外加碳源。
4. **交叉判断**：结合 activated-sludge-ops（运行管理）与 membrane-system-design（膜选型）做工艺合理性复核。
5. **输出报告**：按"输出规范"成文；进正式设计文件/施工图的参数标【待核】并附计算依据。

## 输出规范

结构化计算报告（对话内 Markdown；用户要求时存 md/xlsx，命名 `活性污泥计算_<项目>_<YYYYMMDD>`），固定五段：

1. **输入汇总表**：参数、单位、取值来源（用户给定/默认值）。
2. **各模块结果**：物料平衡、SRT 校验、AOR、膜面积，含中间量（Y_obs、N_assim、N_nitrified）。
3. **工艺选型建议**：MLE/A2O/MLE_POST + 判定理由。
4. **风险与安全系数提示**：SRT 裕量倍数、低温修正、除磷路径提示。
5. **计算依据**：所用公式、参数取值、【待核】清单。

## 脚本用法

```bash
python3 scripts/activated_sludge_calculator.py \
    --Q 20000 --cod_in 500 --cod_eff 50 --tkn_in 45 --nh4_eff 1 \
    --tp_in 7 --tp_eff 0.5 --tss_in 200 --temp 12 --mlss 6000 --srt 15
```

**输入参数**（默认值见 `--help`）：Q 流量 m³/d、COD_in/COD_eff 进出水 COD、TKN_in 进水 TKN、NH4_eff 出水氨氮、TP_in/TP_eff 进出水 TP、TSS_in 进水 TSS、temp 水温℃、mlss MLSS、srt 设计污泥龄、do 好氧区 DO、tn_target/tp_target 出水目标。

## 关键公式速查

- 观测产率：`Y_obs = Y / (1 + b_T·SRT)`，异养 Y_H=0.625、b_H=0.12；自养 Y_A=0.24、b_A=0.05
- 污泥产量：`P_XH_COD = COD_removed × Y_obs_H`，转 VSS ÷1.48，转 TSS ÷0.85
- 氮同化：`N_assim = TSS_total × i_NBM`，i_NBM=0.10(SRT>20d)/0.12
- 硝化量：`N_nitrified = max(TKN_in − NH4_eff − N_assim, 0)`
- 硝化临界：`SRT_crit = 1/(μ_A,eff − b_A,T)`，μ_A,eff = μ_A,T × NH4/(K_NH4+NH4) × DO/(K_DO+DO)
- 需氧量：`AOR = COD_removed×(1−1.42·Y_obs) + N_nitrified×4.57 − NO3_removed×2.86`
- 膜面积：`design_flux = flux/fouling`，`area = Q×1000/(design_flux×24)`
- 温度校正：`k_T = k_20 × θ^(T−20)`

## 关键规则（质量门）

- 计算结果为 ASM2d **简化估算**，正式设计须结合水质实测、生物相镜检与业主/规范要求校核
- 温度是敏感参数（θ 校正），低温（<12℃）时硝化 SRT 显著增大，务必如实输入水温
- 出水目标严格（TP<1 或 TN<10）时选型建议偏保守，提示 EBPR/后置缺氧/外加碳源
- 设计 SRT 应 ≥ SRT_crit × 1.2（安全系数），不足时明确提示
- 涉及正式设计文件/施工图的参数须标【待核】并附计算依据

## 边界与反模式

**不适用场景**：

- 纯物化处理、混凝沉淀、独立膜过滤选型 → membrane-system-design
- 达标率统计、运营月报、多厂对比 → wastewater-ops-analysis
- 培菌驯化、生物相镜检、膨胀控制等实操 → activated-sludge-ops

**禁止行为**：

- 禁止把简化估算直接当施工图设计值交付
- 禁止不问水温就套 20℃ 参数（低温硝化 SRT 显著增大）
- 禁止虚构进出水水质；缺数据先向用户索取

**常见错误**：VSS 与 TSS 混用（本模型按 ÷0.85 换算）；i_NBM 取值不分 SRT 档（>20d 取 0.10，否则 0.12）；膜通量忘记除以污染系数 1.8。

## 依赖说明

- 运行脚本：Python 3 + 标准库即可，无第三方依赖。
- 脚本缺失或损坏：按"关键公式速查"手算，结果口径与脚本一致。
- 交叉技能：activated-sludge-ops（运行判断）、membrane-system-design（膜选型）、wastewater-ops-analysis（达标分析）。

## 实战范例

**示例 1（市政污水厂 AO+MBR 校核）**：用户说"2 万吨/天，进水 COD500、氨氮45、总磷7，水温12℃，MBR，帮我算污泥产量和膜面积" → 跑脚本 → 输出物料平衡 + 膜面积 + 临界 SRT 校验；若 12℃ 下 SRT_crit≈9.5d、设计 15d，裕量约 1.6 倍，判定满足。【待核：进水水质需以实测月均值复核】

**示例 2（SRT 诊断）**：用户说"现有 SRT 8 天，硝化一直不达标，是不是 SRT 不够" → 算 SRT_crit（12℃ 下约 9.5d）→ 判定 8d < 临界 → 建议延长 SRT 或降负荷，并按 1.2 安全系数复算目标 SRT。

**示例 3（污泥脱水干泥量）**：用户问"日产含水率 80% 泥饼多少吨" → 由脚本得干污泥产量 P_X（kg/d）→ 泥饼量 = 干泥 ÷ (1−80%) → 提示与污泥处置合同计量口径核对。
