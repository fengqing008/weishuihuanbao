# 审计程序与证据规则

## 一、审计程序总览

竣工财务决算审计遵循"准备—实施—报告—整改"四阶段八步：

1. 审计准备（条件评估、组建审计组、编制实施方案、送达通知书或签订业务约定书）
2. 审前调查与资料收集
3. 审计实施（建设程序、财务收支、工程造价、建设管理、资产形成与移交、投资绩效六维）
4. 审计证据收集与工作底稿编制
5. 问题定性、处理意见与审计报告编制
6. 审计报告复核
7. 报告出具与送达
8. 整改跟踪与归档

程序先后次序有硬约束：**先竣工结算，后竣工决算，再竣工决算审计**。结算未定案则决算无基准，决算审计失去比对对象。

## 二、审计准备

### 2.1 审计条件评估（五查）

| 检查项 | 判断标准 |
|---|---|
| 决算是否编制完成 | 竣工财务决算报表与说明书已齐备并签字 |
| 结算是否定案 | 工程结算审核报告已出具，量价已确认 |
| 账务是否清理 | 债权债务与财产物资已盘点清楚，账实相符 |
| 基础资料是否齐全 | 立项、概算、合同、结算、账册、验收资料齐备 |
| 权力与依据是否明确 | 委托主体、审计范围、适用规则与地方口径明确 |

### 2.2 审计组组建

专业结构至少覆盖三类：财务审计（账务、资金、报表）、造价审计（工程量、单价、取费）、工程与管理审计（建设程序、合同、现场、验收）。大型项目设审计组长统筹，分工到人并明确复核责任。

### 2.3 审计实施方案要素

审计目标、审计范围（时间跨度与资金科目边界）、审计内容、审计方法、进度安排、人员分工、质量控制措施、风险应对。

### 2.4 审计通知书与业务约定书

- 审计机关：审计通知书，载明被审计单位、审计项目、审计依据、时间、审计组人员与要求。
- 事务所：业务约定书，载明委托事项、双方责任、范围、期限、收费与保密条款。
- 内部审计：审计通知书或立项批复。

**被审计单位责任**：对其提供的会计资料、工程结算材料和其他证明材料的真实性、完整性负责。此责任划分须在报告中写明。

## 三、审前调查与资料收集清单

**立项与批复类**：可行性研究报告及批复、初步设计报告及批复、工程概算批复、用地与规划许可、环评批复。

**招投标与合同类**：招标文件、投标文件、中标通知书、施工合同及补充协议、材料设备采购合同、监理合同、勘察设计合同、咨询服务合同。

**工程与结算类**：施工图纸、工程变更与签证文件、竣工验收报告、工程结算书、结算审核报告、工程量清单。

**财务与会计类**：历年会计凭证、账簿、报表、银行对账单、拨款文件、资金到位凭证、往来明细、固定资产卡片。

**决算与报告类**：竣工财务决算报表、决算说明书、交付使用资产清单、历年审计与检查整改报告、会议纪要。

资料交接须登记清单，注明份数与原件／复印件，双方签字。

## 四、审计实施方法

| 方法 | 适用 |
|---|---|
| 检查 | 凭证、合同、批复、报表等书面资料的核对与穿行 |
| 监盘 | 实物资产、货币资金、器材的现场盘点 |
| 观察 | 工程现场、资产使用状态、内控执行 |
| 查询与函证 | 往来款项、银行存款、重要合同的外部核实 |
| 计算与复核 | 工程量、单价、取费、分摊、汇总的重新计算 |
| 分析性复核 | 概算执行偏差、造价指标、异常波动的比较分析 |

抽查比例按项目规模与风险等级确定，高风险科目（概算外支出、大额签证、异常待摊、账龄较长往来）提高抽查比例，抽查过程留痕。

## 五、审计证据

### 5.1 证据类型

- **文件证据**：合同、批复、凭证、报表、验收文件；
- **实物证据**：现场盘点结果、资产实物；
- **口头证据**：被审计单位说明、相关方询问记录；
- **分析性证据**：比率、趋势、对比分析结论。

### 5.2 证据特性（三性）

- **相关性**：与审计事项直接相关；
- **充分性**：数量足以支撑结论；
- **可靠性**：来源独立、形式合法、链条完整。

外部证据优于内部证据，书面证据优于口头证据。每项问题结论至少两类证据交叉印证。

### 5.3 取证要求

证据须注明来源、时间、提供人、取得方式，原件无法取得的采用复制件并注明；被审计单位对证据有异议的，记录异议内容与理由。

## 六、审计工作底稿

底稿要素：编号、审计事项、审计程序与方法、证据来源与索引、核对结论、发现的偏差与处理、编制人与日期、复核人与日期。

底稿要求：结论有据、数据有源、过程留痕、索引交叉引用（底稿与证据、报告三者的索引编号互通）。底稿生成走 `scripts/audit_working_paper.py`。

## 七、审计报告复核

审计机构对报告逐项复核并出具书面复核意见，六项要点：

1. 审计实施方案确定的审计目标是否实现；
2. 事实是否清楚；
3. 审计证据是否充分；
4. 适用法律、法规、规章是否正确；
5. 评价、定性、处理处罚和移送处理是否恰当；
6. 其他需要复核的事项。

未过复核的报告不得签发。

## 八、整改跟踪

建立问题整改台账，逐项登记问题、责任单位、整改要求、期限、进展、销号状态。对未整改或整改不到位的，向委托方与管理层报告，必要时提请督办。

## 九、"两步并一步"的适用

竣工决算未及时编报、时间紧、任务急、涉及部门多、建设年代久远的项目，可将竣工决算与竣工决算审计两步并作一步：审计组同步协助梳理账务与报表，边编制边审计。适用时须在实施方案中写明，并加派编制力量。

## 十、程序缺陷清单

- 结算未定案即审决算，比对基线缺失；
- 审计组缺造价专业人员，工程量与单价无人核；
- 资料交接无清单，事后无法界定缺项责任；
- 抽查无留痕，比例与范围无法复核；
- 证据单一即定论，无交叉印证；
- 底稿与报告脱节，结论不可追溯；
- 复核流于形式，未出书面复核意见。
