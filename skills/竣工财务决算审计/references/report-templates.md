# 审计报告模板

## 一、报告格式三部分

**封面**：标题（"××××（主体全称）审计报告"或"××公司××建设项目竣工财务决算审核报告"）、编号（审计机关 `×审××报〔20××〕××号`；事务所 `××审字〔20××〕××号`）、被审计单位名称、审计项目名称、审计机构、审计期间、报告日期。

**正文**：八要素（见第三节）。

**落款**：出具报告的单位（审计机关或事务所，加盖公章）、注册会计师签字（事务所类）、签发日期。

## 二、正文八要素（审计机关版）

1. 审计依据、审计开展及相关责任说明
2. 项目建设情况
3. 审计评价意见
4. 审计结果
5. 审计发现问题和处理意见
6. 审计整改及审计成效
7. 审计建议
8. 审计附件

## 三、注册会计师版审核报告骨架

```
××公司××建设项目竣工财务决算
审核报告

××公司（委托单位）：

我们接受委托，对××公司（以下简称"××公司"或"项目单位"）××建设项目
（以下简称"该项目"）截至××年××月××日的竣工财务决算报表进行了审核。
××公司的责任是及时编制该项目的竣工财务决算报表并提供真实、完整的会计
资料和其他相关资料。我们的责任是对这些资料进行审核并发表意见。我们的审核
是依据中国注册会计师审计准则和财政部发布的《会计师事务所从事基本建设工程
预算、结算、决算审核暂行办法》进行的。在审核过程中，我们结合该项目建设的
实际情况，实施了包括查阅合同文件、抽查会计记录、现场盘点等我们认为必要的
审核程序。现将具体审核情况报告如下：

一、项目概况
（一）建设单位概况（名称、历史沿革、统一社会信用代码、注册地址、注册资金、
       法定代表人、主营业务）
（二）建设项目概况（建设地址、主要建设内容、开竣工时间、主要参建单位）
（三）项目批复情况（立项、可研、初设、概算批复的文号与主要内容）

二、审核依据
三、审核范围与程序
四、项目建设资金到位与使用情况
五、竣工财务决算报表审核情况（各表数据、勾稽关系、与概算对比）
六、概算执行情况分析（偏差分项与原因）
七、交付使用资产情况
八、债权债务清理情况
九、审计（审核）发现的问题及整改建议
十、审核结论

（附件：决算报表、审核明细表、注册会计师执业资质证明等）

××会计师事务所（盖章）
注册会计师：×××（签名）
年  月  日
```

## 四、需披露事项清单（通用）

项目概况、批复情况、资金到位情况、法人责任制执行情况、招投标情况、合同管理情况、监理制执行情况、投资支出完成情况、存在问题及整改建议、审核结论。

抄录的批复文件名称、文号、内容须准确完整，不得随意取舍、断章取义。报告内容须准确、客观、平实，不作夸张或未经证实的描述。问题定性和引用法规条文须有依据。

## 五、审计意见类型

| 类型 | 适用情形 |
|---|---|
| 无保留意见 | 报表在所有重大方面公允反映，证据充分 |
| 保留意见 | 存在重大但不具广泛性的错报或范围受限 |
| 否定意见 | 存在重大且具广泛性的错报 |
| 无法表示意见 | 审计范围受限，无法获取充分适当证据 |

意见类型须与证据充分性匹配，证据不足不得出具无保留意见。

## 六、报告复核清单

- [ ] 审计目标是否实现
- [ ] 事实是否清楚
- [ ] 审计证据是否充分
- [ ] 适用法律、法规、规章是否正确
- [ ] 评价、定性、处理处罚和移送处理是否恰当
- [ ] 抄录文号名称是否准确完整
- [ ] 审计意见类型是否与证据匹配
- [ ] 附件是否齐备

## 七、生成命令

```bash
python3 scripts/audit_report_builder.py --input 报告数据.json --out 审计报告.docx --type cpa
python3 scripts/audit_report_builder.py --input 报告数据.json --out 审计报告.docx --type gov
```

报告 Word 输出挂接 Heading 1/2/3 大纲级别并插入可更新目录域，字体按 GB/T 9704-2012 公文参数（标题方正小标宋二号、一级标题黑体三号、正文仿宋_GB2312三号、行距固定28磅）。
