# 实战案例库

本库收录可从公开资料与知识库检索到的竣工财务决算审计实务案例，用于审计要点印证与方法参照。案例数据以来源文件为准，涉及当事人信息作脱敏处理。

## 案例一：某县市某乡、某镇污水厂改造工程——决算编制到审核全链条

**项目主体**：建设单位某县市住房和城乡建设局，项目单位某县市某水务集团有限公司。
**建设内容**：某乡、某镇污水厂改造，新建及改建。
**概算依据**：某发改审批【2019】191号、192号、212号、214号。
**决算基准日**：2022年09月30日。

**投资口径链（审计比对基线）**：

| 口径 | 金额（万元） | 来源 |
|---|---|---|
| 概算批准 | 1,591.75 | 某发改审批【2019】号文 |
| 中标（合同）额 | 1,020.589684 | 中标合同 |
| 送审投资 | 940.083367 | 项目单位决算报表 |
| 审定投资 | 894.114112 | 审核机构审定 |
| 审定较送审 | −45.969255 | 净审减 |

**审减构成**：建筑安装工程 −39.248990 万元，待摊投资 −6.720265 万元，设备工器具 0。设备类无变动是审计关注点——设备审定与送审一致时，须核验是否确实无需调整，避免"照抄送审数"。

**勾稽链印证**：审定投资 894.114112 万元 = 决算表基本建设支出 = 交付使用资产（固定资产）合计；2-2 表资金来源 8,941,282.63 元 = 资金占用 8,941,282.63 元，平衡；差额 141.51 元（其他应收款）在应付款与资金缺口两侧同额，属可解释尾差。

**审计提示**：待摊投资 97.820191 万元全部分摊进入建筑物及构筑物，设备类未分摊——复核设备类是否应参与分摊，分摊口径须在脚注注明。

## 案例二：某县市乡镇生活污水治理工程PPP项目——审核表体系

**审核机构**：苏世建设管理集团有限公司。
**报表体系**：封面 + 2-1 至 2-9 共 10 个工作表（审核汇总表、决算表、资金情况审核明细表、待摊投资审核明细表、交付使用资产审核明细表、转出投资审核明细表、待核销基建支出审核明细表、建设管理费审核明细表、往来明细表）。

**审计提示**：2-6（转出投资）、2-7（待核销基建支出）为空白且合计未填，审计须确认"空白=无此事项"还是"未填列"，不能以空白推定为零；2-8（建设管理费）申报数与审定金额均未填，仅列控制额算法，审计须补测。

## 案例三：某应急改造工程——存量污水处理厂决算审核

**来源**：知识库《4、竣工财务决算审核表-某县市存量污水处理厂应急改造工程》。
**审计提示**：应急改造类项目工期紧、变更多、签证集中，审计重点核查变更签证的真实性与审批链，防止以"应急"名义规避变更审批与概算调整。
