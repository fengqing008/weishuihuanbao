# 审计要点矩阵（逐表逐科目）

按竣工财务决算报表体系与审核表（2-1至2-9）逐表展开审计点、判定规则与高风险信号。金额单位以报表为准（概况表、审核汇总表、资产表多用万元；决算表、资金表、待摊表、往来表多用元），换算关系须逐一核对。

## 一、审核汇总表（2-1）——概算、合同、送审、审定四口径

审计点：批准概算、中标（合同）额、送审投资、审定投资四口径是否完整；审定较送审的增减是否逐项列示；行次（建安工程、设备工器具、工程建设其他费用、待摊投资）归类是否准确。

判定规则：
- 审定投资应等于经审计确认的各分类实际支出之和；
- 送审与审定的差额须逐项说明审减（增）原因与依据，不得只给总额；
- 概算、合同、送审、审定四者关系：一般审定≤送审，送审与合同额差异须有变更、结算依据。

高风险信号：审减无依据、只列总额不列明细、行次串类。

## 二、决算表（2-2）——资金来源与占用平衡

审计点：左栏资金来源（基建拨款、部门自筹、项目资本、资本公积、基建借款、待冲基建支出、应付款、未交款）与右栏资金占用（基本建设支出、货币资金、预付及应收款、固定资产）是否平衡；应付款真实性；结余资金计算。

判定规则：
- 资金来源合计 = 资金占用合计，差额不为0须查应付款与结余科目，禁止以"其他"配平；
- 基本建设支出 = 建筑安装工程投资 + 设备投资 + 待摊投资 + 其他投资；
- 交付使用资产 ≤ 基本建设支出（差额为在建工程）。

高风险信号：表内不平、其他科目配平、应付款长期挂账不清理。

## 三、资金情况表（2-3）——概算、下达、拨付、缺口

审计点：概算批准金额、预算下达金额、已拨付金额、尚需拨付、结余（缺口）四项数据及文件依据。

判定规则：
- 还需要拨付 = 审定投资 − 已拨付使用金额；
- 结余（缺口）= 预算下达金额 − 审定投资金额；
- 缺口资金须写明金额与填补主体（自筹、追加预算或调整概算）。

高风险信号：资金不到位、缺口未落实来源、以概算代替下达。

## 四、待摊投资明细表（2-4/1-6）——47项费用逐项审定

审计点：勘察费、设计费、监理费、环评费、招投标费、项目建设管理费、工程保险费、借款利息、印花税、工程检测费、社会中介机构审计费、其他待摊投资性质支出等逐项据实性；存款利息收入冲减；建设期利息口径。

判定规则：
- 能确定负担对象的直接计入，其余按选定方法分摊，分摊合计 = 待摊投资明细表合计；
- 专户存款利息及财政贴息冲减利息支出，利息收入超过利息支出的部分冲减待摊投资总支出；
- 项目建设管理费按财建〔2016〕504号标准测算，超标准部分审减；招待费不超过管理费的5%（某县口径）；
- 建设期利息：工程费用利息以当期确认进度产值的80%为基数，起算于进度确认当月，止于竣工验收合格之日；工程建设其他费用按组织实施主体分别确定基数与止点；商运或试运行开始时点为资本化截止界点，须书面确认。

高风险信号：超标准列支、无据费用、利息未冲减、管理费超范围（含非本单位员工费用、工资社保）。

## 五、交付使用资产表（2-5/1-4、1-5）——资产真实性与计价

审计点：固定资产（建筑物及构筑物、设备工具器具）、流动资产、无形资产逐项真实性与计价；待摊投资分摊是否落到资产行；移交手续与接收单位。

判定规则：
- 交付使用资产明细表逐行合计 = 交付使用资产总表合计 = 决算表交付使用资产科目；
- 资产成本 = 未分摊前金额 + 分摊待摊投资（+设备安装费）；
- 移交须有交付单位与接收单位双方签章。

高风险信号：资产不实、成本重复计取、权属不清、移交手续缺失。

## 六、转出投资表（2-6/1-8）

审计点：转出投资有无依据、接收单位是否落实、金额是否审定。

判定规则：转出投资须有批准文件与接收单位确认，无依据不得列支。

高风险信号：无依据转出、接收单位未落实。

## 七、待核销基建支出表（2-7/1-7）

审计点：不能形成资产部分的财政投资支出、用于家庭或个人的财政补助支出是否有依据与审批。

判定规则：须有立项或批准文件，无审批手续不予计入。

高风险信号：虚列、无审批、以撤销项目名义列支。

## 八、待摊投资与建设支出归集（科目级）

| 科目 | 审计点 | 判定 |
|---|---|---|
| 建筑安装工程投资 | 与结算书、合同、变更对应 | 逐项核对，无重复计取 |
| 设备投资 | 采购合同、发票、验收单 | 三方主体一致，无多付款欠票 |
| 待摊投资 | 合同、发票、付款凭证 | 据实，分摊合理 |
| 其他投资 | 不需安装设备、工具器具、无形资产 | 有采购与验收依据 |

## 九、往来与结余（2-9）

审计点：应收账款、应付工程款、其他应付款逐户核对，账龄分析，结余资金真实性。

判定规则：往来逐户函证；结余资金 = 资金来源合计 − 基本建设支出 − 交付使用资产 − 转出投资 − 待核销基建支出；结余为正须按规定处理，为负须写明缺口来源。

高风险信号：账外负债、虚假往来、隐匿结余、长期挂账。

## 十、建设程序与招投标

审计点：立项、可研、初设、概算、招投标、合同、监理、竣工验收各程序是否履行；招投标合规性；合同签订与执行合规性。

判定规则：程序缺失或倒置须披露；招投标违规按《招标投标法》处理；合同主体、发票主体、付款主体三方一致方可计入成本。

高风险信号：未招先建、化整为零、程序倒置、合同主体与付款主体不一致。

## 十一、概算执行与超概算

审计点：实际完成投资与概算对比，偏差分项分析。

判定规则：超概算须查明原因（设计变更、标准提高、规模扩大、材料涨价），超概算部分应履行调整概算或另行审批。

风险公式：超概算率 = （实际完成投资 − 概算总投资）÷ 概算总投资 × 100%。

## 十二、尾工工程与结余

审计点：尾工工程量真实性、预留投资额、是否超5%上限。

判定规则：尾工工程为决算时尚未完工的概算内工程或尚未购置的概算内设备，按合同或概算金额预计，不超过批准概（预）算总投资的5%；防止将新增项目列作尾工、增加新内容、自行消化投资包干结余。

高风险信号：尾工超5%、新增项目混入尾工、未完工程量不实。
