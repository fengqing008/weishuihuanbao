# 湖北及某县地方口径衔接

本文件为审计口径与地方规则的衔接说明，报表体系、分摊方法与编制口径的完整内容引用 `ppp-final-account` 技能，本技能不重复建设。

## 一、适用地方规则

| 文件 | 名称 | 审计衔接点 |
|---|---|---|
| 鄂建文〔2023〕45号 | 湖北省乡镇生活污水治理PPP项目竣工结算与竣工决算工作指南 | 结算与决算衔接、报审程序与时限 |
| 利财发〔2022〕6号 | 某县市基本建设项目竣工财务决算管理实施细则 | 报送口径、审核批复权限（100万元以下可不报批复、400万元以上由市财政局批复） |
| 鄂财投评〔2019〕1号 | 财政投资评审相关要求 | 评审与审计衔接 |
| 财政部令第81号 | 基本建设财务规则 | 先审核后批复、6个月批复期 |

## 二、审计与编制/审核的衔接

- **编制口径**以 `ppp-final-account` 为准（决算报表六表结构、待摊投资分摊方法、决算说明书条目）。
- **审核口径**（送审与审定的审增审减）由 `ppp-final-account` 与 `settlement-audit` 覆盖。
- **审计口径**（独立审计程序、证据、底稿、报告、意见）由本技能覆盖。三口径不得相互替代：编制口径求"归集准确"，审核口径求"审减有据"，审计口径求"结论可采信"。

## 三、审计须特别关注的地方特殊事项

1. **土地使用权费用**：合同约定划拨用地、初设批复该项为0的，审计须核对送审是否全额列支（某县项目该科目送审16,399,912.10元、审定0元）。
2. **甲供材**：按材料名称、供应商、合同量、实际供应量、领用单位逐行登记，核验是否在结算中扣回（某县项目甲供材为商品混凝土）。
3. **建设期利息口径**：按工程费用与其他费用分别确定基数与止点，商运或试运行开始时点作为资本化截止界点，须书面确认。
4. **项目建设管理费**：按财建〔2016〕504号标准测算控制额，招待费不超过管理费5%。
5. **结余资金缺口**：写明缺口金额与填补主体（某县项目缺口5,672.071627万元由项目公司自筹）。

## 四、口径核验要求

审计引用地方文件时，须核对文件现行有效性；文号、名称与原件一致。涉及跨口径数据的，逐项标注来源库与文件依据，未确认项标注【待核：来源单位】。
