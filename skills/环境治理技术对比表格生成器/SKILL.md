**专家定位**：环保治理技术按标准维度拉平对比成表——目标污染物、成熟度、成本、周期、风险一表看清，直接进可研与方案比选章节。

**五维评估**：
- 适用场景：①比选污水处理工艺（AAO/MBR/SBR/氧化沟等）；②污泥脱水后处置技术路线对比；③黑臭水体、废气治理方案比选；④方案编制要"一版技术比选"；⑤用户指定维度定制对比表。
- 能力边界：不做精确投资与运行费用测算；不做单技术深度设计计算；不做环评类别判定（环评法规导则速查专家）；不编造精确数字，争议项标【待核】。
- 依赖资产：核心流程对话内直出，无外部依赖；可选 `scripts/gen_compare_table.py` 生成骨架；深化计算联动 wastewater-optimization、membrane-system-design、activated-sludge-calculator。
- 交付质量：标准 13 列齐备（技术名称＋12 维）；定性口径统一高/中/低；表前一行注明对比范围与口径；附定性等级图例。
- 性能表现：单表 4~8 项技术对话内即出；用户指定列优先呈现并补齐缺失标准列。

**四级响应（L1-L4）**：
- L1 问某列定义或某技术归类 → 直接答，引用标准列定义。
- L2 单领域小表（3~4 项技术）→ 按标准列直接成表。
- L3 完整比选章节 → 分步工作流，范围确认与口径核对为两道质量门。
- L4 多领域大比选＋选型倾向 → 逐域成表＋倾向排序＋深化计算移交。

**黄金窗口**：单表 4~8 行技术、12~13 列；跨 3 个以上领域拆多表分别交付。

**专家件索引**：主文件自足——标准列定义、分步工作流与实战范例均在主文件；骨架生成用 `scripts/gen_compare_table.py`。

# 环境治理技术对比表格生成器

## 使用说明

1. **用途**：根据用户指定的环境治理技术类型（如原位治理、末端治理、污水处理工艺、废气治理、污泥处理、黑臭水体治理等），生成包含目标污染物、场景适用性、技。
2. **典型问法**：“技术对比”、“技术比选”、“治理方法对比表格”、“优缺点对比”。
3. **调用方式**：在 ima 对话中直接描述需求或上传相关文件，本技能按触发词自动匹配调用。
4. **注意事项**：精确投资估算与运行费用测算（走投资测算类技能后回填）、单技术深度设计计算、环评类别判定（用环评法规导则速查专家）。

> v2.0.0 专家级（2026-09-07）：九要素结构化升级，补定位/分步工作流检查点/输出规范/边界反模式与多领域实战范例，新增表格骨架生成脚本；标准列定义保持已验证版本不变。

根据用户提供的治理技术类型，生成包含多维度评估指标的标准化对比表格，辅助环保工程技术选型评估。服务对象：环保工程方案编制人员、技术评审人员；产出直接用于可研/方案的技术比选章节。

## 定位声明

本技能是**表格化的技术比选工具**：把某领域的治理技术按统一维度拉平对比，形成标准化 Markdown 表格。定性判断（高/中/低）基于行业共识与规范口径；深化计算联动 wastewater-optimization / membrane-system-design / activated-sludge-calculator。依赖可选脚本 `scripts/gen_compare_table.py`（生成表格骨架）。

## 输出表格维度（标准列）

| 列 | 说明 |
|----|------|
| 技术名称 | 主流/常见的技术方法 |
| 目标污染物 | 该技术主要针对的污染物 |
| 场景适用性 | 适用场景（原位/异位、市政/工业等） |
| 技术成熟度 | 高/中/低 |
| 修复效率 | 高/中/低（相对统一描述） |
| 建设资金 | 高/中/低 |
| 运行成本 | 高/中/低 |
| 系统稳定性 | 高/中/低 |
| 修复周期 | 短/中/长 |
| 环境风险 | 高/中/低 |
| 优点 | 简明列出主要优势 |
| 缺点 | 简明列出主要局限性 |
| （可选）措施 | 用户提及"措施"或"具体措施"时增加 |

用户指定列时以用户列为准，并补充缺失的标准列；未指定时输出全部标准列。

## 分步工作流

**输入 → 处理 → 输出 → 检查点**：

1. **确认对比范围**（输入）：治理技术类型（如污水处理工艺/污泥处理/黑臭水体/废气）+ 用户指定的列。
   - 检查点：范围过宽时先确认细分领域（如"废气"细分 VOCs/脱硫/脱硝）；用户未指定列则用标准列。
2. **列出技术清单**（处理）：该领域主流技术 4~8 项，冷门但重要的补充项注明"视地区应用"。
3. **逐项填维度**（处理）：按标准列定义填写，定性用高/中/低；依据行业共识与规范，不编造精确数字。
   - 检查点：每列口径统一（修复效率为相对描述）；不确定项标【待核】。
4. **生成表格**（输出）：标准 Markdown 表格；用户需要文件时可用脚本生成骨架后填写。
5. **选型倾向**（输出，可选）：表后给 2~3 条选型倾向（按资金/占地/出水要求给出排序）。

## 输出规范

- 交付物：Markdown 表格（对话内或存 `.md`），命名 `技术对比_<领域>_<YYYYMMDD>.md`。
- 表格前一行注明对比范围与口径（如"市政污水处理主流工艺，按万吨级规模定性评估"）。
- 表格后可按用户要求补参考文献或检索指引；技术比选章节可直接引用本表并注明生成日期。
- 定性等级图例：高/中/低（或短/中/长）随表附注，避免读者误读。

## 生成流程

1. **接收输入**：用户指定的治理技术类型或具体场景
2. **列出技术**：针对该领域列出常见或主流的技术方法
3. **填写维度**：根据各列定义，准确填写每种技术的特征
4. **生成表格**：输出标准化的 Markdown 表格
5. **（可选）补充**：提供参考文献或检索指引

## 规则

- 评估指标（成本、效率等）尽量使用"高/中/低"等相对统一的描述
- "优缺点"简明扼要列出主要优势和局限性
- 不遗漏用户指定的任何列
- 不编造不存在的列
- 避免模糊描述，使用标准化评估术语

## 边界与反模式

**不适用场景**：需要精确投资估算与运行费用测算的（走投资测算类技能后回填）；单技术深度设计计算；环评类别判定（→ 环评法规导则速查专家）。

**禁止行为**：不编造"高效/低成本"结论（有争议的定性标【待核】）；不用对比表替代必要的中试或试验数据；不遗漏用户指定列；不虚构技术名称。

**常见错误**：修复效率与达标稳定性混为一谈；建设资金口径不一（有的含征地有的不含）；对分散式治理套用集中式市政口径。

## 依赖说明

- 核心流程无外部依赖（对话内直接生成）。
- 可选脚本：`python3 scripts/gen_compare_table.py --domain 污水处理 --techs AAO,MBR,SBR,氧化沟` 生成骨架表格，再逐格填写定性判断。
- 降级方案：脚本不可用时按标准列手工建表，列名与顺序保持一致。
- 深化计算联动：wastewater-optimization（工艺参数）、membrane-system-design（膜选型）、activated-sludge-calculator（泥龄/污泥量）。

## 实战范例

**示例 1（市政污水处理工艺比选）**：用户输入："生成污水处理工艺的对比表格，从目标污染物、场景适用性、技术成熟度等方面创建表格"

输出示例：

| 工艺 | 目标污染物 | 场景适用性 | 技术成熟度 | 修复效率 | 建设资金 | 运行成本 | 系统稳定性 | 优点 | 缺点 |
|------|-----------|-----------|-----------|---------|---------|---------|-----------|------|------|
| AAO | BOD/TN/TP | 市政污水 | 高 | 高 | 中 | 中 | 高 | 脱氮除磷效果好、运行成熟 | 占地大、能耗较高 |
| MBR | BOD/SS/细菌 | 市政/工业、占地受限 | 高 | 高 | 高 | 高 | 高 | 出水水质好、占地小 | 膜污染、运维成本高 |
| SBR | BOD/TN | 中小规模 | 高 | 中 | 低 | 中 | 中 | 流程简单、无需二沉池 | 连续运行能力弱 |

## 失败模式

1. 对比范围过宽（如只给"废气"）→ 先确认细分领域（VOCs/脱硫/脱硝）再成表，不硬凑。
2. 技术清单不确定（冷门/新兴技术）→ 补注"视地区应用"或标【待核】。
3. 定性口径不一（修复效率与达标稳定性混用）→ 统一按标准列定义，冲突处标注。
4. 用户指定列与标准列冲突 → 以用户列为准并补齐缺失标准列。
5. 需要精确投资/运行费用 → 不在本表硬填，转投资测算类技能后回填。
6. 争议定性（"高效/低成本"无共识）→ 标【待核】，不给绝对结论。
7. 脚本不可用 → 按标准列手工建表，列名与顺序保持一致。
