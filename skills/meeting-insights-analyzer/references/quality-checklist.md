# 会议行为洞察 质量检查清单（meeting-insights-analyzer）

交付前逐条勾选。任一项未过，报告不得交付。编号 1-15 共 15 项。

- [ ] 1. **数据完整性核验**：转录件清单已建，逐件标注说话人标签有无、时间戳有无；无标签的文件已单列并说明处置。
- [ ] 2. **说话人映射经确认**：我的标识名与别名（姓名、昵称、职务、英文名）已列全，并与当事人确认无误，映射表随交付物留存。
- [ ] 3. **口径显式**：报告写明发言占比的字符口径与词数口径、min-turn 阈值、填充词与限定语词表版本，三项参数在 stats.json 中可查。
- [ ] 4. **数字一致**：报告内每处占比、次数、密度均与 stats.json 逐项对齐，无手工改数与四舍五入漂移（占比保留两位小数，次数为整数）。
- [ ] 5. **证据挂原文**：每条行为结论至少 1 条带 [HH:MM:SS] 的原话引用，引用与转录件逐字一致。
- [ ] 6. **假命中已剔除**：统计命中的片段已回读前后 2 分钟上下文，因转录错字、叠句、语气词重复造成的假命中已剔除并记录剔除理由。
- [ ] 7. **三段落格式**：每条反馈均写成"发生了什么（原话）/ 为什么重要（影响）/ 更好的说法（可照念整句）"三段，缺段重写。
- [ ] 8. **行为不人格**：全文无性格标签式表述，措辞落在时间点、行为、影响三要素上。
- [ ] 9. **样本强度标注**：少于 3 场或少于 60 分钟的样本已标"证据强度：低，仅作线索"，并去掉趋势章节。
- [ ] 10. **趋势可比性**：趋势结论的两组样本场次数相差不超过 1 倍且场合同类；不可比时已改为两组单场分析并说明原因。
- [ ] 11. **改进项限额**：单次交付的改进行为不超过 3 项，每项写明可在一周内观察与复算的验证方式。
- [ ] 12. **脱敏到位**：客户名、人名、金额、联系方式已按映射替换，脱敏映射表与报告分开存放且未随报告外发。
- [ ] 13. **重叠发言处置**：存在重叠或碎片发言的场次，已在报告中标注"归属不确定"，且该段未计入打断统计。
- [ ] 14. **降级留痕**：任何一步发生降级（脚本不可用、docx 跳过、人工抽样计数）已在"数据说明"段落写明降级原因、口径与可信度。
- [ ] 15. **使用边界告知**：报告首页已写明本报告仅用于个人沟通复盘与能力提升，不作为绩效评分、人事处置与诉讼证据使用。
