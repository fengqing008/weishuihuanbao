## 常见核对失败点

1. 条号对、内容错：凭记忆写条号，内容来自印象而非原文。
2. 条款被压缩：把含"但是"的分款截成前半句，改变规范含义。
3. 数字被改写：把"三年""百分之二十"写成概数。
4. 越界引用：把司法解释条文标成民法典条号。
