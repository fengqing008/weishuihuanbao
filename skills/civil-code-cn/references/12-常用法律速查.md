## 二、按业务场景的检索入口

### 工程与环境资源保护（常用法律侧）
```bash
python3 scripts/law_search.py --law 刑法 --range 338-346  # 破坏环境资源保护罪
python3 scripts/law_search.py --law 环境保护税法 --kw 税目
```
> 注：生态环境法典条文、排污许可、超标排放处罚等，见「生态环境法律工具箱」（qf-eco-code）技能。

## 三、通用检索参数

| 参数 | 说明 |
|---|---|
| `--list` | 列出库内全部法律 |
| `--law 名称/简称/law_id` | 限定法律（支持中文简称，如"刑法""民法典"） |
| `--all` | 跨全部 15 部法律检索 |
| `--no 338` | 按条号检索 |
| `--range 338-346` | 按条号区间检索 |
| `--kw 关键词` | 关键词检索（默认精确子串） |
| `--fuzzy` | 模糊匹配（2-gram 覆盖率，应对表述差异） |
| `--struct 刑法` | 输出该法编/章/节结构 |
| `--json` | 结构化输出，便于程序化处理 |

## 四、使用纪律

1. 引用条文前必须经检索脚本回原文核对，不得凭记忆写入条号与数额。
2. 各部法版本以本清单为准；涉及修订后重新公布的法律（如环境保护税法 2025 年修正），以最新版本条文作答。
3. 库外规范（司法解释、部门规章、地方性法规、标准限值）不在本库范围，须标注【待核】后另行核验。
4. 司法解释的具体数额标准（如环境污染刑事案件"严重污染环境"的认定标准）属于库外内容，应结合《最高人民法院、最高人民检察院关于办理环境污染刑事案件适用法律若干问题的解释》另行核验。
