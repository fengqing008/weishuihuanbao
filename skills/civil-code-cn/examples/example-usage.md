# 使用示例

典型问法的处理路径与输出形态。民事问题默认查民法典，涉刑、涉公司治理、涉劳动、涉工程管理等查常用法律库（15 部）；生态环境法典及其配套法律问题转「生态环境法律工具箱」（qf-eco-code）。

## 示例1 按条号直查（L1）

**提问**：民法典第五百八十六条讲什么？

**处理**：

```bash
python3 scripts/mfd.py article 586
```

**输出**：

> 《民法典》第五百八十六条　当事人可以约定一方向对方给付定金作为债权的担保。定金合同自实际交付定金时成立。
> 定金的数额由当事人约定；但是，不得超过主合同标的额的百分之二十，超过部分不产生定金的效力。

## 示例2 关键词检索（L2）

**提问**：民法典里关于"定金"的条文有哪些？

**处理**：

```bash
python3 scripts/mfd.py search 定金
```

**输出**：命中第586、587、588条。回读原文甄别后：第586条（定金设立与数额上限）、第587条（定金罚则）、第588条（违约金与定金择一）。检索结果中"约定金钱债权"一句亦含"定金"二字子串，属误命中，按条号回读原文即可剔除。

## 示例3 场景定位（L3）

**提问**：工程款要不回来，民法典有什么依据？

**处理**：
1. 查 `references/10-常用场景法律依据速查.md`：建设工程合同 → 第788—808条，价款优先受偿 → 第807条
2. 回读 `references/03-合同编.md` 核对原文
3. 串联 `references/02-物权编.md` 担保物权相关规定补充受偿顺位

**输出**：第807条原文 + 适用要点（催告 — 折价或拍卖 — 价款优先受偿）；提示受偿顺位、优先受偿权行使期限另见配套司法解释，超出本技能覆盖范围。

## 示例4 综合适用分析（L4）

**提问**：租的房子被房东卖了，我还能继续租吗？

**处理**：
1. 查编章索引：租赁合同 → 合同编租赁合同章（第703—734条）
2. 定位第725条，回读原文

**输出**：

> 《民法典》第七百二十五条　租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响租赁合同的效力。

要点：租赁物所有权变动不影响租赁合同效力，承租人在占有期限内可继续租赁；新所有权人承继原租赁合同。

## 示例5 常用法律按条号直查（L1）

**提问**：刑法第三百三十八条污染环境罪怎么规定的？

**处理**：

```bash
python3 scripts/law_search.py --law 刑法 --no 338
```

**输出**：

> 《中华人民共和国刑法》第三百三十八条　【污染环境罪】违反国家规定，排放、倾倒或者处置有放射性的废物、含传染病病原体的废物、有毒物质或者其他有害物质，严重污染环境的，处三年以下有期徒刑或者拘役，并处或者单处罚金；情节严重的，处三年以上七年以下有期徒刑，并处罚金……

要点：回读原文并标明"第二编 分则 / 第六章 妨害社会管理秩序罪 / 第六节 破坏环境资源保护罪"的章节路径；量刑档次与加重情形逐字引用，具体追诉标准（司法解释）超出本库，标注【待核】。

## 示例6 跨法检索（L2）

**提问**：串通投标涉及哪些法律责任？

**处理**：

```bash
python3 scripts/law_search.py --all --kw 串通投标
python3 scripts/law_search.py --law 招标投标法 --kw 串通
python3 scripts/law_search.py --law 刑法 --no 223
```

**输出**：行政责任（招标投标法第53条罚则）+ 刑事责任（刑法第223条串通投标罪构成与量刑），分列呈现；生态环境主管部门侧的招投标监管条文见 qf-eco-code（如需）。

## 示例7 公司治理与用工（L3）

**提问**：公司董事的忠实义务、员工经济补偿怎么规定？

**处理**：

```bash
python3 scripts/law_search.py --law 公司法 --kw 忠实义务
python3 scripts/law_search.py --law 劳动合同法 --kw 经济补偿
```

**输出**：回读两部法原文，按"法名 + 条号 + 原文"呈现；涉董监高的刑事风险（职务侵占、挪用资金）另引刑法第271、272条。

## 示例8 越界问题的处理

**提问**：污水处理厂超标排放怎么处罚？

**处理**：属生态环境法典调整范围，本库不含。

**输出**：告知该问题超出本技能覆盖范围（仅收民法典与常用法律 15 部），建议转「生态环境法律工具箱」（qf-eco-code）；不臆造条号。
