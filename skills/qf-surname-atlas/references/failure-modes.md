# 失败模式与处置

| 编号 | 失败模式 | 触发条件 | 处置 |
|---|---|---|---|
| F1 | 数据集未收录 | 姓氏不在前100／前20详细库 | 改出通用六类源流说明，退出码2，不编造 |
| F2 | 高德限流 | place_scan 连续调用触发429 | 脚本内置0.5s间隔与逐词重试，仍失败则降级说明 |
| F3 | 高德无Key | AMAP_KEY 未配置 | 地区级降级为说明文字，报告照常生成 |
| F4 | 围栏泄漏 | `:kpi「...」` 写成行内 | 改为块状写法：单独行 `:::kpi` + 内容行 + `:::` |
| F5 | 密度不足 | 底稿各章偏短 | 补足每章300字以上有信息量正文 |
| F6 | 基座副本缺失 | `scripts/htmlbase/` 未就位 | 从基座源拷贝副本，或用 `--no-base` 降级 |
| F7 | 复姓误切 | 单字切分「欧阳」为「欧」 | 先按复姓表整体匹配 |
| F8 | 渲染告警 | md2report 返回非0 | 查看 stderr 尾部，多为围栏或密度问题 |

## 降级链

高德不可用 → 地区级降级为说明；基座不可用 → 简易模板；数据未收录 → 通用说明。**任何降级都不得中断报告生成，也不得编造数据。**
