# 三级数据口径与精度说明

## 一、全国层

- **来源**：公安部户政管理研究中心《二〇一九年全国姓名报告》（排序）＋ 第七次全国人口普查·百家姓排名（人口）。
- **精度**：第1-10位有官方公布的逐姓人口约数；第11-100位仅有排序，无逐姓权威人口。前100大姓合计约占户籍人口85.9%。
- **注意**：不同年份、不同口径（户籍／常住）数字略有差异，本技能以官方公布口径为准。

## 二、省级层

- **第一大姓**：官方数据，源自《二〇一九年全国姓名报告》，31省区市逐省公布；西藏未做姓氏统计。
- **人口估算**：非第一大姓省份，按「全国占比 × 省常住人口」估算，一律标注【估算值】。
- **省常住人口**：采用2020年第七次全国人口普查各省常住人口约数。

## 三、地区级

- **官方现状**：无官方逐县逐市姓氏人口统计。
- **本技能方法**：姓氏地名密度——以高德 POI 检索「姓＋村／庄／家／营／寨／屯」，反映宗族聚居程度。
- **性质**：侧面证据，**不得换算为人口数字**，报告中明确标注其性质。

## 四、标注规则

| 情形 | 标注 |
|---|---|
| 官方数据 | 注来源（如「据公安部2019年全国姓名报告」） |
| 估算数据 | 【估算值】＋估算方法 |
| 侧面证据 | 说明为「侧面反映，非人口数字」 |
| 未收录 | 【暂未收录】＋通用说明 |
