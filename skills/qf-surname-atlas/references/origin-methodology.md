# 姓氏起源考据方法

## 一、六类源流

中国姓氏的形成，大体归为六类：

| 类型 | 释义 | 例 |
|---|---|---|
| 以国为氏 | 以祖先受封的诸侯国名为姓 | 陈、宋、吴、郑、鲁、齐、卫、曹、蔡 |
| 以邑为氏 | 以祖先受封的采邑、食邑为姓 | 刘、杨、赵、魏、韩、范、冯 |
| 以官为氏 | 以祖先所任官职为姓 | 司马、司徒、史、尉、钱、李（大理之官） |
| 以职业为氏 | 以祖先从事的职业或技艺为姓 | 陶（制陶）、屠（屠宰）、卜（占卜）、巫 |
| 以王父字（名）为氏 | 以祖父的字或名为姓 | 高、孔、孙、林 |
| 赐姓与改姓 | 帝王赐姓、避讳避祸改姓、少数民族汉化改姓 | 唐赐姓李、明赐姓朱、鲜卑诸姓改汉姓 |

## 二、考据四原则

1. **多源并存**：一姓往往多源，须并列主支与旁支，不取单一说法为定论。
2. **多重证据**：综合姓氏典籍、地方志、族谱与历史地理，相互参证。
3. **区分史实与传说**：上古传说（如黄帝赐姓）应标明为传说，不作为确证。
4. **注明出处**：引用典籍须标书名与篇章。

## 三、主要参考典籍（公版）

- 《世本》《元和姓纂》《新唐书·宰相世系表》《通志·氏族略》
- 《百家姓》《万姓统谱》
- 近现代：袁义达等《中国姓氏大辞典》《中国姓氏·三百大姓》

## 四、郡望与堂号

- **郡望**：魏晋至隋唐某姓望族聚居地，门第标识。魏晋行九品中正制，士族以郡望相标榜。
- **堂号**：宗族祠堂名号，多取自先贤德业（如王氏三槐堂）或发祥之地。
