# 案例库（case-library）：真实案例、登记模板与检索指引

> 本库遵循**不编造**原则：预置的均为可查证的公开数据与公版典籍案例，未核实项标【待核】；新增案例请按模板登记并注明来源。
> 数据纪律：所有人口数字须标来源；省级估算值一律带【估算值】；地区级只作侧面证据，**不得换算为人口数字**。

## 一、真实案例（含背景 / 做法 / 结果）

### 案例 SZ-001 —— 单姓全量溯源（以「王」姓为例）
- **背景**：用户说「我姓王，帮我查查王姓的起源和分布」，需要一份既有考据又有分布的完整报告。
- **做法**：依次跑 `surname_query.py --surname 王`（取排名、人口、六类源流、郡望、堂号、名人）→ `pop_calc.py --surname 王 --province 陕西`（出全国与省级口径）→ `report_render.py --surname 王 --province 陕西 --out 王姓溯源报告.html`（装配五章以上并渲染单文件 HTML）。
- **结果**：产出《王姓溯源与人口分布》单文件自包含 HTML，含 KPI 卡与「姓氏人口排名示意」程序化 SVG；全国排名与人口标注来源（公安部《二〇一九年全国姓名报告》＋第七次全国人口普查·百家姓排名），省级估算带【估算值】；html_check 复核 FAIL=0。
- **出处**：公安部户政管理研究中心《二〇一九年全国姓名报告》；第七次全国人口普查·百家姓排名（《中国信息报》2022 年发布）。

### 案例 SZ-002 —— 地区级姓氏地名密度扫描（以「王」姓西安为例）
- **背景**：用户说「看看西安有多少姓王的」，希望得到地区级视角。
- **做法**：跑 `place_scan.py --surname 王 --city 西安 --format json > scan.json`，以高德 POI 检索「王＋村／庄／家／营／寨／屯」类地名，统计密度作**侧面证据**；再经 `report_render.py --scan-json scan.json` 内嵌进报告「本地分布」章。
- **结果**：报告明确标注地名密度「侧面反映宗族聚居，非人口数字」，**不**换算为人口；AMAP_KEY 缺失或限流时按失败模式表 F3/F2 **降级**为说明文字，报告照常生成。
- **出处**：高德开放平台 POI 检索（客观测量，仅作侧面参考）。

### 案例 SZ-003 —— 排行查询（全国前 20 大姓）
- **背景**：用户说「全国前 20 大姓有哪些」。
- **做法**：跑 `surname_query.py --list 20`，输出排名表；数据源为 `assets/surname_rank.json`。
- **结果**：输出带来源标注的排名清单；第 1—10 位有官方逐姓人口约数，第 11—100 位仅排序、无逐姓权威人口（如实说明，**不编造**人口数）。
- **出处**：公安部户政管理研究中心《二〇一九年全国姓名报告》。

### 案例 SZ-004 —— 未收录姓氏的容错处置（方法演示）
- **背景**：用户查询一个不在前 100／前 20 详细源流库中的罕见姓氏。
- **做法**：`surname_query.py` 返回空并退出码 2；走**兜底**路径，改出**通用六类源流**说明（以国为氏／以邑为氏／以官为氏／以职业为氏／以王父字为氏／赐姓与改姓），并标注【暂未收录】。
- **结果**：不编造该姓的具体源流与名人；输出通用考据框架并说明数据边界。属**边界条件**的合规处置，非失败。
- **备注**：演示「未收录不臆造」的口径，**示范案例**，不含真实查询对象。

## 二、登记模板

| 字段 | 说明 |
|---|---|
| 姓氏 | 如「王」 |
| 场景 | 个体查询／前N名排行／地区分布 |
| 输入 | 用户原始问法 |
| 调用链 | 依次调用的脚本与参数 |
| 产出 | 报告文件／数据摘要 |
| 数据来源 | 全国/省/地区的具体来源 |
| 备注 | 降级情况、估算项 |

## 三、可复用的标准调用链

- **单姓全量**：surname_query → pop_calc → place_scan → report_render
- **排行查询**：surname_query --list N
- **仅省级**：surname_query + pop_calc --province X
