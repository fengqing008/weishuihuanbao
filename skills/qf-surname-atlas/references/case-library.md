# 案例库（登记模板与检索指引）

> 本库不预置虚构案例。真实案例请按下列模板登记，并注明来源。

## 登记模板

| 字段 | 说明 |
|---|---|
| 姓氏 | 如「王」 |
| 场景 | 个体查询／前N名排行／地区分布 |
| 输入 | 用户原始问法 |
| 调用链 | 依次调用的脚本与参数 |
| 产出 | 报告文件／数据摘要 |
| 数据来源 | 全国/省/地区的具体来源 |
| 备注 | 降级情况、估算项 |

## 可复用的标准调用链

- **单姓全量**：surname_query → pop_calc → place_scan → report_render
- **排行查询**：surname_query --list N
- **仅省级**：surname_query + pop_calc --province X

## 数据来源指引

- 全国：公安部户政管理研究中心历年《全国姓名报告》
- 人口：第七次全国人口普查·百家姓排名（《中国信息报》2022年发布）
- 省级第一大姓：同上姓名报告
- 地区级：高德开放平台 POI 检索
