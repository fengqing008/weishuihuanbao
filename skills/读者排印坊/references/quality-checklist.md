# 排印质检清单（quality-checklist）

> 交付前逐条核对。🔴 为阻断项，任一不过即回退；○ 为提醒项。

## A. 字号与可读性

- 🔴 **G1 正文≥五号**：正文 `font-size` ≥ 10.5pt。低于则违反 GB/T 3179-2009，判不合格。
- ○ 行距 1.5–1.6 倍，段首缩进 2 字符，两端对齐。
- ○ 标题层级字号递减有序（小3→4号→小4→5号）。

## B. 目次

- 🔴 **G2 目次四要素**：栏目、篇名、作者、页码齐备，缺一判不合格。
- 🔴 **G3 页码准确**：目次页码 = 正文实际起始页，连续、无跳号、无重号。
- ○ 栏目标题样式统一、醒目；页码右对齐带引导点。
- ○ 目次页上部 2/3 目次、下部 1/3 版本记录。

## C. 页眉页脚页码

- 🔴 **G4 页眉奇偶镜像**：奇数页篇名在左/栏目在右；偶数页篇名在右/栏目在左。
- 🔴 **G5 卷首语不分栏**：卷首语标题、作者、出处三行不得进入双栏。
- ○ 页码底端外侧，正文起始为 1，前置页不计数。
- ○ 页脚作者名居中，奇偶相同。

## D. 文字完整性

- 🔴 **G6 无缺字**：全文无 tofu（□）。扫全部中文码点是否在字体链覆盖内。
- ○ 标点统一（中文标点、书名号《》、引号""）。

## E. 合规

- 🔴 **G7 未冒用刊号**：输出物不含《读者》刊名/刊号身份标识；封面署名须为自有名称或留白。

## F. 交付完整性

- ○ 三形态齐备（PDF/HTML/Word）或按需说明缺失原因。
- ○ 文件命名不含点号版本号（入库友好）。

## 一键质检

```bash
python3 $S/scripts/layout_check.py --html book.html --report qc.json --strict
```

退出码 0 = 全过；1 = 存在 🔴 阻断项。
