# 栏目结构与排序（column-structure）

> 《读者》以"栏目"为骨架组织版面，栏目既是内容分类，也是阅读节奏的节拍器。

## 一、栏目主序列（常规顺序）

```
卷首语 → 文苑 → 人物 → 社会 → 人生 → 生活 → 文明 → 悦读 → 点滴 → 互动
```

| 序 | 栏目 | 定位 | 典型篇幅 | 版式要点 |
|---|---|---|---|---|
| 1 | 卷首语 | 开篇点睛，单篇 | 800–1500字 | **等宽两栏**，标题/作者/出处不分栏 |
| 2 | 文苑 | 文学性散文、小说 | 1500–3500字 | 双栏，可配题花 |
| 3 | 人物 | 人物纪实/轶事 | 1500–3000字 | 双栏，可配人物小图 |
| 4 | 社会 | 社会观察、杂谈 | 1200–2500字 | 双栏 |
| 5 | 人生 | 人生故事、感悟 | 1200–3000字 | 双栏 |
| 6 | 生活 | 生活智慧、心理 | 1000–2000字 | 双栏 |
| 7 | 文明 | 文史哲科 | 1500–3000字 | 双栏 |
| 8 | 悦读 | 书评/阅读 | 800–1800字 | 双栏 |
| 9 | 点滴 | 短章、语录 | 100–400字 | 可密排、三栏小栏 |
| 10 | 互动 | 编读往来 | 短 | 通栏 |

## 二、常见子栏目

| 主栏目 | 子栏目 |
|---|---|
| 文苑 | 卷首语、书林一叶、原创精品 |
| 社会 | 杂谈随感、话题、社会之窗、今日话题 |
| 人生 | 人世间、人生之旅、两代之间、青年一代、婚姻家庭 |
| 生活 | 生活之友、心理人生、经营之道 |
| 人物 | 人物、名人轶事、回忆 |
| 知识/看世界 | 军事天地、趣味科学、在国外、他山石 |

## 三、节奏编排原则

1. **重轻相间**：一本成书中，长文（文苑/文明）与短文（点滴/互动）交替，避免连续三篇长文造成疲劳。
2. **插图调剂**：板块之间可插小文章或插图改变节奏，塑造"统一版式、灵动细节"。
3. **首篇压阵**：卷首语短而精，作为封面后的第一声势。
4. **栏目不混**：同一栏目文章连续排布，栏目标题页起新栏目。

## 四、目次编排

- 目次按**主栏目分组**，栏目名统一样式
- 每组下列：篇名 + 作者 + 页码
- 卷首语单独列出并标注"卷首语"
- 排序以 manifest 的 `order` 字段为唯一依据（防止 Markdown 顺序与排版顺序不一致）

## 五、与"读者杂志知识库"协同

选取文章时按栏目到知识库取稿（`columns/{栏目}.jsonl` 切片），栏目归属与文风由该技能保证；本技能只负责版式与装配。
