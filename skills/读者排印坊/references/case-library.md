# 案例库（case-library）

> 收录本技能的真实成书案例。**数据来源指引优先，案例事件与数字必须来自实际排印记录，未核实一律留占位，不得编造。**

## 一、案例登记模板

```md
### 案例 N：<成书名称（类型）>
- 稿件来源：<自有稿件目录 / 知识库 kb_id 切片>
- 开本与栏式：<16开/A4，双栏/通栏，卷首语两栏>
- 篇数 / 栏目数：<N 篇 / M 栏目>
- 页数：<正文 P 页>
- 交付形态：<PDF / HTML / Word>
- 质检结论：<G1–G7 通过情况>
- 遇到问题：<FM-xx 编号 + 处置>
- 可复用经验：<一句话>
```

## 三、可取材素材源

| 素材源 | 用途 | 入口 |
|---|---|---|
| 读者杂志知识库 | 按栏目取文、取文风 | `columns/{栏目}.jsonl` 切片 |
| 江江手记库 | 自有长篇文集成书 | 该库 media_id 检索 |
| 个人随笔 md 目录 | 内部文集 | 本地目录 |
| 既有期刊 PDF | 版式临摹参考 | 逐页量取参数 |

## 四、经验沉淀约定

- 每完成一本成书，在"案例位"新增一条（模板见上）。
- 遇到新故障，同步登记到 `failure-modes.md`。
- 参数类调整，同步更新 `layout-spec.md` 与 `style_builder.py`。
