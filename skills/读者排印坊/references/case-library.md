# 案例库（case-library）

> 收录本技能的成书案例。**数据来源指引优先，案例事件与数字必须来自实际排印记录，未核实一律留占位，不得编造。**
> 本库同时保留「案例登记模板」供后续成书逐本回填，并提供 3 则可公开参照的成书案例（含背景 / 做法 / 结果 / 要点）。

## 二、真实案例（3 则）

> 说明：以下三则案例取自本技能的排印实践，作方法论参照。涉及印量、印号、版权页具体数值等无法核实项，
> 一律标注【待核】；**不编造**成书数据，**不臆造**页数与篇数。套用时按当次任务复核，不得直接照抄。

### 案例 1：多栏目文集整册成书（16 开双栏 / 52 篇 / PDF + 网页版）

- **稿件来源**：自有文集 md 目录，按栏目归属与 `order` 字段排入 manifest。
- **开本与栏式**：16 开 185×260mm；卷首语等宽两栏（标题/作者/出处不分栏），正文双栏，长文通栏。栏宽 =（版心 152mm − 栏间距 8mm）/2 = 72mm。
- **篇数 / 栏目数**：52 篇 / 10 栏目（卷首语 → 文苑 → 人物 → 社会 → 人生 → 生活 → 文明 → 悦读 → 点滴 → 互动）。
- **页数**：约 137 页（该数字为排印记录，重排后可能变化）。
- **交付形态**：PDF（WeasyPrint 精排）+ 单文件网页版 HTML（单栏顺读、目次锚点跳转）。
- **质检结论**：G1–G7 通过；目次四要素齐全、篇名单行完整；页眉奇偶镜像正确。
- **遇到问题**：①目次篇名断行成孤字（FM 引例 12）→ 目次表改弹性列宽（篇名 88mm / 作者 24mm / 页码 9mm）；②HTML 与 PDF 目次栏式冲突 → 由 CSS 按媒体分流，HTML 单列、PDF 双栏；③手机端仍双栏 → v1.9.0 起改为独立 `web_theme.css` 注入末尾并全部 `!important`。
- **可复用经验**：两遍编译（先排正文量页码 → 回填目次 → 定稿）是页码正确的唯一稳解；网页版必须与 print 样式分离。

### 案例 2：图文混排成书（一次成书一体化流程 / 三型配图）

- **稿件来源**：自有长篇文集，需为每篇配 1 张跨栏大图 + 1 张栏内小图。
- **开本与栏式**：16 开双栏；配图规格——跨栏大图 figure 152mm / 图 128mm（版心 84%），栏内小图 figure 72mm / 图 66mm（栏宽 92%）。
- **篇数 / 栏目数**：【待核：本次记录篇数】。
- **页数**：【待核】。
- **交付形态**：PDF + 网页版 HTML；配图图集（退底 / 圆形 / 渐隐三型混用）。
- **质检结论**：配图相关门禁通过（不压字、不溢出、比例适配、底色适配）；正文双栏行宽正常。
- **遇到问题**：①AI 生成图底色偏深（实测 `#E6DED3`，比版面纸色 `#FBF8F0` 深约 44）导致矩形贴图感 → 先做底色归一 + 退底/渐隐处理；②半栏浮动图把正文挤到 4–5 字/行 → 改为「占满一栏、居中」；③`.article figure img{width:100%}` 特异性高于 `.figure-wide img` → 改写为 `.article .figure-wide img` 才生效。
- **可复用经验**：配图必须先归一底色再入版；栏内图不浮动、走固定 mm 居中；自动配图缺位时用程序化线稿兜底，保证图文齐备。

### 案例 3：网页版单栏适配与目次锚点（发布级校正）

- **稿件来源**：案例 1 的同一份 manifest，追加网页版交付要求。
- **开本与栏式**：print 双栏（栏宽 72mm）；web 单栏，容器 `max-width:760–800px` 居中，`body{padding:0 18–20px}`。
- **篇数 / 栏目数**：同案例 1（52 篇 / 10 栏目）。
- **页数**：网页版无分页，页码隐藏。
- **交付形态**：单文件自包含 HTML。
- **质检结论**：手机浏览器单栏可读、无横向溢出；目次点按跳转正常。
- **遇到问题**：①早期把网页规则写成 `@media screen{...}` 放在 `theme.css` 中部，被后面的 print 规则按「同特异性后定义者胜」覆盖，手机上仍双栏、右侧大片空白 → v1.9.0 起 `theme.css` 只留 print 规则，网页规则独立成 `web_theme.css`；②`.toc-page` 类名同时用于目次页 section 与页码 span（撞车）→ 页码 span 独立为 `.toc-pg`；③屏幕端正文贴左缘 → `@media screen` 自给留白与容器居中。
- **可复用经验**：print 与 screen 两套样式必须物理隔离；类名撞车是隐蔽 bug 的温床，改版前先跑 `layout_check.py` 与 `typeset_check.py` 双检。

## 四、经验沉淀约定

- 每完成一本成书，在「案例位」新增一条（模板见上）。
- 遇到新故障，同步登记到 `failure-modes.md`（含降级 / 回退 / 兜底处置）。
- 参数类调整，同步更新 `layout-spec.md` 与 `style_builder.py`。
- 质检结论以实际扫描为准，**不得**编造通过记录；未核实的印量、刊号一律标注【待核】。
