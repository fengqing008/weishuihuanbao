# 排印故障处置手册（failure-modes）

> 现场症状 → 根因 → 处置。均来自排印实测与 CSS Paged Media 特性边界。

## FM-01 目次页码错位
- **症状**：目次页码与正文实际页码对不上，或留空。
- **根因**：单遍编译，正文页码尚未定。
- **处置**：走两遍编译——首遍量各篇起始页，回填目次，再编译定稿。

## FM-02 flex 布局分页塌陷
- **症状**：页脚/页眉用 flex 时跨页错乱或消失。
- **根因**：WeasyPrint 对 flex 跨页支持有限。
- **处置**：页眉页脚一律用 `@page` margin box（`@top-*`/`@bottom-*`），正文内慎用 flex。

## FM-03 中文豆腐块（□）
- **症状**：正文出现方框或空白。
- **根因**：字体链缺中文字体。
- **处置**：字体栈含 `Noto Serif CJK SC`/`Songti SC`/`SimSun`；交付前 `layout_check.py` 扫 tofu。

## FM-04 卷首语被整体分栏
- **症状**：卷首语标题或作者名被拆到右栏。
- **根因**：标题/作者/出处也套进了 `column-count`。
- **处置**：标题、作者、出处行置于 `.no-column` 容器，仅正文段 `.col-body` 分栏。

## FM-05 页眉奇偶镜像写反
- **症状**：奇数页栏目名出现在左边。
- **根因**：`:left`/`:right` 对应关系搞反。
- **处置**：`:right`（奇）篇名左、栏目右；`:left`（偶）篇名右、栏目左。

## FM-06 页码含前置页
- **症状**：正文从第 4 页起（封面/扉页/版权页被计数）。
- **根因**：前置页未与正文分计数。
- **处置**：前置页用命名页无页码；正文首页 `counter-reset: page 1`。

## FM-07 开本单位不识别
- **症状**：`size: 16k` 无效，页面变默认尺寸。
- **根因**：WeasyPrint 只认绝对长度。
- **处置**：写 `185mm 260mm`。

## FM-08 目次顺序与正文不符
- **症状**：目次顺序与正文排版顺序不一致。
- **根因**：目次按 Markdown 顺序排，正文按栏目排序。
- **处置**：统一以 manifest 的 `order` 字段为唯一排序源。

## FM-09 栏式切换断字/断栏
- **症状**：单篇从通栏切双栏处，行被截断。
- **根因**：栏式切换未加分栏断点。
- **处置**：切换处 `break-before: column`。

## FM-10 中文路径写盘失败
- **症状**：导出 PDF 报写入错误。
- **根因**：WeasyPrint 对中文目标路径偶发失败。
- **处置**：先写 ASCII 临时路径，再重命名为中文名。

## FM-11 分栏内首行缩进异常
- **症状**：双栏每段缩进错位。
- **根因**：`text-indent` 与 `column` 交互异常。
- **处置**：缩进写在块级段落上（`p { text-indent: 2em }`），不写在分栏容器上。

## FM-12 图片跨栏溢出
- **症状**：内嵌图超出栏宽。
- **根因**：图未设最大宽度。
- **处置**：`img { max-width:100%; height:auto }`，跨栏图用 `column-span: all`。

## 处置通用原则
1. 先复现，再定位到具体 CSS 规则。
2. 优先用 CSS Paged Media 的能力替代布局 hack。
3. 每修一处即重编译并抽检对应页。
