# 危险废物与污泥管理指引

污水处理厂涉固废管理的对象主要是污泥，兼有检修产生的废矿物油、废试剂、废活性炭、废灯管等。管理链条为：属性判定 → 分类收集 → 贮存 → 转移 → 处置 → 台账。

## 一、污泥属性判定（先判来源，再定管理）

依据生态环境部《关于污（废）水处理设施产生污泥危险特性鉴别有关意见的函》：

| 情形 | 管理属性 | 要求 |
|---|---|---|
| 单纯处理城镇生活污水 | 一般固体废物 | 按一般固废规范处置 |
| 专门处理工业废水，或混有少量生活污水 | 危险废物 | 按《国家危险废物名录》与鉴别标准判定 |
| 以生活污水为主，接收达标排放的工业废水 | 一般固体废物 | 工业废水排放重大变化时重新鉴别 |
| 企业自身排放工业废水产生的污泥 | 视鉴别结果 | 在工艺环节采样，按产生量确定最小采样数 |

鉴别流程：排除腐蚀性、易燃性、反应性、急性毒性，检测浸出毒性与毒性物质含量，对照《危险废物鉴别标准》与《危险废物鉴别技术规范》。鉴别由具备能力的机构实施，采样期须保证设备正常运行与工况稳定，委托方提供真实台账。鉴别结论应明确"是否具有危险特性、是否属于危险废物、拟采取的管理方式"。

案例参照：某工业园区污水处理厂对气浮污泥、水解酸化污泥、氧化沟污泥三类开展鉴别，结论为均不具有危险特性，按一般工业固体废物管理，转运至具备条件的填埋场处置，执行转移联单制度并建立全过程台账。

## 二、贮存要求（GB 18597）

1. 专用贮存间，不得露天，不得与其他物品混堆，不得与在线监测设备同室。
2. 地面防渗，设置围堰或导流沟与收集池，防止渗滤液外溢。
3. 分类分区存放，容器完好并贴危险废物标签，标签载明名称、类别、代码、危险特性。
4. 建立入库、出库、结存台账，记录日期、种类、数量、经办人。
5. 贮存期限遵守国家规定，超期须说明并尽快转移。

## 三、转移与联单

1. 交由持危险废物经营许可证的单位处置，核验其许可证范围与有效期。
2. 执行电子转移联单，联单数量、类别、代码与实际一致。
3. 运输环节留存承运单位资质、车辆信息与交接记录。
4. 联单闭环核销：产生方、运输方、处置方三方签章齐全。

## 四、台账与"三对一"核对

| 核对项 | 基准 | 常见差额原因 |
|---|---|---|
| 台账出库量 vs 联单转移量 | 以联单为准倒查台账 | 出库未及时登记 |
| 联单处置量 vs 处置单位接收回执 | 以回执为准 | 运输损耗未说明 |
| 台账结存量 vs 现场实物 | 现场盘点 | 计量误差、含水率变化 |

差额须查明原因并书面说明；无据差额标注【待核：缺×××证据】。

## 五、一般固废与危废的边界红线

- 未做属性判定即将疑似危废按一般固废外运，属违法处置。
- 将危废混入一般固废或生活垃圾，属违法。
- 无台账、无联单的转移，无论去向是否合规，均判不合规。
- 借用他厂联单或修改联单数量，属造假，禁止。
