## 一、招标文件必读六要素台账

拿到招标文件后逐栏填实，缺一栏即为风险敞口。

### 1. 项目概况

| 要素 | 抓取点 |
|---|---|
| 运作模式 | BOT / ROT / TOT / 委托运营 / 特许经营 / BOO / EPC |
| 项目规模 | 处理规模（万 m³/d）、管网长度、泵站座数、服务范围 |
| 招标方式 | 公开招标 / 邀请招标 / 竞争性磋商 / 单一来源；是否资格预审 |
| 项目编号 | 招标编号（用于投标函与全套文件标注） |

### 2. 资格条件（最易致废标）

典型门槛：注册资本、业绩（类似项目数量与规模）、财务（总资产/净资产/营业收入）、授信额度、资质（市政公用工程施工总承包等级 + 环境工程水污染防治专项设计等级）、无行贿犯罪记录、无失信记录。
资格预审与资格后审的差别决定材料准备时点：资格后审项目须在投标文件中一次性备齐全部资格材料。

### 3. 评标办法

抓取总分、分值构成（技术/商务/财务/法律/报价）、评标委员会人数与抽取方式、报价评分公式。详见 `04-scoring-response.md`。

### 4. 合同与商务关键条款

特许经营期或运营期、回报机制（政府付费/使用者付费/可行性缺口补助）、最高限价或招标控制价、出水标准、履约担保、调价机制、保底水量。

### 5. 格式要求

正副本份数与装订方式、是否胶装、逐页小签或加盖鲜章要求、电子标格式（.ESSTF 加密 + .NESSTF 不加密、CA 数字证书）、密封与封口要求。

### 6. 时间节点

公告发布、澄清截止、标前会、保证金截止、投标截止与开标、投标有效期、公示期。以开标日为锚点倒排全部工作。

## 二、废标与否决投标条款八类清单

四份实件均无独立"废标条款"章节，相关条款散见于前附表、投标人须知、评标办法。按八类归集：

### 类型 1 报价类

- 报价超过最高限价按废标处理
- 只允许提交一个有效报价（报价唯一）
- 报价等于或超过招标控制价作废标处理
- 报价在合同执行过程中固定不变，含价格调整要求的视为无效
- 报价明显低于平均报价一定比例（如 20% 或 50%）且不能说明成本的，可否决

### 类型 2 资格与符合性检查类（典型 10 项）

1. 不具备招标公告资格要求中任意一项
2. 投标书或资格证明文件未提供或不符合要求
3. 超出经营范围投标
4. 投标文件无有效印章或无法定代表人有效授权书
5. 投标有效期不足
6. 有不良经济纠纷记录和违法行为
7. 服务周期、付款方式等商务条款不能满足要求
8. 投标文件不完整
9. 提供虚假信息材料
10. 招标文件规定被视为无效投标的其他条款

### 类型 3 技术评议类

- 对招标内容及要求响应与事实不符或虚假响应
- 提供的证明文件或技术资料不能证明所投项目具体要求（原文复制招标文件技术要求相关部分作为投标内容即属此列）
- 投标文件附有招标代理机构和招标人不能接受的条件

### 类型 4 形式、密封、签署类

- 未按要求密封和加写标记，招标人不予受理
- 逾期送达或未送达指定地点
- 正副本未按要求加盖公章和签名
- 无法定代表人授权委托书
- 未按规定格式填写、关键字迹模糊无法辨认
- 份数不符或未标正副本；大写金额歧义
- 未派遣法定代表人或授权代理人参加开标会并通过身份核验

### 类型 5 串通投标与弄虚作假类

同一单位或个人编制、委托同一单位或个人办理投标事宜、项目管理成员或联系人为同一人、文件异常一致或呈规律性差异、文件相互混装。串通或行贿的，投标文件无效且保证金不予返还。

### 类型 6 招标人有权否决投标情形（典型 8 项）

1. 投标文件不符合招标文件要求
2. 投标人发生串通或行贿情形
3. 投标文件含有故意的虚假陈述
4. 投标文件所含信息与资格文件存在本质性差别
5. 未按规定签署投标文件
6. 开标时投标人不愿打开并宣读
7. 未能按规定提交投标保证金或保函
8. 投标文件在很大程度上未按投标人须知要求准备

### 类型 7 保证金没收与放弃中标类

投标有效期内撤回投标；中标人无正当理由拒签协议或未提交履约担保；签订协议时提附加条件；提交虚假资料；以他人名义投标、串通或非法谋取中标。

### 类型 8 重新招标与招标失败类

投标截止时投标人少于 3 个；中标候选人均未通过结果确认谈判；已解密投标文件少于三家；缺乏有效竞争或为了公共利益，招标人可在任何时间否决所有投标。

> 排查口径：建立"废标红线核查表"，把上述条款逐条转为"是否满足/证据在哪"的勾选项，重点盯防四类高发点——超限价与多报价、资格证明缺项或截图时间不符、未按要求密封签署、实质性响应缺失。

## 三、编标计划模板（四阶段）

以某特许经营项目项目投标文件编制计划（第二版）为范本。可直接用脚本按递交截止日自动倒排生成：

```bash
python3 scripts/bid_plan_builder.py --file 招标文件.md --out 编标计划.xlsx
```

脚本自招标文件抓取递交截止时间（抓不到时用 `--deadline "YYYY-MM-DD HH:MM"` 指定），输出四阶段任务表（责任岗位/开始与完成日期/交付物/检查点），并打印澄清发出（T-15）、答疑提问（T-10）等关键日期；日期与岗位为倒排建议，须按投标单位实际安排调整后执行。

### 阶段一 标书编制

| 章节 | 工期 | 说明 |
|---|---|---|
| 投标人致函、授权委托书、资格文件 | 全周期 | 可并行启动 |
| 技术和管理方案 | 全周期 | 含管理制度、员工培训、工艺流程评价优化、劳保安全消防环保、事故应急、设备更新重置、运营维护计划、技术改造 |
| 财务方案 | 全周期 | 投标人财务状况全周期；项目财务分析依赖工艺与成本数据，后置 |
| 法律方案 | 全周期 | 律所函件、对特许经营协议与委托运营协议的响应 |
| 综合实力文件、保证金、其他 | 全周期 | — |
| 污水处理服务单价 | 短周期 | 依赖财务分析结果，后置 |

### 阶段三 打印、签字与装订（含排版、密封）

## 四、提资链（跨专业协同）

编标计划中最具方法论价值的是提资接口，避免串行等待：

- 运营组 → 财务组提资
- 工艺 → 预算、采购、运营、财务四组提资
- 概预算、采购 → 财务组提资

设"提资节点"作为跨专业组交接里程碑，固化在计划中，确保技术与报价数据一致。工艺参数变更后，预算、采购、运营、财务四处数据须同步刷新。

## 五、责任分工范式

按"部门—责任人—材料类别—核心职责"分配，并设总负责人统筹：

- 综合部：基础资质、团队人员身份与劳动合同、资格声明及承诺
- 财务部：财务、税务、社保文件
- 综合部：业绩证明
- 统筹员：投标核心文件
- 总负责人：全流程统筹、审核完整性与真实性、最终确认合规

**时间节点范式**：材料收集启动 → 基础材料收集 → 核心材料收集 → 声明函及承诺文件起草 → 投标文件编制 → 材料审核 → 盖章及密封 → 最终检查及递交（递交截止前一日完成全部检查）。
