# 法规适用、术语统一与缺项模块

> 来源：某市 PPP 招标文件、某特许经营项目招标文件、某城区污水处理厂与某污水处理厂B委托运营招标文件中的条款表述，并结合现行《招标投标法》《政府采购法》及其实施条例的通行口径整理。法规条文以现行有效版本为准，具体项目引用前须核对最新文本。

---

## 一、法规适用判断树

同一份招标文件，适用哪部法决定资格条件、否决条款、质疑投诉路径的写法。先判法，再编标。

```
采购主体是谁？
├─ 国家机关 / 事业单位 / 团体组织
│   └─ 使用的是财政性资金吗？
│       ├─ 是 → 且属集中采购目录以内或采购限额标准以上 → 适用《政府采购法》（及《政府采购法实施条例》）
│       │        未列入集中采购目录、且未达采购限额标准的，按采购人内部采购规定执行
│       └─ 否 → 按项目性质另判
└─ 企业 / 其他主体
    └─ 项目属于工程建设项目吗（大型基础设施、公用事业等关系社会公共利益的项目）？
        ├─ 是 → 适用《招标投标法》（及《招标投标法实施条例》）
        └─ 否 → 按采购方式另判
```

**常见情形**：

| 项目类型 | 主要适用法律 | 典型资格依据 |
|---|---|---|
| 政府采购服务类（如委托运营服务） | 《政府采购法》 | 第二十二条供应商条件 |
| 政府投资的工程建设项目 | 《招标投标法》 | 招标公告或资格预审文件所列资格要求 |
| 政府采购工程 | 两法衔接，按项目性质与监管部门认定 | 须同时核对两法及实施条例 |

**引证规则**：

- 资格条件承诺书：政府采购项目引《政府采购法》第二十二条（供应商应当具备的条件）；工程建设项目引《招标投标法》及其实施条例的相应资格要求。
- 标底保密类条款引《招标投标法》第二十二条。
- 联合体投标引《招标投标法》第三十一条。
- 澄清与修改引《招标投标法实施条例》第二十一条、《政府采购法实施条例》第三十一条。
- 评标澄清引《招标投标法实施条例》第五十二条。
- 质疑期限引《政府采购法》第五十二条。

**纪律**：凡不能百分之百确定的条款编号，标书中一律标注【待核：条款编号】并回原文核对，不凭记忆书写。

## 二、术语统一表（否决投标 / 废标 / 无效投标）

三类否决性表述常被混用，标书与内部沟通须按招标文件原词表述：

| 术语 | 含义与常见场景 | 使用口径 |
|---|---|---|
| 否决投标 | 评标委员会对不合要求的投标作出的否定决定，多见于工程与政府采购评审环节 | 描述评审阶段的否定结论时使用 |
| 废标 | 政府采购语境下，指采购项目整体作废（如符合条件的供应商不足三家），也可被招标文件用于单份投标被否 | 严格按招标文件用词；指整包作废时不得用于单份投标 |
| 无效投标 | 因不满足形式或资格要求自始不产生效力的投标 | 描述形式、资格、密封、签署类缺陷时使用 |
| 不予受理 | 逾期送达、未按要求密封等，招标人当场拒收 | 描述递交环节 |

**纪律**：写标书与写回复函时，直接引用招标文件原词，不自行替换同义词，避免与评标口径错位。

## 三、电子投标专章

电子标与纸质标并行，格式与流程要求不同，漏项即无效。

**关键要素**：

- **CA 数字证书**：用于加密投标文件、加盖电子章；须提前办理并校验有效期，多把锁须确认授权人。
- **标书格式**：常见双格式——加密标书（如 .ESSTF）用于上传开标系统，不加密标书（如 .NESSTF）用于备份或指定用途；两者内容必须一致。
- **电子章**：封面、投标函、承诺函等关键页面加电子章；电子章与实物章法律效力等同，但须确认章样与授权范围。
- **上传与解密**：上传后须在开标时间前完成解密准备；解密失败按招标文件规定处理（如已解密投标文件少于三家，招标失败）。
- **签章位置**：电子签章位置须避开正文关键信息，且不得遮挡评审要点。
- **回执留痕**：上传回执、解密记录、开标记录全部留存，作为响应与争议证据。

**检查点**：电子标须额外核对——CA 证书有效期、加密与不加密标书内容一致性、电子章齐全、上传与解密时间留足。

## 四、联合体投标专章

**协议要素**（共同投标协议应载明）：

1. 联合体各方名称与法定代表人
2. 牵头方（主办方）及各方分工
3. 各方承担的工作内容与责任划分
4. 出资比例或费用分担
5. 对外责任承担方式（连带责任）
6. 联合体内部争议解决方式
7. 授权牵头方代表联合体办理投标事宜的授权条款

**资质与业绩认定规则**：

- 联合体各方均须具备承担招标项目的相应能力。
- 同一专业分工的，按资质等级较低的单位确定联合体资质等级。
- 业绩认定按招标文件规定：部分项目认联合体各方业绩之和，部分仅认牵头方或按分工对应专业认定，须逐条核对。
- 联合体各方就中标项目向招标人承担连带责任。

**投标文件归属**：由牵头方负责编制与签署，封面加盖牵头方章（或按招标文件要求各方盖章）；投标保证金一般由牵头方提交。

**检查点**：联合体须额外核对——共同投标协议已签、牵头方授权明确、各方资质证书齐备且等级符合、业绩认定口径与招标文件一致、盖章主体符合要求。

## 五、澄清与答疑

**招标人的澄清与修改**：

- 招标人可对已发出的招标文件作必要的澄清或修改。
- 澄清或修改影响投标文件编制的，应在投标截止时间至少 15 日前以书面形式通知所有获取招标文件的潜在投标人；不足 15 日的，应顺延投标截止时间。
- 澄清、修改文件为招标文件的组成部分，与招标文件不一致时以后发出的为准。

**投标人的提问（答疑）**：

- 提问须在招标文件规定的时限内以规定形式提出（常见为投标截止前 15 日或 10 日）。
- 招标人的答疑纪要发给全部潜在投标人，具有约束力；答疑纪要不改变招标文件的实质性内容。
- 口头答复不具约束力，须索取书面答疑。

**检查点**：澄清与答疑文件全部收集归档；标书定稿前逐份比对"招标文件 + 澄清 + 修改 + 答疑"，以最后发出的书面文件为准；顺延后的时间节点重排编标计划。

## 六、资格预审与资格后审

| 方式 | 流程 | 编标影响 |
|---|---|---|
| 资格预审 | 先递交资格预审申请文件，通过后才参与投标 | 资格材料在预审阶段一次备齐；通过后投标阶段一般不重复提交 |
| 资格后审 | 投标时一并提交资格材料，开标后由评标委员会审查 | 资格材料须在投标文件中一次性备齐且有效，缺一即被否决 |
| 不做资格审查（资格条件前置） | 招标公告或文件列明资格条件，投标时响应 | 按招标文件要求提供声明或证明 |

**资格预审要点**：资格预审文件发售期与申请文件提交时间须满足法定最短时限；预审通过名单公布后，未通过者不得投标。

**检查点**：先判资格预审还是资格后审；资格后审项目把资格材料当作废标红线逐条勾选。

## 七、投标人质疑与投诉路径

- 质疑：供应商认为采购文件、采购过程或中标结果使自己权益受损，可在知道或应知权益受损之日起 7 个工作日内，以书面形式向采购人或采购代理机构提出质疑。
- 答复：采购人或采购代理机构应在收到质疑后 7 个工作日内作出答复。
- 投诉：质疑答复期满后仍不服，或采购人未在期限内答复的，可在答复期满后 15 个工作日内向同级财政部门投诉。

**使用口径**：质疑与投诉属争议救济程序，须以完整证据链（招标文件、澄清答疑、投标文件、评审记录、书面往来）为支撑，先内部评估得失再启动。

## 八、缺项模块检查点

🔴 编标前须逐项确认下列模块是否需要：

1. 是否电子投标——CA 证书、加密与不加密标书、电子章、上传与解密安排
2. 是否联合体——共同投标协议、牵头方授权、资质与业绩认定口径
3. 有无澄清与修改文件——时限是否顺延、节点是否重排
4. 资格预审还是资格后审——资格材料提交时点与份额
5. 适用《招标投标法》还是《政府采购法》——资格条件与引证条款
6. 质疑投诉时限是否已知悉并留痕
