# 样例：废标红线核查表（脱敏成品）

> 脱敏样例。项目名与单位名作虚构处理，条款措辞为常见表述归集。

## 一、红线条款命中片段（节选）

| 序 | 类别 | 原文片段（节选） |
|---|---|---|
| 1 | 报价类 | 招标控制价 0.85 元/m³，报价等于或超过此价格的投标为无效标，作废标处理 |
| 2 | 报价类 | 只允许提交一个有效报价 |
| 3 | 资格符合性类 | 投标人须提供公告发布日之后"信用中国"查询截图并加盖鲜章 |
| 4 | 形式密封签署类 | 未按要求密封和加写标记的，招标人不予受理 |
| 5 | 形式密封签署类 | 未派遣授权代理人参加开标会、未通过身份核验的，投标文件无效 |
| 6 | 技术评议类 | 原文复制招标文件技术要求相关部分作为投标文件内容的，视为虚假响应 |
| 7 | 串通弄虚作假类 | 同一单位或个人编制投标文件、项目成员或联系人为同一人的，认定为串通投标 |
| 8 | 招标人否决权类 | 投标文件含有故意的虚假陈述的，招标人有权否决 |

## 二、逐条核查清单

| 类别 | 核查项 | 是否满足 | 证据位置 |
|---|---|---|---|
| 报价类 | 报价不超最高限价 | ☑ | 报价表（未超限） |
| 报价类 | 只有一个有效报价 | ☑ | 投标函 |
| 报价类 | 不低于成本价并有说明 | ☑ | 报价合理性分析表 |
| 资格符合性类 | 全部资格要求逐条满足 | ☑ | 资格条件承诺书 |
| 资格符合性类 | 信用截图在公告发布日之后并盖鲜章 | ☐ | 【待补：截图日期须晚于 2026-09-18】 |
| 技术评议类 | 未整段照抄招标技术要求 | ☑ | 技术标全文已改写为响应式 |
| 形式密封签署类 | 密封与标记符合要求 | ☑ | 密封条骑缝章 |
| 形式密封签署类 | 授权委托书齐备且签字人一致 | ☑ | 授权书 + 法定代表人身份证明 |
| 形式密封签署类 | 大写金额无歧义 | ☑ | 报价表大小写一致 |
| 串通弄虚作假类 | 非同一单位或个人编制 | ☑ | 编制单位声明 |
| 保证金没收类 | 已按规定提交保证金 | ☑ | 保函原件 |
| 重新招标类 | 投标人不少于三家 | — | 招标人掌握 |

## 三、结论

- 存在 1 项未闭合（信用截图日期），标书不得递交；
- 处置动作：在公告发布日之后重新截取"信用中国"与"中国政府采购网"查询截图并加盖鲜章，复核后放行。
