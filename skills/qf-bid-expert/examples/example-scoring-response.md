## 编制要点（对照范式）

1. **分档全列**：同一评审因素的各档各占一行，不漏档。
2. **只锚定最高档**：响应情况一律用最高档措辞作答，中间档与 0 分档不展开。
3. **硬指标佐证**：证书名、人数、配置项逐项落到具体证据。
4. **位置可追**：响应位置统一到"册-章-节"，评委照表可查。
