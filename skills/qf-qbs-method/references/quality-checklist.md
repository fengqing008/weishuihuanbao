# 质检清单（含四道门）

QBS 法交付前的逐项校验。四道门任一未过即停在该阶段修正。

## 门一 · 确认门（Step 0—2）

- 🔴 问题陈述卡已获用户确认，核心问题为单点。
- 🔴 荐书评分表含首版年，经典线（≥30 年）校验已执行。
- 🔴 入选书目收敛至 1—2 本，取舍理由已记录。
- 🔴 取书路径为合法来源，版权状态已判定。
- 🔴 无全文时降级方案已确认并标注。

## 门二 · 转换门（Step 3）

- 🔴 提取文本首行 SOURCE 头与目标书一致（核对，非假设）。
- 🔴 内核 Step 9.5 安全扫描返回零。
- 🔴 主 SKILL.md ≤4,000 tokens。
- 🔴 技能目录含 SKILL.md + chapters/ + glossary/patterns/cheatsheet。
- 🔴 章节引用路径全部可达（无死链）。

## 门三 · 解题门（Step 4）

- 🔴 结论先行，直接回应 Step 0 的问题。
- 🔴 每条结论标注来源框架与出处章节。
- 🔴 覆盖边界与遗留问题显式说明。
- 🔴 `qbs_pipeline.py check` 返回"闭环已闭合"。

## 门四 · 归档门（Step 5）

- 🔴 六类产出物齐备（问题卡/评分表/取书路径/技能/解题报告/台账）。
- 🔴 台账五阶段均标记完成。
- 🔴 技能包与报告已归档，路径记录在案。
- 🔴 技能经 `ima_skill_create` 注册（如需发布）。

## 通用检查项

| 检查项 | 标准 |
|:--|:--|
| 数据溯源 | 年份、书名、作者均可核；未确认标【待核：…】 |
| 结论可检验 | 成功标准在问题卡中已定义，结题时逐条对照 |
| 无软性话术 | 不出现"大概/可能/差不多"替代确定性结论 |
| 版权合规 | 全链路来源合法，无影子图书馆痕迹 |

## 自查命令

```bash
python3 scripts/qbs_pipeline.py status   # 看进度
python3 scripts/qbs_pipeline.py check    # 闭环闭合校验
python3 scripts/qbs_pipeline.py doctor   # 脚本自检
```
