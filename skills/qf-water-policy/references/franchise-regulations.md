# 特许经营政策要点

## 一、特许经营权的取得

市政公用事业特许经营一般通过招标、竞争性谈判等竞争方式授予。授予主体为县级以上人民政府或其授权部门。特许经营期限按项目类型确定，一般不超过 30 年。

## 二、特许经营协议核心条款

| 条款 | 要点 |
|---|---|
| 特许经营范围 | 明确区域与业务范围 |
| 期限 | 起止日期与延展条件 |
| 回报机制 | 使用者付费、政府付费或可行性缺口补助 |
| 调价机制 | 调价周期、调价公式、触发条件 |
| 政府监管 | 绩效考核、监督检查 |
| 提前终止 | 终止情形与补偿 |
| 期满移交 | 移交条件、状态、程序 |

## 三、存量项目规范

规范存量项目建设和运营，重点包括：依法依规履行合同、规范政府付费、防范新增隐性债务、完善绩效考核、加强成本监审。

## 四、政府监管与绩效

政府方通过绩效考核与成本监审实施监管。绩效评价结果与政府付费挂钩。成本监审核定合理成本，作为调价依据。

## 五、调价机制要点

调价申请条件（成本变化、政策调整）、调价周期、调价公式（成本加成或收益率法）、听证与审批程序。

## 六、与项目公司的关系

项目公司按特许经营协议承担建设与运营责任。股东各方按出资比例行使权利、承担义务。重大事项按协议与公司章程决策。

## 七、引用要点

引用特许经营政策时，区分国家级基本制度文件与省级实施文件，确认现行有效版本，条款引用规范。
