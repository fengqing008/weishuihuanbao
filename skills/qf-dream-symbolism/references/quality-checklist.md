# 交付质检清单

## 一、内容层

- [ ] 输出末尾附统一免责声明：「本内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。」
- [ ] 三层结构齐备：典籍出处 → 传统解读 → 心理象征。
- [ ] 反兆条目（梦哭主喜、见棺主官财、梦死反主更生）与常义并列，未单取一方。
- [ ] 典籍引文逐字保留，注明书名，未改写未杜撰。
- [ ] 意象库无对应条目时如实说明「未收录」，未临时编造释义。

## 二、边界层

- [ ] 未给出确定性吉凶断言（「必发财」「必离婚」等）。
- [ ] 未将梦象解读用于医疗、心理诊断、投资、婚恋、法律判断。
- [ ] 涉及持续失眠、噩梦、情绪困扰时，已提示寻求专业帮助。
- [ ] 卦象部分明示仅作文化参照，未以卦断事。

## 三、技术层

- [ ] 意象识别命中依据为触发词匹配，未硬凑。
- [ ] 报告正文每章不少于 300 中文字，无空架子章节。
- [ ] 文风无黑话与序列化路标（首先／其次／最后／综上所述等）。
- [ ] HTML 报告经 `scripts/htmlbase/html_check.py` 自检，FAIL=0。
- [ ] 金额数字类信息按千分位；无来源判断不写。

## 四、交付层

- [ ] Markdown 底稿与 HTML 成品同时产出并留存。
- [ ] 报告七章结构完整。
- [ ] 交付物按四件齐备归档（内容／数据溯源／入库／下载链接）。
