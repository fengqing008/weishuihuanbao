# 意象库字段说明与检索指引

## 一、数据结构

assets/dream_symbols.json：

```json
{
  "meta": {"source": "...", "notice": "..."},
  "count": 72,
  "symbols": [
    {
      "name": "蛇",
      "aliases": ["小蛇", "大蛇", "蟒蛇", "蛇咬", "蛇入怀"],
      "category": "动物",
      "classics": ["《周公解梦》：蛇入怀中，主生贵子；蛇随人行，主有阴私。", "..."],
      "meaning": "传统解读……",
      "psych": "心理象征……"
    }
  ]
}
```

字段含义：

| 字段 | 说明 |
|---|---|
| name | 意象规范名，报告小标题用此名 |
| aliases | 触发词列表，识别时与 name 合并、按长度倒序优先匹配 |
| category | 八大类之一 |
| classics | 典籍引文（数组，保留原文，注明书名） |
| meaning | 传统解读（民俗层） |
| psych | 心理象征（现代层） |

## 二、八大类目录

- **动物**：蛇、龙、虎、狗、猫、鱼、鸟、马、鼠
- **自然**：水、火、山、雨、雷、日、月、洪水、地震
- **人物**：亡人、亲人、婴儿、鬼、神仙、陌生人、老人、僧道、皇帝
- **身体**：牙齿、头发、血、眼、手、裸体、受伤、生病、流泪
- **物品**：钱、金玉、刀、镜、船、车、桥、房屋、棺材
- **行为**：飞翔、坠落、奔跑、考试、爬山、洗澡、哭泣、杀人、结婚
- **场所**：学校、医院、坟墓、庙宇、宫殿、市场、树林、洞穴、道路
- **其他**：生子、死亡、失物、得物、晴天、黑夜、穿衣、脱衣、大火

## 三、检索指引

用 scripts 目录下的 dream_parse.py 检索：

```bash
python3 scripts/dream_parse.py --list              # 按类列全部意象
python3 scripts/dream_parse.py --category 行为      # 查看某一类
python3 scripts/dream_parse.py --text "梦见掉牙"    # 从描述匹配
```

## 四、扩充规范

新增意象时应保持字段一致、分类归位、引文注明书名与原文；无可靠典籍依据者标注【待核】并说明来源为民间流传，不得杜撰典籍引文。
