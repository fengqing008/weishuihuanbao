# 传统解梦方法论

## 一、梦的分类传统

《周礼·春官》设「占梦」之官，掌「六梦」之法，是中国最早的梦分类学：

| 类别 | 原文 | 含义 |
|---|---|---|
| 正梦 | 无所感动，平安自梦 | 无外界刺激的自然之梦 |
| 噩梦 | 惊愕而梦 | 因惊惧而生之梦 |
| 思梦 | 觉时所思念之而梦 | 日思夜想所致 |
| 寤梦 | 觉时道之而梦 | 醒时言及、继而入梦 |
| 喜梦 | 喜悦而梦 | 因喜乐而生之梦 |
| 惧梦 | 恐惧而梦 | 因恐惧而生之梦 |

明代陈士元《占梦逸旨》进一步提出「直、象、因、想、人、感」等梦因分类，是古代梦学的集大成。

## 二、以象取意

《梦林玄解》：「梦者，象也。象者，像也。像其形，通其意，而吉凶可知矣。」传统解梦不逐字对译，而是把梦中物象抽象为「象」，再由象推意。步骤为：

1. **取象**：从梦中提取可辨识的物象（动物、自然、身体、行为、场所……）。
2. **辨态**：辨明物象的状态（蛇入怀／蛇咬人；水清／水浊）。
3. **通意**：由象推意，得出民俗认识中的解读。
4. **参境**：结合做梦者处境与典籍记述互参。

## 三、反兆传统

传统解梦中大量存在「反兆」，即梦与所主之事相反：

- 梦哭主喜（《敦煌梦书》「哭而复笑，主忧去喜来」）
- 见棺主官财（取其谐音）
- 梦死反主更生改运
- 梦病反主康健

**处理原则**：引用反兆条目时，必须与常义并列说明，不可单取一方，更不可据此下断言。

## 四、理性一脉

古人论梦并非全然神秘。东汉王充《论衡·纪妖》：「人梦不能自知，觉悟乃知」，主张梦是自然现象；《黄帝内经·灵枢》「淫邪发梦」从脏腑阴阳论梦的生理成因；《列子·周穆王》「昼想夜梦，神形所遇」强调梦与日间心念的关联。这一脉认识，正是本技能把意象解读同时呈现「民俗层」与「心理层」的依据。

## 五、方法边界

- 传统解梦属民俗与古人认识，**不是预言系统**，本技能如实呈现而不背书其灵验性。
- 同一物象在不同典籍、不同版本中可有相反之解，属正常现象，应并列呈现。
- 《周公解梦》系托名之作，版本繁杂；本技能采其民间流传条目的公有领域内容，并辅以敦煌梦书等出土文献。
