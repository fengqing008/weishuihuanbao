# 案例登记模板与来源指引

本文件为案例登记模板。案例库遵循**不编造**原则：仅登记有公开来源、可查证的真实材料；无可靠来源时保留占位并标注数据来源指引，不以虚构案例充数。

## 一、案例登记模板

```
### 案例编号：DR-YYYY-NNN
- 来源类型：典籍原文 / 公开民俗资料 / 用户授权记录（脱敏）
- 出处：
- 梦境描述（脱敏后）：
- 涉及意象：
- 传统解读（含反兆）：
- 心理象征：
- 备注：
```

## 二、可登记案例的类型

1. **典籍中的梦例**：如《左传》所载梦事、《史记》梦兆记载，属公有领域，可逐字登记并注明篇目。
2. **敦煌梦书条目**：出土文献所载占梦条目，可登记并注明卷次。
3. **公开民俗记录**：地方志、民俗学著述中经整理刊布的梦俗记载。
4. **方法示范案例**：为演示技能能力，基于意象库构造的**示范案例**，须在备注中明确标注「示范案例，非真实个案」。

## 三、来源指引

- 典籍原文：中国哲学书电子化计划、国学网等公有领域古籍库。
- 敦煌文献：国际敦煌项目（IDP）公开影像与释文。
- 民俗记录：各级地方志、已刊行的民俗学调查资料。
- 诗歌中的梦：《诗经》《全唐诗》等公有领域文本。

## 四、免责条款

案例部分同样适用统一免责声明：所录内容属中国传统文化研究范畴，供文化了解与民俗参考，不构成任何决策依据。用户提供的个案信息在登记前须脱敏，并取得授权。
