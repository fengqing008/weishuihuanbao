## 二、简介（发布用）

梦象解读——把一段梦境拆解为可辨识的传统意象，逐一给出典籍出处、民俗解读与心理象征三层内容；并可按时间或数字起卦，参看《周易》六十四卦，输出结构清晰的可视化 HTML 报告。收录 72 个传统意象、15 部梦文化典籍条目与六十四卦全表，整理自公有领域资料。定位为中国传统梦文化的研究与了解工具，忠实呈现包括反兆在内的传统解读原貌，不作预言与占断。

## 三、使用说明（6 条）

1. 直接描述梦境即可，如「我梦见一条大蛇入怀，随后飞上天空」。
2. 问单个物象，如「梦见掉牙是什么意思」，会得到该意象的三层解读。
3. 想看出处，可要求列出典籍原文，如「蛇入怀在古籍里怎么说」。
4. 想起卦，给出时间（如 2026-09-26 12:30）或两个数字，会得到本卦与动爻。
5. 想查卦，直接说卦名，如「泰卦是什么意思」。
6. 需要成文，可要求生成完整 HTML 报告。

## 四、使用示例

```
用户：梦见蛇入怀，又飞上天空，帮我解一下。
产出：识别「蛇」「飞翔」两个意象，逐条给出典籍出处、传统解读、心理象征，
     并在末尾附免责声明。

用户：帮我起一卦，2026-09-26 12:30。
产出：巽上乾下 → 小畜卦，第 3 爻动；给出卦辞「亨。密云不雨，自我西郊」与象义，
     明示仅作文化参照。
```

## 五、适用场景

- 了解中国传统的梦象与占梦文化
- 阅读《周公解梦》《敦煌梦书》类文本时查证条目
- 查询《周易》六十四卦的卦辞与象义
- 记录梦境、观察同类意象的重复出现
- 创作与传统文化相关的文稿时取用素材
